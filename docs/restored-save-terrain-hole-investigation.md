# 復元セーブの露頭初期化失敗

## 症状

復元したテンプレートワールドを開始すると、`MapVeinObjectDatastore` が次の例外を出してメインゲームの初期化に失敗することがある。

```text
[MapVeinObjectDatastore] 露頭を立てる地表がありません
```

この例外はクライアントのフォールバック不足ではなく、鉱脈AABB中心XZで実行時のGroundレイが地表を解決できないことを示すデータ検証エラーである。

## 原因

テンプレート地形は外周が矩形でも、Terrain holesによって内部にTerrainColliderで地表を解決できない座標を持つ。したがって、鉱脈AABBの中心が地形のXZ範囲内にあることだけでは配置可能と判定できない。

今回調べた復元データでは、`map.json` の鉱脈456件のうち373件がテンプレートTerrainCollider上で地表を解決できず、有効な地表を持つ鉱脈は83件だった。この全件走査の未解決件数は、実際の起動例外がGroundレイで報告した件数と一致した。

## 修復と検証

修復時は各鉱脈AABBの中心XZをテンプレートTerrainColliderへ照合し、地表を解決できる鉱脈だけを`mapVeins`へ残す。単純な座標範囲フィルターや高さ0へのフォールバックは使わず、通常Playで実行時のGroundレイも通ることを確認する。

修復後は通常のPlay Mode起動を2回行い、いずれも次を確認した。

- `MainGame`シーンへ到達する
- アクティブなテンプレート地形が1枚生成される
- 有効な露頭83件が生成される
- 初期化完了後のUnity Consoleに継続エラーがない

元の`map.json`は修復前に別名で退避し、`save.json`は変更しない。これにより設備・インベントリなどのプレイ状態を維持したまま、起動を妨げる不正な露頭配置だけを除去できる。
