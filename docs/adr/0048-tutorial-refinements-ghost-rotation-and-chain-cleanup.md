# 0048. チュートリアル改善: 相対ゴーストの回転・連結検査、掘削機設置のblockPlace化、チェーン整理

日付: 2026-08-30
状態: 採択

## Context

序盤圧縮チェーン（ADR 0038、`feature/early-game-compression` で実装中）を実プレイした結果、次の問題が観測された。

- 相対座標ゴースト（`relativeBlockPlacePreview`）は `RelativeBlockPlacePreviewTutorialManager.cs:92` で `anchor.OriginalPos + Offset` を無回転加算しており、風車を North 以外の向きで置くとゴースト位置に置いても歯車が繋がらない。地形に埋まるセルも考慮されない
- 掘削機の設置を促す段（粘土・青銅）が inInventoryItem 判定のため、設置してもピンが消えない
- 風車設置費（青銅シート3）・粉砕機設置費（合板1）の導入により、青銅シート/木釘/合板のクラフトチャレンジは到達時点で既に済んでいる

## Decision

### 1. 相対ゴーストはアンカーの向きで回転し、風車設置時に連結全体を検査する

- `relativeBlockPlacePreview` の offset / blockDirection はアンカーローカル座標（アンカー North 基準）とし、設置済みアンカーの BlockDirection で回転して目標セル・向きを算出する
- 風車設置チャレンジ中は、設置プレビューにシャフト・粉砕機のゴーストを連結表示し、連結内のどれかのセルが設置不可（地形・既存ブロック）なら風車自体を設置不可にする
- 机上計算の offset（シャフト(-1,0,2)East・粉砕機(-4,0,2)North）は回転実装後に実測検証して是正する
  出所: ユーザー裁定 2026-08-30「ゴーストの位置に置いても歯車が繋がらない」「機械のローテーションや地形の埋まりを考慮できていない」→ 選択「offsetを風車の向きで回転する」「風車設置時に連結全体の設置可否を検査」
  棄却案: チュートリアル中の風車向きNorth固定／埋まりゴーストの赤表示で置き直し誘導／目標セルの地形を削る

### 2. シャフトと粉砕機は1チャレンジ・ゴースト2個同時表示

- 「木のシャフトで風車と繋ぐ」「粉砕機を設置して動かす」を「シャフトと粉砕機を設置して動かす」1件に統合し、relativeBlockPlacePreview を2つ持たせる。完了判定は gearConnectedBlock（粉砕機）のまま
  出所: ユーザー裁定 2026-08-30 原文「シャフトの設置する場所が違う。粉砕機も違う。また、この2つを一気に出したい」→ 選択「1チャレンジに統合・ゴースト2個」
  棄却案: 2チャレンジのまま前段から両ゴースト表示

### 3. 掘削機設置の案内は blockPlace 系チャレンジに分割する

- 「粘土を入手する」「青銅の鉱石を5個採掘する」の前に「粘土鉱脈に風力掘削機を設置する」「青銅の鉱脈に風力掘削機を設置する」（blockPlaceOnVein＋veinPin）を新設し、アイテム段からピンを外す。veinRestrictedPlacement（設置制限）は掛けない
  出所: ユーザー裁定 2026-08-30 原文「採掘機設置のチュートリアルを出す時、必ずブロックプレイスのチャレンジとして作ってほしい。風力採掘機を設置したのに、チュートリアルピンが消えないのは違和感がある」→ 選択「設置チャレンジを前置して分割」「ピンだけで制限は掛けない」
  棄却案: 設置チャレンジへの置き換え（アイテム段の削除）／設置制限も掛ける

### 4. 青銅シート・木釘9本・合板の3チャレンジを削除する

- 粉砕機稼働→原始研究4へ直結。以降は研究完了チャレンジの合間にチュートリアルを挟む形
  出所: ユーザー裁定 2026-08-30 原文「青銅シートを作る というチャレンジはすでに要らなくなっているのに存在している」「木釘を9本作る → このチャレンジいらなくない？」→ 選択「3件とも削除」
  棄却案: 青銅シートだけ削除

### 5. 原始研究4直後にベルトコンベア教育2段を新設する

- 「歯車ベルトコンベアを設置する」（場所指定なし blockPlace）→「木のシャフトをベルトの横に設置する」（設置されたベルトをアンカーに relativeBlockPlacePreview）
- 後段の完了判定は「シャフトがそのベルトに歯車接続した時点」。回転供給は問わない（完了判定typeの追加が要る場合の名称・実装は agent前提でplanに委ねる）
  出所: ユーザー裁定 2026-08-30 原文「原子研究4がおわったあと、ベルトコンベアのチュートリアルをやる（接続することで回転を供給できることを教える。」「歯車ベルトの横にシャフトをつなげることで、それらがつながることをちゃんと示したい」「ベルトを適当なところにはいちさせ、その横にシャフトがつながることを示す」→ 復唱確認「前者」（隣接成立で完了・回転不問）
  棄却案: 粉砕機の空き歯車面へのベルト相対設置／ベルト複数本の搬送教育／ゴーストなし gearConnectedBlock のみ／回転到達まで要求

### 6. 文言・ヒント

- タイトル「木を伐採して原木を入手する」→「原木を3個入手する」（itemCount3は既存）
- 「①木の板を選択」→「①木の板をクリックして選択」
- クラフトを要求する全チャレンジ（木の棒・砕いた石材・レンガ・青銅鉱石の粉 等）に keyControl Tab「インベントリを開く」を足す
  出所: ユーザー裁定 2026-08-30（.decisions/2026-08-30-原木タイトルは個数入りにし板選択はクリックを明記する.md ほか）

- クライアント: RelativeBlockPlacePreviewTutorialManager の回転対応・複数ゴースト対応、風車設置時の連結設置可否検査（設置プレビュー拡張）
- サーバー/スキーマ: シャフト-ベルト隣接接続の完了判定（既存 gearConnectedBlock で表現できなければ challenges.yml 拡張）
- マスタ: challenges.json のチェーン再編（削除3・分割2・統合1・ベルト2段追加・文言）。moorestech_master 側PRとピン更新
