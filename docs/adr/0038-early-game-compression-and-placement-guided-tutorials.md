# 序盤は研究1〜3削除と要求数変更で圧縮し、鉱脈・歯車接続は設置システムで案内する

序盤（生きる基盤チャレンジ＋原始研究）は手クラフトが唯一の入手経路である期間が長く、
原始研究1〜8の研究コストだけで約300回、ブロック設置費込みで約190回（最適解）の手クラフトを要求していた。
最大の壁は原始研究8の板100（板を作る加工機を解放する直前に板を100枚手作りさせる）と、
粉砕機・加工機の設置に要る合板（1バッチ=板3+棒1+木釘3+合板1=8回）だった。

本ADRは2本立てで扱う。(1) マスタデータのみの圧縮、(2) 鉱脈と歯車接続を設置システム側で案内する機能追加。

## 決定1: 圧縮はレシピ構成を変えず、研究削除・要求数変更・チャレンジ削除で行う

- 石の斧は装備済みで開始する（初期装備機構を本repoに実装）。風力掘削機（`requiredPower: 0`・石/原木/青銅の鉱石/粘土を採掘）は `initialUnlocked: true`
- 上記により払い出しが空になる原始研究1〜3を削除し、旧原始研究4を根にする。表示名は原始研究1〜6へ振り直す（GUID不変）
- 研究コストは「その時点で機械化できているアイテムだけで払わせる」原則。手作業しか無い板・棒・青銅シートは0（行削除）または一桁、機械化済みのレンガ・青銅インゴット・砕石（新研究3以降）は据え置き
- 数値（新番号）: 研究1 板3棒3砕石2／研究2 レンガ30／研究3 青銅インゴット5レンガ30／研究4 青銅40レンガ94砕石84／研究5 板10青銅シート5砕石30／研究6以降は完全据え置き
- ブロック設置費: 風力掘削機 板2砕石1／石窯 砕石5レンガ5／粉砕機 合板1砕石5青銅シート1／燃料式風車 レンガ30棒5青銅シート3／加工機 合板2青銅シート4。合板は各機械に最低1枚残す（構成不変）
- 木のシャフトの設置ブロック解放を新研究4から新研究3へ移す（決定3の成立要件）
- 結果: 最適解で約40回、下手打ちで約80回。これが現制約内の床であり、それ以下は加工機の前倒し（B案）が要る

## 決定2: 石器ラインは削除し、開幕スキットとクラフト操作説明を付け替える

- attackSpeed は振り間隔（秒、`MiningProgressState.cs:89`）であり石の斧(1)は石器(2〜3)の上位互換。装備済み開始で石器・小石に役割は残らない
- 削除: 小石を3個拾う／石器を作る／石器を装備する／石の斧を作る／石の斧を装備する／旧原始研究1・2・3を完了する
- 残す: 石を採掘する（3）・砕いた石材を作る（3）。最初の掘削機に砕石が要る
- 開幕スキット2本は「木を伐採して原木を入手する」の `startedActions` へ、クラフトUI説明（itemViewHighLight, keyControl(Tab)）は「木の板を3枚作る」へ移す

出所: ユーザー裁定 2026-08-26 原文「そもそも、ガッツリ石器系のフェーズを消したい」／2026-08-27 一括提示の承認（上記）

## 決定3: 鉱脈と歯車接続は設置システム側で案内し、完了判定を2種新設する

- **木の鉱脈チュートリアル**: 最初の掘削機設置の直後に「木の鉱脈に風力掘削機を設置する」を置く。進行中は設置プレビューで原木鉱脈だけをハイライトし、掘削機の設置先をその鉱脈上に限定する（新チュートリアルtype `veinRestrictedPlacement`：veinGuid＋blockGuid）。完了判定は新設 `blockPlaceOnVein`。鉱脈名の常設ラベルは保留
- **鉱脈限定は「種別」単位という制約**: `veinGuid` は鉱脈の種類を指す識別子で、マップ上の1本を指さない（生成ワールド実測: mapVeins 1601件 / distinct veinGuid 9件、最大618インスタンス）。`MapVeinInfoJson` に `instanceId` は無いため、原木鉱脈を指すと同種618本が全て光り、そのどれに置いても制限を通過しチャレンジも達成する。instanceId の導入は見送り、種別基準であることを名前とコメントで表明する（[[2026-08-28-鉱脈の同一性は種別で持ち単一インスタンス限定はしない.md]]）
- **歯車接続の常設明示**: 歯車系ブロックの設置プレビューで、接続できる面と接続相手を強調表示する（チュートリアル限定ではない常設機能）
- **相対座標チュートリアル**: 新type `relativeBlockPlacePreview`（基準blockGuid＋オフセット＋向き）。既存 `blockPlacePreview` は絶対座標で生成マップに合わない
- **接続チュートリアル3段**（新研究3直後）: 燃料式風車を設置（blockPlace）→ 木のシャフトで繋ぐ（relativeBlockPlacePreview）→ 粉砕機を設置して動かす（新設 `gearConnectedBlock` + relativeBlockPlacePreview）

- ユーザー裁定 2026-08-28 原文「Xで歯車の接続がどれ同士でつながるのかを明示し、さらに相対座標チュートリアルもついかする どの座標同士がつながるかぱっと見わからないからそれを明示したい」
- ユーザー裁定 2026-08-28 原文「開放は採掘機じゃなかった、クラッシャーだった、それと、風車と破砕機のシャフトがつながるようにブロックを設置しない機械が動かないから、そのチュートリアルが必要」
