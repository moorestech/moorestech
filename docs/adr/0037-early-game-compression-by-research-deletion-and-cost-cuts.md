# 序盤の圧縮は研究ノードの削除と要求アイテム数の変更だけで行う

序盤（原始研究1〜8）の手クラフト回数が約305回に達し、そのうち板207回・棒25回は原始的な加工機（原始研究8）まで、
砕いた石材25回は原始的な粉砕機（原始研究6）まで、手クラフト以外の入手手段が存在しない。
とくに原始研究8は板100を要求しており、「板を自動生産する機械を解放する直前に板を100枚手作りさせる」構造になっている。

これを、レシピのアイテム構成には一切触れず、次の3つだけで圧縮する。
(1) 石の斧を装備済みで開始し風力掘削機を初期解放することで払い出しが空になる原始研究1〜3を削除する。
(2) 各研究ノードの要求アイテム数を、その時点で機械化できていないアイテムに限って大きく削る。
(3) 風力掘削機の設置費を下げる。

風力掘削機は `requiredPower: 0` で石・原木・青銅の鉱石・粘土の4種すべてを掘れるため、
初期解放するだけで序盤の採掘が全自動になり、手掘りの往復がゲーム開始直後に消える。

出所:
- スコープを「レシピ構成は不変・研究/チャレンジの削除と付け替え・要求アイテム数の変更だけ」に限定: ユーザー裁定 2026-08-27 原文「とりあえず、既存のチャートやレシピのアイテム構成は変えず、チャンレジや研究の削除と微調整（削除分の付け替え等どうしても必要な調整）、要求アイテム数の変更だけをしたい。」
- 石の斧を装備済みで開始・風力掘削機を初期解放: ユーザー裁定 2026-08-27 原文「石の斧を装備済み。風力掘削機は初期解放←ここは賛成。」
- 板・棒・砕石を自動生産する機械の早期化を棄却: ユーザー裁定 2026-08-27 原文「板・棒・砕石を自動生産する機械←ここは絶対に反対今後数十時間分のバランス調整やり直しになる。ちゃんとどの機会でどのレシピを作るか考えてほしい」
- 手クラフト回数の圧倒的削減と即自動化を目的とすること: ユーザー裁定 2026-08-26 原文「とりあえずクラフトしないといけない回数を圧倒的減らす。ゲーム始めてすぐ自動が入れるようにする。石の斧も作らずデフォルトでセットするようにする。」
- 一括クラフト（1回で5個）を棄却: ユーザー裁定 2026-08-26 原文「5個のアイテムを一気に加工できると自動加圧が全く働かなくなる」
- 手クラフトの存在自体ではなく解消手段の不在が問題であること: ユーザー裁定 2026-08-26 原文「それ自体は問題じゃないが、長い間それを解消する手段がないのが問題。特に石窯とかもそう、他の機械や、研究開放に必要なアイテムがクラフトでしか入手できないのが問題」
- 期限の撤廃と展示用ブランチ限定の撤回: ユーザー裁定 2026-08-26 原文「とりあえず、緊急対応はやめてちゃんとやる。期日は設けない」
- 原始研究1〜3の削除と下表の要求アイテム数の採択: ユーザー裁定 2026-08-27 原文「一旦それで置き換えて」→ 提示した削除案と数値表を採択
- 削減ルール（機械化前のアイテムだけ削り機械化済みは据え置く）: agent前提（「自動加圧が全く働かなくなる」という棄却理由を満たす唯一の削り方であるため）
- 小石・石器チャレンジの削除と開幕スキットの付け替え: agent前提（`equipmentSlotCount` が1で石の斧が石器の上位互換であるため、装備済み開始と石器装備チャレンジが両立しない）
- 原始研究6と7を統合しないこと・レンガと研究7以降の砕石を据え置くこと: agent前提（今回のスコープを削除と数値に限る裁定に従う）

## 決定内容

### 削除する研究ノード

| ノード | 現在の払い出し | 削除できる理由 |
| --- | --- | --- |
| 原始研究1 | 石・砕いた石材のレシピ表示 | 風力掘削機の設置に砕いた石材が要るため初期解放が必須になり、払い出しが空になる |
| 原始研究2 | 石の斧のレシピ表示 | 石の斧を装備済みで開始するため空になる |
| 原始研究3 | 風力掘削機 | 初期解放するため空になる |

付け替えは `石` / `砕いた石材` / `石の斧` の `initialUnlocked` を true にすることと、
風力掘削機ブロックの `initialUnlocked` を true にすることだけ。原始研究4が新しい起点（`prevResearchNodeGuids: []`）になる。

### 要求アイテム数

アイテム種別は変更しない。太字が変更後の値。

| ノード | 現在 | 変更後 |
| --- | --- | --- |
| 原始研究4（石窯） | 板20 / 棒20 / 砕石10 | 板**8** / 棒**6** / 砕石**4** |
| 原始研究5（青銅） | 板10 / レンガ45 | 板**5** / レンガ45 |
| 原始研究6（粉砕機・燃料式風車） | 青銅インゴット30 / レンガ50 / 棒20 | 青銅インゴット**10** / レンガ50 / 棒**6** |
| 原始研究7（歯車・ベルト） | 青銅40 / レンガ94 / 砕石84 / 棒20 / 板32 | 青銅40 / レンガ94 / 砕石84 / 棒**6** / 板**10** |
| 原始研究8（加工機） | 板100 / 青銅シート35 / 砕石30 | 板**15** / 青銅シート**10** / 砕石30 |
| 風力掘削機（設置費） | 板10 / 砕石5 | 板**4** / 砕石**2** |

据え置いた値には理由がある。レンガは原始研究4で解放される石窯が作るため、
研究7以降の砕いた石材は原始研究6で解放される粉砕機が作るため、
どちらも「機械を建てて回させるための要求」として機能する。ここを下げると自動化の動機が消える。

### 削減の効果

原始研究4〜8を完了するまでの手クラフトが約305回から約69回になる。
採掘は風力掘削機が石・原木・青銅の鉱石・粘土をすべて自動で供給するため、手掘りはほぼ消える。

## Considered Options

- 板・棒・砕石を自動生産する機械（原始的な加工機・粉砕機）を最序盤へ前倒しし、設置費を木材だけで閉じた第0ティアを新設する — 手クラフトからの脱出路を最短で作れる案として提示したが、「今後数十時間分のバランス調整やり直しになる」ため棄却（ユーザー裁定 2026-08-27）
- 手クラフトの出力を1回5個にして待ち時間を消す — 「自動加圧が全く働かなくなる」ため棄却（ユーザー裁定 2026-08-26）
- 原始研究1〜6のコストを一律係数で割る — レンガや砕いた石材など機械化済みのアイテムまで下がり、機械を建てる動機が消えるため棄却し、機械化前のアイテムに限る削減へ差し替えた
- 展示用ブランチ限定でmasterへマージしない / 明日の展示に間に合わせる — どちらも撤回済み（ユーザー裁定 2026-08-26「緊急対応はやめてちゃんとやる。期日は設けない」）

## Consequences

- **初期装備を与える機構がマスタデータに存在しない。** `PlayerInventoryDataStore.GetInventoryData` は空のインベントリを生成するだけで、初期アイテム・初期装備のスキーマフィールドも無い。「石の斧を装備済みで開始」だけはJSON編集で完結せず、スキーマ追加かサーバー側の初期化コードが要る。本ADRの変更のうちコードに触れるのはここだけ
- 小石と石器は、レシピとアイテムとしては残るが到達動機が無くなる（`equipmentSlotCount` が1で石の斧が上位互換のため、持ち替えは純粋な劣化）。石器を装備させるチャレンジは装備済み開始と両立しないので削除する
- 開幕スキット2本とチャレンジHUDの説明は「小石を3個拾う」が抱えているため、チャレンジ削除に伴って付け替えが必要になる
- チャレンジは32件から、研究1〜3完了の3件・石器系3件・石の斧系2件が消えて24件程度になる。`prevChallengeGuids` の張り替えが要る
- 原始研究9以降のコスト（板100・棒200等）は据え置く。原始研究8で加工機が解放済みのため機械が供給する側に回り、既存のバランスが崩れない
- 原始研究6と7は統合しない。粉砕機は歯車動力機であり、原始研究6の時点では燃料式風車に直付けする形でしか回せず、ベルトで結んだラインになるのは原始研究7からという段差が残る
