# ブループリントのコピー・貼り付けは通常設置のセル解決・高さ・ドラッグ列を共用する

ブループリント（BP）のコピー範囲指定は「左ボタン長押しのXZドラッグ＋ホイールで上面高さ」から「1クリックで始点、もう1クリックで終点」へ変える。始点・終点・貼り付けアンカーのセルは通常の1x1ブロック設置と同じ解決（ヒット面の外側セル＋Q/Eの高さオフセット）で決め、コピー範囲は2セルを対角とする直方体とする。貼り付けはQ/Eで高さを変えられ、左ドラッグでBPを一列に並べて設置できる。保存済みBPのサムネイルはブロック群をアイコン撮影器で写した画像をクライアントで生成して配信する。

## 実測した原因（2026-10-08・worktree blueprint-copy-paste-ux `PlaytestResults/20261008_180049/blueprint-copy-box-probe/`）

- 高さの膨張: 原因: 実測（証拠: probeB で終点をチェスト天面にすると box 高さ6、probeC で石窯天面にすると7、地面→地面は5。`BlueprintCopySystem.CalcBox` が終点Yに既定 `_topYOffset=4` を足す）
- 1マスずれ: 原因: 実測（証拠: probeD 東面ヒット (3.07,32.55,2.25) → 始点セル (3,33,2)、probeD2 南面ヒット → (2,33,1)。`PlaceSystemUtil.SnapHitPointToCell` が XZ Floor・Y RoundToInt で面の外側かつ1段上へ落ちる）。probeD は範囲がチェストの隣になり BP が EmptyArea で未登録・無通知だった
- 貼り付けの Q/E 無効: 原因: 実測（証拠: probeE で E 押下後も `PlacementHeightOffset.Value` 0→0、ゴースト位置 (6,32,6) 不変。`BlueprintPasteSystem` は高さの正を読まず `UsesPlacementHeight=false`）
- サムネイル無し: 原因: 実測（証拠: probeG スクショでBP枠は名前テキストのみ。`BuildMenuEntryDtoFactory.ResolveIconUrl` がBP系に null を返す）
- 連続設置: 実測ではクリック反復で2個目も貼れる（probeF）。要望は列設置と確定

## 決定と出所

- 始点・終点・貼り付けアンカーのセルは、通常の1x1設置と同じ解決（ヒット面の外側セル。天面なら上、側面なら隣）＋ `PlacementHeightOffset` を使う。
  出所: ユーザー裁定 2026-10-08 原文「コピー範囲を指定する時、1ブロックを設置するのとおなじ感覚で設置したい。ホバーしてる先を選択。Q,Eで高さ調整、みたいな」→ 選択「面の外側のセル（推奨）」 [[2026-10-08-BPコピーの始点終点と貼り付けアンカーは1x1設置と同じ面の外側セルを選ぶ]]
- コピー範囲は始点セルと終点セル（各々Q/E込み）を対角とする直方体。ホイールの高さ調整と既定上面(+4)は廃止し、コピー中のホイール占有も無くなる。交差判定は現行どおり「占有セルが1つでも交差すれば対象」。
  出所: ユーザー裁定 2026-10-08 原文「Q,Eで高さ調整、みたいな」→ 選択「始点・終点それぞれのセル（Q/E込み）で直方体を決める（推奨）」 [[2026-10-08-BPコピー範囲は始点終点2セルのAABBで決めホイール高さと既定上面を廃止する]]
- 操作は1クリックで始点、もう1クリックで終点。名前入力モーダルをESC等でキャンセルしたら始点を保ったまま終点選択へ戻る。
  出所: ユーザー裁定 2026-10-08 原文「クリック長押しではなく、1クリックで始点を選択、もう1クリック終点を選択、みたいな感じにしたい。また、モーダルが出た時にESCキャンセルしたら終点を選択するようにしたい」
- プレビュー: 始点は赤い半透明の1x1キューブ、終点は緑の半透明1x1キューブ、範囲は半透明の直方体。
  出所: ユーザー裁定 2026-10-08 原文「始点、終点選択時、プレビューで始点は赤い1x1ブロックっぽい表示（すけている）終点は緑の1x1ブロックの表示。プレビュー範囲も半透明で表示する」
- 貼り付けは Q/E の高さオフセット（`PlacementHeightOffset`）をアンカーへ加える（`UsesPlacementHeight=true`）。
  出所: ユーザー裁定 2026-10-08 原文「不具合、考古学：ブループリントを設置する時、Q,Eで高さ調整できない」
- 連続設置は通常ブロックと同じ左ドラッグの列設置。間隔はBP内ブロック全体の外形（回転後AABB寸法）を単位に詰め、`CalculateRun` を流用、セーブ形式は変えない。
  出所: ユーザー裁定 2026-10-08 原文「ブループリントも連続設置したい」→ 選択「通常ブロックと同じドラッグ列設置（推奨）」 [[2026-10-08-BP連続設置は通常ブロックと同じドラッグ列でブロック外形を間隔に並べる]]
- サムネイルはBP内ブロックのプレファブをオフセット通りに並べ `BlockIconImagePhotographer` で撮影した画像。クライアントで生成・メモリキャッシュし、既存の `/api/*-icons/{key}.png` と同じ経路でビルドメニューとホットバーへ配信。セーブ形式は変えない。
  生成のタイミングはライブラリ更新（作成・削除・ログイン時同期）を起点に未撮影分を先回りで撮り、撮影済みのBPだけにURLを載せる（Web側のアイコン配信は欠落を負キャッシュするため、要求時生成では初回404が固定化する）。
  出所: agent前提（ユーザーによる詳細設計の委任。plan 2026-10-08 Phase 2.6 で ADR を plan に合わせた）
  出所: ユーザー裁定 2026-10-08 原文「不具合？：ブループリントのサムネイルが表示されない」→ 選択「BPのブロック群を斜め上から撮影した画像（推奨）」 [[2026-10-08-BPサムネイルはブロック群をアイコン撮影器で斜め上から写した画像にする]]
- 終点選択中はカーソルツールチップへ範囲内ブロック数を常時出し、0個なら終点確定を拒んで理由を赤表示する。サーバーの EmptyArea 拒否は最終防衛として残し、拒否時はログと通知の両方へ出す。
  出所: ユーザー裁定 2026-10-08 選択「終点選択中に範囲内ブロック数をカーソルツールチップに出し、0個なら終点確定を拒む（推奨）」 [[2026-10-08-BPコピーは終点選択中に範囲内ブロック数を出し0個なら確定を拒む]]
- 始点未確定のホバー中も赤い1x1キューブをカーソルセルに追従表示する（始点候補の表示）。右短押し（`TryCancelInProgressOperation`）は始点を破棄して未選択へ戻す。名前確定後は選択を畳みコピーツール選択のまま。
  出所: agent前提（既存 `TryCancelInProgressOperation` の二段階解除と、確定後にツール選択を維持する現行挙動を踏襲）
- 範囲の直方体表示は既存の設置プレビュー材質（複製）に `MaterialConst.PlaceableColor` を使う。始点マーカーは `MaterialConst.NotPlaceableColor`（赤）、終点マーカーは原文「緑」に合わせた新規の緑定数（既存の設置可色は青寄りで緑ではない）。
  出所: agent前提（ユーザーによる詳細設計の委任。原文「始点は赤い…終点は緑の1x1ブロック」）
- 範囲内ブロック数の判定はクライアントの `BlockGameObjectDataStore` で行い、サーバー `BlueprintCreateService` の交差判定（占有セルが1つでも範囲内）と同じ規則にする。
  出所: agent前提（サーバー判定と同規則でなければ表示と結果が食い違う）

- 境界の大型ブロックは一部でも範囲に入れば丸ごとコピー（現行維持）。範囲内ブロック数にも数える。
  出所: ユーザー裁定 2026-10-08 選択「一部でも入れば丸ごとコピー（現行維持・推奨）」 [[2026-10-08-BP境界の大型ブロックは一部でも範囲に入れば丸ごとコピーする]]
- 以降の詳細仕様はユーザーの委任に基づき agent が決める。
  出所: ユーザー裁定 2026-10-08 原文「とりあえず、自分が最もUXのいいBPシステムを考えて実装方針を定めてほしい」 [[2026-10-08-BP改善の詳細設計はagentへ委任しUX最良案で方針を定める]]
- 貼り付け・ドラッグ列で一部のブロックが既存ブロックと重なる／資材不足のときは、置けるブロックだけ設置し置けないものは赤ゴーストで示す（現行の部分設置を維持。列設置でも要素単位）。
  出所: agent前提（ユーザーによる詳細設計の委任。通常ブロックの列設置と同じ「置ける分だけ」の規則に揃える）
- 貼り付けアンカーは、コピー範囲の中心ではなく「コピーされたブロック群の外形（AABB）のXZ中心セル・最下段」にする。サーバー `BlueprintCreateService` のアンカー算出を範囲中心からブロック外形中心へ変える。BPのオフセットは相対値のままなのでセーブ形式は変わらない（旧BPは旧アンカー基準のオフセットのまま貼れる）。
  出所: agent前提（ユーザーによる詳細設計の委任。選択時の余白でゴーストがカーソルからずれないこと、ドラッグ列の間隔がブロック外形基準であることと整合させるため）
- 始点未確定のホバー中はツールチップに何も出さず、始点確定後に「範囲内 N ブロック」を出す。終点確定で名前入力モーダルを開き、確定でCreate送信、送信中は次の始点を受け付けない。
  出所: agent前提（ユーザーによる詳細設計の委任）

## Consequences

- `.decisions/2026-08-05-建築ツールのホイール占有は接続ツールとBPコピー両方で装備切替を抑止する` のBPコピー分は、ホイール高さ調整の廃止により前提ごと消える（接続ツール分は残る）。
- 通常設置の `CalcPlacePoint`（1x1サイズ指定）と `PlacementHeightOffset` をBP側から共用するため、`SnapHitPointToCell` は役目を失う。
- ドラッグ列の間隔はBPに保存されない選択範囲寸法ではなくブロック外形で決まるため、余白込みで並べたい場合はセーブ形式変更が別途必要になる。
