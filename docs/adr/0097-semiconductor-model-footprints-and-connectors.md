# 0097: 半導体機械の模型とマスタの占有・接続位置を整合させる

## Status
Accepted

## Context
専用4機はマスタ3×2×3に対し本体境界が(0.5,0.5,0.5)〜(3.5,3.5,3.5)。ベルト模型3本に対し実接続は前後2口。左側液体口は論理的に存在するが表示部品がない。空気清浄機も1×2×1から本体が突出する。証拠は調査報告と計測JSONにある。
原因: 実測（証拠: docs/evidence/2026-11-07-semiconductor-models/measurements.json、各Prefab本体と子Transform。供給動作は修正後に検証する）。

## Decision
調査で示した占有・接続位置へ模型を合わせる案で実装し、必要なマスタの修正を合わせて行う。
出所: ユーザー裁定 2026-11-07「じゃあそれでモデルとマスタを変更してほしい」。元の依頼は「ウエハ切断機とかそこらへんのモデル」「半導体関連のブロックの修正計画」。

専用4機の占有3×2×3、前後中央のベルト接続、左側中央液体入力を基準にする。模型全体を一括scaleせず本体・装飾・文字を局所調整する。空気清浄機は1×2×1と水平4方向入力を維持する。
出所: agent前提（ユーザーが承認した調査提案の具体化。現行マスタの配置・接続を保存する）。

化学プラントは本体・ポート別に追加計測し、表示と論理を合わせる。不要なマスタ変更やレシピ量変更で見た目の欠落を吸収しない。
出所: agent前提（マスタとPrefabの実物から修正対象を確定する）。

## Considered Options
提示した修正案を採用。追加の棄却案なし。

## Consequences
Unity Editorを経由してPrefabを保存する。4方向の接続と実供給・加工・搬出をunityプレイ録画テストで検証する。別repo変更には別PRとpush済みコミットへのピン更新を含める。

## QAで確認した撮影回帰への追従
新しい空気清浄機形状でアイコン上端の切断が生じた。独立した画像観測とカメラ投影計算で確認。共通撮影の中心を外接AABB中心とし、外接球を視野へ収める距離にする。撮影専用レイヤーの既存契約にもポートを揃える。
出所: agent前提（承認されたモデル修正により導入された表示回帰の是正。新規APIや型は作らない）。原因: 実測（画像最上段に非白画素151個、頭部切断を目視確認、変更前後計測の頂点投影y93.1→-47.8。記録は.superpowers/sdd/icon-crop-evaluation.md）。
