# 入力3〜4種のレシピは半導体製造で解放する電気精密組立機で作る

電気汎用工作装置は入力コネクタが2口しかないのに、入力3〜4種のレシピが12件（クリーンルームフィルター、品質/速度/省エネ/生産性モジュールLv1、GPULv1、GPU衛星Lv1〜5、反物質爆弾）載っていた。2口では素材を混ぜたベルトなしに自動化できず、3Dモデルの見た目とも合わない。そこで入力4口の電気機械「電気精密組立機」を足し、12件をそちらへ移す。12件はすべて半導体製造以降で解放されるので、機械を半導体製造で解放すれば進行は壊れない。

## 決定

- **入力4口の電気機械を新設し、半導体製造で解放する。**
  出所: ユーザー裁定 2026-11-04 原文「入力3〜4で加工できる機械を半導体製造といっしょに解放したい」
- **作れるのは入力3〜4種の12件だけ。12件は電気汎用工作装置から外して新機械へ移す。** 2種以下のレシピは工作装置だけに残す。
  出所: ユーザー裁定 2026-11-04 選択「12件を移すだけ（推奨）」
- **見た目は仮の箱で先に出し、モデルが出来たら prefab パスとコネクタ位置を差し替える。**
  出所: ユーザー裁定 2026-11-04 選択「仮の箱で先に出す（推奨）」
- **名前は「電気精密組立機」。**
  出所: ユーザー裁定 2026-11-04 選択「電気精密組立機（推奨）」
- **大きさは 横7×高さ4×奥行き5。入力4口は背面に x=0,2,4,6 と1マスずつ空けて並べ、出力1口は正面中央（x=3）。**
  出所: ユーザー裁定 2026-11-04 選択「4x4x4・背面に4口並べる」＋メモ原文「4 + 一個ずつあきがあるので横7ブロック」→ 解釈確認へのメモ原文「奥行き5でそれで」
- **消費電力40、建設コストは鋼鉄フレーム10＋発展電子回路5＋制御モータ4。**
  出所: ユーザー裁定 2026-11-04 選択「電力40・鋼鉄フレーム系（推奨）」
- 仮の箱は 1×1×1 の TmpBlock ではなく、7×4×5 に合う箱を組んだ仮プレハブを Unity Editor 経由で新しく作り Addressables に登録する。
  出所: agent前提（TmpBlock は1マスの立方体で大きさが合わない。データセンターの仮プレハブ 45af3db96d と同じ作り方）
- **移す12件の加工時間は変えない。**
  出所: ユーザー裁定 2026-11-04 選択「そのまま（推奨）」
- **品質モジュールは使えない（工作装置と同じ）。**
  出所: ユーザー裁定 2026-11-04 選択「使えない（推奨）」
- 移す12件のレシピGUID・入出力は変えず、blockGuid だけ付け替える。研究の解放リストもそのまま効く。
  出所: agent前提（GUIDを変えると研究済みワールドの解放状態が新レシピに引き継がれないため）
- 機械の残りの値は電気汎用工作装置に揃える: ElectricMachine、入力スロット4、出力スロット2、モジュールスロット4、待機電力率0.2、配線パラメータ同じ、ビルドメニューは 生産・電気機械。
  出所: agent前提（移すレシピの元の機械と同じ条件にし、入力口以外の差を作らない）
- セーブ済みの電気汎用工作装置で12件のどれかを選んでいた機械は、変換しない。レシピGUIDはマスタに残るので選択はそのまま復元され、選び直すまで工作装置で作れてしまう。
  出所: ユーザー裁定 2026-11-04 選択「何もしない」（提示した対案「ロード時に機械とレシピの対応が合わなければ選択を外し警告ログ」を棄却）

## Considered Options

- 既存モデル（電気汎用工作装置など）を流用し入力口をデータ上だけ足す: 見た目の口とコネクタ位置がずれる。ユーザー棄却。
- モデルを先に作ってからデータを入れる: ユーザー棄却。
- 工作装置の上位互換にして2種以下の17件も複製する: レシピが2重管理になる。ユーザー棄却。
- 3×4×4・左右2口ずつ: ユーザー棄却。
- 名前「電気多入力組立機」「電気組立機」: ユーザー棄却。
- 電力・建設コストを工作装置と同じにする: ユーザー棄却。
- 加工時間を上位設備として短縮する／品質モジュールを使えるようにする: ユーザー棄却。
- 旧セーブの工作装置の選択をロード時に外す（C# 小変更）: ユーザー棄却。
