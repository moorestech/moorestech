# 電線ツールは「延長」操作に一本化し、明示配線のみを行う

電線ツールの全操作を「起点→終点への延長。成功したら終点が次の起点」という単一モデルに統一する。終点は既存の電気ブロック（接続）でも、その場で新設する電柱（設置＋接続）でもよく、起点なしの空間クリックは「終点だけの延長」＝電柱の孤立設置とみなす。プロトコルは `va:electricWireExtend` に統合し、リクエストで終点種別を区別、応答は共通で「成否＋終点InstanceId（=次の起点）」を返す。起点の更新は応答確認後のみ行う。`va:electricWireConnectionEdit` は切断（Disconnect）専用に縮小し、Connectモードは廃止する。

電線ツール経由の配線はプレイヤーが明示した1本のみとし、新設電柱の周辺自動配線は行わない（孤立設置・延長設置とも）。自動接続はビルドメニューからの通常設置専用の振る舞いとして住み分け、通常設置の「電線を賄えなければ設置拒否」ゲートは維持したうえで、拒否理由（電線不足・接続範囲外等）をtooltipで表示する。

電線プレビュー（延長プレビュー・自動接続プレビューの両系統）は、端点解決（`ElectricWireConnectionPoint` マーカー→無ければ上面中央）とカテナリー曲線描画を実描画と共通化する。あわせて、電線ツールの電柱種はキー/スクロールで解放済み種をサイクル選択、向きは通常設置と同じ回転キーをゴーストに効かせ、右クリック等での起点解除を追加する。

## Considered Options

- プレビューは端点のみ統一し直線のまま — 棄却。垂れ下がり分の見た目差が残る。
  出所: ユーザー裁定 2026-08-05（AskUserQuestionで「端点＋カテナリーも統一」を選択）
- 接続をSendOnlyのまま楽観的に即チェーン — 棄却。失敗時に起点だけ移動する不整合が出る。
  出所: ユーザー裁定 2026-08-05「ベース1でよくて、これってうまいこと両者を共通化できないかな」
- プロトコル2本のままクライアント側だけ共通化 — 棄却。「最初の1本を置けば以降は同じ」で両操作は本質的に同一。
  出所: ユーザー裁定 2026-08-05（「プロトコルごと統合」を選択）
- 孤立設置しても起点にしない — 棄却。連続配線の操作数が増える。
  出所: ユーザー裁定 2026-08-05（「置ける。新電柱が起点になる」を選択）
- 孤立設置・延長設置でも周辺自動配線する — 棄却。「どことも接続しない単品電柱」が作れず、コスト表示と実消費も食い違う。
  出所: ユーザー裁定 2026-08-05（「真に孤立」「明示の1本のみ」を選択）
- 通常設置をベストエフォート接続化 — 棄却。「置けたら必ず繋がっている」保証を維持し、無言拒否は理由tooltipで解消する。
  出所: ユーザー裁定 2026-08-05「なんで拒否されたかtooltipで表示するように」
- 電柱の向き・種類選択を別タスク送り — 棄却。agent推奨だったがユーザーが今回スコープに含めると裁定。
  出所: ユーザー裁定 2026-08-05（スコープ質問で①②③すべて選択）
- 電柱種はビルドメニューの最終選択を記憶 — 棄却。メニューを開かず切替できるサイクル方式を採用。
  出所: ユーザー裁定 2026-08-05（「キー/スクロールでサイクル」を選択）
- クライアント自動接続プレビューの解放フィルタ追加・回転キーのゴースト適用は既存実装との整合修正。
  出所: agent前提（サーバー `ConnectToolSelector.UnlockedByToolType` / `CommonBlockPlaceSystem` の回転入力との同型化）

## Consequences

- サーバー: `ElectricWireExtendService` から周辺自動配線（`ExecuteExtendWithOrigin` の追加課金分）を除去し、既存ブロック終点の接続実行を追加。`ElectricWireConnectionEditProtocol` はDisconnect専用化。既存テスト（extend/connectionEdit）の書き換えが必要。
- クライアント: `ElectricWireEditMode` に孤立設置経路を追加（`GearChainPolePlaceExtendMode.DecideIsolatedPlace` と同型）。送信・応答受け・起点更新は1系統に集約。
- プレビューのコスト表示と実消費が一致する（周辺自動配線の廃止による）。
- 通常設置UIに拒否理由の表示経路（failure reason → tooltip）が新設される。
