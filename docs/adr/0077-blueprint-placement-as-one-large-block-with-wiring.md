# ADR 0077: BPは外接箱を1個の大きなブロックとして置き、内部配線ごと貼り付ける

- Status: Accepted
- Date: 2026-10-09

## Context

ADR 0076（BPコピー・貼り付けの通常設置共用。PR #1484）で、貼り付けアンカーは「1x1設置と同じ面の外側セル＋Q/E」になり、作成時アンカーは「コピーされたブロック群の外形のXZ中心セル・最下段」へ変わり、左ドラッグの列設置が入った。それでも次が残る。

- 貼り付けは外接箱の中心を「1x1の面の外側セル」に合わせるだけなので、大きいBPを既存ブロックの側面へ向けると外接箱の半分が既存ブロックへめり込む。地面では地形を見ずヒットセルのYを底にする（ADR 0037/0047 はBP貼り付けを「別タスク」として地形追従から外していた）。
- 保存オフセットの基準は作成時期で混在する（#1484 以前のBPは選択箱中心基準）。
- BPは配線（電線・歯車チェーン）を保存せず、貼り付けた電気ブロックは周辺自動配線で元と違うつながり方になる。
- BPの設置対象は `CreateRequiredItems()` が空で、ビルドメニューに必要素材が出ない（ADR 0041 に明記）。
- 貼り付けプレビューは重なりしか見ず、素材不足でも青い。サーバーは送信順に払えるブロックだけ置く。ADR 0076 は agent前提で「資材不足は置ける分だけ」としていた。
- 大きいBPのプレビューがちらつく。原因: 推測（根拠: ゴーストがレイを遮ると地面/面以外のヒットでセル解決が失敗し全ゴーストを隠し、次フレームで再表示する筋。未再現）。

## Decision

1. **BPの外接箱（全ブロック占有セルを囲む最小直方体）を貼り付け基準にし、保存オフセットの基準も外接箱の最小角へ正規化する。** 既存セーブのBPはロード時マイグレーションで変換する。
   出所: ユーザー裁定 2026-10-09 原文「範囲外の空気ブロックは詰めて最低限のAABBにする」→ 選択「B A＋保存データも正規化」
   棄却案: A 貼り付け時に計算するだけ（保存形式不変）／C Aに加えて範囲選択表示も外接箱へ縮める

2. **地面に当てたときは外接箱をXZでカーソル中心に置き、底は外接箱底面フットプリント内の地形最高点を含むセル（ADR 0047 と同規則）。Q/Eの高さオフセットも効かせる。**
   出所: ユーザー裁定 2026-10-09 原文「設置時も中心にしたり」「普通のブロックと同じ体験でBPを設置するようにしたい」→ 選択「通常と同じ地形最高点」
   棄却案: カーソル直下の地面を底にする

3. **既存ブロックの側面に当てたときは外接箱を面の外側へ接し、面に平行な横方向はカーソル中心、縦は最下段をカーソルの段に揃えて上へ広げる。**
   出所: ユーザー裁定 2026-10-09 原文「ブロックの横の側面にカーソルがあるのであれば、そこを起点にひろがるみたいな」→ 選択「底を当てたセルに揃える」
   棄却案: 縦もカーソル中心（通常ブロックと完全同一）

4. **BPは両端ともBP内ブロックである電線・歯車チェーンの接続を保持し、貼り付け時に復元して素材を消費する。外へ伸びる接続は捨てる。**
   出所: ユーザー裁定 2026-10-09 原文「BPで電線等の配線情報もほじするようにしたい」→ 選択「電線＋歯車チェーン」
   棄却案: 電線だけ

5. **BP貼り付けで置く電気ブロックは周辺自動配線を行わず、保存配線だけを復元する。**
   出所: ユーザー裁定 2026-10-09 選択「自動配線しない」
   棄却案: 復元＋BP外へだけ自動配線／復元＋通常どおり全自動配線

6. **必要素材（重ならず置けるブロック分＋復元する配線分）が1つでも足りなければ、ゴースト全体を赤にし、クリックしても何も置かない。不足素材はカーソルtooltipに出す。**
   出所: ユーザー裁定 2026-10-09 原文「必要アイテム数が足りて無くても設置プレビューが可能の青く表示される」「いや、やはり全体が置けないにする」
   棄却案: 足りる分だけ置く（一度採択後に撤回）。ADR 0076 の agent前提「資材不足は置ける分だけ」を本決定で置き換える

6b. **ドラッグ列設置では素材不足の判定をBP1個単位で行う。** 始点側から賄えるBPの個数までを丸ごと青、超えたBPは丸ごと赤で置かない。
   出所: ユーザー裁定 2026-10-09 選択「BP1個単位」（予測A・確信中→的中）
   棄却案: 列全体で判定

7. **貼り付けプレビューは復元予定の電線・歯車チェーンもブロックゴーストと同じ青/赤の線で描く。**
   出所: ユーザー裁定 2026-10-09 選択「線もゴーストで出す」

8. **ビルドメニューにBPの必要素材を出す。**
   出所: ユーザー裁定 2026-10-09 原文「ビルドメニューで必要アイテム数を表示してほしい」

9. **大きいBPのちらつきを解消する。**
   出所: ユーザー裁定 2026-10-09 原文「大きいBPだとチカチカする」
   直し方は実装冒頭で再現・計測して原因を確定してから決める。出所: agent前提（原因が推測のため。moores-grill-with-docs §1.2）

## Consequences

- BPのセーブ形式が変わる（オフセット基準・配線の追加）。`WorldSaveAllInfo.CurrentVersion` を上げ、移行ステップとテストを同梱する。
- 既存BPは中身の相対配置を保ったまま、同じカーソル位置に対する置き位置が変わる。
- 素材不足の全体拒否はサーバー側でも一括で判定しないと、プレビューとの食い違いで一部だけ置かれうる。
