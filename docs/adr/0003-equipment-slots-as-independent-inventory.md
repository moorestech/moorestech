# 装備スロットは独立したインベントリにする

ホットバーがアイテムを持たなくなる（ADR-0002）ため、斧や石器といったツールの置き場所として装備スロットを新設する。メインインベントリはマスタでスロット数が拡張される可変長なので、マシンのモジュールスロットのように**末尾レンジとして持たせるとインデックスがサイズに依存する**（旧ホットバーが抱えていた問題そのもの）。そのため装備スロットは `InventoryType.Equipment` を持つ独立した `IOpenableInventory` とし、既存のアイテム移動・整理プロトコルをそのまま使う。

## Consequences

- スロット数はマスタ定義の固定値。1枠1個までで、`items.yml` のトップレベルに新設する `tools` 配列に列挙されたアイテムだけが入る。
- 「特定のアイテムしか受け付けないインベントリ」は既存にないため、インベントリ側が受入可否を宣言し移動サービスがそれを尊重する機構を新設する（マシンのモジュールスロットは無制限で、前例にならない）。
- 選択中の装備は通常モードのホイールで循環し、空も選べる。HUD右端に常設表示する。
- 手持ち3Dモデルと採掘アニメーションの参照元がホットバーから装備スロットへ移る。
