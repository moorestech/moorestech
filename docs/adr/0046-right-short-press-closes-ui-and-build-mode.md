# 0046. パネル外の右短押しでUIと建築モードを解除する

日付: 2026-08-30
状態: 採択

## Context

建築モード（`PlaceBlockState`）の終了はEsc/B/Tab/同じ数字キー再押しのキーボード入力のみで、マウスでのキャンセルが無い。パネル型UI（インベントリ・ビルドメニュー等）も同様にEsc/Tab/固有キーのみで閉じ、10状態が各自 `GetNextUpdate` で閉じ条件を持つ。「画面外クリックで閉じる」共通機構は uGUI にも webui にも無い。
建築モード中の左クリックは設置操作そのもの（`CommonBlockPlaceSystem` 押下でドラッグ開始→離して設置）。右クリックはTPSのカメラ回転（`UiStateCameraPolicyService` の右ボタン押下/離しで CameraLook/PointerFree 切替）と電線ツールの起点解除（`ElectricWireConnectSystem`）に使われている。インベントリ系パネル上の右クリックは「半分取る/1個置く」。

## Decision

- **キャンセル入力は左クリックでなく右クリック。** 左クリックは設置操作のまま。
  出所: ユーザー裁定 2026-08-30 原文「左クリックを押したらビルドモードをキャンセルしたい」→ 選択「実は右クリックの意味」
  棄却案: 設置不可位置での左クリック／UI外の左クリック全般
- **右短押し（押してから動かさず離す）だけが解除入力。右ドラッグはTPS回転のまま。**
  出所: ユーザー裁定 2026-08-30「短押し(動かさず離す)でキャンセル、ドラッグは回転のまま」
  棄却案: 右押下で即キャンセル
- **対象はパネル型UI全般、発火はUIパネル外（ワールド/背景）のみ。** プレイヤー/ブロック/列車インベントリ・ビルドメニュー・チャレンジ一覧・破壊モード・建築モード。パネル上の右クリックは従来のアイテム操作。ポーズメニュー・スキット・デバッグ・リサーチツリー（全画面）は対象外。
  出所: ユーザー裁定 2026-08-30 原文「全体的に、左クリックを押したらUIを解除できるようにする」→ 選択「全画面で、UIパネル外(ワールド/背景)を右短押ししたら閉じる」
  棄却案: 建築/破壊モードだけ／パネル上でも閉じる
- **右短押しは各画面のEscと同じ意味（二段階解除）。** 破壊モード選択中は選択解除のみ、電線起点保持中は起点解除のみ、解除対象が無ければ閉じる。
  出所: ユーザー裁定 2026-08-30「Escと同型: 選択/起点があればそれを解除、無ければモード終了」
  棄却案: 常にモード終了
- **操作ヒントHUDには載せない。** ESCと同じ自明扱い、localizationキー追加なし。
  出所: ユーザー裁定 2026-08-30「載せない（ESCと同じ自明扱い）」
  棄却案: 各画面に「右クリック 閉じる」を追加
- 右短押しの検出は1サービスに集約し、各 `IUIState` は Esc 判定と並べてそれを問い合わせる（agent前提: `HotbarTapInputService`/`UiStateCameraPolicyService` と同じ「入力解釈サービスをUIState側が呼ぶ」前例。閉じ先は各画面のEscと同一）。
- パネル外判定は押下時点の `UiPointerHitTest.IsPointerOverAnyUi()` を使う（agent前提: 全設置系の左クリックゲートと同じ判定。webuiのポインタ状態も含まれる）。移動閾値は数px程度の定数（agent前提: 値は実装時に決めPlayMode録画で確認）。
- 電線ツールの既存の右押下即起点解除は短押し判定へ置き換える（agent前提: 裁定2の帰結。押下即発火のままだとTPS右ドラッグで起点が消える現状挙動も同時に直る）。

## Consequences

- 全対象UIStateに右短押し判定が1行ずつ入る。Escと並置するため各状態の閉じ条件は引き続き自状態に留まる（共通基底は作らない）。
- FPSはカーソル固定で常時回転のため、右ボタンは短押し判定なしでも衝突しないが、規則を一本化するため同じ短押し判定を通す。
- 新設入力サービスの単体テスト（短押し/ドラッグ/パネル上の3分岐）と、建築モード・インベントリの録画プレイテストが要る。
- `.decisions/2026-08-30-ビルドモードのキャンセルは左クリックでなく右クリックにする.md` ほか同日4件が裁定の正。
