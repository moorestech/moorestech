# 0045. ビルドメニューは1本スクロールにしサイドバーはカテゴリへのジャンプにする

日付: 2026-08-30
状態: 採択

## Context

Web UIのビルドメニュー（`moorestech_web/webui/src/features/buildMenu/`）は「カテゴリ縦ModeSwitch | 検索+選択カテゴリのサブカテゴリ別グリッド | 詳細サイドバー」の3列で、サイドバーは表示カテゴリを切り替えるタブとして機能している。検索中はサイドバーを無効化し「カテゴリ / サブカテゴリ」複合見出しの別モードへ切り替わる。カテゴリを跨いで探すたびにタブを押し直す必要があり、全体を眺めながら選ぶことができない。Unity側 `BuildMenuView.cs` にはカテゴリ概念が無く、本ADRの対象はWeb UIのみ。

## Decision

- **カテゴリ切替を廃止し、全カテゴリを「カテゴリ大見出し → サブカテゴリ小見出し＋SlotGrid」の2階層で1本のスクロールに並べる。サイドバーはカテゴリ単位のショートカットで、押すとそのカテゴリ大見出しへスクロールする。**
  出所: ユーザー裁定 2026-08-30 原文「ブロックはカテゴリをやめて、長い1スクロールプラス、サイドバーはそのショートカットという位置づけにする」→ 選択「カテゴリ見出し＋サブカテゴリ小見出し、サイドバーはカテゴリのみ」
  棄却案: サブカテゴリ見出しのみでサイドバーもサブカテゴリ単位／カテゴリ見出しのみでサブカテゴリ見出し廃止
  [[2026-08-30-ビルドメニューは1本スクロールでサイドバーはカテゴリ見出しへのジャンプにする]]

- **サイドバーのハイライトはスクロール視口上端にあるカテゴリに追従する（scroll-spy）。**
  出所: ユーザー裁定 2026-08-30 選択「スクロール位置に追従（scroll-spy）」
  棄却案: 最後に押した項目を光らせるだけ／ハイライトなし
  [[2026-08-30-ビルドメニューサイドバーのハイライトはスクロール位置に追従する]]

- **検索は同じ2階層リストの絞り込み。ヒットの無いカテゴリ/サブカテゴリは非表示、サイドバーはヒットの無いカテゴリ項目だけ無効化。検索専用の複合見出しは廃止。**
  出所: ユーザー裁定 2026-08-30 選択「同じレイアウトで絞り込み、サイドバーはヒットのあるカテゴリだけ有効」
  棄却案: 現行維持（検索中はサイドバー無効・複合見出し）
  [[2026-08-30-ビルドメニュー検索中も1本スクロールのままサイドバーはヒットカテゴリだけ有効にする]]

- **ジャンプはスムーズスクロール。移動中は押した項目のハイライトを固定し、到達後にscroll-spyへ戻す。**
  出所: ユーザー裁定 2026-08-30 選択「スムーズスクロール」（移動中のハイライト固定は agent前提・ちらつき回避）
  棄却案: 即時ジャンプ
  [[2026-08-30-ビルドメニューのジャンプはスムーズスクロールにする]]

- **カテゴリ大見出しは本文色の大きめラベル＋FadeRule、上にカテゴリ間余白。サブカテゴリ小見出しは現行の `--text-muted` ラベル＋FadeRule のまま。**
  出所: ユーザー裁定 2026-08-30 選択「本文色の大きめラベル＋FadeRule、上にカテゴリ間余白」
  棄却案: サブカテゴリと同スタイルで余白だけ広げる／カテゴリ名をサブカテゴリ見出しに前置
  [[2026-08-30-ビルドメニューのカテゴリ大見出しは本文色大ラベルとFadeRuleで区切る]]

- agent前提（ユーザー確認済み 2026-08-30）:
  - セッション内保持の `categoryGuid` は廃止。検索文字列・scrollTop・詳細stickyは従来どおり保持（[[2026-08-05-ビルドメニューはタブ検索スクロールをセッション内で丸ごと保持する]]）
  - リスト末尾に余白を足し、末尾カテゴリへジャンプしてもその見出しが視口上端に来てscroll-spyと一致させる
  - エントリの無いカテゴリはサイドバー・スクロールともに非表示（現行踏襲）
  - サイドバーは縦ModeSwitch部品・固定高トークンを継続使用し、webui-design §8.11 を本ADRに合わせて改定

## Consequences

- `sectionsForCategory`/`searchSections`/`resolveSelectedCategory` はカテゴリ階層を持つ構造へ置き換わり、`compositeHeading` は消える。
- e2e（`buildMenu.spec.ts`／`buildMenuLayout.spec.ts`／`capture-buildmenu.ts`）とプレイテストDSL（`PlaytestUiOps.cs` のカテゴリクリック）は「クリック＝ジャンプ」として引き続き動くが、カテゴリ切替を前提とした assertion は書き換える。
- 全エントリを常時DOMに置くため描画量は増えるが、性能最適化は考慮しない方針（AGENTS.md）。
