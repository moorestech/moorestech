# ADR 0039: チュートリアル誘導表示を原色赤＋拡縮ループにする

- Status: Accepted
- Date: 2026-08-28
- 関連: ADR 0029（キーヒント様式）, .decisions/2026-08-22-キーヒント赤字はチュートリアルHUD限定とする.md,
  .decisions/2026-08-20-keyControlはキーキャップ付きHUDヒントとしてWebで復活させる.md

## Context

チュートリアルの誘導表示（keyControlヒントHUD・UIハイライト枠・ワールドピンの画面外矢印）が
ワールド背景に埋もれて見落とされる。現行は次のとおりで、いずれも静止している。

- keyControlヒント: `--tutorial-key-hint-color: var(--text-insufficient)` = `#ff7878`（薄い赤）
- UIハイライト枠: 枠線 `#ffdd57`（黄）＋ 同色24%のグロー
- ワールドピン画面外矢印: `fill: var(--text-high-contrast)`（白）＋ ネイビー縁取り

## Decision

誘導表示の3種を **原色赤 `#ff0000`** に統一し、**拡縮ループアニメーション**を付ける。

### 1. keyControlヒントHUD

- `--tutorial-key-hint-color` を `#ff0000` にする。適用範囲は **チュートリアルHUDのみ**で、
  インベントリ画面左下・研究画面左下のキーヒントは白のまま（2026-08-22裁定の範囲を維持）。
- 拡縮ループ **1.0↔1.08 / 1200ms / ease-in-out / infinite** を `.hint` に付ける。

出所: ユーザー裁定 2026-08-28 原文「Tabを押してください、みたいな画面上に出すチュートリアルは原色赤にして、拡縮のループアニメーションをさせたい」
→ 選択「#ff0000・チュートリアルHUDのみ」「1.0↔1.08 / 1200ms」

### 2. UIハイライト枠

- 枠線を `#ff0000`、グローを `rgb(255 0 0 / 24%)` にする。ラベル面（`--world-pin-face` ＋ 白文字）は現状維持。
- 拡縮ループ **1.0↔1.03 / 1200ms** を **既存の `.highlight` div の `transform`** に付ける。
  内側ノードを足してクリップと見た目を分離する案は採らない。

出所: ユーザー裁定 2026-08-28 原文「UIハイライトとも原色赤にして、こちらも軽く拡縮ループアニメーションしたい」
→ 選択「枠線＋グロー両方を純赤」「既存divにtransform: scale」「1.0↔1.03 / 1200ms」

**受容する帰結**: `clip-path` は同じ要素に載っており `transform` と一緒に拡縮する。よって祖先スクロール枠の
クリップ境界も同周期で呼吸し、最大時に境界の外へ約±1px漏れ、最小時に内へ食い込む。振幅1.03で数px以下に収まる
ことを確認したうえでユーザーが選択肢としてこれを採択した。ラベル面は別要素なので脈動せず固定位置に残る。

### 3. ワールドピンの画面外矢印

- `fill` を `#ff0000` にする。縁取り（`stroke: var(--world-pin-face)`）は現状維持。
- 拡縮ループ **1.0↔1.08 / 1200ms** を付ける。

出所: ユーザー裁定 2026-08-28 原文「Hud矢印も」→ 選択「ワールドピンの画面外矢印」「純赤化＋拡縮ループ」

矢印の `transform` は `WorldPinOverlay.tsx` がインライン（`translate/rotate/scale(--ui-scale)`）で書いており、
CSSアニメーションはカスケード上インラインstyleに勝つため、同じ要素で `transform` を動かすと回転と位置が消える。
よって脈動は子の `.arrow svg` 側に付けて合成する。
出所: agent前提（インラインtransformとCSSアニメーションの優先順位。@property でのvar合成より支持要件が軽い）

### 4. トークン

`#ff0000` と脈動の諸元は tokens.css の共有トークンを単一の値源とし、機能側CSSに色・秒数を直書きしない
（webui-design §9「機能側CSSへの色の直書き」禁止）。
出所: agent前提（webui-design の既存規約）

## Considered Options（棄却）

- **キーヒント全部を純赤**（インベントリ左下・研究左下も）: 2026-08-22裁定を覆すため不採用。パネル内に載るヒントは可読性の問題がない。
- **#ff2d2d（濃いめの赤）**: `#ff0000` は暗背景で沈むという懸念からの折衷案。ユーザーは原色を明示指定した。
- **ハイライトを内側ノードで拡縮**（外側divがclip-path固定、内側divが枠線＋scale）: クリップ漏れが起きない代わりにDOMが1段増える。ユーザーが既存div方式を選択。
- **枠の振幅を1.08（全要素同一諸元）/ 1.05・1600ms**: 「軽く」の指定に対し1.03を採択。
- **D&Dドラッグガイド矢印も赤化**: 対象外。既存の移動ループのままとする。
- **矢印は純赤化のみ（アニメ無し）/ 縁取りも白へ反転**: 不採用。

## Consequences

- webui-design SKILL.md §8.19 の「面・枠・光彩・**アニメーションは持たず**」は本裁定で撤回し、拡縮ループを持つ様式へ改める。
- 誘導表示3種が同じ赤と同じ周期で脈打つため、チュートリアル中の視界は現行より強く動く。
- ハイライト枠はスクロールコンテナ端でクリップ境界が微小に呼吸する（上記の受容済み帰結）。
