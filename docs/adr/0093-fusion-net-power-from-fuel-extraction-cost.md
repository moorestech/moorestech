# 核融合の差し引き電力は燃料づくりの大電力で作り、炉本体は既存の燃料発電機のままモジュールを挿さない

作者メモは核融合炉を「最初は差し引きちょいプラス、モジュールで効率化して差し引きを増やす」としている。炉本体にモジュールを効かせるには発電機へモジュールの仕組みを新設する必要がある。そこで差し引きの負担を燃料（重水素）づくりに置く。水から重水素を作る重水素抽出装置が莫大な電力を食い、炉は重水素を燃やして大きな電力を出す。燃料機械は既存の機械なのでモジュールスロットを持ち、S1 の省エネ（消費↓）・生産性（燃料↑）モジュールを挿すと差し引き電力が増える。炉本体は既存の燃料発電機（ElectricGenerator の液体燃料）のままにする。

## 決定

- **核融合炉は既存の燃料発電機。** 新しい液体「重水素」を燃料にし、燃えている間は一定の大電力を出す。モジュールスロット・点火電力・再起動の手順は持たない。
- **重水素抽出装置は既存の電気機械。** 水を入れて重水素を出し、要求電力を大きく取る。モジュールスロットを持つ。
- **初期の差し引き電力は「小さいが既存の発電機より大きい」に合わせる。** 評価は運転中の電力収支だけで、建設資材の回収期間は含めない。 炉1基に要る抽出装置の台数×消費を、炉の発電から引いた値が、モジュールなしでガソリン発電機数台分になるよう値を決める。モジュールを挿すと抽出装置の消費が下がり（省エネ）、同じ台数で出る重水素が増える（生産性）。
- **反物質製造装置が核融合の大電力の使い道になる。** 反物質の製造に炉数基分の電力を要求し、反物質爆弾（終端研究の素材）につなぐ。

## Considered Options

- 炉本体にモジュールスロットを付け、同じ燃料で発電量を増やす: 発電機へモジュールの仕組みの新設が要る。ユーザーが不採用。
- 燃料機械と炉本体の両方にモジュールを効かせる: 同上。ユーザーが不採用。
- 稼働中の炉が副産物として反物質を出す: 発電機にアイテム出力の仕組みが要る。比較案（ユーザーによる棄却は未確認）。
