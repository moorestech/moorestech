# ホットバーはアイテムではなく設置対象を持つ

ホットバーはメインインベントリ末尾9スロットの別名で、実アイテムを保持していた。一方で設置系はすでにビルドメニュー→設置対象という経路に移行済みで、ホットバーの選択アイテムは設置に一切関与していなかった。Satisfactory 型の建築体験に寄せるため、**ホットバーはアイテム保持をやめ、設置対象IDへの参照9個だけを持つ**ことに決めた。割当はプレイヤー単位でセーブに永続し、数字キーで即座に建築モードへ入る。

## Consequences

- メインインベントリ末尾9スロットの特別扱い（拾得時の優先挿入・ソート除外・Web契約の `hotbarSlots`）を完全に撤廃する。`PlayerInventoryConst` のホットバー系APIは削除。
- 数字キーは押すたびに建築モードへの出入りを切り替える。空の枠を押すと建築モードを抜ける。
- 解決できない割当（マスタから消えたブロック、削除されたブループリント）はロード時に削除する。
- uGUI の `HotBarView` は役割を失うため削除し、割当と選択中の枠は非MonoBehaviourのクライアントモデルが所有する。プレイテストDSLの `GiveItemToHotbar` / `SelectHotbar` も作り直す。
- ホットバーの手持ちアイテムでツールを使う経路が消えるため、ツールは装備スロットへ移る（ADR-0003）。
