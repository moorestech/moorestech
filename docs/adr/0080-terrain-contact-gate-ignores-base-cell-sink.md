# ADR 0080: 地形接触ゲートは最下段セルの沈みを判定しない

- Status: Accepted
- Date: 2026-10-15
- Related: ADR 0047（既定設置Yは地形最高点を含むセル）

## Context

ADR 0047 で既定の設置セルYを floor（地形最高点を含むセル）にし、通常設置から地形重なりゲートを外した。
一方、ベルト・レール橋脚・電線ツールの電柱ゴースト・歯車チェーンポールの4設置系は「地形に埋まっています」のゲートを残した。
4系統の実Prefabには `GroundCollisionDetector` が付いておらず、ゲートは実際には一度も働いていなかった。

#1499 で `BlockPreviewObject.ConfigureTerrainContact` が、検出器の無いPrefabへマスター占有サイズから各面0.02m内側の
Trigger箱を生成するようになり、ゲートが初めて働いた。箱の下面はセルY+0.02m、設置Yは floor なので、
地表の端数が0.02mを超えるとほぼ必ず埋まり判定になり、歯車チェーンポール・レール橋脚がほとんど置けなくなった。

## Decision

**生成する判定箱のy範囲を `[1+inset, blockSize.y-inset]` にし、最下段1セル（ADR 0047 が許す沈み）を判定から外す。**

- `blockSize.y <= 1` のブロック（ベルト・レール橋脚など）は判定箱を作らない。#1499 前と同じく地形ゲートは働かない
- Prefabに `GroundCollisionDetector` が付いている場合はそれを従来どおり使う（本ADRの対象外）
- 判定は「触れたら不可」のまま。深さの閾値は「最下段セルの上面」で固定する
- **4設置系の設置セルYも通常設置と同じ「占有セルの地形最高点を含むセル」にする**（`PlacementGroundCellResolver.TryResolveCellFromGround`）。照準1点の `floor(hit.y)` をやめる。ブロック面ヒット（積み重ね）はレイのセルのまま。占有セルの地表が取れなければ「地面が見つかりません」の理由を出して置かない

出所（Y決定）: ユーザー裁定 2026-10-15。照準1点の floor のままだと緩い斜面でも 3x4x3 ポールが照準位置の約2割で埋まり判定になる、という指摘に対し選択「Yを最高点に揃えて同PRで直す」。裁定記録: `.decisions/2026-10-15-地形ゲート付き4設置系の設置Yもフットプリント最高点で決める.md`

出所: ユーザー裁定 2026-10-15。提示「①判定箱の下端を1セル持ち上げる（ADR0047整合、高さ1のブロックは箱を作らず#1499前と同じ挙動）」に対し原文「ok、これの修正計画を立てて。」

裁定記録: `.decisions/2026-10-15-地形ゲート付き設置の判定箱は最下段セルを除き撤去返却はMaxStackで分ける.md`

## Considered Options

### 1. 4設置系からも地形ゲートを外す（棄却）

#1499 前の実挙動と完全に一致し最も単純。ただし崖の中へポール上部が刺さる配置も通る。
棄却理由: ユーザー裁定 2026-10-15 で①を選択。

### 2. 照準1点の floor のまま出し、斜面の照準依存は後続issueにする（棄却）

棄却理由: ユーザー裁定 2026-10-15 選択「Yを最高点に揃えて同PRで直す」。斜面で「置けない」報告が続く負債を残さない。

### 3. 判定箱の inset を数cm広げる（棄却）

地表の端数は0〜1mにほぼ一様に分布するため、許容を数cm広げても通る割合は数%しか増えない。

## Consequences

- 高さ2以上のブロック（歯車チェーンポール 3x4x3・コンパクト歯車チェーンポール 1x2x1・電柱 1x5x1 等）は、
  Yが占有最高点を含むセルになるため、平面に近い地表では判定箱へ地表が入らない。設置不可になるのは、
  セル内の4隅サンプルの間で地表が最下段セルを超えて盛り上がる崖・尾根だけになる
- 4設置系の Y の決め方が通常設置・BP貼り付けと揃う。斜面では照準位置によらず同じセルになる
- 高さ1のブロックは地形ゲートを持たない。崖の中に潜る配置も通る（ADR 0047 の通常設置と同じ割り切り）
- ADR 0047 Considered Options 4（深さ判定へ緩める案）は通常設置について棄却されたままで、本ADRは4設置系だけに適用する
