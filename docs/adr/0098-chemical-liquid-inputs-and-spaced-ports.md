# 0098: 化学プラントを液体入力専用にし入力口を離す

Status: Accepted

## Decision
ロケット燃料はガソリン100＋ナフサ200→1個、8秒。IPAは化学プラントの既存レシピを維持、高純度シリコンは最新6f693a6でアイテム/レシピが既に廃止済みなので復活させず、現行工程を維持する（確認後の実データ照合で判明）。化学プラントの固体入力コネクタと表示をなくし、固体製品の出口は維持。
出所: ユーザー裁定2026-11-07の原文と確認回答は.decisions/2026-11-07-化学プラントを液体入力専用にして口を1マス空ける.md。

入力0は既存(3,1,0)/-Z、入力1を(2,1,0)から(1,1,0)/-Zへ動かす。タンクindex0/1を維持し、接続相手セル(3,1,-1)/(1,1,-1)間に空セル(2,1,-1)が入る。出力は(2,1,10)/+Zを維持。
出所: agent前提（既存口を残し、1マス空ける最小変更）。異種液でも空の隣接パイプへ流入できる条件はFluidSimulationStepper.cs:80等で確認、動作は今回の焦点検証で測る。

モデルは依頼されたrevertに従いChemical Plants.prefabをPR1615前の版へ戻し、必要な2入力/1出力の表示だけUnity経由で足す。以前の6設備・共通カメラ変更へ波及させない。
出所: agent前提（先行のユーザー原文「化学プラントのマスタとモデルをrevertして」を今回の確定内容に合わせる）。マスタは液体2入力/1出力が必要なので全体revertせず固体入力だけ戻す。

inputSlotCount=1は旧版と同じまま保持する。ポート撤去はコネクタと模型を対象にし、保存済み入力スロットの材料を落とす容量削減は行わない。保存フィールド・タンク数・出力スロット数を変えない。
出所: agent前提（MachineSaveRestorerの容量超過時にアイテムを落とす経路を避け、依頼されたport撤去に限定）。
