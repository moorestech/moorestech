# 削除ツールのF長押しは選択件数で3段に伸ばし、Ctrl押下中のなぞり・箱で削除候補を外す

ADR 0079 の「長押しは件数に関係なく2秒」「選択は追加のみで個別除外は作らない」を覆す。F 長押しの満了時間を選択件数で 0.75 秒／1.25 秒／1.75 秒の3段に変え、Ctrl を押している間のなぞり・箱は選択へ足す代わりに選択から外す。ESC／右短押しの全解除は残す。

## Considered Options

- 長押し時間の段: 1件／2〜9件／10件以上、1〜9件／10〜49件／50件以上 — 棄却。採択: 1〜4件 0.75秒／5〜19件 1.25秒／20件以上 1.75秒。
  出所: ユーザー裁定 2026-10-19 原文「個数に応じて段階的に長くするようにしたい」「0.75s 1.75s あとその両者の中間」→ 選択「1〜4件 / 5〜19件 / 20件以上」
- 数える件数: 巻き込みで消える接続線等も含めた実際に消える総数 — 棄却。採択: ツールチップに出ている選択件数（種類を問わず1候補=1件）。選択が空のホバー1件削除は1件として 0.75 秒。
  出所: ユーザー裁定 2026-10-19 選択「ツールチップの選択件数」（ホバー1件の扱いは同日の段の質問文に明記して採択）
- 候補の取り消し: 選択済みを動かさず左クリックで1件外す／ESC・右短押しを「直前のなぞり・箱1回分を戻す」に変える — 棄却。採択: Ctrl+左ドラッグでなぞった候補を外す、Ctrl+Shift+2点の箱で箱内の候補を外す。通常の左操作は追加のまま、ESC／右短押しは全解除のまま。
  出所: ユーザー裁定 2026-10-19 原文「さくじょ候補を取り消しできるようにしたい」→ 選択「Ctrl押し中は外す」
- 追加か除外かは押下の瞬間（なぞりの開始・箱の始点クリック）の Ctrl で決め、途中で Ctrl を離しても切り替えない。Ctrl+左クリック（動かさず）はなぞり1件分として1件外す。
  出所: agent前提（なぞり開始時にカテゴリーを固定する既存規則と同型。押下中に意味が変わると結果が読めない）
- 除外のなぞりは追加のなぞりと同じ照準（最前面・なぞり中は同カテゴリー固定）で、通った対象のうち選択済みのものだけを外し、未選択は無視する。
  出所: agent前提（追加と除外で照準を共有する）
- 除外の箱: 撤去できるかを問わず選択済みなら全部外す — 棄却。採択: 追加の箱と同じ解決結果（撤去可能・カテゴリーを問わず・接続線は入らない）のうち選択済みのものだけを外す。選択後に撤去不可になった候補は Ctrl+なぞりか ESC 全解除で外す。
  出所: ユーザー裁定 2026-10-19 選択「撤去できる物だけ外す」
- 外した対象は赤プレビューを解除する。選択が変わるので長押し進捗は 0 に戻る（ADR 0079 の既存規則）。除外の箱の終点待ち中はツールチップに「外す件数」を出す。
  出所: agent前提（ADR 0079 の進捗リセット規則・箱の件数表示と同型）
- キーヒントに「Ctrl+左ドラッグ 選択から外す」を足す。Ctrl+Z（Undo）との衝突は無い（Ctrl 単独押下ではなぞりも箱も始まらない）。
  出所: agent前提

## Consequences

- クライアント: `DeleteHoldConfirm` の固定 `HoldSeconds` を件数から満了時間を返す段の表に置き換え、件数を選択側からプッシュする。`DeleteSelection` に除外のなぞり・除外の箱を足す。サーバーは変更なし。
- CONTEXT.md: 「削除の確定」「なぞり選択」「箱選択」を改め、「選択からの除外」を足す。
- 覆した裁定: `.decisions/2026-10-16-削除ツールのF長押しは件数に関係なく2秒で確定する.md`、`.decisions/2026-10-16-削除ツールの選択は追加のみでESCの全解除だけを持ち個別除外は作らない.md`。新しい裁定: `.decisions/2026-10-19-削除ツール*.md`。
