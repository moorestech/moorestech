# 0083 設置モードのプレビュー専用表示をプレイヤー周囲20mのブロックに限る

日付: 2026-10-18

## 背景
設置モードに入ると PlaceBlockState.OnEnter が全 BlockGameObject の PreviewOnlyObject（枠線 BlockPreviewBoundingBox・InventoryConnectorView・GearConnectorView）を一斉に描画し、ブロック数が多いワールドで重い。
原因: 推測（根拠: 依頼者の体感と、全ブロック×枠線18オブジェクトを描画するコード。プロファイラ実測は実装時に前後比較で取る）

## 決定
1. 設置モード中のプレビュー専用表示は、プレイヤー位置から半径20m以内のブロックだけ描画する。
   出所: ユーザー裁定 2026-10-18 原文「枠線やプレビューを周りの一定mを出す、みたいにしたい」→ 選択「プレイヤー位置」「20m」
   棄却: 照準レイが最初に当たった1ブロックだけ（一度選択後に原文で撤回）／中心を照準地点／半径10m・40m
2. 対象ブロックの判定は全ブロックを毎フレーム走査せず、効率的に行う。
   出所: ユーザー裁定 2026-10-18 原文「ただしどのブロックをだすかは効率的に判定したい」
3. 判定方式は ColliderDistanceCullingManager／ColliderCullingChunkTable の前例に従い、ブロックをチャンクへ登録し、プレイヤーが一定距離動いた時だけアクティブチャンク集合の差分を切り替える。チャンク寸法・再評価距離は20m半径に合わせて別定数を持つ。
   出所: agent前提（既存コライダー距離カリングの前例。設計原則「着手前に前例を探す」）
4. 半径外でも PreviewOnlyObject の GameObject と面コライダーは有効のまま残し、レンダラーだけを切る。設置レイは Block レイヤーを除外し枠線の面コライダーに当てて隣接設置を解決しているため、GameObject ごと切ると半径外ブロックの横に置けなくなる。
   出所: agent前提（PlaceSystemUtil.TryRaycastPlacementSurface の現行仕様）。ユーザーへの質問文に「当たり判定は残すので半径外のブロックの横にも今どおり置ける」と明示したうえで回答を得た
5. 設置モード外では従来どおり全ブロックのプレビュー専用表示を消す。設置モード中に新規設置されたブロックも、設置アニメーション完了後に半径判定に従う。
   出所: agent前提（現行 OnExit／OnPlaceBlock の挙動を維持）
