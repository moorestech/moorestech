# 0033: 初期チュートリアル再編（研究4.5廃止と改番・研究チャレンジ全件化・機械レシピ解放の同期則）

- Status: Accepted
- Date: 2026-08-25

## Context

ADR 0029 の初期チュートリアルを実プレイして、ユーザーから次が挙がった（2026-08-25）:

1. 建設ショートカット（build-menu→hotbar のドラッグ誘導）のチュートリアルは一旦なくす
2. 風力採掘機設置の設置先ピンは粘土でなく木にしたい
3. 粘土の入手が原始研究4の前に来るのはおかしい（風力採掘機設置 → 研究4 → 粘土入手 の順）
4. レンガを作る、の後のチャレンジは石窯を作る、にする
5. すべての原始研究の研究チャレンジを追加し、解放アイテムとチャレンジの順番を見直す
6. 原始研究4.5をやめて全部+1ずつにする
7. 研究4で不要な機械レシピ解放（木炭・低品質な鉄の塊・青銅インゴット×2・鉄インゴット×2）を消し、アイテム解放と同時に機械レシピも解放されるようマスタを整理する（銅鉱石の粉など、明らかに原始研究で解放すべきでないものが解放対象になっている）
8. 青銅の鉱石を5個採掘は（旧）4.5完了後に出現させる

調査で確定した事実（moorestech_master `60e815a`、v8 mod）:
- 現行チェーン: …研究3 → 風力掘削機設置（veinPin=粘土鉱脈＋hotbarドラッグ誘導）→ 粘土入手 → レンガ → 青銅鉱石5個 → 青銅鉱石の粉3個 → 研究4 → 石窯設置（hotbarドラッグ誘導）→ 青銅インゴット → 青銅シート → 木釘9 → 合板 → 補強棒材 → 木のフレーム。研究チャレンジは研究1〜4のみ
- 原始研究は 1,2,3,4,4.5,5,6,7,8 の9本。4.5＝青銅の鉱石/青銅インゴット/青銅鉱石の粉のアイテム解放（コスト 木の板10＋レンガ45）
- 研究4は石窯レシピ7本を解放するが、出力アイテムの解放研究は 木炭=新しい燃料、鉄インゴット=鉄の時代、青銅インゴット=4.5、砂鉄/低品質な鉄の塊=どこでも解放されない。研究5の粉砕機レシピにも 銅鉱石の粉（銅の採掘）・鉄鉱石の粉（鉄の時代）が混じる
- 補強棒材/木のフレームの解放は「木材の組み立て」（旧研究8の後続）なので、現行位置（研究5の前）では作れず既に破綻している
- 風力掘削機の mineSettings は 石/原木/青銅の鉱石/粘土。原木鉱脈（`56ab3155`）は map.json・generation.json 双方に存在する
- 石窯・風力掘削機はアイテムでなくビルドメニューから素材直払い（石窯＝砕いた石材20＋レンガ5）。「石窯を作る」＝既存 `blockPlace 石窯`
- 低品質な鉄の塊の参照は items.json と機械レシピ `砂鉄+木炭→低品質な鉄の塊` の1本のみ。砂鉄は同レシピと仮置き手クラフト `木の棒×5→砂鉄`（initialUnlocked=true）のみ

## Decision

### 1. チャレンジチェーンの骨格

```
研究3 → 風力掘削機設置(veinPin=原木鉱脈) → 研究4 → 粘土入手(veinPin=粘土鉱脈 新設) → レンガ → 石窯設置
→ 研究5(旧4.5) → 青銅鉱石5 → 青銅鉱石の粉3 → 青銅インゴット
→ 研究6(旧5) → 青銅シート → 木釘9 → 合板
→ 研究7(旧6) → 研究8(旧7) → 研究9(旧8) → 木材の組み立て完了 → 補強棒材 → 木のフレーム
```

- 素材・レシピの観点で各時点の達成可能性を機械的に確認済み（解放済みブロック・手クラフト・石窯レシピだけで作れる）
- 出所: ユーザー裁定 2026-08-25 原文「風力採掘機設置 → 原子研究4の解放 → 粘土の入手 の順番じゃないといけない」「レンガを作る、の後のチャレンジは石窯を作る、にする」「青銅の鉱石を5個採掘← これも原子研究4.5を完了してから出現するようにしてほしい」→ 上記骨格を提示し「ok」
- agent前提: 補強棒材/木のフレームを末尾へ移すのは解放研究（木材の組み立て）の位置から導いた。研究5〜7のクラフトコスト量（レンガ45/50/94等）は解放順の破綻ではないので触らない

### 2. 研究チャレンジの範囲

- `completeResearch` チャレンジは番号付き原始研究1〜9の全件＋「木材の組み立てを完了する」1件（補強棒材の直前）。研究9後に枝分かれする他の名前付き原始ノード（原始ロジスティクス改善・建築土台・燃料式風車の作成・新しい燃料・軸の変更）は直線チェーンに載せない
- 出所: ユーザー裁定 2026-08-25 原文「すべての原子研究の研究チャレンジを追加する」→ 選択「番号付き1〜9だけ＋木材の組み立て1件」「それでok」
- agent前提: 新設研究チャレンジの tutorials は既存4件と同型（`uiHighLight research.node-<guid>`）

### 3. 研究4.5の廃止と改番

- 旧4.5→5、旧5→6、旧6→7、旧7→8、旧8→9 に改番。`researchNodeGuid` は維持し、researchNodeName・チャレンジ題名・localization 行だけ改番する（GUID振り直しは `research.node-<guid>` アンカーと prev 参照の全追従が必要で利点がない）
- 出所: ユーザー裁定 2026-08-25 原文「原子研究4.5をやめて、ちゃんと全部+1ずつなるようにする」。GUID維持は agent前提（Q5 の文中で明示提示し「ok」を得たが、質問の主題は別項だったため裁定には昇格させない）

### 4. 機械レシピ解放の同期則（全研究ノードへ適用）

> 機械レシピは**出力アイテムを解放する研究ノード**で解放する。入力アイテムのほうが後で解放される場合は**入力側の研究ノード**で解放する。

- 研究4に残る石窯レシピは `粘土+原木→レンガ` の1本。`青銅鉱石の粉+原木→青銅インゴット` は研究5(旧4.5)、木炭レシピと木炭入りの青銅/鉄レシピは「新しい燃料」、`鉄鉱石の粉+原木→鉄インゴット` は「鉄の時代」、粉砕機の 銅鉱石の粉/鉄鉱石の粉 は「銅の採掘」「鉄の時代」へ移す
- 出所: ユーザー裁定 2026-08-25 原文「アイテムがアンロックされると同時に機械レシピもアンロックされるようにマスタ設定を調整する」「この辺を全部整理する」→ 上記一般則を提示し「ok」
- agent前提（planning時の精密化・ユーザー未提示）: 要件集合に**機械ブロックの解放ノード**も含め、要件全てを祖先に持つ支配ノードを解放ノードとする（機械未解放で使えないレシピを先に見せない）。支配ノードが無い並列枝の8件は現状維持。適用は `tools/research_sync/sync_machine_recipe_unlocks.py` が機械的に行う

### 5. 低品質な鉄の塊・砂鉄の全削除

- アイテム定義2件、機械レシピ `砂鉄+木炭→低品質な鉄の塊`、手クラフト `木の棒×5→砂鉄`、両者の localization 行を削除する。クライアントテスト用Mod（EditModeInPlayingTestMod）の同名定義は別データなので触らない
- 出所: ユーザー裁定 2026-08-25 原文「低品質な鉄の塊ってどこからも使われてないよね、それを確認それ関連して全部消す」→ 4点セットを提示し「ok」

### 6. 建設ショートカット誘導の撤去

- 風力掘削機設置・石窯設置から `uiDragGuide build-menu.entry-block-* → hotbar.hud` を消し、代わりの案内は足さない
- 出所: ユーザー裁定 2026-08-25 原文「建設ショートカットのチュートリアルは一旦なくす」→ 選択「消すだけで代替案内なし」「ok」。棄却: ビルドメニューを開くキーの keyControl ヒントを付ける

### 7. 題名

- 「石窯を作る」は既存題名「石窯を設置する」のまま位置だけ移す（出所: ユーザー裁定 2026-08-25 原文「レンガを作る、の後のチャレンジは石窯を作る、にする」→ 提示「チャレンジ題名は現行の「石窯を設置する」のままでよいですか？…推奨: 現行題名を維持（位置だけ移す）」に「ok」）
