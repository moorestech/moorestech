# ブロックの向きは水平4方向だけにし、既存の縦置きはロード時に寝かせる

Shift+R の縦回転は #1581 で操作から外したが、`BlockDirection` には上向き・下向き各4つ（Up*/Down*）が残っていた。縦向きを必要とする機能は無く（ベルトの坂は上り・下りの別ブロック、縦の壁は壁パネル）、縦向き固有の不具合（moorestech-vd9u・moorestech-dou2）の温床になっている。そこで向きを North・East・South・West の4つにし、旧セーブに残る縦置きはロード時のマイグレーションで変換する。

## 決定

- **`BlockDirection` から Up*/Down* を消し、North=0・East=1・South=2・West=3 に振り直す。** 12向きを前提にした回転・原点補正・最大座標・Undo・相対ガイドの分岐も4向きへ畳む。
  出所: ユーザー裁定 2026-11-03 原文「この辺キャッチアップして垂直方向を消す処理を作って」＋承認した推奨「列挙から Up*/Down* を消し、関連する分岐を削る」。番号の振り直しは agent前提（整数で保存しているので、どちらにしても全向きの読み替えが要り、欠番を残す理由が無い）
- **セーブ版を 9→10 に上げ、ブロック（`blocks[].direction`）とブループリント（`blueprints[].blocks[].direction`）の向きを新しい番号へ読み替える。**
  出所: ユーザー裁定 2026-11-03 承認した推奨「セーブのマイグレーションを書く」「旧セーブが変換されることを確かめるテストを同梱する」
- **縦向きのクリーンルームパネルは、板が同じ面に来る向きのクリーンルーム壁パネルへ置き換える。** 計算すると Up/Down どちらも同じ方位の向き（例: UpWest・DownWest → 壁パネル West）になる。
  出所: ユーザー裁定 2026-11-03 承認した推奨「縦向きのクリーンルームパネルは向きを合わせて壁パネルへ置き換え」。対応表は agent前提（両 prefab の板の位置と回転から算出）
- **それ以外の縦向きブロックは、占有範囲の最小の隅（`OriginalPos`）を保ったまま同じ方位の水平向きへ寝かせる。**
  出所: ユーザー裁定 2026-11-03 承認した推奨「それ以外の縦向きブロックは同じ方位の水平向きへ寝かせる」
- **寝かせた結果の占有範囲が他のブロックと重なるときは、そのブロックをセーブから消す（中のアイテムも消える）。消した件数と位置はログに出す。ブループリント内でも同じ規則を当てる。**
  出所: ユーザー裁定 2026-11-03 質問「重なるときはどうしますか？」→ 選択「重なる分だけ撤去（推奨）」

## Considered Options

- 重なるならロードを止める（マイグレーション失敗）: データは消えないがワールドが開けなくなる。不採用（ユーザー裁定）
- 重なっても寝かせる: 同じマスに2つのブロックが載る壊れた状態になり得る。不採用（ユーザー裁定）
