# 0016: 初期チュートリアルのチャレンジ構成を研究と同期させ再設計する

- Status: Accepted
- Date: 2026-08-18

## Context

研究とチャレンジを繋ぐ機構が存在せず、初期チュートリアル（カテゴリ「生きる基盤」23件直列）では
#11風力掘削機設置・#16石窯設置が研究完了（原始研究1〜3 / 4）に依存するにもかかわらず、
keyControlチュートリアルの文言だけで研究画面へ誘導していた。さらにkeyControl文言はWebUIでは
非表示（uGUI廃止Phase1・Web配信topicなし）のため、WebUIプレイヤーには誘導が一切見えず、
研究を完了しない限りチャレンジが達成不能のまま詰む構造だった。

あわせて、設置操作のチュートリアルが無い・ビルドメニュー→ホットバーのD&D登録（実装済み）が
教えられていない・左上の目標HUD（CurrentChallengeHud・実装済み）の存在が示されていない、
という3点のオンボーディング欠落があった。

## Decision

### 1. 新タスク種別 completeResearch を追加する

- taskCompletionType に `completeResearch` を追加し、taskParam は単一 `researchNodeGuid`。
- サーバー側は既存の `ResearchEvent.OnResearchCompleted` を購読するイベント購読型タスクとして実装
  （既存3種別と同型・前例一致）。
- 出所: ユーザー裁定 2026-08-18「新タスク種別を追加」「単一researchNodeGuid」
- agent前提（取りこぼし防止のため一本道）: タスク開始時に ResearchDataStore の完了状態を照会し、
  既に完了済みなら即クリア扱いとする。asmdefは Game.Challenge → Game.Research の参照を追加
  （逆参照が無いことは確認済み・循環しない）。

### 2. チャレンジ並びの再設計（備蓄廃止・研究4件挿入）

- 備蓄チャレンジ3件（板40/棒35/砕石25）は廃止する。
  出所: ユーザー裁定 2026-08-18「備蓄チャレンジはそもそも消していいと思ってる」
- 研究チャレンジは研究毎に1件ずつ（原始研究1〜4の計4件）を、素材が揃う各時点へ分散配置する。
  出所: ユーザー裁定 2026-08-18「研究毎に1件ずつ」「素材順に分散配置」
- 確定した並び（23件直列）:
  ①小石3 → ②石器 → ③原木3 → ④板5 → ⑤棒5 → ⑥【新】原始研究1完了 → ⑦石5 → ⑧砕石5 →
  ⑨【新】原始研究2完了 → ⑩石の斧 → ⑪【新】原始研究3完了 → ⑫風力掘削機設置 → ⑬粘土 →
  ⑭レンガ → ⑮青銅鉱石5 → ⑯青銅鉱粉3 → ⑰【新】原始研究4完了 → ⑱石窯設置 → 以降既存のまま。
  研究の解放順（研究1→砕石レシピ表示、研究2→石の斧、研究3→掘削機、研究4→石窯レシピ）と
  素材の流れが一致する。研究3・4の必要素材はチャレンジsummaryで提示する。
  出所: ユーザー裁定 2026-08-18「この並びでよい」

### 3. チュートリアル提示の再設計（WebUI前提）

- 既存#11/#16のkeyControl文言（WebUIで元々非表示）は削除し、研究画面への誘導は
  新設の研究チャレンジ側チュートリアルへ移す。
  出所: ユーザー裁定 2026-08-18「研究チャレンジ側へ移す」
- 設置チュートリアルは新チャレンジを作らず⑫風力掘削機設置（と⑱石窯設置）に付与する。
  誘導は veinPin（鉱脈ピン）+ 任意位置設置とし、blockPlacePreview の座標固定ゴーストは使わない。
  出所: ユーザー裁定 2026-08-18「#11に付与」「veinPin+任意位置」
- D&D登録の提示は新tutorialType（仮称 uiDragGuide）を追加する: from/to のUI要素ID
  （uiHighLightと同じanchor方式）を指定し、WebUIに矢印がfrom→toへ移動をループする
  新presentation kindを追加する。対象UIが閉じている間はanchor未解決で非表示とし、
  「Bでビルドメニューを開く」まではチャレンジsummary文言で誘導する。
  出所: ユーザー裁定 2026-08-18「特定のui要素から特定のui要素へ矢印を移動させるアニメーションを
  ループさせるUIにしたい」
- 左上目標HUDの提示は①のチャレンジで、開始スキット（100_start_game）への言及追記 +
  uiHighLightによるHUD枠線ハイライト（HUD用anchor新設）を併用する。
  出所: ユーザー裁定 2026-08-18「スキット+枠線HL併用」

## Considered Options（棄却）

- 文言誘導の改善のみ（機構追加なし）: 同期を実現しないため棄却。出所: ユーザー裁定 2026-08-18
- チャレンジクリアで研究を解放する逆方向連結（gameAction追加）: 解放SSOT=research.json の
  既存裁定と衝突するため棄却。出所: ユーザー裁定 2026-08-18
- 備蓄チャレンジ数量の再計算・維持: 廃止裁定により消滅。出所: ユーザー裁定 2026-08-18
- 操作説明のスキット化・uiHighLight文言吹き出し新設: 矢印アニメ機構の採用により棄却。
  出所: ユーザー裁定 2026-08-18
