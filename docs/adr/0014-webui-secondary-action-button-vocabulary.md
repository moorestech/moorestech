# Web UI に副次アクションボタンの語彙を追加する

インベントリの「整理」ボタンは stage 右上へ浮かせた仮実装（Mantine `Button` + 色ハードコード `rgb(50 52 67)`）で、デザイン哲学 §2 が「様式に含めない・前例として引用しない」と免責していた。これを `GamePanel` のタイトル行右端という正規の置き場へ移すにあたり、免責のまま残さず様式化する。ただしホワイトリストには**副次アクション用の押しボタンという語彙が存在しない**（青グラデの `RecipeActionButton` は §5 で主要アクション限定、`ModeSwitch` は択一切替、`IconButton` は面なしアイコン）ため、`shared/ui` に汎用の副次アクションボタンを新設し §8.6 へ追記する。面は検索入力（§8.9）と同族の `--gauge-track`、文字は `--text-high-contrast`、hover は面の明化、`:focus-visible` は `ModeSwitch` 踏襲、寸法は固定長トークン。ドメイン語彙は持たせない。

出所: ユーザー裁定 2026-08-17（Q3「整理ボタンは改修してインベントリの表示領域についでに移したい」／Q5「B」＝様式化する／Q6「A」＝新語彙を `shared/ui` へ新設する）

## Considered Options

- **配置だけ直し見た目と §2 の仮実装注記は据え置く**（却下）: uGUI正本に整理ボタンの正解があるか未調査という理由で推奨したが、ユーザーが様式化を選択した。
- **`ModeSwitch` の選択済みボタン面を `composes` で流用**（却下）: 部品としては択一切替のままで意味が合わない。
- **`IconButton` + ソートアイコンへ置換**（却下）: 新語彙ゼロで済むが「整理」という語が消えて意味が伝わりにくい。
- **`GamePanel` の body 先頭/末尾へ置く**（却下）: グリッドが押されるため `minHeight` と正本合わせの実測値を全て引き直すことになる。タイトル行右端へ絶対配置すれば `--title-shift-x` 等のピクセル調整に干渉しない。
  出所: ユーザー裁定 2026-08-17（Q4「A」＝`GamePanel` に汎用 `titleAction` を追加）

## Consequences

- `GamePanel` は `titleAction?: ReactNode` という汎用スロットを持つ。ドメイン語彙は持ち込まない。
- `PauseMenuPanel` / `ChallengePanel` / `ModalHost` には素の Mantine `Button` が残る。同語彙へ寄せる候補だが**今回は着手しない**（見た目が変わる範囲を依頼のスコープに留めるため）。
  出所: ユーザー裁定 2026-08-17（Q6「他のButtonは今回触らない」を承諾）
