# 0011: レシピビューアはタブを廃止し1エントリ1レシピの単一リストで表示する

日付: 2026-08-17
状態: 採択

## 背景

Web UI（`moorestech_web/webui`）のレシピビューア（`features/recipe`）は、選択アイテムのレシピを種別タブ（クラフト / 機械ブロック別、Mantine `Tabs variant="pills"`）に分け、タブ内では `RecipePager`（`< 1/n >`）で1件ずつ表示している。パネル上端にはクリック不可のハンマー絵の装飾タブ（`ItemHeader` のSVG、uGUI時代の見た目移植）が生えているが機能していない。右のアイテム一覧（`ItemListPanel`）では、所持素材から集計した「今作れる個数」が0のアイテムにも数字バッジ「0」が描画され、またアイテム数テキストの色が白/黒で不統一になっている。

なおUI改修の対象はWeb UIのみで、uGUI側は今後一切参照・改修しない（[[2026-08-17-クラフトUI改修はWebUI専任でuGUIは今後見ない]]）。

## 決定

1. **タブ・ページャ・装飾タブを全廃止し、選択アイテムの全レシピを1本の縦スクロールリストで表示する。1エントリ=1レシピ。** クラフトレシピと機械レシピが同一リストに混在するのは意図どおり。選択中アイテムの名前ヘッダーはリスト上部に残す。
   出所: ユーザー裁定 2026-08-17（依頼文＋リスト構造確認への「合っている」、[[2026-08-17-装飾タブ削除後もアイテム名ヘッダーは残す]]）
2. **並び順はクラフトレシピ優先→機械レシピ。**
   出所: ユーザー裁定 2026-08-17（[[2026-08-17-レシピ単一リストはクラフトレシピを優先表示する]]）
3. ~~**クラフトレシピエントリは「素材→矢印→結果」のレシピ行の直下に、エントリ幅のクラフト実行ボタン（秒数表示込み）を置く2段構成。**~~ **（2026-08-20 に決定4とともに置換）** 秒数・矢印・操作を中央列へ縦積みし、クラフトボタンは矢印の真下の固定幅ボタンになった。出所: [[2026-08-20-レシピ中央列は秒数と矢印と操作の縦積みにする]] / [[2026-08-20-矢印中心揃えのためクラフトボタンを縮める]]
   （以下は置換前の記述） エントリが従来より縦に大きくなるのは許容。素材の所持数表示（不足減光＋所持/必要の赤字）と長押し連続クラフトは現状の挙動を維持する。
   出所: ユーザー裁定 2026-08-17（[[2026-08-17-クラフトエントリはレシピ行の下に全幅実行ボタン]]）
4. ~~**機械レシピエントリはクラフトエントリと同じベースで、ボタン部分が「ブロックアイコン＋ブロック名＋秒数」のクリック不可情報表示に置き換わる。**~~ **（2026-08-20 に決定3とともに置換）** 秒数は矢印の上へ移り、矢印の下はブロックアイコン＋ブロック名になった。素材を必要数のみ表示し所持数チェックを付けない点は現行も維持している。
   （以下は置換前の記述） 素材は必要数のみ表示し、所持数チェックは付けない。
   出所: ユーザー裁定 2026-08-17（[[2026-08-17-機械レシピエントリはブロックアイコン名前秒数を表示]]、[[2026-08-17-機械レシピの素材は必要数のみで所持数チェックしない]]）
5. **アイテム一覧のクラフト可能数バッジは0のとき描画しない。** 1以上のときのみ数字を出す。スロット面のグレー/白（作れない/作れる）の塗り分けは維持する。
   出所: ユーザー裁定 2026-08-17（[[2026-08-17-アイテム一覧のクラフト可能数0はバッジ非表示]]）
6. **アイテム数テキストの色は黒で統一する。** 現状の白/黒混在を解消する。
   出所: ユーザー裁定 2026-08-17「アイテム数のテキストが白かったり黒かったりすることがあるんだけど黒で統一」

## 検討した代替案

- **マスタ定義順のまま混在 / 成果物アイテムIDでグルーピング**: 並び順の代替案。クラフト優先が採択され却下（出所: ユーザー裁定 2026-08-17）。
- **結果アイテムの真下に小さな実行ボタン**: 全幅ボタン案が採択され却下（出所: ユーザー裁定 2026-08-17）。
- **機械レシピ素材にも所持数表示を付けて完全統一**: 機械レシピは手クラフトしないため過不足が意思決定に関係せず却下（出所: ユーザー裁定 2026-08-17）。
- **0バッジ非表示に加えスロット面の色分けも廃止**: 作れる/作れないの情報を残すため却下（出所: ユーザー裁定 2026-08-17）。

## 影響

- `features/recipe` のタブ構成ロジック（`buildRecipeTabs`）・`RecipePager`・装飾タブ（`ItemHeader` のSVG部）とそれらのe2e（`craftTabVisual.spec.ts` 等）は削除または全面書き換えになる。
- タブ切替を前提としたキー操作（`RecipeSelectionKeyHandler`）は単一リスト前提へ整理する。
- 機械レシピの秒数はスキーマ上ワイヤに既に乗っている（`time`）ため、サーバー・topic側の変更は不要の見込み。
