# 0082 走りの操作方式をトグル/ホールドから選べるようにし、トグルを既定にする

日付: 2026-10-16

## 背景
走り（Sprint）は Shift 押しっぱなしのホールド式だけだった。長距離移動で Shift を押し続ける負担がある。

## 決定
1. ポーズメニューの設定画面に「走り: トグル / ホールド」を置き、既定はトグル。
   出所: ユーザー裁定 2026-10-16 原文「設定に走るキーをトグルを追加して、そっちをデフォルトにしたい」→ 選択「Shift押すたび走/歩を切替」
   棄却: 「常に走る」オン/オフ（押下中だけ歩く）
2. トグル時、走り状態は Shift の操作（決定8の単独押し離し）で反転するだけ。立ち止まっても、ESCメニュー・文字入力を挟んでも維持する。
   出所: ユーザー裁定 2026-10-16 自由記述「素直に実装したらそうなる方で」→ 復唱「止まっても走りONのまま。歩きに戻すのはShiftだけ」→「その解釈でよい」
   棄却: 止まったら解除（Minecraft型）
3. トグル時、移動を止めないメニュー（インベントリ・研究・ビルドメニュー等）を開いている間の Shift は走りを反転しない。ホールド時は従来どおり一括移動とダッシュを兼ねる。
   出所: ユーザー裁定 2026-10-16 選択「メニュー中は切替しない」
   棄却: メニュー中もShiftのたびに反転する
4. フライモードの×6速も同じ走り状態に従い、フライ側に専用処理を足さない。
   出所: ユーザー裁定 2026-10-16 選択「同じ設定に従う」
   棄却: フライ中は常にホールド
5. 走りON/OFFのHUD表示は出さない。
   出所: ユーザー裁定 2026-10-16 選択「出さない」
   棄却: 走りON中だけHUDにアイコン
6. トグル時、ゲーム開始直後の走り状態は ON（WASDだけで走る）。走り状態そのものは保存しない。
   出所: ユーザー裁定 2026-10-16 選択「開始時から走り」
   棄却: 開始時は歩き
7. ゲームパッドは正式対応外だが、入力設定に残る左トリガーの Sprint 割当も分けずに同じ方式で共用する（パッド専用処理は書かない）。
   出所: ユーザー裁定 2026-10-16 自由記述「パッドは対応していないはずだが.教養」→ 復唱「『共用』の誤変換。正式対応外だが同じ走り操作として共用する」→「その解釈でよい」
   棄却: Shiftだけに適用し左トリガーはホールドのまま
8. トグル時の反転は「Shift 単独の押し離し」だけ: 押してから離すまでに他のキー・クリックが無ければ、離した瞬間に反転する。Shift+R・削除ツールの Shift+クリック・ベルト/電柱の向き・Shift を押したまま WASD を押し始めた場合は反転しない。
   出所: ユーザー裁定 2026-10-16 選択「Shift単独の押し離しだけで切替」（シミュレーター予測A・中で的中）
   棄却: 押した瞬間に常に反転／建築・削除モード中は反転しない

## 既存裁定の読み方
- 状態保持の裁定は「止まっても走り状態を保ち、Shift操作でだけ切り替える」を定める。反転時点は決定8の単独押し離し裁定が定める。保持の過去記録にある「Shift押下で反転」は時点の根拠にしない。過去の裁定ファイルは履歴として保持する。

## agent前提
- 設定の保存は言語選択と同じ PlayerPrefs（前例: `Client.Localization/Localize.cs`）。Web UI ⇄ Unity は言語と同じ action＋topic の組（前例: `LocalizationActions.cs` の `localization.setLocale`）。
- 不正な保存値はToggleへ実修復し、起動中は設定画面へ復旧記録を表示する。有効方式の明示選択で復旧記録を解除する。
- 同一InputSystemイベント内の全新規ボタン押下を扱い、Sprint開始と他キーの同時押下は単独候補にしない。先行して保持されたキーは新規押下に数えない。
- 設定画面の UI は言語選択と同じ `ModeSwitch` の択一。
- 設定画面でホールド→トグルへ切り替えた瞬間も、開始時と同じく走り ON から始める。
- 走り状態の判定規則は `Client.Input` の `SprintInputResolver` 1か所、`StarterAssetsInputs.sprint` への書き込みは `StarterAssetsInputs.ApplySprint` 1か所。`ThirdPersonController` / `PlayerFlightMotion` は `sprint` を読むだけで変更しない。

## 帰結
- 既存プレイヤーも既定でトグルになる（設定未保存のため）。
