# 採掘をサーバ権威にする

これまでの採掘はクライアント権威だった。クライアントがホットバーの手持ちからツールを判定し、`MapObjectAcquisitionProtocol` に `attackDamage` を数値で送りつけ、サーバはツールの所持を確認せずHPを削っていた。装備スロットがサーバ側のインベントリになり（ADR-0003）、サーバが「装備中のツール」を知れるようになったため、**ダメージ算出と連打間隔の検証をサーバへ移す**。

クライアントは「この instanceId を掘った」だけを送る。サーバは選択中の装備スロットのツールと mapObject の `miningTools` からダメージを引き、前回打撃から `attackSpeed` 秒が経っていなければその打撃を無視する。

## Consequences

- 選択中の装備インデックスもサーバが保持し、セーブに保存する。
- 進捗バーは従来どおりクライアント予測のままで、演出は変わらない。
- デバッグの高速採掘（`MapObjectSuperMine`）は `int.MaxValue` を送る方式が使えなくなるため、サーバ側の `DebugParameters` で処理する。
- プレイヤー座標もサーバは持っているが、クライアント申告値であり防御力が乏しいため距離検証は行わない。
