# 設置モードのプレビュー専用部品を半径内だけ有効にした前後の計測（2026-11-14）

ADR 0101 の前後比較。変更前は 49fbb72f77（PR #1670 のブランチ）、変更後は 784bb70d16。

## 結論
- **設置モードに入る遷移は 211〜220ms → 16〜19ms（2回目以降）、1回目は 251 → 42ms。出る遷移は 69〜74ms → 8〜10ms。**（実測、本番の遷移の流れ）
- 遷移のほぼすべてがプレビュー表示（`PlaceBlockPreviewDisplay.OnEnter`）で、その中身は全ブロックの矢印（`PreviewOnlyObject`）を半径に関係なく有効にする処理だった。
- プレイヤーが動いたときの半径の再評価（1m ごと）は、1回あたり平均 0.27 → 0.35ms、p99 2.4 → 3.5ms と少し増えた。半径に出入りする部品を有効・無効にするようになったため。

## 計測環境
Windows（Unity Editor PlayMode、Debug）、ベースラインワールド `2026-10-22-world_1`（15,082ブロック、プレイヤー半径 20m 内は 177ブロック）。

## 結果
### 設置モードの出入り（実測、ms、`../benchmark/run-buildmode-entry.sh`）
入る（1回目）・出る・入る・出る… の順。

| | 入る | 出る |
|---|---|---|
| 変更前 | **251**・218・219・220・211 | 74・69・73・72 |
| 変更後 | **42**・16・17・16・19 | 10・8・8・9 |

遷移の中の `GameObject.ActivateAwakeRecursively`（Profiler の self）は、変更前 175〜176ms、変更後 2.7〜7.0ms。変更後の1回目の 42ms には、設置プレビューのプレハブの初回生成（`Instantiate.Produce` 15ms）が入る。

生データ: `../benchmark/results/2026-11-14T2249_before-preview-radius_buildmode.txt`、`../benchmark/results/2026-11-14T2246_after-preview-radius_buildmode.txt`

### 変更前の遷移の中身（実測）
- 遷移を作る処理ごとの時間（`../benchmark/snippets/buildmode-enter-breakdown.cs`）: プレビュー表示 177ms、前の画面を閉じる処理・カメラの設定・状態変更の通知は合わせて 1ms 未満。
- 入ったときに新しく有効になる Transform: 矢印 41,059、枠の辺 4,425、歯車の接続線 44。
- 部品の種類ごとの有効化（`../benchmark/snippets/placement-preview-activation-cost.cs`）: 矢印 15,243個の有効化 126ms・無効化 54ms、歯車の接続線 1,841個 3.0ms、搬入出口の線 225個 0.3ms。全ブロックをたどって隠す指示をもう一度出すだけで 19ms。
- 歯車の接続線は `SetEnableRenderers(false)` が `SetActive(false)` なので、半径外では「有効にしてすぐ無効に戻す」ことになっていた。

### 作り方の比較（スニペットで本番と同じ部品への指示を再現、各5回の中央値、`../benchmark/snippets/buildmode-entry-variants.cs`）
| 作り方 | 入る |
|---|---:|
| 今の作り（半径に関係なく全部を有効にする） | 172.4ms |
| 矢印だけ半径内で有効にする | 43.9ms |
| 矢印と歯車の接続線を半径内だけにする | 27.3ms |
| さらに、半径外の隠れた矢印・歯車の線・枠の借り口への呼び出しを省く | 14.1ms |
| 全部品を半径内だけにし、半径外のブロックには何も呼ばない（採用） | 6.5ms |
| 同じことを半径内のブロックの一覧だけを回ってやる | 6.4ms |

再現は1回の呼び出しの中で続けて起こしたもので、本番の遷移の流れ（上の表）とは数値が一致しない。採用した形の本番の値は上の表の 16〜19ms。

### 半径の再評価（移動中の負担、実測、`run-radius-move-cost.sh`）
設置モード中に、プレビュー半径の判定の中心をプレイヤー位置から全ブロックの中心へ 1m ずつ 300m ずらし、1回ごとの時間を測った（プレイヤーが歩くと 1m ごとに同じ再評価が走る）。

| | 合計 | 平均 | p50 | p90 | p99 | 最大 |
|---|---:|---:|---:|---:|---:|---:|
| 変更前 | 80.3ms | 0.268ms | 0.134 | 0.515 | 2.355 | 3.046 |
| 変更後 | 104.7ms | 0.349ms | 0.148 | 0.799 | 3.458 | 3.723 |

生データ: `radius-move-cost.txt`

## テスト
Windows のバッチモードで、関連テスト 72件（`BlockPreviewOnlyObjectsView`・`PlaceBlockPreviewDisplay`・照準・八分木・設置の入口ほか）がすべて通った。

## 推測（未確認）
- 変更後の遷移に残る 16〜19ms の中身は分けて測っていない。再現の内訳（変更前の測定から）では、半径内 177ブロックぶんの枠の辺の貸し出しと部品の有効化が大半と見ている。
