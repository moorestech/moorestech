# UITK 段階 4 部品「進捗」（C4-b） Implementation Plan

> **For the controller session (実装を担うsubagentはこのブロックを無視してよい):** このplanの実行は moores-subagent-driven-development スキルが担う。実行モード（規模ゲート未満の単一subagent実装モード／閾値超のタスクごと派遣）は同スキルの規模ゲートに従って決める。ステップはチェックボックス（`- [ ]`）記法で書く。

**Goal:** Web 版 `shared/ui` の進捗の 3 部品（`BarSeries`・`ProgressArrowGlyph`・`ProgressArrowBar`）を、Web と同じ見た目の UITK 部品として `Client.Ui/Components/Gauges/` に作り、Web の vitest を写した L0・L1、部品ギャラリーの見本、参照キャプチャとの並べ比べ（720p・2560×1080）まで済ませて `feature/uitk` へ取り込む。

**Architecture:** 3 部品ともドメインを知らない `VisualElement` 派生で、値は `float`（0..1）か `float?` で受ける。`BarSeries` と `ProgressArrowBar` は `GaugeBar`（C2-c）と同じ「溝の面＋内周の線の子＋充填の子」の写し方で、Web の CSS module 1 枚を USS 1 枚へ写す。`ProgressArrowGlyph` は Web の inline SVG の 3 層（溝・充填・輪郭）と drop-shadow を、viewBox を `xMidYMid meet` で当てはめた箱の中の子要素 4 枚（影・溝・充填の切り抜き・輪郭）で写し、path は Painter2D、drop-shadow のにじみは輪郭をずらした輪の頂点カラー（Linear 合成用に α 補正）で描く。充填の切り抜きは Web の `clipPath` の矩形と同じ x=2〜2+117×値 の `overflow: hidden` の要素で、静止表示（Web の `value=null`）は状態クラス `--idle` で切り抜きごと隠す。

**Tech Stack:** Unity 6000.3.8f1 UI Toolkit（ランタイムパネル・USS カスタムプロパティ・Painter2D・`MeshGenerationContext.Allocate`）、NUnit＋`com.unity.ui.test-framework`（`UiTestHost`）、uloop CLI、ffmpeg（参照の切り抜き）、node（トークン生成器）、gh CLI、bd（Beads）

- **パスの略記**: `S/` = `moorestech_client/Assets/Scripts/`、`W/` = `moorestech_web/webui/src/`。Files 節と各コマンドはリポジトリ相対の完全なパスで書く
- **正本**: 裁定 `.decisions/2026-11-06-UITK*.md`、統合計画 `origin/master:docs/uitk-migration/plan.md`、設計書 `docs/uitk-migration/execution/component-architecture.md`（§2.1・§2.5・§3・§4.3・§7.1。この計画で A-85〜A-89 を足す）、実行計画 `docs/uitk-migration/execution/execution-plan.md`（レーン C4-b の行・§4.3・§6）。食い違ったら 裁定 → 統合計画 → 設計書 → 実行計画 → この計画 の順で上が勝つ

```csharp
using UnityEngine.UIElements;

namespace Client.Ui.Components.Gauges
{
    /// <summary>
    /// 0〜1 を幅で満たす帯状の進捗ゲージ（Web の shared/ui/ProgressArrowBar。名前に反して矢印形ではない）
    /// Bar-shaped progress gauge filled by width (Web shared/ui/ProgressArrowBar; not arrow-shaped despite the name)
    /// </summary>
    public sealed class ProgressArrowBar : VisualElement
    {
        // Web の部品が固定で付ける testid。液体の行と採掘機が同じ名前で照準する
        // The testid the Web component hard-codes; the fluid row and the miner aim at the same name
        private const string FixedTestid = "progress-arrow-bar";

        private readonly VisualElement _fill;

        public ProgressArrowBar()
        {
            name = FixedTestid;
            pickingMode = PickingMode.Ignore;
            AddToClassList("progress-arrow-bar");

            // 線は充填より先に置き、充填が内側の線を覆う Web の重なりにそろえる
            // The outline goes before the fill so the fill covers the inset line, matching the Web layering
            var outline = new VisualElement { pickingMode = PickingMode.Ignore };
            outline.AddToClassList("progress-arrow-bar__outline");
            Add(outline);
            _fill = new VisualElement { pickingMode = PickingMode.Ignore };
            _fill.AddToClassList("progress-arrow-bar__fill");
            Add(_fill);

            SetValue(0f);
        }

        public void SetValue(float ratio01)
        {
            _fill.style.width = Length.Percent(GaugeRatio.Clamp01(ratio01) * 100f);
        }
    }
}
```

```csharp
using System.Collections.Generic;
using UnityEngine.UIElements;

namespace Client.Ui.Components.Gauges
{
    /// <summary>
    /// 0〜1 の値を古い順に縦棒で並べる読み取り専用の時系列（Web の shared/ui/BarSeries）。null の棒は溝だけ
    /// Read-only time series of zero-to-one values as vertical bars, oldest first (Web shared/ui/BarSeries); a null bar draws only its track
    /// </summary>
    public sealed class BarSeries : VisualElement
    {
        private const string BarClassName = "bar-series__bar";
        private const string LeadingBarClassName = "bar-series__bar--leading";
        private const string EmptyBarClassName = "bar-series__bar--empty";

        private readonly List<VisualElement> _bars = new();
        private readonly List<VisualElement> _fills = new();

        public BarSeries(string testid)
        {
            name = testid;
            pickingMode = PickingMode.Ignore;
            AddToClassList("bar-series");
        }

        public void SetValues(IReadOnlyList<float?> ratios01)
        {
            // 棒の数を値の数にそろえてから、古い順に左から高さを当てる（Web は values.map で毎回作り直す）
            // Match the bar count to the values, then set heights left to right, oldest first (the Web rebuilds through values.map)
            while (_bars.Count < ratios01.Count) AddBar();
            while (ratios01.Count < _bars.Count) RemoveLastBar();
            for (var i = 0; i < ratios01.Count; i++)
            {
                var ratio = ratios01[i];
                _bars[i].EnableInClassList(EmptyBarClassName, !ratio.HasValue);
                _fills[i].style.height = Length.Percent(ClampedRatio(ratio) * 100f);
            }

            #region Internal

            void AddBar()
            {
                // 先頭の棒だけ隙間を持たない（USS に gap が無いので左の margin で写す）
                // Only the leading bar has no gap (USS lacks gap, so the left margin carries it)
                var bar = NewPart(BarClassName);
                bar.EnableInClassList(LeadingBarClassName, _bars.Count == 0);

                // 線は充填より先に置き、充填が内側の線を覆う Web の重なりにそろえる
                // The outline goes before the fill so the fill covers the inset line, matching the Web layering
                bar.Add(NewPart("bar-series__bar-outline"));
                var fill = NewPart("bar-series__bar-fill");
                bar.Add(fill);
                Add(bar);
                _bars.Add(bar);
                _fills.Add(fill);
            }

            void RemoveLastBar()
            {
                var last = _bars.Count - 1;
                _bars[last].RemoveFromHierarchy();
                _bars.RemoveAt(last);
                _fills.RemoveAt(last);
            }

            // null は溝だけなので 0、値は NaN と範囲外を 0..1 へ丸める（Web の index.tsx の式）
            // Null draws only the track so it is 0; values clamp NaN and out-of-range to 0..1 (the Web index.tsx expression)
            float ClampedRatio(float? ratio)
            {
                return ratio.HasValue ? GaugeRatio.Clamp01(ratio.Value) : 0f;
            }

            VisualElement NewPart(string className)
            {
                var part = new VisualElement { pickingMode = PickingMode.Ignore };
                part.AddToClassList(className);
                return part;
            }

            #endregion
        }
```

```csharp
using UnityEngine;
using UnityEngine.UIElements;

namespace Client.Ui.Components.Gauges
{
    /// <summary>
    /// Web の矢印の SVG path（M2 27H69V2L119 39L69 76V51H2Z・viewBox 121×78）の頂点と当てはめ・ずらし
    /// Vertices, fitting and offsetting of the Web arrow SVG path (M2 27H69V2L119 39L69 76V51H2Z, viewBox 121x78)
    /// </summary>
    internal static class ProgressArrowGlyphPath
    {
        public const float ViewBoxWidth = 121f;
        public const float ViewBoxHeight = 78f;
        public const float ArrowLeft = 2f;
        public const float ArrowRight = 119f;
        public const float ArrowSpan = ArrowRight - ArrowLeft;
        public const int VertexCount = 7;
        public const int FillTriangleIndexCount = 9;

        // path の頂点を画面座標（y 下向き）の時計回りに並べる（Web の ARROW_PATH と同じ順）
        // Path vertices clockwise in screen space (y down), in the Web ARROW_PATH order
        private static readonly Vector2[] Vertices = { new(2f, 27f), new(69f, 27f), new(69f, 2f), new(119f, 39f), new(69f, 76f), new(69f, 51f), new(2f, 51f) };

        // 軸の長方形 2 枚と先端の三角 1 枚。ずらしても x=69 の 4 頂点が一直線に並び続けるので有効なまま
        // Two shaft triangles and the head; the four x=69 vertices stay collinear under offsetting, so they remain valid
        private static readonly ushort[] FillTriangles = { 0, 1, 5, 0, 5, 6, 2, 3, 4 };

        public static ushort FillTriangleIndexAt(int position)
        {
            return FillTriangles[position];
        }

        // SVG の既定 preserveAspectRatio（xMidYMid meet）の倍率
        // The scale of the SVG default preserveAspectRatio (xMidYMid meet)
        public static float ScaleOf(Vector2 size)
        {
            return Mathf.Min(size.x / ViewBoxWidth, size.y / ViewBoxHeight);
        }

        public static Rect FitViewBox(Vector2 size)
        {
            var scale = ScaleOf(size);
            var width = ViewBoxWidth * scale;
            var height = ViewBoxHeight * scale;
            return new Rect((size.x - width) / 2f, (size.y - height) / 2f, width, height);
        }

        // 倍率を掛けた path を Painter2D に閉じた多角形として描き込む（塗りと輪郭が共有する）
        // Trace the scaled path into Painter2D as a closed polygon (shared by fill and outline)
        public static void Trace(Painter2D painter, float scale)
        {
            painter.BeginPath();
            painter.MoveTo(Vertices[0] * scale);
            for (var i = 1; i < VertexCount; i++) painter.LineTo(Vertices[i] * scale);
            painter.ClosePath();
        }

        public static void WriteOffset(float scale, float distance, Vector2 shift, Vector2[] destination)
        {
            // 各頂点を前後の辺の外向き法線の和の向きへ、辺が distance だけ平行に動く長さ（miter）で動かす
            // Move each vertex along the sum of its two edges' outward normals by the miter length that shifts each edge by distance
            for (var i = 0; i < VertexCount; i++)
            {
                var incoming = OutwardNormal(Vertices[(i + VertexCount - 1) % VertexCount], Vertices[i]);
                var outgoing = OutwardNormal(Vertices[i], Vertices[(i + 1) % VertexCount]);
                var miter = (incoming + outgoing) / (1f + Vector2.Dot(incoming, outgoing));
                destination[i] = Vertices[i] * scale + miter * distance + shift;
            }

            #region Internal

            // 時計回り（y 下向き）の辺の外側は進む向きを左へ 90° 回した側
            // For a clockwise edge in y-down space the outside is the direction rotated 90 degrees to the left
            Vector2 OutwardNormal(Vector2 from, Vector2 to)
            {
                var edge = (to - from).normalized;
                return new Vector2(edge.y, -edge.x);
            }

            #endregion
        }
    }
```

```csharp
using UnityEngine;

namespace Client.Ui.Components.Gauges
{
    /// <summary>
    /// ガウスでぼかした形の、縁から符号付き距離（外が正）の点の被覆率 Φ(-d/σ)
    /// Coverage Φ(-d/σ) of a Gaussian-blurred shape at a signed distance from its edge (outside positive)
    /// </summary>
    /// <remarks>
    /// CSS の drop-shadow の第 3 値は標準偏差 σ そのもの（Filter Effects 1 の等価 SVG は feGaussianBlur stdDeviation=radius。box-shadow の σ=ぼかし/2 とは違う）。直線の縁の被覆率はその累積分布になる。
    /// erf は Abramowitz-Stegun 7.1.26（誤差 1.5e-7）で、8 bit の α には十分。
    /// The third CSS drop-shadow value is σ itself (the Filter Effects 1 SVG equivalent is feGaussianBlur stdDeviation=radius, unlike box-shadow's σ = blur/2); coverage across a straight edge is its cumulative distribution.
    /// erf uses Abramowitz-Stegun 7.1.26 (error 1.5e-7), ample for an 8-bit alpha.
    /// </remarks>
    internal static class GaussianEdgeCoverage
    {
        public static float At(float signedDistance, float sigma)
        {
            var z = signedDistance / (sigma * Mathf.Sqrt(2f));
            return 0.5f * (1f - Erf(z));

            #region Internal

            float Erf(float x)
            {
                var magnitude = Mathf.Abs(x);
                var t = 1f / (1f + 0.3275911f * magnitude);
                var polynomial = t * (0.254829592f + t * (-0.284496736f + t * (1.421413741f + t * (-1.453152027f + t * 1.061405429f))));
                var positive = 1f - polynomial * Mathf.Exp(-magnitude * magnitude);
                return x < 0f ? -positive : positive;
            }

            #endregion
        }
    }
}
```

```csharp
using Client.Ui.Components.Panels;
using UnityEngine;
using UnityEngine.UIElements;

namespace Client.Ui.Components.Gauges
{
    /// <summary>
    /// 矢印の drop-shadow を、線の外縁を下へずらした縁の内外 2σ を刻む輪の頂点カラーのメッシュとして組む
    /// Builds the arrow drop-shadow as a vertex-colored mesh of rings spanning 2σ inside and outside the stroke's outer edge shifted down
    /// </summary>
    /// <remarks>
    /// 輪 0（内端）の内側は芯として輪 0 の濃さで塗る。輪 k は縁からの距離 (2k/8-1)·2σ にあり、濃さは Web の α に被覆率を掛けて
    /// GamePanelFaceOpacityRamp.OpacityAt で Linear 合成用に補正する。8 段は GamePanelFace の SegmentsPerFade と同じ刻み。
    /// The inside of ring 0 (inner end) fills as the core at ring 0's alpha. Ring k sits at (2k/8-1)·2σ from the edge; its alpha multiplies the Web alpha by coverage
    /// and is corrected for Linear blending through GamePanelFaceOpacityRamp.OpacityAt. Eight steps match GamePanelFace.SegmentsPerFade.
    /// </remarks>
    internal static class ProgressArrowGlyphShadowMesh
    {
        public const int RingCount = 8;
        public const int VertexCount = (RingCount + 1) * ProgressArrowGlyphPath.VertexCount;
        public const int IndexCount = ProgressArrowGlyphPath.FillTriangleIndexCount + RingCount * ProgressArrowGlyphPath.VertexCount * 6;

        // にじみを刻む幅（片側 2σ で被覆率は 2.3% まで落ちる）
        // Span of the blur on each side (coverage falls to 2.3% at 2σ)
        private const float SigmaSpan = 2f;

        public static void Build(float scale, float silhouetteOutset, float offsetY, float blur, Color shadowColor, Vertex[] vertices, ushort[] indices)
        {
            // drop-shadow のぼかしは標準偏差そのもの（box-shadow の半分ではない）
            // A drop-shadow blur is the standard deviation itself (not half of it as in box-shadow)
            var sigma = blur;
            var ring = new Vector2[ProgressArrowGlyphPath.VertexCount];
            WriteRingVertices();
            var cursor = 0;
            WriteCore();
            WriteBands();

            #region Internal

            // 輪ごとに縁からの距離で形をずらし、その距離の被覆率から濃さを決める
            // Offset the shape by each ring's distance from the edge and derive its alpha from the coverage there
            void WriteRingVertices()
            {
                for (var k = 0; k <= RingCount; k++)
                {
                    var fromEdge = (2f * k / RingCount - 1f) * SigmaSpan * sigma;
                    ProgressArrowGlyphPath.WriteOffset(scale, silhouetteOutset + fromEdge, new Vector2(0f, offsetY), ring);
                    var tint = shadowColor;
                    tint.a = GamePanelFaceOpacityRamp.OpacityAt(shadowColor.a, GaussianEdgeCoverage.At(fromEdge, sigma));
                    for (var corner = 0; corner < ring.Length; corner++)
                        vertices[k * ring.Length + corner] = new Vertex { position = new Vector3(ring[corner].x, ring[corner].y, Vertex.nearZ), tint = tint };
                }
            }

            void WriteCore()
            {
                for (var i = 0; i < ProgressArrowGlyphPath.FillTriangleIndexCount; i += 3)
                    WriteClockwise(ProgressArrowGlyphPath.FillTriangleIndexAt(i), ProgressArrowGlyphPath.FillTriangleIndexAt(i + 1), ProgressArrowGlyphPath.FillTriangleIndexAt(i + 2));
            }

            // 隣り合う輪の同じ辺を四角で結ぶ
            // Join the same edge of neighbouring rings with a quad
            void WriteBands()
            {
                var corners = ProgressArrowGlyphPath.VertexCount;
                for (var k = 0; k < RingCount; k++)
                for (var corner = 0; corner < corners; corner++)
                {
                    var innerFrom = (ushort)(k * corners + corner);
                    var innerTo = (ushort)(k * corners + (corner + 1) % corners);
                    var outerFrom = (ushort)(innerFrom + corners);
                    var outerTo = (ushort)(innerTo + corners);
                    WriteClockwise(innerFrom, outerTo, innerTo);
                    WriteClockwise(innerFrom, outerFrom, outerTo);
                }
            }

            // 画面座標（y 下向き）で時計回りになる順に入れ替えて書く（GamePanelFace と同じ向き）
            // Write in the order that winds clockwise in screen space (y down), the same as GamePanelFace
            void WriteClockwise(ushort a, ushort b, ushort c)
            {
                var pa = vertices[a].position;
                var pb = vertices[b].position;
                var pc = vertices[c].position;
                var clockwise = (pb.x - pa.x) * (pc.y - pa.y) - (pb.y - pa.y) * (pc.x - pa.x) > 0f;
                indices[cursor++] = a;
                indices[cursor++] = clockwise ? b : c;
                indices[cursor++] = clockwise ? c : b;
            }

            #endregion
        }
    }
}
```

```csharp
    /// 矢印の drop-shadow の層。線の外縁を影の形として、ずらしてにじませた輪のメッシュを描く（設計書 A-88）
    /// Drop-shadow layer of the arrow; draws the shifted, blurred ring mesh using the stroke's outer edge as the shadow shape (design A-88)

    {
        private const string ShadowColorProperty = "--progress-arrow-glyph-layer-shadow";
        private const string OffsetYProperty = "--progress-arrow-glyph-layer-shadow-offset-y";
        private const string BlurProperty = "--progress-arrow-glyph-layer-shadow-blur";
        private const string StrokeWidthProperty = "--progress-arrow-glyph-layer-stroke-width";

        private readonly Vertex[] _vertices = new Vertex[ProgressArrowGlyphShadowMesh.VertexCount];
        private readonly ushort[] _indices = new ushort[ProgressArrowGlyphShadowMesh.IndexCount];
        private Color _shadowColor;
        private float _offsetY;
        private float _blur;
        private float _strokeWidth;
        private bool _hasStyle;

        public ProgressArrowGlyphShadow()
        {
            AddToClassList("progress-arrow-glyph__shadow");
            pickingMode = PickingMode.Ignore;
            generateVisualContent += DrawShadow;
            RegisterCallback<CustomStyleResolvedEvent>(_ => OnCustomStyleResolved());
            RegisterCallback<GeometryChangedEvent>(_ => MarkDirtyRepaint());
        }

        private void OnCustomStyleResolved()
        {
            var hasColor = UssCustomStyleReader.TryReadColor(customStyle, ShadowColorProperty, out _shadowColor);
            var hasOffset = UssCustomStyleReader.TryReadPixels(customStyle, OffsetYProperty, out _offsetY);
            var hasBlur = UssCustomStyleReader.TryReadPixels(customStyle, BlurProperty, out _blur);
            var hasWidth = UssCustomStyleReader.TryReadPixels(customStyle, StrokeWidthProperty, out _strokeWidth);
            _hasStyle = hasColor && hasOffset && hasBlur && hasWidth;

            // ぼかし 0 は σ=0 で輪が潰れるので描かない（Web の値は 1px。0 にした USS の誤りを知らせる）
            // A zero blur collapses the rings at σ=0, so skip drawing (the Web value is 1px; report the USS mistake)
            if (_hasStyle && _blur <= 0f)
            {
                Debug.LogError($"[ProgressArrowGlyphShadow] {BlurProperty} must be positive but was {_blur}px; the shadow is not drawn");
                _hasStyle = false;
            }
            MarkDirtyRepaint();
        }

        private void DrawShadow(MeshGenerationContext context)
        {
            // silent-ok: 値の解決前と寸法 0（非表示・配置前）は描かない / 値は UssCustomStyleReader と上の LogError が知らせ、寸法のつまみの誤りは L1 の寸法テストと並べ比べが捕まえる
            // silent-ok: draw nothing before values resolve or at size 0 (hidden, pre-layout) / UssCustomStyleReader and the LogError above report values; L1 size tests and the comparison catch wrong size knobs
            var scale = ProgressArrowGlyphPath.ScaleOf(contentRect.size);

            // 影の形は線の外縁（線幅の半分だけ外）。ずれとぼかしは CSS の px のままで viewBox の倍率を掛けない
            // The shadow shape is the stroke's outer edge (half the width outside); offset and blur stay in CSS px, unscaled by the viewBox
            ProgressArrowGlyphShadowMesh.Build(scale, _strokeWidth * scale / 2f, _offsetY, _blur, _shadowColor, _vertices, _indices);
            var mesh = context.Allocate(_vertices.Length, _indices.Length);
            mesh.SetAllVertices(_vertices);
            mesh.SetAllIndices(_indices);
        }
```

```csharp
    /// </summary>
    /// <remarks>
    /// 作った直後は静止表示（Web の value=null。充填層を持たない）。SetProgress(0) は幅 0 の充填を持つ進捗で静止とは別。
    /// 寸法は --craft-arrow-width/height を部品だけが持ち、viewBox 121×78 を SVG 既定の xMidYMid meet で当てはめる。
    /// Starts in the static form (Web value=null, no fill layer); SetProgress(0) is progress with a zero-width fill, distinct from static.
    /// Only the component holds the --craft-arrow-width/height size and fits the 121x78 viewBox with the SVG default xMidYMid meet.
    /// </remarks>
    public sealed class ProgressArrowGlyph : VisualElement
    {
        private const string IdleClassName = "progress-arrow-glyph--idle";

        private readonly VisualElement _viewBox;
        private readonly VisualElement _fillClip;
        private readonly ProgressArrowGlyphFace _fill;

        public ProgressArrowGlyph(string testid)
        {
            name = testid;
            pickingMode = PickingMode.Ignore;
            AddToClassList("progress-arrow-glyph");

            // Web の SVG と同じ順に重ねる: 影（filter）→ 溝 → 充填の切り抜き → 切り抜きの外の輪郭
            // Stack in the Web SVG order: shadow (filter), track, the fill clip, then the outline outside the clip
            _viewBox = NewPart("progress-arrow-glyph__view-box");
            Add(_viewBox);
            _viewBox.Add(new ProgressArrowGlyphShadow());
            _viewBox.Add(new ProgressArrowGlyphFace("progress-arrow-glyph__track"));
            _fillClip = NewPart("progress-arrow-glyph__fill-clip");
            _fillClip.style.left = Length.Percent(ProgressArrowGlyphPath.ArrowLeft / ProgressArrowGlyphPath.ViewBoxWidth * 100f);
            _viewBox.Add(_fillClip);
            _fill = new ProgressArrowGlyphFace("progress-arrow-glyph__fill");
            _fillClip.Add(_fill);
            _viewBox.Add(new ProgressArrowGlyphOutline());

            RegisterCallback<GeometryChangedEvent>(_ => FitViewBox());
            SetIdle();
        }

        public void SetProgress(float ratio01)
        {
            // Web の clipPath の rect（x=2・幅 117×値）を、viewBox の幅に対する % の切り抜きで写す
            // Copy the Web clipPath rect (x=2, width 117 times value) as a clip in percent of the viewBox width
            var clamped = GaugeRatio.Clamp01(ratio01);
            _fillClip.style.width = Length.Percent(ProgressArrowGlyphPath.ArrowSpan * clamped / ProgressArrowGlyphPath.ViewBoxWidth * 100f);
            RemoveFromClassList(IdleClassName);
        }

        public void SetIdle()
        {
            AddToClassList(IdleClassName);
        }

        private void FitViewBox()
        {
            // NaN と負の寸法はトークンの誤りなので知らせる
            // NaN or negative sizes are token mistakes, so report them
            var size = contentRect.size;
            if (float.IsNaN(size.x) || float.IsNaN(size.y) || size.x < 0f || size.y < 0f)
            {
                Debug.LogError($"[ProgressArrowGlyph] {name} has an invalid size {size}; the arrow is not fitted");
                return;
            }

            // silent-ok: 非表示の祖先の下と配置前は寸法 0 なので当てはめない / 寸法のつまみの誤りは L1 の寸法テストと並べ比べが捕まえる（前例 DeleteModeWarningBand）
            // silent-ok: a hidden ancestor or pre-layout gives size 0, so skip fitting / L1 size tests and the comparison catch wrong size knobs (precedent DeleteModeWarningBand)
            if (size.x <= 0f || size.y <= 0f) return;
            var box = ProgressArrowGlyphPath.FitViewBox(size);

            // 箱を xMidYMid meet の位置に置き、切り抜きの中の充填の面を viewBox の原点と幅にそろえる
            // Place the box at the xMidYMid meet position and align the fill face inside the clip to the viewBox origin and width
            _viewBox.style.left = box.x;
            _viewBox.style.top = box.y;
            _viewBox.style.width = box.width;
            _viewBox.style.height = box.height;
            _fill.style.left = -ProgressArrowGlyphPath.ArrowLeft * box.width / ProgressArrowGlyphPath.ViewBoxWidth;
            _fill.style.width = box.width;
        }

        private static VisualElement NewPart(string className)
        {
            var part = new VisualElement { pickingMode = PickingMode.Ignore };
            part.AddToClassList(className);
            return part;
        }
```

- **D-18（動き）**: 進捗の変化に transition を付けない。理由: Web §8.13「進捗はアニメーションを付けない」、CSS module にも transition が無い
- **D-19（ジオメトリの当てはめ）**: viewBox の箱の位置と充填の面の左と幅は、ルートの `GeometryChangedEvent` で C# が px で当てる。切り抜きの左と幅は % で持つ（寸法に依らない）。理由: `xMidYMid meet` の倍率は幅と高さの小さい方で決まり、USS の % では表せない。切り抜きを % にしておくと `SetProgress` が寸法の決まる前でも正しい
- **D-20（祖先の上書きのプローブ）**: テスト用の `.gauge-knob-probe` は、既定とも充填の白とも違う色（充填 `--bevel-c1`・溝 `--color-content-primary`）と、既定と違う寸法（矢印は既定のちょうど 2 倍）を当てる。理由: `ProgressArrowGlyph` の充填が `--gauge-fill` に従わないことを、上書きした値と白が同じだと確かめられない。2 倍は viewBox の倍率の検算を簡単にする
- **D-21（出し入れ）**: `ProgressArrowBar` は値なし（Web の `progress == null` で描かない）の状態を持たず、出し入れは使い手が行う。理由: Web の部品も値なしを知らず、使い手（`FluidSlotRow`）が条件で描く。C4-a の `FluidSlotRow.ClearProgress()` が持つ
- **D-22（層の値の解決の畳み方）**: 層は読んだ値の可否を `_hasStyle` 1 つに畳み、影はぼかし 0 以下も LogError を出したうえで同じ偽に畳む。理由: 前例 `IconButtonCloseGlyph`・`GamePanelFace` と同じ形で、読めない値は `UssCustomStyleReader`、ぼかし 0 はその場の LogError が名前を出すので、畳んでも誰がどこで気づくかは失われない（出所: 設計検査 Phase 2.6 5-C→指揮の agent 既定）
- **D-23（同じ導出を 1 本に）**: NaN を 0 にして 0..1 へ丸める式は Gauges の internal `GaugeRatio.Clamp01` 1 本にし、このレーンの 3 部品と既存の `GaugeBar.SetValue`（`GaugeBar.cs:44` の同じ式を 1 行置き換え、`GaugeBarTest` が緑のままを確かめる）が使う（Web の `W/shared/clamp01.ts` 1 本に対応）。viewBox の倍率は `ProgressArrowGlyphPath.ScaleOf`、path の組み立ては `ProgressArrowGlyphPath.Trace` の 1 本だけが持ち、層は呼ぶだけ。理由: 同じ導出が散ると、Web が丸め方や path を変えたときに 1 か所だけ追従し損ねる。C2-c はマージ済みで W3 で `Gauges/` を書くのは C4-b だけなので所有の衝突が無く、`GaugeBar` を据え置くとこの PR 自身が二重化を作る（出所: 設計検査 Phase 2.6 検査6・user-simulator→指揮の agent 既定）
- **D-24（影の α の前提の検査）**: `OpacityAt` の前提（影のトークンの α が暗い色の式で補正済み）を、生成器の式の行に加えて L0（`ProgressArrowGlyphShadowMeshTest`「影の色のトークンは暗い色の式でWebのα045へ逆に解ける」）でも確かめる。Task 7 で α を実測で選び直して式の行を `uss` 固定に替えても、この L0 が残る。理由: 式の行だけが前提を守る形だと、選び直した後に前提を確かめるものが消える（出所: 設計検査 Phase 2.6 5-E→指揮の agent 既定）
- **D-25（寸法 0 の当てはめ）**: `ProgressArrowGlyph.FitViewBox` は寸法 0 を `silent-ok:` で飛ばし、LogError は NaN と負の寸法（トークンの誤り）だけに出す。理由: 使い手（機械の加工行・`RecipeRow`）が祖先を `display: none` で閉じると寸法 0 の `GeometryChangedEvent` が来うるので、LogError だと閉じるたびに Error が出て使い手の L1 を落とす。前例 `DeleteModeWarningBand` も寸法 0 を黙って描かない。表示に戻すと次の `GeometryChangedEvent` で当てはめ直すことを L1 で確かめる（出所: 独立評価→指揮の agent 既定）
- **D-26（影の σ）**: 影のぼかし 1px を標準偏差 σ そのものとして扱う（`sigma = blur`）。理由: CSS の `filter: drop-shadow()` の第 3 値は Filter Effects 1 で等価 SVG の feGaussianBlur stdDeviation=radius と定義され、σ＝ぼかし/2 になるのは box-shadow（CSS Backgrounds の blur radius）のほう。σ を半分にすると縁から 1px 外の被覆率が Web の 0.158655 から 0.022750 に落ち、影が細く硬くなる（出所: 独立評価→指揮の agent 既定）
- **D-27（テストの画素の丸め）**: L1 の寸法の比較は、トークンとの比較を 0.5px、丸めた箱から導いた子（viewBox・切り抜き・充填の面・層）を 1px まで許し、導いた値の期待は部品ごとに（並べた 2 本でも別々に）、その部品が実際に受けた丸め後の `contentRect` から `ProgressArrowGlyphPath.FitViewBox`／`ScaleOf` で計算する。端数そのもの（% の切り抜き・viewBox の `style.width`／`style.left`）は丸め前の style で 1e-3 まで一致を見る。理由: `UiTestHost` は倍率 1 でレイアウトを整数 px に丸める（前例 `SlotFrameLookTest`「51.68 が 52」・`SlotGridTest` の許容差 1・台帳 LX-42）。トークンの端数（53.622×30.53）から出した期待を 0.05px で比べると正しい実装でも落ちる（出所: 独立評価→指揮の agent 既定）
