# UITK 段階 4 部品「スロット族 2: 液体」（C4-a） Implementation Plan

> **For the controller session (実装を担うsubagentはこのブロックを無視してよい):** このplanの実行は moores-subagent-driven-development スキルが担う。実行モード（規模ゲート未満の単一subagent実装モード／閾値超のタスクごと派遣）は同スキルの規模ゲートに従って決める。ステップはチェックボックス（`- [ ]`）記法で書く。

**Goal:** Web 版の液体のスロット族（`shared/ui/FluidSlot`・`FluidAmountSlot`・`FluidSlotRow`）を、Web と同じ見た目の UITK 部品として `Client.Ui/Components/Slots/Fluid/` に作り、液体の背面の色を Content 層（`GameContentPresentation.FluidFace`）に足し、液体マスタの色の形式をサーバーのマスタのロード時検証（`FluidMasterUtil.Validate`）に足して、L0・L1・部品ギャラリー・参照キャプチャとの並べ比べ（720p・2560×1080）まで済ませて `feature/uitk` へ取り込む。

**Architecture:** 部品はドメインを知らない `VisualElement` 派生で、液体の絵は `UiIcon`、量は `double`、中身は判別 union の `FluidSlotContent`（空・ゴースト・中身の sealed 派生。各派生は自分に要る値だけを持ち、null をモードに使わない）で受ける。液体の色は必須で、形式（`#RRGGBB`）はマスタのロード時に検証して起動で止めるので、描く側は色の欠けを扱わない。ID → `UiIcon`・色の解決は Content の `GameContentPresentation` 1 か所（設計書 A-4・A-53）。`FluidSlot` は Web と同じく SlotFrame を使わない暗い四角（Mantine の dark-4 の線・dark-8 の面）に、下から量の割合で液体の色を満たすフィル・絵・白字に黒縁の量を重ねる。`FluidAmountSlot` は C3-a の `SlotFrame`（白面）＋`SlotContent`（絵）に、白縁の黒字の量の帯を足す。量の縁はどちらも C3-a の `OutlinedCountLabel`（縁だけの Label を後ろに敷く 2 層）を使い、黒縁のために縁の色のつまみ `--outlined-count-label-stroke` を 1 つ足す。`FluidSlotRow` は C2-c の `UiGroup(UiGap.Xs)` に `FluidSlot` を並べ、C4-b の `ProgressArrowBar` を末尾に出し入れする。

**Tech Stack:** Unity 6000.3.8f1 UI Toolkit（ランタイムパネル・USS カスタムプロパティ）、UniRx、NUnit＋`com.unity.ui.test-framework`（`UiTestHost`）、uloop CLI、ffmpeg（参照の切り抜き）、gh CLI、bd（Beads）

- **パスの略記**: `S/` = `moorestech_client/Assets/Scripts/`、`W/` = `moorestech_web/webui/src/`。Files 節と各コマンドはリポジトリ相対の完全なパスで書く
- **正本**: 裁定 `.decisions/2026-11-06-UITK*.md`、統合計画 `docs/uitk-migration/plan.md`、設計書 `docs/uitk-migration/execution/component-architecture.md`（§2.1・§2.3・§3・§4.3・§7.1。この計画で A-95〜A-99 を足す。末尾の「設計書・実行計画へ反映する行」）、実行計画 `docs/uitk-migration/execution/execution-plan.md`（レーン C4-a の行・§4.3・§6）。食い違ったら 裁定 → 統合計画 → 設計書 → 実行計画 → この計画 の順で上が勝つ
- **ゴール（ユーザーの原文）**: 「WebUIと同じ見た目で、適切な設計、コンポーネント化されたUITKベースのUIを開発すること」

```csharp
using System;

namespace Client.Ui.Components.Slots
{
    /// <summary>
    /// 量と容量からフィルの割合 0..1 を出す（Web の fillRatio と clamp01）
    /// Fill ratio 0..1 from amount and capacity (the Web fillRatio and clamp01)
    /// </summary>
    internal static class FluidFillRatio
    {
        public static float Of(double amount, double capacity)
        {
            // 容量 0 以下は 0、NaN は 0、範囲外は 0..1 へ丸める
            // Capacity at or below 0 gives 0, NaN gives 0, and out-of-range values clamp to 0..1
            if (capacity <= 0) return 0f;
            var ratio = amount / capacity;
            // silent-ok: Web の clamp01 と同じく数でない割合は空のフィルとして描く。容量はサーバーの FluidContainer が有限で 0 以上に保つ（D-18）ので割合が NaN になるのは量が NaN のときだけ / そのとき同じマスの量の字が SlotAmountFormat で "NaN" と出て、プレイテストの画面で気づく
            if (double.IsNaN(ratio)) return 0f;
            return (float)Math.Clamp(ratio, 0d, 1d);
        }
    }
```

```csharp
using System;
using Client.Ui.Foundation.Icons;
using Client.Ui.Foundation.Text;
using Client.Ui.Foundation.Tooltip;
using Client.Ui.State.Text;
using UnityEngine.UIElements;

namespace Client.Ui.Components.Slots
{
    /// <summary>
    /// 液体 1 マス。背面のフィル・絵・量・名前のツールチップ（Web の FluidSlot）
    /// One fluid cell: back fill, picture, amount and name tooltip (the Web FluidSlot)
    /// </summary>
    public sealed class FluidSlot : VisualElement
    {
        private const string FillShownStateClass = "fluid-slot--fill-shown";
        private const string AmountShownStateClass = "fluid-slot--amount-shown";
        private const string GhostStateClass = "fluid-slot--ghost";

        private readonly VisualElement _fill;
        private readonly GameIcon _icon;
        private readonly OutlinedCountLabel _amount;

        public FluidSlot(string testid)
        {
            name = testid;
            AddToClassList("fluid-slot");

            // フィル → 絵 → 量の順に重ね、量を最前面に残す（Web の子の順）
            // Stack fill, picture, then amount so the amount stays frontmost (the Web child order)
            _fill = new VisualElement { pickingMode = PickingMode.Ignore };
            _fill.AddToClassList("fluid-slot__fill");
            Add(_fill);
            _icon = new GameIcon();
            _icon.AddToClassList("fluid-slot__icon");
            Add(_icon);

            // 量は白字に黒縁（Web の .iconTextOutlineDark）。縁の色は置き場のクラスがつまみで黒にする
            // The amount is white with a dark outline (the Web .iconTextOutlineDark); the placement class turns the outline knob black
            _amount = new OutlinedCountLabel(this, "fluid-slot__amount", UiTypographyClass.TextBold);
        }

        public void SetFluid(FluidSlotContent content)
        {
            switch (content)
            {
                case EmptyFluidSlotContent:
                    ShowEmpty();
                    break;
                case GhostFluidSlotContent ghost:
                    ShowGhost(ghost);
                    break;
                case FilledFluidSlotContent filled:
                    ShowFilled(filled);
                    break;
                default:
                    throw new ArgumentOutOfRangeException(nameof(content), content.GetType().Name, "FluidSlotContent subtypes are closed; a new one must be drawn here");
            }

            #region Internal

            void ShowEmpty()
            {
                // 空タンクは素の枠だけ。ツールチップの印も外す（Web は Tooltip ごと描かない）
                // An empty tank is the bare frame only; the tooltip mark goes too (the Web renders no Tooltip)
                EnableInClassList(GhostStateClass, false);
                EnableInClassList(FillShownStateClass, false);
                EnableInClassList(AmountShownStateClass, false);
                _icon.ClearIcon();
                HoverTooltipMark.Unmark(this);
            }

            void ShowGhost(GhostFluidSlotContent ghost)
            {
                // フィル無しで絵と必要量だけを透かす
                // Fade only the picture and required amount, without a fill
                EnableInClassList(GhostStateClass, true);
                EnableInClassList(FillShownStateClass, false);
                ShowPictureAndAmount(ghost.Icon, ghost.Amount);
            }

            void ShowFilled(FilledFluidSlotContent filled)
            {
                // 高さと色は Web と同じく動的な値をインラインで当てる
                // Height and color are dynamic values applied inline, as on the Web
                EnableInClassList(GhostStateClass, false);
                EnableInClassList(FillShownStateClass, true);
                _fill.style.height = Length.Percent(FluidFillRatio.Of(filled.Amount, filled.Capacity) * 100f);
                _fill.style.backgroundColor = filled.Face;
                ShowPictureAndAmount(filled.Icon, filled.Amount);
            }

            void ShowPictureAndAmount(UiIcon icon, double amount)
            {
                // 絵が欠けたら何も代わりに出さない（フィルが残るので。Web の fallback none）
                // A missing picture shows no substitute, since the fill remains (the Web fallback none)
                _icon.SetIcon(icon, GameIconFallback.None);
                _amount.SetText(UiText.FromVerbatim(SlotAmountFormat.Format(amount)));
                EnableInClassList(AmountShownStateClass, true);
                HoverTooltipMark.Mark(this, icon.Label);
            }

            #endregion
        }
    }
}
```

```csharp
using System;
using Client.Ui.Foundation.Icons;
using Client.Ui.Foundation.Text;
using Client.Ui.Foundation.Tooltip;
using Client.Ui.State.Text;

namespace Client.Ui.Components.Slots

    /// <summary>
    /// 容量の無い液体 1 マス。アイテムと同じ白面の枠に絵と量の帯（Web の FluidAmountSlot）
    /// One capacity-less fluid cell: the item's white frame with a picture and an amount band (the Web FluidAmountSlot)
    /// </summary>
    public sealed class FluidAmountSlot : VisualElement
    {
        private readonly SlotFrame _frame;
        private readonly SlotContent _content;
        private readonly VisualElement _amountBand;
        private readonly OutlinedCountLabel _amount;

        public IObservable<SlotGesture> OnSlotGestured => _frame.OnSlotGestured;

        public FluidAmountSlot(string frameTestid)
        {
            // testid・印・ポインタは Web と同じく枠が持つ
            // The frame owns the testid, mark and pointer, as on the Web
            pickingMode = PickingMode.Ignore;
            AddToClassList("fluid-amount-slot");
            _frame = new SlotFrame(frameTestid);
            _content = new SlotContent();
            _frame.Add(_content);
            Add(_frame);

            // 量の帯は枠幅の右寄せで、testid を持つので出さないときは木から外す（Web は要素ごと描かない）
            // The amount band is right-aligned across the frame and carries a testid, so it leaves the tree when hidden (the Web renders nothing)
            _amountBand = new VisualElement { name = frameTestid + "-amount", pickingMode = PickingMode.Ignore };
            _amountBand.AddToClassList("fluid-amount-slot__amount");
            _amount = new OutlinedCountLabel(_amountBand, "fluid-amount-slot__amount-layer", UiTypographyClass.TextMedium);
        }

        public void SetFluid(UiIcon icon, SlotAmountBadge badge)
        {
            if (icon == null) throw new ArgumentNullException(nameof(icon), "FluidAmountSlot always shows a fluid; the screen must not pass an empty one");

            // 白面は常に中身あり（液体の絵は必ずあり、欠けても名前の文字を描く）
            // The white face always has content (a fluid picture always exists, and a missing one draws the name)
            _frame.SetState(new SlotFrameState(false, true, false, false, false));
            _content.SetIcon(icon, GameIconFallback.Label);
            HoverTooltipMark.Mark(_frame, icon.Label);
            ApplyBadge();

            #region Internal

            void ApplyBadge()
            {
                if (!(badge is ShownSlotAmountBadge shown))
                {
                    _amountBand.RemoveFromHierarchy();
                    return;
                }
                _amount.SetText(UiText.FromVerbatim(SlotAmountFormat.Format(shown.Amount)));
                if (_amountBand.parent == null) _frame.Add(_amountBand);
            }

            #endregion
        }
    }
}
```

```csharp
using System.Collections.Generic;
using Client.Ui.Components.Gauges;
using Client.Ui.Foundation.Layout;
using UnityEngine.UIElements;

namespace Client.Ui.Components.Slots
{
    /// <summary>
    /// 液体のマスの横並びと任意の進捗の矢印（Web の FluidSlotRow）
    /// A row of fluid cells with an optional progress arrow (the Web FluidSlotRow)
    /// </summary>
    public sealed class FluidSlotRow : VisualElement
    {
        // Web の FluidSlot が固定で付ける testid
        // The testid the Web FluidSlot always sets
        private const string SlotTestid = "fluid-slot";
        private const string EmptyStateClass = "fluid-slot-row--empty";

        private readonly UiGroup _group;
        private readonly List<FluidSlot> _slots = new();
        private readonly ProgressArrowBar _progress;
        private bool _progressShown;

        public FluidSlotRow(string testid)
        {
            name = testid;
            pickingMode = PickingMode.Ignore;
            AddToClassList("fluid-slot-row");
            AddToClassList(EmptyStateClass);
            _group = new UiGroup(UiGap.Xs);
            Add(_group);
            _progress = new ProgressArrowBar();
            _group.AddItem(_progress);
            _group.SetItemShown(_progress, false);
        }

        public void SetFluids(IReadOnlyList<FluidSlotContent> fluids)
        {
            // 位置ごとにマスを使い回し、足りなければ足し余れば外す（Web の key=i）
            // Reuse cells by position, adding or removing the difference (the Web key=i)
            ResizeSlots(fluids.Count);
            for (var i = 0; i < fluids.Count; i++) _slots[i].SetFluid(fluids[i]);
            EnableInClassList(EmptyStateClass, fluids.Count == 0);

            #region Internal

            void ResizeSlots(int count)
            {
                // マスの数が同じなら矢印を入れ直さない（量の通知ごとの再取り付けを避ける）
                // Skip re-adding the arrow when the cell count is unchanged
                if (_slots.Count == count) return;
                while (_slots.Count > count)
                {
                    _slots[_slots.Count - 1].RemoveFromHierarchy();
                    _slots.RemoveAt(_slots.Count - 1);
                }
                while (_slots.Count < count)
                {
                    var slot = new FluidSlot(SlotTestid);
                    _slots.Add(slot);
                    _group.AddItem(slot);
                }
                // 足したマスの後ろへ矢印を戻す（AddItem の再追加は末尾へ移す）
                // Move the arrow back after added cells (re-adding moves it to the end)
                _group.AddItem(_progress);
                _group.SetItemShown(_progress, _progressShown);
            }

            #endregion
        }

        public void SetProgress(float ratio01)
        {
            _progress.SetValue(ratio01);
            _progressShown = true;
            _group.SetItemShown(_progress, true);
        }

        public void ClearProgress()
        {
            _progressShown = false;
            _group.SetItemShown(_progress, false);
        }
    }
}
```

- **D-7（色の解析の置き場）**: マスタの `color`（string）→ `Color` の解析は Content の `GameContentPresentation.FluidFace` の中で `ColorUtility.TryParseHtmlString` を呼ぶ。理由: 部品はマスタを知らない（層の向き）。形式の検証はサーバーのロード時にある（D-15）ので、ここの失敗は検証の穴で、黙って黒や白に倒さず例外で止める
