# UITK 段階 4 部品「ノードグラフ」（C4-d） Implementation Plan

> **For the controller session (実装を担うsubagentはこのブロックを無視してよい):** このplanの実行は moores-subagent-driven-development スキルが担う。実行モード（規模ゲート未満の単一subagent実装モード／閾値超のタスクごと派遣）は同スキルの規模ゲートに従って決める。ステップはチェックボックス（`- [ ]`）記法で書く。

**Goal:** Web 版 `shared/treeView`（研究ツリーとチャレンジ一覧のパン・ズーム・慣性つきのノードグラフ）を、Web と同じ見た目と操作感の UITK 部品 `NodeGraphView` として `Client.Ui/Components/NodeGraph/` に作り、Web のテスト 29 件（部品 17・純ロジック 12）を写した L0・L1、部品ギャラリーの見本、参照キャプチャとの並べ比べ（720p・2560×1080）まで済ませて `feature/uitk` へ取り込む。

**Architecture:** `NodeGraphView` はドメインを知らない `VisualElement` 派生で、ノードは「キー・Y 上向きのツリー座標・親のキー列・画面が作ったカードの `VisualElement`」の値の列（`NodeGraphContent`）で受ける。ビューポート（`overflow: hidden`）の中のキャンバス 1 枚に `style.translate`／`style.scale`（`transform-origin: 0 0`）を当ててパン・ズームし、線は Painter2D の 1 層（ノードの下）、ノードはキャンバス座標の点に置いた包みの子にカードを入れる。押下の分類は Foundation の `UiPressGesture`、滑走は Foundation の `UiInertiaAnimation`（閉じた式・1 次元を方向ベクトルに載せる）、速度はポインタ事象の時刻から Web と同じ式で平滑する。ビューポートのセッション内の保持は画面の State（`Client.Ui.State/<機能>/Session/`）が持ち、部品は変化を `OnViewportChanged` で流し、作り直した直後の `RestoreViewport` で受け取る（Web のモジュールの Map とキーの代わり。前例 `GameScrollView.OnScrollOffsetChanged`／`SetScrollOffset` と `BuildMenuSessionStore`）。

**Tech Stack:** Unity 6000.3.8f1 UI Toolkit（ランタイムパネル・USS カスタムプロパティ・Painter2D・`style.translate`/`style.scale`）、UniRx、NUnit＋`com.unity.ui.test-framework`（`UiTestHost`・`simulate`）、uloop CLI、ffmpeg（参照の切り抜き）、gh CLI、bd（Beads）

- **パスの略記**: `S/` = `moorestech_client/Assets/Scripts/`、`W/` = `moorestech_web/webui/src/`。Files 節と各コマンドはリポジトリ相対の完全なパスで書く
- **正本**: 裁定 `.decisions/2026-11-06-UITK*.md`、統合計画 `origin/master:docs/uitk-migration/plan.md`、設計書 `docs/uitk-migration/execution/component-architecture.md`（§2.7 のノードグラフの行・§2.8・§3・§4.3・§7.1。この計画で A-115〜A-119 を足した）、実行計画 `docs/uitk-migration/execution/execution-plan.md`（レーン C4-d の行・§4.3・§6）。食い違ったら 裁定 → 統合計画 → 設計書 → 実行計画 → この計画 の順で上が勝つ
- **ゴール（ユーザーの原文）**: 「WebUIと同じ見た目で、適切な設計、コンポーネント化されたUITKベースのUIを開発すること」

```csharp
using System.Collections.Generic;
using UnityEngine;

namespace Client.Ui.Components.NodeGraph
{
    /// <summary>
    /// ツリー座標（Y 上向き）とキャンバス座標（Y 下向き）の写像。web: moorestech_web/webui/src/shared/treeView/treeGeometry.ts
    /// Mapping between tree coordinates (Y up) and canvas coordinates (Y down); web: moorestech_web/webui/src/shared/treeView/treeGeometry.ts
    /// </summary>
    internal static class NodeGraphGeometry
    {
        // Web の TreeView.tsx が境界に渡す余白（computeTreeCanvasBounds(..., 200)）
        // The padding the Web TreeView.tsx passes to the bounds (computeTreeCanvasBounds(..., 200))
        public const float CanvasPadding = 200f;

        public static NodeGraphCanvasBounds ComputeCanvasBounds(IReadOnlyList<Vector2> treePositions, float padding)
        {
            // ノードが無ければ余白だけの正方形
            // With no nodes the canvas is the padding square alone
            if (treePositions.Count == 0) return new NodeGraphCanvasBounds(padding * 2f, padding * 2f, padding, padding);

            var min = treePositions[0];
            var max = treePositions[0];
            foreach (var position in treePositions)
            {
                min = Vector2.Min(min, position);
                max = Vector2.Max(max, position);
            }

            // 上端は Y の最大（Y を下向きへ裏返す）
            // The top edge is the largest Y (Y is flipped downward)
            return new NodeGraphCanvasBounds(max.x - min.x + padding * 2f, max.y - min.y + padding * 2f, padding - min.x, max.y + padding);
        }

        public static Vector2 ToCanvasPoint(Vector2 treePoint, NodeGraphCanvasBounds bounds)
        {
            return new Vector2(treePoint.x + bounds.OffsetX, bounds.OffsetY - treePoint.y);
        }

        public static NodeGraphLine LineBetween(Vector2 from, Vector2 to)
        {
            var delta = to - from;
            return new NodeGraphLine(from, delta.magnitude, Mathf.Atan2(delta.y, delta.x) * Mathf.Rad2Deg);
        }
    }
}
```

```csharp
        // Web の MIN_VIEW_SCALE・MAX_VIEW_SCALE・WHEEL_ZOOM_SENSITIVITY

        {
            // 倍率を指数で動かし、カーソルの下のワールドの点を固定する
            // Move the scale exponentially and keep the world point under the cursor fixed
            var scale = Mathf.Clamp(viewport.Scale * Mathf.Exp(-webDeltaY * WheelZoomSensitivity), MinScale, MaxScale);
```

```csharp
using UnityEngine;

namespace Client.Ui.Components.NodeGraph
{
    /// <summary>
    /// パンの慣性の定数と速度の計算（速度は px/ms）。web: moorestech_web/webui/src/shared/treeView/viewport/viewport.ts
    /// Pan inertia constants and velocity math (px/ms); web: moorestech_web/webui/src/shared/treeView/viewport/viewport.ts
    /// </summary>
    /// <remarks>
    /// τ=325ms は iOS 系のスクロールの減衰の標準値。上限 3px/ms で最大の滑走は 3×325≒975px（Web のコメントのまま）
    /// τ=325 ms is the standard iOS-style decay; the 3 px/ms cap bounds the glide at 3×325≒975 px (as the Web comment says)
    /// </remarks>
    internal static class NodeGraphPanVelocity
    {
        public const float FrictionTauMs = 325f;
        public const float MinFlingSpeed = 0.15f;
        public const float StopSpeed = 0.01f;
        public const float MaxFlingSpeed = 3f;
        public const long SampleMaxGapMs = 80;
        public const long ReleaseStallMs = 80;
        public const float SmoothingTauMs = 50f;

        public static Vector2 Blend(Vector2 velocity, Vector2 delta, float dtMs)
        {
            // 直近の標本で速度を平滑し、急停止の外れ値を均す
            // Smooth the velocity with the latest sample to even out sudden-stop outliers
            var alpha = 1f - Mathf.Exp(-dtMs / SmoothingTauMs);
            return velocity + (delta / dtMs - velocity) * alpha;
        }

        public static Vector2 Clamp(Vector2 velocity)
        {
            var speed = velocity.magnitude;
            if (speed <= MaxFlingSpeed) return velocity;
            return velocity * (MaxFlingSpeed / speed);
        }

        public static UiInertiaAnimation CreateGlide(float speed, IUiInertiaStep step)
        {
            // 減衰率は 1/τ。両軸とも同じ τ なので向きは変わらず、速さ 1 本の閉じた式で写せる（D-6）
            // The decay rate is 1/τ; both axes share τ, so the direction never changes and one closed-form speed suffices (D-6)
            // look-exception: LX-87
            return new UiInertiaAnimation(speed, 1f / FrictionTauMs, StopSpeed, step);
        }
    }
}
```

```csharp
using UnityEngine;

namespace Client.Ui.Components.NodeGraph
{
    /// <summary>
    /// ドラッグ中の速度を追い、離したときに滑走するかを決める。web: moorestech_web/webui/src/shared/treeView/viewport/usePanInertia.ts の trackMove・release
    /// Tracks drag velocity and decides on release whether to glide; web: trackMove and release in moorestech_web/webui/src/shared/treeView/viewport/usePanInertia.ts
    /// </summary>
    internal sealed class NodeGraphPanInertiaTracker
    {
        private Vector2 _velocity;
        private long _lastMoveAtMs;
        private bool _hasLastMove;

        public void Reset()
        {
            _velocity = Vector2.zero;
            _hasLastMove = false;
        }

        public void TrackMove(Vector2 delta, long nowMs)
        {
            // 同じフレームの 2 つ目の移動（間隔 0）は標本にせず速度を保つ（D-7）
            // A second move in the same frame (zero gap) is not a sample and keeps the velocity (D-7)
            if (_hasLastMove && nowMs == _lastMoveAtMs) return;

            // 最初の標本・逆行・80ms 超の間隔は速度を作らない（Web と同じ）
            // The first sample, a backward clock or a gap over 80 ms builds no velocity (same as the Web)
            var hadLastMove = _hasLastMove;
            var gapMs = nowMs - _lastMoveAtMs;
            _lastMoveAtMs = nowMs;
            _hasLastMove = true;
            if (!hadLastMove || gapMs < 0 || gapMs > NodeGraphPanVelocity.SampleMaxGapMs)
            {
                _velocity = Vector2.zero;
                return;
            }
            _velocity = NodeGraphPanVelocity.Blend(_velocity, delta, gapMs);
        }

        public bool TryStartFling(long releasedAtMs, out Vector2 velocity)
        {
            // 止まってから離した・遅すぎる速度は滑走させない
            // No glide after holding still before release, or below the fling speed
            velocity = NodeGraphPanVelocity.Clamp(_velocity);
            if (!_hasLastMove || releasedAtMs - _lastMoveAtMs > NodeGraphPanVelocity.ReleaseStallMs) return false;
            return velocity.magnitude >= NodeGraphPanVelocity.MinFlingSpeed;
        }
    }
}
```

```csharp
using System;
using System.Collections.Generic;
using Client.Ui.Foundation.Theme;
using UnityEngine;
using UnityEngine.UIElements;

namespace Client.Ui.Components.NodeGraph
{
    /// <summary>
    /// ノードの間の線を Painter2D で描く層（キャンバスを覆い、ノードの下に置く）。web: TreeView.module.css の .line
    /// Layer that strokes the lines between nodes with Painter2D (covers the canvas, sits below the nodes); web: .line in TreeView.module.css
    /// </summary>
    internal sealed class NodeGraphEdgeLayer : VisualElement
    {
        private const string EdgeColorProperty = "--node-graph-edge-color";
        private const string EdgeWidthProperty = "--node-graph-edge-width";

        private IReadOnlyList<NodeGraphLine> _lines = Array.Empty<NodeGraphLine>();
        private Color _edgeColor;
        private float _edgeWidth;
        private bool _hasStroke;

        public NodeGraphEdgeLayer()
        {
            AddToClassList("node-graph__edges");
            pickingMode = PickingMode.Ignore;
            generateVisualContent += DrawEdges;
            RegisterCallback<CustomStyleResolvedEvent>(OnCustomStyleResolved);
        }

        public void SetLines(IReadOnlyList<NodeGraphLine> lines)
        {
            _lines = lines;
            MarkDirtyRepaint();
        }

        public static Vector2 StrokeStart(NodeGraphLine line, float width)
        {
            // Web の線は高さ w の帯を左端の中央（transform-origin: 0 50%）で回すので、中心線は点から w/2 下を通る（A-117）
            // The Web line is a w-tall band rotated about its left-middle (transform-origin: 0 50%), so the center line runs w/2 below the point (A-117)
            return line.Origin + new Vector2(0f, width / 2f);
        }

        private void OnCustomStyleResolved(CustomStyleResolvedEvent evt)
        {
            // 読めなくなったときも描き直し、前回の線を残さない。読めない名前は UssCustomStyleReader が LogError で出す
            // Repaint even when unreadable so stale lines never linger; UssCustomStyleReader logs any unresolved name
            var hasColor = UssCustomStyleReader.TryReadColor(customStyle, EdgeColorProperty, out _edgeColor);
            var hasWidth = UssCustomStyleReader.TryReadPixels(customStyle, EdgeWidthProperty, out _edgeWidth);
            _hasStroke = hasColor && hasWidth;
            MarkDirtyRepaint();
        }

        private void DrawEdges(MeshGenerationContext context)
        {
            // silent-ok: 色と太さの解決前は描かない / 解決できなければ UssCustomStyleReader が LogError を出す
            if (!_hasStroke) return;

            // 端は平ら（Web の帯の端と同じ）で、全部の線を 1 本のパスにまとめて描く
            // Butt ends (like the Web band ends); all lines go into one path
            var painter = context.painter2D;
            painter.strokeColor = _edgeColor;
            painter.lineWidth = _edgeWidth;
            painter.lineCap = LineCap.Butt;
            painter.BeginPath();
            foreach (var line in _lines)
            {
                var start = StrokeStart(line, _edgeWidth);
                var radians = line.AngleDegrees * Mathf.Deg2Rad;
                painter.MoveTo(start);
                painter.LineTo(start + new Vector2(Mathf.Cos(radians), Mathf.Sin(radians)) * line.Length);
            }
            painter.Stroke();
        }
    }
}
```

```csharp
        private readonly Dictionary<VisualElement, string> _keyByWrapper = new();
        private NodeGraphCanvasBounds _bounds;

        public NodeGraphScene(VisualElement canvas)
        {
            _canvas = canvas;
            _canvas.Add(_edgeLayer);
            ApplyBounds(NodeGraphGeometry.ComputeCanvasBounds(Array.Empty<Vector2>(), NodeGraphGeometry.CanvasPadding));
        }

        public bool HasNodes => _keyByWrapper.Count > 0;

        public void Rebuild(IReadOnlyList<NodeGraphNode> nodes)
        {
            // 前回の包みを外し、重なったキーを除いた列で境界を決める
            // Remove the previous wrappers and size the canvas from the nodes without duplicate keys
            foreach (var wrapper in _keyByWrapper.Keys) wrapper.RemoveFromHierarchy();
            _keyByWrapper.Clear();
            var placedNodes = new List<NodeGraphNode>();
            var nodeByKey = IndexByKey();
            var positions = new List<Vector2>();
            foreach (var node in placedNodes) positions.Add(node.TreePosition);
            ApplyBounds(NodeGraphGeometry.ComputeCanvasBounds(positions, NodeGraphGeometry.CanvasPadding));

            // 線を先（下）、ノードを後（上）に入力の順で置く。z-index は使わず子の順で決める
            // Lines first (below), then nodes (above) in input order; child order decides, never z-index
            _edgeLayer.SetLines(BuildLines());
            foreach (var node in placedNodes) AddWrapper(node);

            #region Internal

            Dictionary<string, NodeGraphNode> IndexByKey()
            {
                // 重なったキーは後のノードを置かず開発者へ知らせる（Web は黙って上書きする。A-117）
                // A duplicate key drops the later node and tells the developer (the Web overwrites silently; A-117)
                var index = new Dictionary<string, NodeGraphNode>();
                foreach (var node in nodes)
                {
                    if (index.TryAdd(node.Key, node))
                    {
                        placedNodes.Add(node);
                        continue;
                    }
                    Debug.LogError($"[NodeGraphView] duplicate node key '{node.Key}' is not placed");
                }
                return index;
            }

            List<NodeGraphLine> BuildLines()
            {
                // 線は子の点を始点に親の点へ向かう。グラフに無い親は描かずに知らせる（Web は黙って飛ばす。A-117）
                // A line runs from the child point to the parent point; a parent missing from the graph is not drawn and is reported (the Web skips silently; A-117)
                var lines = new List<NodeGraphLine>();
                foreach (var node in placedNodes)
                {
                    foreach (var previousKey in node.PreviousKeys)
                    {
                        if (!nodeByKey.TryGetValue(previousKey, out var previous))
                        {
                            Debug.LogError($"[NodeGraphView] node '{node.Key}' refers to missing previous key '{previousKey}'; the line is not drawn");
                            continue;
                        }
                        lines.Add(NodeGraphGeometry.LineBetween(ToCanvasPoint(node.TreePosition), ToCanvasPoint(previous.TreePosition)));
                    }
                }
                return lines;
            }

            void AddWrapper(NodeGraphNode node)
            {
                // 包みは点に置く幅 0 の要素。拾わず、中のカードが押下を受ける
                // The wrapper is a zero-size element at the point; it does not pick, and the card inside receives presses
                var point = ToCanvasPoint(node.TreePosition);
                var wrapper = new VisualElement { pickingMode = PickingMode.Ignore };
                wrapper.AddToClassList("node-graph__node");
                wrapper.style.left = point.x;
                wrapper.style.top = point.y;
                wrapper.Add(node.Card);
                _canvas.Add(wrapper);
                _keyByWrapper.Add(wrapper, node.Key);
            }

            #endregion
        }

        public Vector2 ToCanvasPoint(Vector2 treePoint)
        {
            return NodeGraphGeometry.ToCanvasPoint(treePoint, _bounds);
        }

        public bool TryFindNodeKey(VisualElement pressTarget, out string key)
        {
            // 押下の対象から親を辿り、最初に見つかった包みのキーを返す（Web の closest）
            // Walk up from the press target and return the first wrapper's key (the Web closest)
            for (var current = pressTarget; current != null && current != _canvas; current = current.parent)
            {
                if (_keyByWrapper.TryGetValue(current, out key)) return true;
            }
            key = null;
            return false;
        }

        private void ApplyBounds(NodeGraphCanvasBounds bounds)
        {
            _bounds = bounds;
            _canvas.style.width = bounds.Width;
            _canvas.style.height = bounds.Height;
        }
    }
}
```

```csharp
using Client.Ui.Foundation.Motion.Playback;
using UnityEngine;
using UnityEngine.UIElements;

namespace Client.Ui.Components.NodeGraph
{
    /// <summary>
    /// ビューポートの押下を分類してパン・タップ・滑走にする。web: moorestech_web/webui/src/shared/treeView/useTreePanGesture.ts と viewport/usePanInertia.ts
    /// Classifies viewport presses into pan, tap and glide; web: useTreePanGesture.ts and viewport/usePanInertia.ts
    /// </summary>
    /// <remarks>
    /// UiPressMove は時刻を持たないので、ポインタ事象の時刻を UiPressGesture より先に登録した受け手で記録して速度に使う（A-116）
    /// UiPressMove carries no time, so pointer event timestamps are recorded by callbacks registered before UiPressGesture and used for velocity (A-116)
    /// </remarks>
    internal sealed class NodeGraphPanController : IUiPressGestureHandler
    {
        private readonly NodeGraphView _view;
        private readonly NodeGraphPanInertiaTracker _tracker = new();
        private UiMotionHandle _glide;
        private long _lastPointerTimestamp;

        public NodeGraphPanController(NodeGraphView view)
        {
            _view = view;

            // 同じ要素の同じ相の受け手は登録順に走るので、記録と滑走の停止を先に登録する
            // Callbacks on the same element and phase run in registration order, so recording and glide stop go first
            view.RegisterCallback<PointerDownEvent>(OnAnyPointerDown);
            view.RegisterCallback<PointerMoveEvent>(evt => _lastPointerTimestamp = evt.timestamp);
            view.RegisterCallback<PointerUpEvent>(evt => _lastPointerTimestamp = evt.timestamp);
            new UiPressGesture(view, this);
        }

        public void CancelGlide()
        {
            // silent-ok: 滑走していなければ止めるものが無い / 正常系で知らせる相手はいない
            if (_glide == null) return;
            _glide.Cancel();
            _glide = null;
        }

        public void OnPressStarted(Vector2 panelPosition)
        {
            _tracker.Reset();
        }

        public void OnDragMoved(UiPressMove move)
        {
            // 座標はパネル px（＝ビューポートの局所の px）なので、そのまま速度とパンに使う
            // Coordinates are panel px (= viewport-local px), so they feed velocity and pan as-is
            _tracker.TrackMove(move.SinceLast, _lastPointerTimestamp);
            _view.PanBy(move.SinceLast);
        }

        public void OnDragEnded(Vector2 panelPosition)
        {
            // silent-ok: 止まってから離した・遅い回は Web と同じく滑走しない / 正常系で知らせる相手はいない
            if (!_tracker.TryStartFling(_lastPointerTimestamp, out var velocity)) return;
            _glide = UiMotionPlayer.Play(_view, NodeGraphPanVelocity.CreateGlide(velocity.magnitude, new NodeGraphGlideStep(_view, velocity.normalized)));
        }

        public void OnTapped(VisualElement pressTarget)
        {
            _view.TapAt(pressTarget);
        }

        public void OnAborted(bool dragged)
        {
            // 取消・捕捉の喪失はドラッグ済みでも滑走させない
            // A cancel or lost capture never glides, even after dragging
            _tracker.Reset();
            CancelGlide();
        }

        private void OnAnyPointerDown(PointerDownEvent evt)
        {
            // 押下は受理の可否（右ボタン・第 2 ポインタ）によらず滑走を止める（Web の onPointerDown の包み）
            // Any press stops the glide whether or not it is accepted (right button, second pointer), like the Web onPointerDown wrapper
            _lastPointerTimestamp = evt.timestamp;
            CancelGlide();
        }
    }
}
```

```csharp
using System;
using Client.Ui.Foundation.Theme;
using UniRx;
using UnityEngine;
using UnityEngine.UIElements;

namespace Client.Ui.Components.NodeGraph
{
    /// <summary>
    /// パン・ズーム・慣性つきのノードグラフ（研究ツリー・チャレンジ一覧）。web: moorestech_web/webui/src/shared/treeView/TreeView.tsx
    /// Node graph with pan, zoom and inertia (research tree, challenge list); web: moorestech_web/webui/src/shared/treeView/TreeView.tsx
    /// </summary>
    /// <remarks>
    /// ビューポートの保持は画面が持つ。変化は OnViewportChanged で流し、作り直した直後に RestoreViewport で戻すと初回の中央寄せと寸法の追従をしない
    /// The screen keeps the viewport; changes flow out on OnViewportChanged, and RestoreViewport right after rebuilding skips initial centering and resize-follow
    /// </remarks>
    public sealed class NodeGraphView : VisualElement
    {
        // Web のホイール 1 ノッチの deltaY（CefUnity の ScrollInputPipeline.WheelPixelsPerStep。GameScrollView と同じ値。A-118）
        // The Web deltaY per wheel notch (CefUnity ScrollInputPipeline.WheelPixelsPerStep; same as GameScrollView; A-118)
        private const float WebWheelDeltaPerNotch = 60f;
        private const string ClipInsetProperty = "--node-graph-clip-inset";

        private readonly VisualElement _canvas;
        private readonly NodeGraphScene _scene;
        private readonly NodeGraphPanController _pan;
        private readonly Subject<string> _onNodeTapped = new();
        private readonly Subject<NodeGraphViewport> _onViewportChanged = new();
        private bool _restored;
        private NodeGraphViewport _viewport;
        private NodeGraphFocus _initialFocus = NodeGraphFocus.None;
        private bool _hasCentered;
        private bool _hasClipInset;
        private float _clipInset;
        private Vector2 _lastContentSize;

        public IObservable<string> OnNodeTapped => _onNodeTapped;
        public IObservable<NodeGraphViewport> OnViewportChanged => _onViewportChanged;

        public NodeGraphView(string testIdPrefix)
        {
            // 根とキャンバスと線・ノードの場面を作る
            // Build the root, the canvas and the edge/node scene
            name = $"{testIdPrefix}-viewport";
            AddToClassList("node-graph");
            _canvas = new VisualElement { name = $"{testIdPrefix}-canvas" };
            _canvas.AddToClassList("node-graph__canvas");
            Add(_canvas);
            _scene = new NodeGraphScene(_canvas);
            _viewport = NodeGraphViewport.Identity;
            ApplyViewport();

            // 押下とパンは Foundation の UiPressGesture、ホイール・寸法・つまみは自分で受ける
            // Press and pan go through Foundation UiPressGesture; wheel, size and knobs are handled here
            _pan = new NodeGraphPanController(this);
            RegisterCallback<WheelEvent>(OnWheel);
            RegisterCallback<GeometryChangedEvent>(OnGeometryChanged);
            RegisterCallback<CustomStyleResolvedEvent>(OnCustomStyleResolved);
        }

        public void SetGraph(NodeGraphContent content)
        {
            _scene.Rebuild(content.Nodes);
            _initialFocus = content.InitialFocus;
            CenterOnInitialFocusOnce();
        }

        public void RestoreViewport(NodeGraphViewport viewport)
        {
            // 画面が保持した値へ戻し、以後の初回の中央寄せと寸法の追従を止める。戻した値は流さない（Web のマウント時の復元と同じ）
            // Return to the screen-held value and stop initial centering and resize-follow; the restored value is not emitted (same as the Web mount restore)
            _restored = true;
            _viewport = viewport;
            ApplyViewport();
        }

        internal void PanBy(Vector2 delta)
        {
            SetViewport(new NodeGraphViewport(_viewport.X + delta.x, _viewport.Y + delta.y, _viewport.Scale));
        }

        internal void TapAt(VisualElement pressTarget)
        {
            // silent-ok: ノードの外の押下は Web と同じく何も選ばない / 押下の対象にノードが無いだけで異常ではない
            if (!_scene.TryFindNodeKey(pressTarget, out var key)) return;
            _onNodeTapped.OnNext(key);
        }

        private void OnWheel(WheelEvent evt)
        {
            // 祖先のスクロールへ渡さず、滑走を止める（Web の preventDefault と inertia.cancel）
            // Keep it from ancestor scrolling and stop the glide (the Web preventDefault and inertia.cancel)
            evt.StopPropagation();
            _pan.CancelGlide();

            // カーソルを内容 box の座標へ直し、1 ノッチを Web の deltaY 60 へ換算してズームする（横成分は無視）
            // Convert the cursor to content-box coordinates, scale one notch to the Web deltaY 60, and zoom (horizontal ignored)
            var cursor = this.WorldToLocal(evt.mousePosition) - contentRect.position;
            var webDeltaY = evt.delta.y * WebWheelDeltaPerNotch / WheelEvent.scrollDeltaPerTick;
            SetViewport(NodeGraphViewportMath.ZoomAt(_viewport, cursor, webDeltaY));
        }

        private void OnGeometryChanged(GeometryChangedEvent evt)
        {
            // 復元しなかったときだけ、寸法の変化で中央に見えていた点を保つ（0 からの初回は動かさない。Web useKeepViewCenterOnResize）
            // Only when not restored, keep the centered point across size changes (not from zero; the Web useKeepViewCenterOnResize)
            var size = contentRect.size;
            // silent-ok: 0 へ縮む回（display: none の祖先）は追従も記録もしない / 開き直した寸法で次の回から追従する
            if (size.x <= 0f || size.y <= 0f) return;
            var keepsCenter = !_restored && _hasClipInset && _lastContentSize.x > 0f && _lastContentSize.y > 0f && size != _lastContentSize;
            if (keepsCenter) SetViewport(NodeGraphViewportMath.ShiftForResize(_viewport, _lastContentSize, size));
            if (_hasClipInset) _lastContentSize = size;
            CenterOnInitialFocusOnce();
        }

        private void OnCustomStyleResolved(CustomStyleResolvedEvent evt)
        {
            // silent-ok: 読めなければ前回の逃げのまま / UssCustomStyleReader が LogError を出す
            if (!UssCustomStyleReader.TryReadPixels(customStyle, ClipInsetProperty, out var inset)) return;
            // silent-ok: 同じ値なら書き直さず、style の再解決の繰り返しを起こさない / 正常系
            if (_hasClipInset && Mathf.Approximately(inset, _clipInset)) return;

            // クリップの逃げを padding と同量の負の margin で当てる（Web の calc(-1 * inset)。A-47）
            // Apply the clip clearance as padding plus an equal negative margin (the Web calc(-1 * inset); A-47)
            _clipInset = inset;
            _hasClipInset = true;
            style.paddingLeft = inset;
            style.paddingRight = inset;
            style.paddingTop = inset;
            style.paddingBottom = inset;
            style.marginLeft = -inset;
            style.marginRight = -inset;
            style.marginTop = -inset;
            style.marginBottom = -inset;
        }

        private void CenterOnInitialFocusOnce()
        {
            // silent-ok: 寄せた後・復元した後・ノードか注目点か逃げか寸法が未着の間は寄せない / 揃った次の SetGraph か寸法の変化で 1 回だけ寄る（Web と同じ）
            if (_hasCentered || _restored || !_scene.HasNodes || !_initialFocus.TryGetPoint(out var focus) || !_hasClipInset || contentRect.width <= 0f) return;

            // 事前のズームの倍率を保ったまま、注目点を内容 box の中央に据える
            // Center the focus point in the content box while keeping any earlier zoom scale
            _hasCentered = true;
            SetViewport(NodeGraphViewportMath.CenterOn(_scene.ToCanvasPoint(focus), contentRect.size, _viewport.Scale));
        }

        private void SetViewport(NodeGraphViewport viewport)
        {
            _viewport = viewport;
            ApplyViewport();
            _onViewportChanged.OnNext(viewport);
        }

        private void ApplyViewport()
        {
            // CSS の translate(x, y) scale(s)（transform-origin: 0 0）と同じ変換をキャンバスへ当てる
            // Apply the same transform as CSS translate(x, y) scale(s) with transform-origin 0 0
            _canvas.style.translate = new Translate(_viewport.X, _viewport.Y);
            _canvas.style.scale = new Scale(new Vector2(_viewport.Scale, _viewport.Scale));
        }
    }
}
```

```csharp
    /// </summary>
    public class NodeGraphViewMotionTest : NodeGraphTestStage
    {
        private const int MaxFrames = 500;

        /// <web-test file="src/shared/treeView/TreeViewViewportState.test.ts">keeps gliding after a fast drag is released and eventually stops</web-test>
        [Test]
        public void 速いドラッグを離すと滑走しやがて止まる()

        public void ポインタが取り消されると滑走せず中断する()
        {
            var view = MountGraph();
            var start = DragRightFourTimes(view);

            // 捕捉を奪って中断させる（UITK の取消と同じ経路）
            // Steal the capture to abort (the same path as a UITK cancel)
            var thief = new VisualElement { name = "capture-thief" };
            rootVisualElement.Add(thief);
            thief.CapturePointer(PointerId.mousePointerId);
            simulate.MouseMove(start + new Vector2(64f, 0f));
            simulate.FrameUpdate();
            thief.ReleasePointer(PointerId.mousePointerId);
            simulate.MouseUp(start + new Vector2(64f, 0f), MouseButton.LeftMouse);
            for (var frame = 0; frame < 10; frame++) simulate.FrameUpdateMs(16);

            AssertViewport(64f, 0f, 1f, ReadViewport(view));
        }

        [Test]
        public void 右ボタンの押下でも滑走が止まる()
        {
            var view = MountGraph();
            FlingRight(view);
            simulate.FrameUpdateMs(16);
            simulate.FrameUpdateMs(16);

            // 受理されない押下でも滑走は止まる（Web の onPointerDown の包み）
            // Even an unaccepted press stops the glide (the Web onPointerDown wrapper)
            var point = ContentOrigin(view) + new Vector2(300f, 250f);
            simulate.MouseDown(point, MouseButton.RightMouse);
            simulate.MouseUp(point, MouseButton.RightMouse);
            var stoppedAt = ReadViewport(view).X;
            for (var frame = 0; frame < 10; frame++) simulate.FrameUpdateMs(16);

            Assert.Greater(stoppedAt, 64f, "it was gliding");
            Assert.AreEqual(stoppedAt, ReadViewport(view).X, Tolerance);
        }

        private NodeGraphView MountGraph()
        {
            var view = MountView(MountHost(400f, 300f));
            view.SetGraph(new NodeGraphContent(new[] { Node("a", 0f, 0f, Card("card-a")) }, NodeGraphFocus.None));
            simulate.FrameUpdate();
            return view;
        }

        private Vector2 DragRightFourTimes(NodeGraphView view)
        {
            // 16ms ごとに x を 16・32・48・64 へ動かす（Web テストと同じ）
            // Move x to 16, 32, 48 and 64 every 16 ms (same as the Web test)
            var start = ContentOrigin(view) + new Vector2(20f, 20f);
            simulate.MouseDown(start, MouseButton.LeftMouse);
            for (var step = 1; step <= 4; step++)
            {
                simulate.FrameUpdateMs(16);
                simulate.MouseMove(start + new Vector2(16f * step, 0f));
            }
            return start;
        }

        private void FlingRight(NodeGraphView view)
        {
            var start = DragRightFourTimes(view);
            simulate.FrameUpdateMs(6);
            simulate.MouseUp(start + new Vector2(64f, 0f), MouseButton.LeftMouse);
        }

        private int RunUntilStill(NodeGraphView view)
        {
            // 3 フレーム続けて動かなければ止まったとみなす
            // Treat three motionless frames in a row as stopped
            var previous = ReadViewport(view).X;
            var stillFrames = 0;
            for (var frame = 1; frame <= MaxFrames; frame++)
            {
                simulate.FrameUpdateMs(16);
                var x = ReadViewport(view).X;
                stillFrames = Mathf.Approximately(x, previous) ? stillFrames + 1 : 0;
                previous = x;
                if (stillFrames >= 3) return frame;
            }
            return MaxFrames;
        }
```

```python
import subprocess
import sys

# 1 列（縦の断面）の画素を ffmpeg で読み、地との差が閾値を超える行の範囲・重心・芯の色を出す
# Reads one pixel column via ffmpeg and prints the rows that differ from the ground, their weighted center and core color
png, x, y0, y1, ground_hex = sys.argv[1], int(sys.argv[2]), int(sys.argv[3]), int(sys.argv[4]), sys.argv[5]
ground = tuple(int(ground_hex[i:i + 2], 16) for i in (0, 2, 4))
raw = subprocess.run(["ffmpeg", "-loglevel", "error", "-i", png, "-vf", f"crop=1:{y1 - y0}:{x}:{y0}", "-f", "rawvideo", "-pix_fmt", "rgb24", "-"], capture_output=True, check=True).stdout
rows = [tuple(raw[i:i + 3]) for i in range(0, len(raw), 3)]
weights = [sum(abs(c - g) for c, g in zip(px, ground)) for px in rows]
hits = [i for i, w in enumerate(weights) if w > 12]
total = sum(weights[i] for i in hits)
center = sum((y0 + i + 0.5) * weights[i] for i in hits) / total if total else float("nan")
core = rows[max(range(len(rows)), key=lambda i: weights[i])]
print(f"rows={[y0 + i for i in hits]} center={center:.2f} core={core}")
```

断面の取り方: 水平の線は縦の列（`x` 固定）、斜めの線も縦の列で測り、太さは `行数 × cos(22.1°)` に直す（傾き 148/364）。カードの縦の中心は、同じ線の両端のカードの中央の列で地と違う行の最初と最後の中点として同じ道具で測る（`rows=` の端）。位置の比べは「線の中心 − 基準直線」で行う。基準直線は両端のカードの中心 (x端, y端)・(x他端, y他端) を結ぶ直線で、測る列 `x測` での値は `y端 + (y他端 − y端) / (x他端 − x端) × (x測 − x端)`。切り抜きの座標は全体の座標へ戻してから引く（水平の線は傾き 0 なので「線の中心 − 端のカードの縦の中心」と同じ）。Web と UITK で同じ式を使い、測る列が両者で違ってもずれが傾きで生じないようにする

- **D-1（A-115）API の形**: `NodeGraphView(string testIdPrefix)`・`SetGraph(NodeGraphContent)`・`IObservable<string> OnNodeTapped`・`RestoreViewport(NodeGraphViewport)`・`IObservable<NodeGraphViewport> OnViewportChanged`。設計書 §2.7 の行にあった `CenterOn(string nodeKey)` は持たない。Web の公開 API は 1 回限りの `initialFocus` だけで、任意の時に寄せる命令は無く、研究もチャレンジもそれで足りている。ビューポートの保持は画面の State（`Client.Ui.State/<機能>/Session/`）が持ち、部品は変化を流し（マウント時と復元の値は流さない）、作り直しの直後に戻してもらう。前例は `GameScrollView.OnScrollOffsetChanged`／`SetScrollOffset`（部品は値を流し・受けるだけ）と `Client.Ui.State/BuildMenu/Session/BuildMenuSessionStore`（セッション内の保持は State）。却下: `CenterOn` を残す（Web に無い挙動を作ることになり、テストの写し先も無い）、画面が作った可変の保持の入れ物を ctor で部品へ渡す（部品が外の可変状態へ書き込み、Set／IObservable で値を出し入れする部品の約束が崩れる。設計検査 V-1）、Web と同じくキー文字列で静的な Map を引く（部品が全体の可変状態を持ち、テストの間で漏れる。画面の寿命で消える Web の Map と寿命も揃わない）、`renderNode` に当たる `Func<>` を受ける（AGENTS.md で禁止） `RestoreViewport` は前例 `GameScrollView.SetScrollOffset` と違って値を流さない（Web のマウント時の復元は変化として扱わないため。R-6 のテストで固定）。
- **D-2 カードの受け方**: ノードごとに画面が作った `VisualElement` を受け、部品は点に置いた幅 0 の包み（拾わない）に入れる。中心寄せ（Web の `translate(-50%, -50%)`）とチャレンジの `scale(UIScale)` はカードが持つ。Web の包みも位置を持たずカードが自分の位置を持つので、役割は同じ。カードは包みの外へはみ出すが、UITK は overflow を切らない親の外の子も拾う（Gesture の L1 で確かめる）
- **D-3（A-117）線の描き方**: Painter2D の 1 層をキャンバスの最初の子に置き、全部の線を 1 本のパスで描く（実行計画のレーンの行「Painter2D の線」）。色と太さは部品 USS の `.node-graph__edges` で受け直す。却下: 線ごとに回した 3px の要素（Web の写しには近いが、ノード数の線の要素が増え、レーンの指定とも違う）
- **D-4（A-117）中心が 1.5px 下**: Web の `.line` は高さ 3px の帯を左端の中央で回すため、線の中心がノードの点から 1.5px 下を通る。見た目を同じにするため `StrokeStart` で同じ量を下げる。却下: 点を通す（Web の見た目から 1.5px ずれる。ゴールは Web と同じ見た目）
- **D-5（A-117）入力の誤り**: グラフに無い親のキーは線を描かず、重なったキーは後のノードを置かず、どちらも `Debug.LogError`。Web は黙って飛ばす・上書きするが、AGENTS.md は無音の縮退を禁じる。チャレンジは別カテゴリの前提を持ちうるので、画面がキーを絞って渡す（S5-challenge への申し送り）
- **D-6（A-116・LX-87）滑走**: Foundation の `UiInertiaAnimation`（閉じた式）を、離したときの向きに固定して 1 次元で載せる。Web は両軸とも同じ τ で向きが変わらないので形は同じで、総距離だけ 2.5% 短い（LX-87）。Web の「decays speed to 1/e after one time constant」は滑走の変位の傾きで同じことを見る。却下: Web の離散積分を部品に写す（動きの基盤が 2 本になる。設計書 §1.2）
- **D-7 同じ時刻の移動**: 速度の追跡は間隔 0 の移動を標本にせず速度を保つ。UITK は 1 フレームに複数の移動が同じ時刻で届きうるが、Web の規則（間隔 ≤ 0 で速度 0）のままだと速いドラッグの滑走が消える。間隔 < 0・> 80ms・最初の標本は Web と同じく 0 に戻す
- **D-8（A-116）時刻の出どころ**: `UiPressMove` に時刻が無いので、`PointerDownEvent`・`PointerMoveEvent`・`PointerUpEvent` の `timestamp` を記録する受け手を `UiPressGesture` より先に登録して読む（同じ要素・同じ相は登録順に走る）。押下の受け手は受理の可否によらず滑走を止める（Web の `onPointerDown` の包み）。却下: `UiPressMove` に時刻を足す（Foundation の変更でこのレーンの所有外。integrator へ申告）、スケジューラで毎フレーム時刻を取る（Task 1 の前提テストが落ちたときの代わりの道として残す）
- **D-9 第 2 ポインタの写し方**: マウスは 1 本なので、タッチの指 0（pointerId 1）の押下と解放を `PointerDownEvent.GetPooled(Touch, EventModifiers)` で作りビューポートへ `SendEvent` する。取消は UITK の `PointerCancelEvent` と同じ中断に入る「捕捉の喪失」で起こす（前例 `UiPressGestureTest`） この L1 の指 0 は主ポインタなので `UiPressGesture` の `_press != null` の門を通る（Web の hijack の意図）。主でないポインタを拒む `isPrimary` の門は Foundation 側の L1 が持つ。
- **D-10（A-118）ホイール**: UITK の 1 ノッチ（`WheelEvent.scrollDeltaPerTick`）を Web の deltaY 60（CefUnity の 1 ノッチ）に換算し、カーソルは内容 box の座標に直す。60 は `GameScrollView` と同じ値の 2 本目なので、共有の候補として integrator へ申告する（作らない）
- **D-11（A-119）中央寄せと寸法の追従の時期**: Web はレイアウトが同期なので、データが来た時点で寸法が決まっている。UITK はレイアウトが次のフレームなので、`SetGraph` で寄せられなければ `GeometryChangedEvent` で 1 回だけ寄せ直す。逃げ（padding）が当たる前の寸法で寄せないよう、逃げを読めた後に限る。寸法の追従も逃げを読めた後の寸法だけを前回の値として記録する
- **D-12 カーソル（要裁定）**: `cursor: grab`・`grabbing` は一目で分かる見た目の差なので、agent 既定の LX にせず裁定に上げる（設計書 §7.2 Q-2・PLAN-W3c の done.md「要裁定」）。選択肢: (a) USS の `cursor: url(...)` でテクスチャのカーソル（部品の USS とパン中のクラスだけで閉じるのでこのレーンが足す。手の絵は裁定に添えてもらい自作しない） (b) 写さず LX-146 (c) OS カーソルの持ち主（画面全体の入力）へ渡す（integrator へ依頼）。推奨は (a)。`Components/NodeGraph/` を書くのはこのレーンだけなので、(a)・(b) を後続に回すと持ち主が居なくなる。そのため裁定が無いままマージしない（Task 9 Step 3）
- **D-12 の裁定（実行時に追記）**: (a) テクスチャのカーソル。手の絵 2 枚（開いた手・握った手、32×32、黒の縁取りの白い手）はこのレーンが自作し、OS の画像は複製しない。USS の `cursor` がランタイムで効かなければ Foundation の入口から `Cursor.SetCursor` で切り替える。出所: 指揮の agent 既定（ユーザーへ報告済み）。これで Task 9 Step 3 の裁定待ちは解けた
- **D-21 の読み替え（実行時に追記）**: LX-86 は S2-tutorial が先に使ったため、このレーンの取り置きは全 uitk ブランチで未使用の LX-146 へ読み替えた（LX-145 まで他計画が割り当て済み）。裁定が (a) なので LX-146 は欠番。LX-87〜90 はそのまま。出所: 指揮の指示
- **実行時の読み替え**: 計画の「Codex セッション」はこの Claude Code セッションと subagent で読み替える（ユーザー指示）。pr-independent-review は廃止済みで moores-code-review と bug-pass を使う
- **D-13 録画と登録**: unityプレイ録画テストは撮らない。この部品は本番の画面に載らず（研究・チャレンジの画面は S4-research・S5-challenge）、ランタイムの経路が無い。手触りはギャラリーで手で動かして確かめる（Task 6 Step 2）。`MainGameUiRegistration` にも足さない（DI の登録が無い部品）

- **D-23 評価の軽微で据え置くもの**: (1) 包みの子への `flex-shrink: 0` は画面が作るカードの根にも効く。カードの USS が `flex-shrink` を書けば衝突するので、S4/S5 への申し送りに「カードの根で flex-shrink を書かない」を 1 行足す。(2) 同じ時刻の移動を標本にせず捨てると、その変位も捨てて次の標本の速度を低く見積もる。Web は速度 0 にするので Web より悪くはなく、Gesture・Motion の L1 の期待は変わらないため据え置く（並べ比べで滑走の距離が目に見えて短ければ持ち越しに直す） (3) 内容 box が 0 へ縮む回（祖先の `display: none`）は寸法の追従も記録もしない（Web は条件付き描画で外すのでこの経路が無い。0 から戻る回は Web と同じく動かさないので、隠して開き直しても視野は変わらない）。包みは `align-items: flex-start` にし、幅が auto のカードが幅 0 に引き伸ばされないようにする（Web のカードは絶対配置で中身の幅）。(4) クリップの逃げで端の枠が切られないかは L1 で固定せず、Task 7 の撮影で端のカードの枠が見えることを目で確かめる（UITK の overflow の切り口が padding box か content box かは未実測）。(5) worktree の片付け（`moores-wt rm`）は worktree の中から自分を消せないので指揮に渡す（実行計画 §4.3 の手順 5 の例外）。(6) 第 2 ポインタの L1 が `[Ignore]` に倒れたときは、done.md の「未確認」にも「第 2 ポインタの拒否は L1 で検証していない」と書く
