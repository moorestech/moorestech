# UITK 段階 4 部品「掴み層と分割ドラッグ・舞台の上段 3 列」（C4-e） Implementation Plan

> **For the controller session (実装を担うsubagentはこのブロックを無視してよい):** このplanの実行は moores-subagent-driven-development スキルが担う。実行モード（規模ゲート未満の単一subagent実装モード／閾値超のタスクごと派遣）は同スキルの規模ゲートに従って決める。ステップはチェックボックス（`- [ ]`）記法で書く。

**Goal:** Web 版の `GrabOverlay`（掴んだアイテムをカーソル中心に描く絵）・`splitDrag`（左ドラッグの等分配り）・`slotActions` の進入（右ドラッグの 1 個ずつ配り）と、`App.tsx` の `.stage` の上段 3 列（`inv`・`viewer`・`items`）を UITK に写す。S4-alpha・S4-inventory・S4-recipe・S4-research が使う口（`StageColumnsLayout`・`IPlayerInventoryOperations`・`PlayerItemActionExecutor`・`IPlayerSlotDragCommands`・`PlayerGrabModel`）をここで用意し、L1・参照キャプチャとの位置の並べ比べ・unityプレイ録画テストまで済ませて `feature/uitk` へ取り込む。

**Architecture:** 掴み絵は持ち物系の画面部品として `Client.Ui/Screens/GrabOverlay/` に置き、既にある Foundation の `UiLayer.Grab`（`UiFamily.Viewport`）の層へ載せる（設計書 §2.7 と実行計画の行「Foundation の Grab 層」の折り合い。D-1）。追従は `PointerMoveEvent` ではなく、S2-mode-tooltip が実測で選んだ `Client.Input.Pointer.InputSystemPointerPositionStream`（InputSystem の onEvent、同じフレーム）を 2 機能目として使い、その登録を `MainGameUiRegistration` の基盤区画へ上げる（D-2）。ドラッグの終わり（Web の window `mouseup`）は新しい `InputSystemPointerButtonStream` で受ける（D-3）。掴みの中身は `Client.Ui.State/Inventory/Grab/PlayerGrabModel` が `IPlayerInventoryOperations` の変化通知から作り、実行は `Client.Ui.State/Inventory/Actions/PlayerItemActionExecutor`（L0-s4a の `PlannedItemAction` のうちプレイヤー側 3 種）と `Client.Ui.State/Inventory/Drag/PlayerSlotDragCommands`（L0-s4a の `SplitDragSession` と `PlayerSlotActionPlanner` の進入の計画）が持つ。上段 3 列は `Client.Ui/Foundation/Stage/Columns/StageColumnsLayout`（UITK に grid が無いので横並びの flex と列の左マージンで写す）を `UiLayer.Screen`（`UiFamily.Stage`）に 1 つ載せ、研究画面の間だけ左の余白を 0 にする。

**Tech Stack:** Unity 6000.3.8f1 UI Toolkit（ランタイムパネル・USS カスタムプロパティ）、Input System（`InputSystem.onEvent`・`InputTestFixture`）、UniRx、VContainer、NUnit＋`com.unity.ui.test-framework`（`UiTestHost`・`PanelSimulator`）、uloop CLI、プレイテスト DSL（`run-scenario.sh`）、ffmpeg（参照の画素の読み取り）、gh CLI、bd（Beads）

- **パスの略記**: `S/` = `moorestech_client/Assets/Scripts/`、`W/` = `moorestech_web/webui/src/`。Files 節と各コマンドはリポジトリ相対の完全なパスで書く
- **正本**: 裁定 `.decisions/2026-11-06-UITK*.md`、統合計画 `docs/uitk-migration/plan.md`、設計書 `docs/uitk-migration/execution/component-architecture.md`（§1.2 Stage・§2.7・§4.2・§4.4・A-45）、実行計画 `docs/uitk-migration/execution/execution-plan.md`（レーン C4-e の行・§4.3・§6）。食い違ったら 裁定 → 統合計画 → 設計書 → 実行計画 → この計画 の順で上が勝つ。この計画が設計書・実行計画と食い違う所は末尾の「設計書・実行計画へ反映する行（指揮が統合）」に挙げた
- **ゴール（ユーザーの原文）**: 「WebUIと同じ見た目で、適切な設計、コンポーネント化されたUITKベースのUIを開発すること」

```csharp
using System;
using UnityEngine.UIElements;

namespace Client.Ui.Foundation.Stage.Columns
{
    /// <summary>
    /// 舞台の上段 3 列の入れ物。画面は列へ Add するだけで、位置と余白はここが持つ
    /// Container of the three top-row stage columns; screens only Add into a column and this owns position and padding
    /// </summary>
    public sealed class StageColumnsLayout : VisualElement
    {
        private const string RootClass = "stage-columns";
        private const string LeftPaddingCollapsedClass = "stage-columns--left-padding-collapsed";
        private const string ColumnClass = "stage-columns__column";

        private readonly VisualElement _inv;
        private readonly VisualElement _viewer;
        private readonly VisualElement _items;

        public StageColumnsLayout()
        {
            name = "stage-columns";
            AddToClassList(RootClass);

            // 入れ物も列も拾わない（Web の .stage は透明な grid で、拾うのは中のパネルだけ）
            // Neither the container nor the columns pick (Web .stage is a transparent grid; only panels inside pick)
            pickingMode = PickingMode.Ignore;
            _inv = CreateColumn("stage-column-inv", "inv");
            _viewer = CreateColumn("stage-column-viewer", "viewer");
            _items = CreateColumn("stage-column-items", "items");
        }

        public VisualElement Get(StageColumn column)
        {
            return column switch
            {
                StageColumn.Inv => _inv,
                StageColumn.Viewer => _viewer,
                StageColumn.Items => _items,
                _ => throw new ArgumentOutOfRangeException(nameof(column), column, null),
            };
        }

        public void SetLeftPaddingCollapsed(bool collapsed)
        {
            EnableInClassList(LeftPaddingCollapsedClass, collapsed);
        }

        private VisualElement CreateColumn(string columnName, string modifier)
        {
            var column = new VisualElement { name = columnName, pickingMode = PickingMode.Ignore };
            column.AddToClassList(ColumnClass);
            column.AddToClassList($"{ColumnClass}--{modifier}");
            Add(column);
            return column;
        }
    }
}
```

```csharp
using System;
using UniRx;
using UnityEngine;
using UnityEngine.InputSystem;
using UnityEngine.InputSystem.LowLevel;

namespace Client.Input.Pointer
{
    /// <summary>
    /// マウスの左ボタンが離れたフレームに 1 回流す（Web の window mouseup の代わり。UI の拾いに依らない）
    /// Publishes once in the frame the left mouse button is released (stands in for Web's window mouseup; independent of UI picking)
    /// </summary>
    public sealed class InputSystemPointerButtonStream
    {
        private readonly Subject<Unit> _onPrimaryButtonReleased = new();
        private bool _wasPressed;

        public IObservable<Unit> OnPrimaryButtonReleased => _onPrimaryButtonReleased;

        // 最後に届いたイベントでの左ボタンの押下（同じフレームの押下と解放の後先を分割ドラッグが確かめる。D-20）
        // Left button state as of the last event (split-drag checks press/release ordering within a frame; D-20)
        public bool IsPrimaryButtonPressed()
        {
            return _wasPressed;
        }

        public InputSystemPointerButtonStream()
        {
            // マウス無しなら理由を警告
            // Warn why when there is no mouse
            if (Mouse.current == null) Debug.LogWarning("[InputSystemPointerButtonStream] Mouse.current is null; no button release will be published until a mouse sends events");
            InputSystem.onEvent += OnInputEvent;
        }

        private void OnInputEvent(InputEventPtr eventPtr, InputDevice device)
        {
            // 左ボタンの押下→解放の変わり目だけを流す
            // Publish only the pressed-to-released edge of the left button
            if (device != Mouse.current) return;
            if (!eventPtr.IsA<StateEvent>() && !eventPtr.IsA<DeltaStateEvent>()) return;
            if (!Mouse.current.leftButton.ReadValueFromEvent(eventPtr, out var value)) return;
            var pressed = 0.5f <= value;
            var released = _wasPressed && !pressed;
            _wasPressed = pressed;
            if (released) _onPrimaryButtonReleased.OnNext(Unit.Default);
        }
    }
}
```

（`ReadValueFromEvent` が左ボタンを含まない DeltaStateEvent〈位置だけ〉で false を返すことは前例の位置の流れで実証済み。ボタンの押下の閾値 0.5 は `ButtonControl.pressPoint` の既定〈`InputSettings.defaultButtonPressPoint`〉と同じ。テストが閾値で落ちたら `Mouse.current.leftButton.pressPointOrDefault` を使う）

```csharp
using System;
using System.Collections.Generic;
using Client.Ui.State.Inventory.Actions;
using Client.Ui.State.ItemMove;
using Client.Ui.State.Items;
using Core.Master;
using UniRx;

namespace Client.Tests.Ui.State.Inventory
{
    /// <summary>
    /// 持ち物の読み書きの口のテスト用の実装。コントローラと同じ移動の規則で配列を書き換え、呼び出しを記録する
    /// Test double for the inventory port; rewrites arrays with the controller's move rules and records calls
    /// </summary>
    public sealed class RecordingPlayerInventoryOperations : IPlayerInventoryOperations
    {
        private static readonly SlotItem Empty = new(ItemMaster.EmptyItemId, 0);
        private readonly SlotItem[] _main;
        private readonly SlotItem[] _equipment;
        private readonly Subject<Unit> _onInventoryChanged = new();
        private SlotItem _grab = Empty;

        public List<(ItemMoveSlotRef from, ItemMoveSlotRef to, int count)> Moves { get; } = new();
        public List<ItemMoveSlotRef> Collects { get; } = new();
        public IObservable<Unit> OnInventoryChanged => _onInventoryChanged;

        public RecordingPlayerInventoryOperations(int mainSlotCount, int equipmentSlotCount)
        {
            _main = new SlotItem[mainSlotCount];
            _equipment = new SlotItem[equipmentSlotCount];
            Array.Fill(_main, Empty);
            Array.Fill(_equipment, Empty);
        }

        public void SetMain(int slot, SlotItem item)
        {
            _main[slot] = item;
            _onInventoryChanged.OnNext(Unit.Default);
        }

        public void SetGrab(SlotItem item)
        {
            _grab = item;
            _onInventoryChanged.OnNext(Unit.Default);
        }

        public SlotItem ReadMain(int slot)
        {
            return _main[slot];
        }

        public PlayerInventorySnapshot ReadSnapshot()
        {
            return new PlayerInventorySnapshot((SlotItem[])_main.Clone(), _grab, (SlotItem[])_equipment.Clone());
        }

        public SlotItem ReadGrab()
        {
            return _grab;
        }

        public bool TryMoveItem(ItemMoveSlotRef from, ItemMoveSlotRef to, int count, out string denyReason)
        {
            Moves.Add((from, to, count));
            var source = Read(from);
            denyReason = source.IsEmpty ? "empty_slot" : source.Count < count ? "insufficient_count" : null;
            if (denyReason != null) return false;
            Apply();
            _onInventoryChanged.OnNext(Unit.Default);
            return true;

            #region Internal

            // コントローラの MoveItem と同じ: 別 ID への全量は入れ替え・別 ID への部分は何もしない・それ以外は加算
            // Same as the controller's MoveItem: full move onto another id swaps, partial onto another id is a no-op, else add
            void Apply()
            {
                var target = Read(to);
                var differentId = !target.IsEmpty && target.ItemId != source.ItemId;
                if (differentId && count != source.Count) return;
                if (differentId)
                {
                    Write(to, source);
                    Write(from, target);
                    return;
                }
                Write(to, new SlotItem(source.ItemId, target.Count + count));
                var rest = source.Count - count;
                Write(from, rest <= 0 ? Empty : new SlotItem(source.ItemId, rest));
            }

            #endregion
        }

        public void CollectItems(ItemMoveSlotRef target)
        {
            Collects.Add(target);
        }

        private SlotItem Read(ItemMoveSlotRef slot)
        {
            return slot.Area switch
            {
                ItemMoveArea.Main => _main[slot.Slot],
                ItemMoveArea.Equipment => _equipment[slot.Slot],
                ItemMoveArea.Grab => _grab,
                _ => throw new ArgumentOutOfRangeException(nameof(slot), slot, null),
            };
        }

        private void Write(ItemMoveSlotRef slot, SlotItem item)
        {
            switch (slot.Area)
            {
                case ItemMoveArea.Main: _main[slot.Slot] = item; break;
                case ItemMoveArea.Equipment: _equipment[slot.Slot] = item; break;
                case ItemMoveArea.Grab: _grab = item; break;
                default: throw new ArgumentOutOfRangeException(nameof(slot), slot, null);
            }
        }
    }
}
```

```csharp
    {
```

```csharp
        public LocalPlayerInventoryOperations(LocalPlayerInventoryController controller, LocalPlayerEquipment equipment)
        {
            _controller = controller;
            _equipment = equipment;

            // grab（インデクサ外）・スロット・装備の 3 本を 1 本にまとめる
            // Merge the three sources: grab (outside the indexer), slots and equipment
```

```csharp
using System;
using System.Collections.Generic;
using Client.Ui.State.Commands;
using Client.Ui.State.ItemMove;
using UnityEngine;

namespace Client.Ui.State.Inventory.Actions
{
    /// <summary>
    /// プレイヤー側の計画（移動・分割・集め）を Web のホスト（InventoryActions）と同じ意味で実行する。ブロック側は S4-alpha
    /// Executes player-side plans (move, split, collect) with the Web host's (InventoryActions) meaning; block-side belongs to S4-alpha
    /// </summary>
    public sealed class PlayerItemActionExecutor
    {
        private readonly IPlayerInventoryOperations _operations;

        public PlayerItemActionExecutor(IPlayerInventoryOperations operations)
        {
            _operations = operations;
        }

        public UiCommandResult Execute(IReadOnlyList<PlannedItemAction> actions)
        {
            // 順に実行し、最初の拒否で止めてそれを返す
            // Run in order and stop at the first rejection, returning it
            foreach (var action in actions)
            {
                var result = ExecuteOne(action);
                if (result is UiCommandRejected) return result;
            }
            return UiCommandAccepted.Instance;

            #region Internal

            UiCommandResult ExecuteOne(PlannedItemAction action)
            {
                return action.Kind switch
                {
                    PlannedItemActionKind.InventoryMoveItem => MoveItem(action.From, action.To, action.Count),
                    PlannedItemActionKind.InventorySplit => Split(action.From),
                    PlannedItemActionKind.InventoryCollect => Collect(action.From),
                    _ => throw new ArgumentOutOfRangeException(nameof(actions), action, "ブロック側の計画がプレイヤー側の実行器へ来た（S4-alpha のブロック実行器へ渡す配線の誤り）"),
                };
            }

            UiCommandResult MoveItem(ItemMoveSlotRef from, ItemMoveSlotRef to, int count)
            {
                // 同じ番地への移動はホストと同じく成功の何もしない
                // A move onto the same slot is a successful no-op, like the host
                if (from == to) return UiCommandAccepted.Instance;
                return _operations.TryMoveItem(from, to, count, out var denyReason) ? UiCommandAccepted.Instance : PlayerItemActionRejections.FromMoveDenyReason(denyReason);
            }

            UiCommandResult Split(ItemMoveSlotRef from)
            {
                // grab を持っていれば拒否、中身が無ければ拒否、半分が 0 なら成功の何もしない（ホストと同じ順）
                // Reject while holding, reject an empty slot, and treat a zero half as a successful no-op (host order)
                var snapshot = _operations.ReadSnapshot();
                if (!snapshot.Grab.IsEmpty) return new UiCommandRejected(UiCommandRejectReason.SplitGrabNotEmpty, "");
                if (!snapshot.TryResolveSlot(from, out var slot))
                {
                    Debug.LogWarning($"[PlayerItemActionExecutor] split on stale slot {from} ignored");
                    return UiCommandAccepted.Instance;
                }
                if (slot.IsEmpty) return new UiCommandRejected(UiCommandRejectReason.ItemSourceSlotEmpty, "");
                var half = slot.Count / 2;
                return half <= 0 ? UiCommandAccepted.Instance : MoveItem(from, ItemMoveSlotRef.Grab, half);
            }

            UiCommandResult Collect(ItemMoveSlotRef clicked)
            {
                // 集め先は今の grab で決める（ホストの ResolveCollectTarget と同じ）
                // The target follows the current grab (same as the host's ResolveCollectTarget)
                _operations.CollectItems(_operations.ReadGrab().IsEmpty ? clicked : ItemMoveSlotRef.Grab);
                return UiCommandAccepted.Instance;
            }

            #endregion
        }
    }
}
```

```csharp
using System.Collections.Generic;
using Client.Ui.State.ItemMove;

namespace Client.Ui.State.Inventory.Drag
{
    /// <summary>
    /// 分割ドラッグの等分（Web ホストの SplitDragActionHandler と同じ: 一意で grab を受けられる行先に grab ÷ 行先数）
    /// Split-drag share (same as the Web host's SplitDragActionHandler: grab / destinations over unique slots that accept the grab)
    /// </summary>
    public static class SplitDragDistribution
    {
        public static SplitDragShare Plan(PlayerInventorySnapshot inventory, IReadOnlyList<ItemMoveSlotRef> slots)
        {
            var grab = inventory.Grab;
            var destinations = new List<ItemMoveSlotRef>();
            var stale = 0;
            foreach (var slot in slots)
            {
                if (destinations.Contains(slot)) continue;
                // 枠数が縮んだ後の古い番地は数えて除く（呼び手がログに出す）
                // Stale refs after the slot count shrank are counted and dropped (the caller logs them)
                if (!inventory.TryResolveSlot(slot, out var item))
                {
                    stale++;
                    continue;
                }
                // 受けられるのは空・同じアイテム・grab が空のとき（ホストの IsAllowedToAddWithRemain と同じ）
                // Accepts an empty slot, the same item, or any slot while grab is empty (host IsAllowedToAddWithRemain)
                if (!item.IsEmpty && !grab.IsEmpty && item.ItemId != grab.ItemId) continue;
                destinations.Add(slot);
            }
            var countPerSlot = destinations.Count == 0 ? 0 : grab.Count / destinations.Count;
            return new SplitDragShare(destinations, countPerSlot, stale);
        }
    }
}
```

```csharp
using System;
using Client.Ui.State.Commands;
using Client.Ui.State.Inventory.Actions;
using Client.Ui.State.Inventory.Logic;
using Client.Ui.State.ItemMove;
using UnityEngine;

namespace Client.Ui.State.Inventory.Drag
{
    /// <summary>
    /// 進入と分割ドラッグの実行。計画は L0-s4a、実行は持ち物の口とプレイヤー側の実行器
    /// Runs enters and split drag; planning is L0-s4a, execution is the inventory port and the player-side executor
    /// </summary>
    public sealed class PlayerSlotDragCommands : IPlayerSlotDragCommands
    {
        private readonly IPlayerInventoryOperations _operations;
        private readonly PlayerItemActionExecutor _executor;
        private readonly IPrimaryPointerButton _button;
        private readonly SplitDragSession _session = new();

        public PlayerSlotDragCommands(IPlayerInventoryOperations operations, PlayerItemActionExecutor executor, IPrimaryPointerButton button)
        {
            _operations = operations;
            _executor = executor;
            _button = button;
        }

        public UiCommandResult BeginSplitDrag(ItemMoveSlotRef slot)
        {
            RequireClickableSlot(slot);
            _session.Begin(slot);

            // 同じフレームで解放が先に流れていたら、この開始の解放は来ないのでここで確定する（D-20）
            // If the release already ran earlier in this frame, no release will follow this begin, so end it here (D-20)
            return _button.IsPressed() ? UiCommandAccepted.Instance : EndSplitDrag();
        }

        public void EnterWithLeftButton(ItemMoveSlotRef slot)
        {
            RequireClickableSlot(slot);
            // silent-ok: 分割ドラッグ外の左ボタンの進入は Web の session.enter と同じく何もしない / 配りが起きないことはプレイヤーが画面で見る
            if (!_session.IsActive) return;
            var plan = PlayerSlotActionPlanner.PlanLeftEnter(_operations.ReadSnapshot(), slot);
            if (plan is EnterSplitDragPlan enter) _session.Enter(enter.Target);
            else Debug.LogWarning($"[PlayerSlotDragCommands] split-drag enter ignored: {plan.GetType().Name} for {slot}");
        }

        public UiCommandResult EnterWithRightButton(ItemMoveSlotRef slot)
        {
            RequireClickableSlot(slot);
            var plan = PlayerSlotActionPlanner.PlanRightEnter(_operations.ReadSnapshot(), slot);
            switch (plan)
            {
                case ItemActionsPlan actions:
                    return _executor.Execute(actions.Actions);
                case StaleSlotIgnoredPlan stale:
                    Debug.LogWarning($"[PlayerSlotDragCommands] right-button enter on stale slot {stale.Target} ignored");
                    return UiCommandAccepted.Instance;
                default:
                    throw new ArgumentOutOfRangeException(nameof(slot), plan, "右ボタンの進入の計画に未知の種類。ここへ分岐を足すこと");
            }
        }

        public UiCommandResult EndSplitDrag()
        {
            // silent-ok: 分割ドラッグ外の解放は Web の end() と同じく何もしない / 毎回の左クリックの解放で通るので記録しない
            var slots = _session.End();
            if (slots.Count == 0) return UiCommandAccepted.Instance;

            var share = SplitDragDistribution.Plan(_operations.ReadSnapshot(), slots);
            if (0 < share.IgnoredStaleCount) Debug.LogWarning($"[PlayerSlotDragCommands] split-drag dropped {share.IgnoredStaleCount} stale slot(s)");
            if (share.Destinations.Count == 0) return new UiCommandRejected(UiCommandRejectReason.SplitDragNoValidSlots, "");
            // silent-ok: 1 か所あたり 0 個はホストと同じ成功の何もしない / grab が残ったままなのはプレイヤーが掴み絵で見る
            if (share.CountPerSlot <= 0) return UiCommandAccepted.Instance;

            // ホストと同じく 1 か所の失敗で残りを止めない。失敗は開発者向けのログへ
            // Like the host, one failure does not stop the rest; failures go to the developer log
            foreach (var destination in share.Destinations)
            {
                if (_operations.TryMoveItem(ItemMoveSlotRef.Grab, destination, share.CountPerSlot, out var denyReason)) continue;
                Debug.LogWarning($"[PlayerSlotDragCommands] split-drag move to {destination} denied: {denyReason}");
            }
            return UiCommandAccepted.Instance;
        }

        private static void RequireClickableSlot(ItemMoveSlotRef slot)
        {
            // 行先は main・装備だけ（Web ホストの TryParseClickableSlotRef と同じ範囲）
            // Destinations are main and equipment only (same range as the Web host's TryParseClickableSlotRef)
            if (slot.Area == ItemMoveArea.Main || slot.Area == ItemMoveArea.Equipment) return;
            throw new ArgumentOutOfRangeException(nameof(slot), slot, "分割ドラッグ・進入の番地は main・装備だけ（grab・ブロックは配線の誤り。ブロックは S4-alpha）");
        }
    }
}
```

```csharp
using UnityEngine;
using UnityEngine.UIElements;

namespace Client.Ui.Screens.GrabOverlay
{
    /// <summary>
    /// 掴んだアイテムをポインタ中心に描く絵（Web GrabOverlay の写し）。何も拾わない
    /// Picture of the held item centered on the pointer (port of Web GrabOverlay); picks nothing
    /// </summary>
    public sealed class GrabOverlayView : VisualElement
    {
        private const string RootClass = "grab-overlay";
        private const string ShownClass = "grab-overlay--shown";

        private readonly IGrabOverlayPointer _pointer;
        private readonly ItemSlot _slot = new("grab-overlay-slot");
        private bool _shown;

        public GrabOverlayView(IGrabOverlayPointer pointer)
        {
            _pointer = pointer;
            name = "grab-overlay";
            AddToClassList(RootClass);
            Add(_slot);
            GrabOverlayPickingIgnore.Apply(this);

            // 入力のイベントと同じフレームで位置を書く（PointerMoveEvent は拾わない所で届かない。D-2）
            // Write the position in the same frame as the input event (PointerMoveEvent misses non-pickable areas; D-2)
            _pointer.OnPointerMovedOnScreen.Subscribe(MoveTo);
        }

        public void ShowGrab(ItemSlotContent content)
        {
            // 中身の差し替えで子が増えても拾わないよう毎回かけ直す
            // Re-apply after each content change so newly created children never pick
            _slot.SetContent(content);
            GrabOverlayPickingIgnore.Apply(this);
            var appearing = !_shown;
            _shown = true;
            EnableInClassList(ShownClass, true);

            // 出た瞬間は今のポインタへ合わせる（Web は最後の mousedown の位置へ同期）
            // On appearing, snap to the current pointer (Web syncs to the last mousedown position)
            if (appearing) MoveTo(_pointer.CurrentPointerOnScreen());
        }

        public void HideGrab()
        {
            _shown = false;
            EnableInClassList(ShownClass, false);
        }

        private void MoveTo(Vector2 pointerOnScreen)
        {
            // silent-ok: 隠している間と載る前は位置を持たず、出る瞬間に合わせ直す / ずれは GrabOverlayViewTest と録画が捕まえる
            if (!_shown || panel == null) return;
            var inParent = parent.WorldToLocal(_pointer.ScreenToPanel(panel, pointerOnScreen));
            style.left = inParent.x;
            style.top = inParent.y;
        }
    }
```

```csharp
using Client.Ui.Components.Slots;
using Client.Ui.Content;
using Client.Ui.State.Inventory.Grab;
using Client.Ui.State.Items;
using Client.Ui.State.Routing;
using UniRx;

namespace Client.Ui.Screens.GrabOverlay
{
    /// <summary>
    /// 掴みと画面のどちらが変わっても、絵を出すかと中身を決め直す
    /// Re-decides visibility and content of the grab picture whenever the grab or the screen changes
    /// </summary>
    public sealed class GrabOverlayBinding
    {
        private readonly GrabOverlayView _view;
        private readonly IReadOnlyReactiveProperty<SlotItem> _grab;
        private readonly IReadOnlyReactiveProperty<UiRoutingSnapshot> _routing;
        private readonly GameContentPresentation _content;

        public GrabOverlayBinding(GrabOverlayView view, IReadOnlyReactiveProperty<SlotItem> grab, IReadOnlyReactiveProperty<UiRoutingSnapshot> routing, GameContentPresentation content)
        {
            _view = view;
            _grab = grab;
            _routing = routing;
            _content = content;
        }

        public void Bind()
        {
            // 2 本を別々に購読して同じ判断をやり直す（CombineLatest は Func の合成を要るので使わない）
            // Subscribe to both separately and redo the same decision (CombineLatest needs a Func selector)
            _grab.Subscribe(_ => Refresh());
            _routing.Subscribe(_ => Refresh());
        }

        private void Refresh()
        {
            var grab = _grab.Value;
            if (!GrabOverlayVisibility.IsShown(_routing.Value.Screen, grab))
            {
                _view.HideGrab();
                return;
            }
            _view.ShowGrab(new ItemSlotContent(_content.Item(grab.ItemId), grab.Count, new ItemSlotMarks(false, false, false), null, null, null));
        }
    }
}
```

```csharp
// 掴み絵（GrabOverlay）・分割ドラッグ・舞台の上段 3 列を UITK（GameUi）で通す
// Runs the grab picture (GrabOverlay), split drag and the top-row stage columns on UITK (GameUi)
// 実行前に PlayMode を止め、execute-dynamic-code で UiSystemEditorSwitch.Set(UiSystem.GameUi) を立ててから run-scenario.sh を呼ぶ
// Stop PlayMode and call UiSystemEditorSwitch.Set(UiSystem.GameUi) via execute-dynamic-code before run-scenario.sh
using System.Linq;
using Client.Game.InGame.Context;
using Client.Game.InGame.UI.Inventory.Main;
using Client.Game.InGame.UI.UIState;
using Client.Input;
using Client.Playtest;
using Client.Playtest.Input;
using Client.Playtest.Operations;
using Client.Playtest.UiElements;
using Client.Ui.Foundation.Root;
using Client.Ui.State.Inventory.Actions;
using Client.Ui.State.Inventory.Drag;
using Client.Ui.State.ItemMove;
using Cysharp.Threading.Tasks;
using UnityEngine;
using UnityEngine.InputSystem;
using UnityEngine.UIElements;
using VContainer;

var options = new PlaytestRunOptions { Record = true };
return PlaytestRunner.Run("uitk-grab-overlay", options, async p =>
{
    p.Assert(UiInputExclusivity.ActiveUiSystem == UiSystem.GameUi, "全体スイッチが UITK（GameUi）");

    // 背景Editorでも注入入力が届くよう焦点無視へ切り替える
    // Ignore focus so injected input reaches a background Editor
    InputSystem.settings.backgroundBehavior = InputSettings.BackgroundBehavior.IgnoreFocus;
    InputSystem.settings.editorInputBehaviorInPlayMode = InputSettings.EditorInputBehaviorInPlayMode.AllDeviceInputAlwaysGoesToGameView;
    SemanticInput.EnsureDevices();
    InputSystem.EnableDevice(Keyboard.current);
    InputSystem.EnableDevice(Mouse.current);

    // 鉄インゴットを 16 個持って持ち物を開く（画面は未実装でも UI の状態と画面の判定は持ち物になる）
    // Give 16 iron ingots and open the inventory (the screen is unimplemented, but UI state and routing become the inventory)
    await p.SkipOpeningSkitIfPlaying();
    await p.ExitToGameScreen();
    await p.GiveItem("鉄インゴット", 16);
    await p.PressKey(Key.Tab);
    await p.WaitUiState(UIStateEnum.PlayerInventory, 15f);

    // 舞台の上段 3 列が Screen 層にあり、持ち物では左の余白 40
    // The top-row columns exist on the Screen layer with a 40px left padding on the inventory
    var columns = GameUiRoot.Instance.GetRootElement().Q<VisualElement>("stage-columns");
    p.Assert(columns != null, "舞台の上段 3 列（stage-columns）がある");
    p.Note($"列の左の余白={columns?.resolvedStyle.paddingLeft}");
    p.Assert(columns != null && Mathf.Abs(columns.resolvedStyle.paddingLeft - 40f) < 0.5f, "持ち物では左の余白 40");

    // 鉄インゴットのあるメインの枠を探し、本番の実行器で掴む（S4-alpha の左押下と同じ口）
    // Find the main slot holding the ingots and pick it up with the production executor (same port as S4-alpha's left press)
    var resolver = ClientDIContext.DIContainer.DIContainerResolver;
    var operations = resolver.Resolve<IPlayerInventoryOperations>();
    var executor = resolver.Resolve<PlayerItemActionExecutor>();
    var commands = resolver.Resolve<IPlayerSlotDragCommands>();
    var snapshot = operations.ReadSnapshot();
    var source = Enumerable.Range(0, snapshot.MainSlots.Count).First(i => snapshot.MainSlots[i].Count == 16);
    var empties = Enumerable.Range(0, snapshot.MainSlots.Count).Where(i => snapshot.MainSlots[i].IsEmpty).Take(3).ToArray();
    p.Note($"掴む枠={source} 配る枠={string.Join(",", empties)}");
    var pointA = new Vector2(Screen.width * 0.3f, Screen.height * 0.5f);
    SemanticInput.MouseMoveTo(pointA);
    executor.Execute(new[] { PlannedItemAction.MoveItem(ItemMoveSlotRef.Main(source), ItemMoveSlotRef.Grab, 16) });
    await p.Until(() => operations.ReadGrab().Count == 16, 5f, "grab に 16 個");
    p.Assert(await IsCenteredAsync(pointA, "A"), "掴んだ瞬間に絵がポインタ A を中心に出る");

    // 動かすと絵が付いて来る
    // Moving the pointer makes the picture follow
    var pointB = new Vector2(Screen.width * 0.7f, Screen.height * 0.35f);
    SemanticInput.MouseMoveTo(pointB);
    p.Assert(await IsCenteredAsync(pointB, "B"), "絵がポインタ B へ付いて来る");
    await p.Screenshot("grab-follows");

    // 左ボタンを押したまま 3 枠を通り、注入した解放で等分が確定する（16 ÷ 3 = 5、端数 1）
    // Hold the left button through three slots; the injected release commits the share (16 / 3 = 5, remainder 1)
    SemanticInput.MouseButtonDown(0);
    await p.WaitSeconds(0.2f);
    commands.BeginSplitDrag(ItemMoveSlotRef.Main(empties[0]));
    commands.EnterWithLeftButton(ItemMoveSlotRef.Main(empties[1]));
    commands.EnterWithLeftButton(ItemMoveSlotRef.Main(empties[2]));
    SemanticInput.MouseButtonUp(0);
    await p.Until(() => operations.ReadGrab().Count == 1, 5f, "分割ドラッグの確定で grab に端数 1");
    var after = operations.ReadSnapshot();
    p.Assert(empties.All(i => after.MainSlots[i].Count == 5), "通った 3 枠に 5 個ずつ");
    await p.Screenshot("split-drag-done");

    // 持ち物を閉じると絵が隠れる
    // Closing the inventory hides the picture
    await p.PressKey(Key.Tab);
    await p.WaitUiState(UIStateEnum.GameScreen, 15f);
    var hidden = GameUiRoot.Instance.GetRootElement().Q<VisualElement>("grab-overlay");
    p.Assert(hidden != null && hidden.resolvedStyle.display == DisplayStyle.None, "持ち物を閉じると絵が隠れる");

    #region Internal

    // 絵の中心（左下原点の画面 px）がポインタから 2px×倍率以内
    // The picture's center (bottom-left-origin screen px) lies within 2px x scale of the pointer
    async UniTask<bool> IsCenteredAsync(Vector2 pointer, string label)
    {
        await p.WaitSeconds(0.5f);
        var overlay = await PlaytestUiElementOps.FindUi("grab-overlay");
        if (!overlay.IsFound)
        {
            p.Note($"絵が見つからない（{overlay.Status}）");
            return false;
        }
        var scale = GameUiRoot.Instance.GetRootElement().panel.scaledPixelsPerPoint;
        var distance = Vector2.Distance(overlay.ScreenRect.center, pointer);
        p.Note($"{label}: 絵の中心={overlay.ScreenRect.center} ポインタ={pointer} 距離={distance:F1}px 倍率={scale}");
        return distance <= 2f * scale;
    }

    #endregion
});
```
