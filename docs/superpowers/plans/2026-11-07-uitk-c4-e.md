# UITK 段階 4 部品「掴み層と分割ドラッグ・舞台の上段 3 列」（C4-e） Implementation Plan

> **For the controller session (実装を担うsubagentはこのブロックを無視してよい):** このplanの実行は moores-subagent-driven-development スキルが担う。実行モード（規模ゲート未満の単一subagent実装モード／閾値超のタスクごと派遣）は同スキルの規模ゲートに従って決める。ステップはチェックボックス（`- [ ]`）記法で書く。

**Goal:** Web 版の `GrabOverlay`（掴んだアイテムをカーソル中心に描く絵）・`splitDrag`（左ドラッグの等分配り）・`slotActions` の進入（右ドラッグの 1 個ずつ配り）と、`App.tsx` の `.stage` の上段 3 列（`inv`・`viewer`・`items`）を UITK に写す。S4-alpha・S4-inventory・S4-recipe・S4-research が使う口（`StageColumnsLayout`・`PlayerSlotRef`・`PlayerItemActionConversion`・`IPlayerInventoryOperations`・`PlayerItemActionExecutor`・`IPlayerSlotDragCommands`・`PlayerGrabModel`）をここで用意し、L1・参照キャプチャとの位置の並べ比べ・unityプレイ録画テストまで済ませて `feature/uitk` へ取り込む。

**Architecture:** 掴み絵は持ち物系の画面部品として `Client.Ui/Screens/GrabOverlay/` に置き、既にある Foundation の `UiLayer.Grab`（`UiFamily.Viewport`）の層へ載せる（設計書 §2.7 と実行計画の行「Foundation の Grab 層」の折り合い。D-1）。追従は `PointerMoveEvent` ではなく、S2-mode-tooltip が実測で選んだ `Client.Input.Pointer.InputSystemPointerPositionStream`（InputSystem の onEvent、同じフレーム）を 2 機能目として使い、その登録を `MainGameUiRegistration` の基盤区画へ上げる（D-2）。ドラッグの終わり（Web の window `mouseup`）は新しい `InputSystemPointerButtonStream` で受ける（D-3）。掴みの中身は `Client.Ui.State/Inventory/Grab/PlayerGrabModel` が掴み専用の流れ `LocalPlayerInventoryController.OnGrabChanged`（既存の `OnInventoryRefreshed` の購読者に要求を増やさないため別の流れ。D-4・死活表）から作り、掴み絵の表示は State の `GrabOverlayModel` が掴みと画面から `GrabOverlayViewModel` を組み、Presenter が `View.Render` へ渡す（前例 `ModeHudModel`・`CursorTooltipModel`。D-23）。実行の番地と行為はプレイヤー側の型（`PlayerSlotRef`〈main・装備だけ〉と `PlayerItemAction` の派生）で、grab・ブロックは型の上で渡らない（D-24）。L0-s4a の計画との境目は `PlayerItemActionConversion.TryConvert` 1 か所。実行は `Client.Ui.State/Inventory/Actions/PlayerItemActionExecutor` と `Client.Ui.State/Inventory/Drag/PlayerSlotDragCommands`（L0-s4a の `SplitDragSession` と `PlayerSlotActionPlanner` の進入の計画。分割ドラッグの確定〈配る副作用〉の持ち主はここの 1 か所。D-26）が持つ。上段 3 列は `Client.Ui/Foundation/Stage/Columns/StageColumnsLayout`（UITK に grid が無いので横並びの flex と列の左マージンで写す）を `UiLayer.Screen`（`UiFamily.Stage`）に 1 つ載せ、研究画面の間だけ左の余白を 0 にする。

## 死活表（既存機構に触る所にぶら下がる操作）

このレーンは既存の `LocalPlayerInventoryController`（grab の書き換え）・`InputSystem.onEvent`・ポインタの位置の流れの DI 登録に触る。掴みの通知は既存の `OnInventoryRefreshed` に足さず、掴み専用の `OnGrabChanged` にする（`OnInventoryRefreshed` の購読者のうち `ResearchNodeStateStore` は研究画面の表示中にサーバーへ `GetResearchNodeStates` を取り直すので、足すと grab が絡む移動 1 回ごとにサーバーへの要求が増える。D-4）。`OnGrabChanged` の購読者はこのレーンの `PlayerGrabModel` だけで、GameUi の系でだけ登録される。

| 操作 | 計画の後も動くか | 根拠 |
|---|---|---|
| Web の系: 掴む・置く・移す・Shift の移動（`inventory.move_item`） | 動く（変化なし） | `InventoryActions` は `TryMoveItem`→`MoveItem` のまま。`OnInventoryRefreshed` の回数は変わらず（`LocalPlayerInventoryControllerGrabNotifyTest` の 5 件目）、`OnGrabChanged` は Web の系に購読者がいない |
| Web の系: 分割ドラッグ（`inventory.split_drag`）・split・collect | 動く（変化なし） | `SplitDragActionHandler`・`CollectActionHandler`（`InventoryItemCollector`）も `MoveItem` 経由。上と同じ |
| Web の系: ビルドメニューの所持数の表示 | 動く（変化なし） | `BuildMenuTopic` は `OnInventoryRefreshed` を購読し、その回数は変わらない |
| 研究画面の充足表示（両方の系） | 動く（要求は増えない） | `ResearchNodeStateStore` は `OnInventoryRefreshed` を購読し、`OnGrabChanged` を購読しない。サーバーへの取り直しの回数は今と同じ |
| サーバーとの同期（移動の送信・サーバーからの grab の更新） | 動く（変化なし） | `OnGrabChanged` は `SetInventory()` の後で流すだけで、`SendMoveItemData` の値と順を変えない。`SetGrabItem`（`NetworkEventInventoryUpdater`）は流れを 1 本足すだけ |
| GameUi の系: カーソルのツールチップ | 動く | 位置の流れの登録が基盤区画へ移るだけで Singleton は 1 つ（Task 7 Step 2 で確認） |
| GameUi の系: 既存の入力（`InputSystem.onEvent` の他の購読者） | 動く | `InputSystemPointerButtonStream` は購読者が 1 つ増えるだけで、イベントを消費しない |
| Web の系の DI | 動く | `MainGameUiRegistration` は `uiSystem != UiSystem.GameUi` で何も登録しないので、`GrabGameUiRegistration`（`PlayerGrabModel`・`PlayerSlotDragCommands` の解放の購読）は Web の系で動かない |

死ぬ・弱くなる操作は無い。

```csharp
using System;
using UniRx;
using UnityEngine;
using UnityEngine.InputSystem;
using UnityEngine.InputSystem.LowLevel;

namespace Client.Input.Pointer
{
    /// <summary>
    /// マウスの左ボタンが離れたフレームに 1 回流す（Web の window mouseup の代わり。UI の拾いに依らない）
    /// Publishes once in the frame the left mouse button is released (stands in for Web's window mouseup; independent of UI picking)
    /// </summary>
    public sealed class InputSystemPointerButtonStream
    {
        private readonly Subject<Unit> _onPrimaryButtonReleased = new();
        private bool _wasPressed;

        public IObservable<Unit> OnPrimaryButtonReleased => _onPrimaryButtonReleased;

        // 最後に届いたイベントでの左ボタンの押下（同じフレームの押下と解放の後先を分割ドラッグが確かめる。D-20）
        // Left button state as of the last event (split-drag checks press/release ordering within a frame; D-20)
        public bool IsPrimaryButtonPressed()
        {
            return _wasPressed;
        }

        public InputSystemPointerButtonStream()
        {
            // マウス無しなら理由を警告
            // Warn why when there is no mouse
            if (Mouse.current == null) Debug.LogWarning("[InputSystemPointerButtonStream] Mouse.current is null; no button release will be published until a mouse sends events");
            InputSystem.onEvent += OnInputEvent;
        }

        private void OnInputEvent(InputEventPtr eventPtr, InputDevice device)
        {
            // 左ボタンの押下→解放の変わり目だけを流す
            // Publish only the pressed-to-released edge of the left button
            if (device != Mouse.current) return;
            if (!eventPtr.IsA<StateEvent>() && !eventPtr.IsA<DeltaStateEvent>()) return;
            if (!Mouse.current.leftButton.ReadValueFromEvent(eventPtr, out var value)) return;
            var pressed = 0.5f <= value;
            var released = _wasPressed && !pressed;
            _wasPressed = pressed;
            if (released) _onPrimaryButtonReleased.OnNext(Unit.Default);
        }
    }
}
```

（`ReadValueFromEvent` が左ボタンを含まない DeltaStateEvent〈位置だけ〉で false を返すことは前例の位置の流れで実証済み。ボタンの押下の閾値 0.5 は `ButtonControl.pressPoint` の既定〈`InputSettings.defaultButtonPressPoint`〉と同じ。テストが閾値で落ちたら `Mouse.current.leftButton.pressPointOrDefault` を使う）

```csharp
        public RecordingPlayerInventoryOperations(int mainSlotCount, int equipmentSlotCount)
        {
            _main = new SlotItem[mainSlotCount];
            _equipment = new SlotItem[equipmentSlotCount];
            Array.Fill(_main, Empty);
            Array.Fill(_equipment, Empty);
        }

        public void SetMain(int slot, SlotItem item)
        {
            _main[slot] = item;
        }

        public void SetGrab(SlotItem item)
        {
            _grab = item;
            _onGrabChanged.OnNext(Unit.Default);
        }

        public SlotItem ReadMain(int slot)
        {
            return _main[slot];
        }

        public PlayerInventorySnapshot ReadSnapshot()
        {
            return new PlayerInventorySnapshot((SlotItem[])_main.Clone(), _grab, (SlotItem[])_equipment.Clone());
        }

        public SlotItem ReadGrab()
        {
            return _grab;
        }

        public PlayerItemMoveOutcome MoveToGrab(PlayerSlotRef from, int count)
        {
            Moves.Add($"{from}->Grab x{count}");
            return Move(Read(from), item => Write(from, item), _grab, SetGrabSilently, count);
        }

        public PlayerItemMoveOutcome MoveFromGrab(PlayerSlotRef to, int count)
        {
            Moves.Add($"Grab->{to} x{count}");
            return Move(_grab, SetGrabSilently, Read(to), item => Write(to, item), count);
        }

        public PlayerItemMoveOutcome MoveBetweenSlots(PlayerSlotRef from, PlayerSlotRef to, int count)
        {
            Moves.Add($"{from}->{to} x{count}");
            return Move(Read(from), item => Write(from, item), Read(to), item => Write(to, item), count);
        }

        public void CollectToGrab()
        {
            Collects.Add("Grab");
        }

        public void CollectToSlot(PlayerSlotRef slot)
        {
            Collects.Add(slot.ToString());
        }

        // コントローラの TryMoveItem＋MoveItem と同じ: 空・不足は拒否、別 ID への全量は入れ替え、別 ID への部分は何もしない、それ以外は加算
        // Same as the controller's TryMoveItem+MoveItem: reject empty/short, swap a full move onto another id, ignore a partial one, else add
        private PlayerItemMoveOutcome Move(SlotItem source, Action<SlotItem> writeSource, SlotItem target, Action<SlotItem> writeTarget, int count)
        {
            if (source.IsEmpty) return PlayerItemMoveOutcome.SourceEmpty;
            if (source.Count < count) return PlayerItemMoveOutcome.SourceCountShort;
            var differentId = !target.IsEmpty && target.ItemId != source.ItemId;
            if (differentId && count != source.Count) return PlayerItemMoveOutcome.Moved;
            if (differentId)
            {
                writeTarget(source);
                writeSource(target);
            }
            else
            {
                writeTarget(new SlotItem(source.ItemId, target.Count + count));
                var rest = source.Count - count;
                writeSource(rest <= 0 ? Empty : new SlotItem(source.ItemId, rest));
            }
            _onGrabChanged.OnNext(Unit.Default);
            return PlayerItemMoveOutcome.Moved;
        }

        private void SetGrabSilently(SlotItem item)
        {
            _grab = item;
        }

        private SlotItem Read(PlayerSlotRef slot)
        {
            return slot.IsEquipment ? _equipment[slot.Slot] : _main[slot.Slot];
        }

        private void Write(PlayerSlotRef slot, SlotItem item)
        {
            if (slot.IsEquipment) _equipment[slot.Slot] = item;
            else _main[slot.Slot] = item;
        }
    }
}
```

```csharp
{
    /// <summary>
    /// プレイヤーがクリックできる枠（main・装備）の番地。grab とブロックは型の上で作れない（Web ホストの TryParseClickableSlotRef の範囲）
    /// Address of a player-clickable slot (main, equipment); grab and block cannot be built (range of the Web host's TryParseClickableSlotRef)
    /// </summary>
    public readonly struct PlayerSlotRef : IEquatable<PlayerSlotRef>
    {
        public readonly bool IsEquipment;
        public readonly int Slot;

        private PlayerSlotRef(bool isEquipment, int slot)
        {
            IsEquipment = isEquipment;
            Slot = slot;
        }

        public static PlayerSlotRef Main(int slot) => new(false, slot);
        public static PlayerSlotRef Equipment(int slot) => new(true, slot);

        // L0-s4a の番地からの境目。grab・ブロックは false（呼び手がブロック側へ回す）
        // Boundary from L0-s4a refs; grab and block give false (the caller routes them to the block side)
        public static bool TryFrom(ItemMoveSlotRef slot, out PlayerSlotRef playerSlot)
        {
            var isPlayerSlot = slot.Area == ItemMoveArea.Main || slot.Area == ItemMoveArea.Equipment;
            playerSlot = isPlayerSlot ? new PlayerSlotRef(slot.Area == ItemMoveArea.Equipment, slot.Slot) : default;
            return isPlayerSlot;
        }
```

```csharp
using System;
using Client.Ui.State.Commands;
using UnityEngine;

namespace Client.Ui.State.Inventory.Actions
{
    /// <summary>
    /// プレイヤー側の行為。種類ごとに型を分け、実行の中身は各型が持つ（外では派生できない）
    /// Player-side action; one type per kind, each owning its execution (cannot be derived outside)
    /// </summary>
    public abstract class PlayerItemAction
    {
        private protected PlayerItemAction()
        {
        }

        internal abstract UiCommandResult Run(IPlayerInventoryOperations operations);

        // 移動の結果を拒否理由へ（失敗の写しはここ 1 か所）
        // Maps a move outcome to a reject reason (the only place this mapping lives)
        private protected static UiCommandResult FromOutcome(PlayerItemMoveOutcome outcome)
        {
            return outcome switch
            {
                PlayerItemMoveOutcome.Moved => UiCommandAccepted.Instance,
                PlayerItemMoveOutcome.SourceEmpty => new UiCommandRejected(UiCommandRejectReason.ItemSourceSlotEmpty, ""),
                PlayerItemMoveOutcome.SourceCountShort => new UiCommandRejected(UiCommandRejectReason.ItemSourceCountShort, ""),
                _ => throw new ArgumentOutOfRangeException(nameof(outcome), outcome, null),
            };
        }
    }

    public sealed class PickUpToGrabAction : PlayerItemAction
    {
        public PlayerSlotRef From { get; }
        public int Count { get; }

        public PickUpToGrabAction(PlayerSlotRef from, int count)
        {
            From = from;
            Count = count;
        }

        internal override UiCommandResult Run(IPlayerInventoryOperations operations) => FromOutcome(operations.MoveToGrab(From, Count));
    }

    public sealed class PlaceFromGrabAction : PlayerItemAction
    {
        public PlayerSlotRef To { get; }
        public int Count { get; }

        public PlaceFromGrabAction(PlayerSlotRef to, int count)
        {
            To = to;
            Count = count;
        }

        internal override UiCommandResult Run(IPlayerInventoryOperations operations) => FromOutcome(operations.MoveFromGrab(To, Count));
    }

    public sealed class MoveBetweenSlotsAction : PlayerItemAction
    {
        public PlayerSlotRef From { get; }
        public PlayerSlotRef To { get; }
        public int Count { get; }

        public MoveBetweenSlotsAction(PlayerSlotRef from, PlayerSlotRef to, int count)
        {
            From = from;
            To = to;
            Count = count;
        }

        internal override UiCommandResult Run(IPlayerInventoryOperations operations)
        {
            // silent-ok: 同じ枠への移動はホストと同じく成功の何もしない / 枠が変わらないことはプレイヤーが画面で見る
            if (From == To) return UiCommandAccepted.Instance;
            return FromOutcome(operations.MoveBetweenSlots(From, To, Count));
        }
    }

    public sealed class SplitToGrabAction : PlayerItemAction
    {
        public PlayerSlotRef From { get; }

        public SplitToGrabAction(PlayerSlotRef from)
        {
            From = from;
        }

        internal override UiCommandResult Run(IPlayerInventoryOperations operations)
        {
            // grab を持っていれば拒否、中身が無ければ拒否、半分が 0 なら成功の何もしない（ホストと同じ順）
            // Reject while holding, reject an empty slot, and treat a zero half as a successful no-op (host order)
            var snapshot = operations.ReadSnapshot();
            if (!snapshot.Grab.IsEmpty) return new UiCommandRejected(UiCommandRejectReason.SplitGrabNotEmpty, "");
            if (!snapshot.TryResolveSlot(From.ToItemMoveSlotRef(), out var slot))
            {
                Debug.LogWarning($"[PlayerItemAction] split on stale slot {From} ignored");
                return UiCommandAccepted.Instance;
            }
            if (slot.IsEmpty) return new UiCommandRejected(UiCommandRejectReason.ItemSourceSlotEmpty, "");
            var half = slot.Count / 2;
            // silent-ok: 1 個の分割は半分が 0 でホストと同じ成功の何もしない / grab が空のままなのはプレイヤーが掴み絵の無いことで見る
            if (half <= 0) return UiCommandAccepted.Instance;
            return FromOutcome(operations.MoveToGrab(From, half));
        }
    }

        public PlayerSlotRef Clicked { get; }

        public CollectAction(PlayerSlotRef clicked)
        {
            Clicked = clicked;
        }

        internal override UiCommandResult Run(IPlayerInventoryOperations operations)
        {
            // 集め先は今の grab で決める（ホストの ResolveCollectTarget と同じ）
            // The target follows the current grab (same as the host's ResolveCollectTarget)
            if (operations.ReadGrab().IsEmpty) operations.CollectToSlot(Clicked);
            else operations.CollectToGrab();
            return UiCommandAccepted.Instance;
        }
    }
```

```csharp
using Client.Ui.State.ItemMove;

namespace Client.Ui.State.Inventory.Actions
{
    /// <summary>
    /// L0-s4a の計画 1 件をプレイヤー側の行為へ写す境目。写せない（ブロック側の）計画は false で、S4-alpha がブロックの実行器へ回す
    /// Boundary converting one L0-s4a plan into a player-side action; unconvertible (block-side) plans give false and S4-alpha routes them to its block executor
    /// </summary>
    public static class PlayerItemActionConversion
    {
        public static bool TryConvert(PlannedItemAction action, out PlayerItemAction playerAction)
        {
            playerAction = action.Kind switch
            {
                PlannedItemActionKind.InventoryMoveItem => ConvertMove(),
                PlannedItemActionKind.InventorySplit => ConvertSplit(),
                PlannedItemActionKind.InventoryCollect => ConvertCollect(),
                _ => null,
            };
            return playerAction != null;

            #region Internal

            // 枠どうし・枠→grab・grab→枠の 3 形だけを写す
            // Convert only slot-to-slot, slot-to-grab and grab-to-slot
            PlayerItemAction ConvertMove()
            {
                var fromSlot = PlayerSlotRef.TryFrom(action.From, out var from);
                var toSlot = PlayerSlotRef.TryFrom(action.To, out var to);
                if (fromSlot && toSlot) return new MoveBetweenSlotsAction(from, to, action.Count);
                if (fromSlot && action.To.Area == ItemMoveArea.Grab) return new PickUpToGrabAction(from, action.Count);
                if (action.From.Area == ItemMoveArea.Grab && toSlot) return new PlaceFromGrabAction(to, action.Count);
                return null;
            }

            PlayerItemAction ConvertSplit()
            {
                return PlayerSlotRef.TryFrom(action.From, out var from) ? new SplitToGrabAction(from) : null;
            }

            PlayerItemAction ConvertCollect()
            {
                return PlayerSlotRef.TryFrom(action.From, out var clicked) ? new CollectAction(clicked) : null;
            }

            #endregion
        }
    }
}
```

```csharp
    /// Production inventory port; calls the controller's validated move (sent to the server) and collect, mapping deny strings to the outcome enum once here
    /// </summary>
    public sealed class LocalPlayerInventoryOperations : IPlayerInventoryOperations
    {
        private readonly LocalPlayerInventoryController _controller;
        private readonly LocalPlayerEquipment _equipment;

        public IObservable<Unit> OnGrabChanged => _controller.OnGrabChanged;

        public LocalPlayerInventoryOperations(LocalPlayerInventoryController controller, LocalPlayerEquipment equipment)
        {
            _controller = controller;
            _equipment = equipment;
        }

        public PlayerInventorySnapshot ReadSnapshot()
        {
            // メインはメインの枠だけ（サブインベントリはブロック側の番地で S4-alpha が読む）
            // Main covers only the main slots; the sub-inventory is read through block refs by S4-alpha
            var inventory = _controller.LocalPlayerInventory;
            var main = new SlotItem[inventory.MainSlotCount];
            for (var i = 0; i < main.Length; i++) main[i] = ToSlotItem(inventory[i]);
            var equipment = new SlotItem[_equipment.Slots.Count];
            for (var i = 0; i < equipment.Length; i++) equipment[i] = ToSlotItem(_equipment.Slots[i]);
            return new PlayerInventorySnapshot(main, ReadGrab(), equipment);
        }

        public SlotItem ReadGrab()
        {
            return ToSlotItem(_controller.GrabInventory);
        }

        public PlayerItemMoveOutcome MoveToGrab(PlayerSlotRef from, int count)
        {
            return Move(ToLocalType(from), from.Slot, LocalMoveInventoryType.Grab, 0, count);
        }

        public PlayerItemMoveOutcome MoveFromGrab(PlayerSlotRef to, int count)
        {
            return Move(LocalMoveInventoryType.Grab, 0, ToLocalType(to), to.Slot, count);
        }

        public PlayerItemMoveOutcome MoveBetweenSlots(PlayerSlotRef from, PlayerSlotRef to, int count)
        {
            return Move(ToLocalType(from), from.Slot, ToLocalType(to), to.Slot, count);
        }

        public void CollectToGrab()
        {
            _controller.CollectItems(LocalMoveInventoryType.Grab, 0);
        }

        public void CollectToSlot(PlayerSlotRef slot)
        {
            _controller.CollectItems(ToLocalType(slot), slot.Slot);
        }

        private PlayerItemMoveOutcome Move(LocalMoveInventoryType fromType, int fromSlot, LocalMoveInventoryType toType, int toSlot, int count)
        {
            if (_controller.TryMoveItem(fromType, fromSlot, toType, toSlot, count, out var denyReason)) return PlayerItemMoveOutcome.Moved;

            // コントローラの拒否コード（Web の inventory.move_item と同じ綴り）を結果へ写すのはここだけ
            // The only place the controller's deny code (same spelling as Web inventory.move_item) becomes an outcome
            return denyReason switch
            {
                "empty_slot" => PlayerItemMoveOutcome.SourceEmpty,
                "insufficient_count" => PlayerItemMoveOutcome.SourceCountShort,
                _ => throw new ArgumentOutOfRangeException(nameof(denyReason), denyReason, "LocalPlayerInventoryController.TryMoveItem の未知の拒否コード。PlayerItemMoveOutcome に足すこと"),
            };
        }

        private static LocalMoveInventoryType ToLocalType(PlayerSlotRef slot)
        {
            return slot.IsEquipment ? LocalMoveInventoryType.Equipment : LocalMoveInventoryType.MainOrSub;
        }

        private static SlotItem ToSlotItem(IItemStack stack)
        {
            return new SlotItem(stack.Id, stack.Count);
        }
    }
```

```csharp
using System.Collections.Generic;
using Client.Ui.State.Inventory.Actions;
using Client.Ui.State.ItemMove;

namespace Client.Ui.State.Inventory.Drag
{
    /// <summary>
    /// 分割ドラッグの等分（Web ホストの SplitDragActionHandler と同じ: 一意で grab を受けられる行先に grab ÷ 行先数）
    /// Split-drag share (same as the Web host's SplitDragActionHandler: grab / destinations over unique slots that accept the grab)
    /// </summary>
    public static class SplitDragDistribution
    {
        public static SplitDragShare Plan(PlayerInventorySnapshot inventory, IReadOnlyList<PlayerSlotRef> slots)
        {
            var grab = inventory.Grab;
            var destinations = new List<PlayerSlotRef>();
            var stale = 0;
            foreach (var slot in slots)
            {
                if (destinations.Contains(slot)) continue;
                // 枠数が縮んだ後の古い番地は数えて除く（呼び手がログに出す）
                // Stale refs after the slot count shrank are counted and dropped (the caller logs them)
                if (!inventory.TryResolveSlot(slot.ToItemMoveSlotRef(), out var item))
                {
                    stale++;
                    continue;
                }
                // 受けられるのは空・同じアイテム・grab が空のとき（ホストの IsAllowedToAddWithRemain と同じ）
                // Accepts an empty slot, the same item, or any slot while grab is empty (host IsAllowedToAddWithRemain)
                if (!item.IsEmpty && !grab.IsEmpty && item.ItemId != grab.ItemId) continue;
                destinations.Add(slot);
            }
            // 配り先が無いかは Destinations.Count で見る（CountPerSlot の 0 は grab が配り先より少ない場合も含む）
            // Check Destinations.Count for no targets (CountPerSlot 0 also covers grab smaller than the target count)
            var countPerSlot = destinations.Count == 0 ? 0 : grab.Count / destinations.Count;
            return new SplitDragShare(destinations, countPerSlot, stale);
        }
    }
}
```

```csharp
using System.Collections.Generic;
using Client.Ui.State.Commands;
using Client.Ui.State.Inventory.Actions;
using Client.Ui.State.Inventory.Logic;
using Client.Ui.State.ItemMove;
using Client.Ui.State.Toast;
using UniRx;
using UnityEngine;
using VContainer.Unity;

namespace Client.Ui.State.Inventory.Drag
{
    /// <summary>
    /// 進入と分割ドラッグの実行。確定（配る副作用とその結果のトースト）の持ち主はこのクラスの CommitSplitDrag 1 か所
    /// Runs enters and split drag; the commit (distribution side effect and its toast) is owned solely by CommitSplitDrag here
    /// </summary>
    public sealed class PlayerSlotDragCommands : IPlayerSlotDragCommands, IInitializable
    {
        private const string SplitDragCommandName = "inventory.split_drag";

        private readonly IPlayerInventoryOperations _operations;
        private readonly PlayerItemActionExecutor _executor;
        private readonly IPrimaryPointerButton _button;
        private readonly UiCommandResultToaster _toaster;
        private readonly SplitDragSession _session = new();

        public PlayerSlotDragCommands(IPlayerInventoryOperations operations, PlayerItemActionExecutor executor, IPrimaryPointerButton button, UiCommandResultToaster toaster)
        {
            _operations = operations;
            _executor = executor;
            _button = button;
            _toaster = toaster;
        }

        public void Initialize()
        {
            // どこで左ボタンを離しても確定する（Web の window mouseup → session.end）
            // Commit wherever the left button is released (Web window mouseup -> session.end)
            _button.OnReleased.Subscribe(_ => CommitSplitDrag());
        }

        public void BeginSplitDrag(PlayerSlotRef slot)
        {
            _session.Begin(slot);

            // 同じフレームで解放が先に流れていたら、この開始の解放は来ないのでここで確定する（D-20）
            // If the release already ran earlier in this frame, no release will follow this begin, so commit here (D-20)
            if (!_button.IsPressed()) CommitSplitDrag();
        }

        public void EnterWithLeftButton(PlayerSlotRef slot)
        {
            // silent-ok: 分割ドラッグ外の左ボタンの進入は Web の session.enter と同じく何もしない / 配りが起きないことはプレイヤーが画面で見る
            if (!_session.IsActive) return;
            var plan = PlayerSlotActionPlanner.PlanLeftEnter(_operations.ReadSnapshot(), slot.ToItemMoveSlotRef());
            if (plan is EnterSplitDragPlan) _session.Enter(slot);
            else Debug.LogWarning($"[PlayerSlotDragCommands] split-drag enter ignored: {plan.GetType().Name} for {slot}");
        }

        public UiCommandResult EnterWithRightButton(PlayerSlotRef slot)
        {
            var plan = PlayerSlotActionPlanner.PlanRightEnter(_operations.ReadSnapshot(), slot.ToItemMoveSlotRef());
            if (plan is not ItemActionsPlan planned)
            {
                Debug.LogWarning($"[PlayerSlotDragCommands] right-button enter ignored: {plan.GetType().Name} for {slot}");
                return UiCommandAccepted.Instance;
            }
            return _executor.Execute(ToPlayerActions(planned.Actions));

            #region Internal

            // 番地がプレイヤー側なので計画もプレイヤー側だけ。写せない計画は開発者向けのログへ
            // The slot is player-side so plans are too; any unconvertible plan goes to the developer log
            List<PlayerItemAction> ToPlayerActions(IReadOnlyList<PlannedItemAction> actions)
            {
                var converted = new List<PlayerItemAction>();
                foreach (var action in actions)
                {
                    if (PlayerItemActionConversion.TryConvert(action, out var playerAction)) converted.Add(playerAction);
                    else Debug.LogWarning($"[PlayerSlotDragCommands] right-button enter skipped non-player action {action}");
                }
                return converted;
            }

            #endregion
        }

        private void CommitSplitDrag()
        {
            // silent-ok: 分割ドラッグ外の解放は Web の end() と同じく何もしない / 毎回の左クリックの解放で通るので記録しない
            var slots = _session.End();
            if (slots.Count == 0) return;
            _toaster.Report(SplitDragCommandName, Distribute(slots));

            #region Internal

            UiCommandResult Distribute(IReadOnlyList<PlayerSlotRef> passed)
            {
                var share = SplitDragDistribution.Plan(_operations.ReadSnapshot(), passed);
                if (0 < share.IgnoredStaleCount) Debug.LogWarning($"[PlayerSlotDragCommands] split-drag dropped {share.IgnoredStaleCount} stale slot(s)");
                if (share.Destinations.Count == 0) return new UiCommandRejected(UiCommandRejectReason.SplitDragNoValidSlots, "");
                // silent-ok: 1 か所あたり 0 個はホストと同じ成功の何もしない / grab が残ったままなのはプレイヤーが掴み絵で見る
                if (share.CountPerSlot <= 0) return UiCommandAccepted.Instance;

                // ホストと同じく 1 か所の失敗で残りを止めない。失敗は開発者向けのログへ
                // Like the host, one failure does not stop the rest; failures go to the developer log
                foreach (var destination in share.Destinations)
                {
                    var outcome = _operations.MoveFromGrab(destination, share.CountPerSlot);
                    if (outcome != PlayerItemMoveOutcome.Moved) Debug.LogWarning($"[PlayerSlotDragCommands] split-drag move to {destination} denied: {outcome}");
                }
                return UiCommandAccepted.Instance;
            }

            #endregion
        }
    }
}
```

```csharp
namespace Client.Ui.Screens.GrabOverlay
```

```csharp
    /// <summary>
    /// 掴んだアイテムをポインタ中心に描く絵（Web GrabOverlay の写し）。表示の判断は受け取った ViewModel に従い、何も拾わない
    /// Picture of the held item centered on the pointer (port of Web GrabOverlay); follows the given view model and picks nothing
    /// </summary>
    public sealed class GrabOverlayView : VisualElement
    {
        private const string RootClass = "grab-overlay";
        private const string ShownClass = "grab-overlay--shown";

        private readonly IGrabOverlayPointer _pointer;
        private readonly GameContentPresentation _content;
        private readonly ItemSlot _slot = new("grab-overlay-slot");
        private bool _shown;

        public GrabOverlayView(IGrabOverlayPointer pointer, GameContentPresentation content)
        {
            _pointer = pointer;
            _content = content;
            name = "grab-overlay";
            AddToClassList(RootClass);
            Add(_slot);
            GrabOverlayPickingIgnore.Apply(this);

            // 入力のイベントと同じフレームで位置を書く（PointerMoveEvent は拾わない所で届かない。D-2）
            // Write the position in the same frame as the input event (PointerMoveEvent misses non-pickable areas; D-2)
            _pointer.OnPointerMovedOnScreen.Subscribe(MoveTo);
        }

        public void Render(GrabOverlayViewModel model)
        {
            if (model is not GrabOverlayHolding holding)
            {
                _shown = false;
                EnableInClassList(ShownClass, false);
                return;
            }

            // 中身の差し替えで子が増えても拾わないよう毎回かけ直す
            // Re-apply after each content change so newly created children never pick
            _slot.SetContent(new ItemSlotContent(_content.Item(holding.ItemId), holding.Count, new ItemSlotMarks(false, false, false), null, null, null));
            GrabOverlayPickingIgnore.Apply(this);
            var appearing = !_shown;
            _shown = true;
            EnableInClassList(ShownClass, true);

            // 出た瞬間は今のポインタへ合わせる（Web は最後の mousedown の位置へ同期）
            // On appearing, snap to the current pointer (Web syncs to the last mousedown position)
            if (appearing) MoveTo(_pointer.CurrentPointerOnScreen());
        }

        private void MoveTo(Vector2 pointerOnScreen)
        {
            // silent-ok: 隠している間と載る前は位置を持たず、出る瞬間に合わせ直す / ずれは GrabOverlayViewTest と録画が捕まえる
            if (!_shown || panel == null) return;
            var inParent = parent.WorldToLocal(_pointer.ScreenToPanel(panel, pointerOnScreen));
            style.left = inParent.x;
            style.top = inParent.y;
        }
    }
```

```csharp
        // A left press converts and runs the L0-s4a plan, the same path S4-alpha wires
        private void PressLeft(PlayerSlotRef target)
        {
            var context = PlayerSlotContext.WithBlockClosed(_operations.ReadSnapshot(), new FixedMaxStackLookup(100));
            switch (PlayerSlotActionPlanner.PlanLeftDown(context, target.ToItemMoveSlotRef(), false))
            {
                case ItemActionsPlan planned:
                    Toaster.Report("inventory.move_item", _executor.Execute(Convert(planned)));
                    break;
                case BeginSplitDragPlan:
                    _commands.BeginSplitDrag(target);
                    break;
                default:
                    Assert.Fail($"想定外の計画 {target}");
                    break;
            }
            simulate.FrameUpdate();
        }

        private static List<PlayerItemAction> Convert(ItemActionsPlan planned)
        {
            var actions = new List<PlayerItemAction>();
            foreach (var action in planned.Actions)
            {
                Assert.IsTrue(PlayerItemActionConversion.TryConvert(action, out var playerAction), action.ToString());
                actions.Add(playerAction);
            }
            return actions;
        }
```

```csharp
// 掴み絵（GrabOverlay）・分割ドラッグ・舞台の上段 3 列を UITK（GameUi）で通す
// Runs the grab picture (GrabOverlay), split drag and the top-row stage columns on UITK (GameUi)
// 実行前に PlayMode を止め、execute-dynamic-code で UiSystemEditorSwitch.Set(UiSystem.GameUi) を立ててから run-scenario.sh を呼ぶ
// Stop PlayMode and call UiSystemEditorSwitch.Set(UiSystem.GameUi) via execute-dynamic-code before run-scenario.sh
using System.Linq;
using Client.Game.InGame.Context;
using Client.Game.InGame.UI.Inventory.Main;
using Client.Game.InGame.UI.UIState;
using Client.Input;
using Client.Playtest;
using Client.Playtest.Input;
using Client.Playtest.Operations;
using Client.Playtest.UiElements;
using Client.Ui.Foundation.Root;
using Client.Ui.State.Inventory.Actions;
using Client.Ui.State.Inventory.Drag;
using Cysharp.Threading.Tasks;
using UnityEngine;
using UnityEngine.InputSystem;
using UnityEngine.UIElements;
using VContainer;

var options = new PlaytestRunOptions { Record = true };
return PlaytestRunner.Run("uitk-grab-overlay", options, async p =>
{
    p.Assert(UiInputExclusivity.ActiveUiSystem == UiSystem.GameUi, "全体スイッチが UITK（GameUi）");

    // 背景Editorでも注入入力が届くよう焦点無視へ切り替える
    // Ignore focus so injected input reaches a background Editor
    InputSystem.settings.backgroundBehavior = InputSettings.BackgroundBehavior.IgnoreFocus;
    InputSystem.settings.editorInputBehaviorInPlayMode = InputSettings.EditorInputBehaviorInPlayMode.AllDeviceInputAlwaysGoesToGameView;
    SemanticInput.EnsureDevices();
    InputSystem.EnableDevice(Keyboard.current);
    InputSystem.EnableDevice(Mouse.current);

    // 鉄インゴットを Web の参照と同じ個数だけ持って持ち物を開く（画面は未実装でも UI の状態と画面の判定は持ち物になる）
    // Give as many iron ingots as the Web reference holds and open the inventory (the screen is unimplemented, but UI state and routing become the inventory)
    const int GrabCount = 52;
    await p.SkipOpeningSkitIfPlaying();
    await p.ExitToGameScreen();
    await p.GiveItem("鉄インゴット", GrabCount);
    await p.PressKey(Key.Tab);
    await p.WaitUiState(UIStateEnum.PlayerInventory, 15f);

    // 舞台の上段 3 列が Screen 層にあり、持ち物では左の余白 40
    // The top-row columns exist on the Screen layer with a 40px left padding on the inventory
    var columns = GameUiRoot.Instance.GetRootElement().Q<VisualElement>("stage-columns");
    p.Assert(columns != null, "舞台の上段 3 列（stage-columns）がある");
    p.Note($"列の左の余白={columns?.resolvedStyle.paddingLeft}");
    p.Assert(columns != null && Mathf.Abs(columns.resolvedStyle.paddingLeft - 40f) < 0.5f, "持ち物では左の余白 40");

    // 鉄インゴットのあるメインの枠を探し、本番の実行器で掴む（S4-alpha の左押下と同じ口）
    // Find the main slot holding the ingots and pick it up with the production executor (same port as S4-alpha's left press)
    var resolver = ClientDIContext.DIContainer.DIContainerResolver;
    var operations = resolver.Resolve<IPlayerInventoryOperations>();
    var executor = resolver.Resolve<PlayerItemActionExecutor>();
    var commands = resolver.Resolve<IPlayerSlotDragCommands>();
    var snapshot = operations.ReadSnapshot();
    var source = Enumerable.Range(0, snapshot.MainSlots.Count).First(i => snapshot.MainSlots[i].Count == GrabCount);
    var empties = Enumerable.Range(0, snapshot.MainSlots.Count).Where(i => snapshot.MainSlots[i].IsEmpty).Take(3).ToArray();
    p.Note($"掴む枠={source} 配る枠={string.Join(",", empties)}");
    var pointA = new Vector2(Screen.width * 0.3f, Screen.height * 0.5f);
    SemanticInput.MouseMoveTo(pointA);
    executor.Execute(new PlayerItemAction[] { new PickUpToGrabAction(PlayerSlotRef.Main(source), GrabCount) });
    await p.Until(() => operations.ReadGrab().Count == GrabCount, 5f, $"grab に {GrabCount} 個");
    p.Assert(await IsCenteredAsync(pointA, "A"), "掴んだ瞬間に絵がポインタ A を中心に出る");

    // 動かすと絵が付いて来る
    // Moving the pointer makes the picture follow
    var pointB = new Vector2(Screen.width * 0.7f, Screen.height * 0.35f);
    SemanticInput.MouseMoveTo(pointB);
    p.Assert(await IsCenteredAsync(pointB, "B"), "絵がポインタ B へ付いて来る");
    await p.Screenshot("grab-follows");

    // Web の参照と同じ舞台座標 (700, 560) へ動かして並べ比べ用に撮る（舞台は高さに合わせて横は中央）
    // Move to the Web reference's stage point (700, 560) and shoot for comparison (stage fits the height, centered horizontally)
    var stageScale = Screen.height / 720f;
    var pointC = new Vector2((Screen.width - 1280f * stageScale) / 2f + 700f * stageScale, Screen.height - 560f * stageScale);
    SemanticInput.MouseMoveTo(pointC);
    p.Assert(await IsCenteredAsync(pointC, "C"), "絵が比べる点 C へ付いて来る");
    await p.Screenshot("grab-compare");

    // 左ボタンを押したまま 3 枠を通り、注入した解放で等分が確定する（52 ÷ 3 = 17、端数 1）
    // Hold the left button through three slots; the injected release commits the share (52 / 3 = 17, remainder 1)
    SemanticInput.MouseButtonDown(0);
    await p.WaitSeconds(0.2f);
    commands.BeginSplitDrag(PlayerSlotRef.Main(empties[0]));
    commands.EnterWithLeftButton(PlayerSlotRef.Main(empties[1]));
    commands.EnterWithLeftButton(PlayerSlotRef.Main(empties[2]));
    SemanticInput.MouseButtonUp(0);
    await p.Until(() => operations.ReadGrab().Count == GrabCount % 3, 5f, $"分割ドラッグの確定で grab に端数 {GrabCount % 3}");
    var after = operations.ReadSnapshot();
    p.Assert(empties.All(i => after.MainSlots[i].Count == GrabCount / 3), $"通った 3 枠に {GrabCount / 3} 個ずつ");
    await p.Screenshot("split-drag-done");

    // 持ち物を閉じると絵が隠れる
    // Closing the inventory hides the picture
    await p.PressKey(Key.Tab);
    await p.WaitUiState(UIStateEnum.GameScreen, 15f);
    var hidden = GameUiRoot.Instance.GetRootElement().Q<VisualElement>("grab-overlay");
    p.Assert(hidden != null && hidden.resolvedStyle.display == DisplayStyle.None, "持ち物を閉じると絵が隠れる");

    #region Internal

    // 絵の中心（左下原点の画面 px）がポインタから 2px×倍率以内
    // The picture's center (bottom-left-origin screen px) lies within 2px x scale of the pointer
    async UniTask<bool> IsCenteredAsync(Vector2 pointer, string label)
    {
        await p.WaitSeconds(0.5f);
        var overlay = await PlaytestUiElementOps.FindUi("grab-overlay");
        if (!overlay.IsFound)
        {
            p.Note($"絵が見つからない（{overlay.Status}）");
            return false;
        }
        var scale = GameUiRoot.Instance.GetRootElement().panel.scaledPixelsPerPoint;
        var distance = Vector2.Distance(overlay.ScreenRect.center, pointer);
        p.Note($"{label}: 絵の中心={overlay.ScreenRect.center} ポインタ={pointer} 距離={distance:F1}px 倍率={scale}");
        return distance <= 2f * scale;
    }

    #endregion
});
```
