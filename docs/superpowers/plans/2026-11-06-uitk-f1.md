# UITK F1 基盤整え（段階 2 の前・C1/C4/C5/C6/C8/C9・namespace・Toaster・ギャラリー枠・見た目の例外台帳）Implementation Plan

> **For the controller session (実装を担うsubagentはこのブロックを無視してよい):** このplanの実行は moores-subagent-driven-development スキルが担う。実行モード（規模ゲート未満の単一subagent実装モード／閾値超のタスクごと派遣）は同スキルの規模ゲートに従って決める。ステップはチェックボックス（`- [ ]`）記法で書く。

**Goal:** 段階 2〜5 の部品レーン・画面レーンが「Web と同じ見た目で、層の向きが守られ、部品として再利用できる」形で書き始められるよう、段階 1 の基盤を設計書 `docs/uitk-migration/execution/component-architecture.md` §1.4 の C1・C4・C5・C6・C8・C9 と [A-7]・[A-9]・[A-15] の形へ作り替え、検査（L2）・つまみの効き（L1）・舞台の寸法（L1）を足し、段階 1 の見た目を変えずに（変わるのは Web へ寄る差だけ）`feature/uitk` へマージコミットで取り込む。

**Architecture:** integrator の直列レーン（実行計画 §1.1 の F1 行・§3）。Editor を使う。作業は「動かす（namespace・ディレクトリ）→束ねる（tss）→外す（StyleSheet 引数・カタログ）→一本化（OnClicked・SetText・Toaster）→検査を足す（層の向き・Mantine・calc・つまみ・例外台帳）→層と舞台を割る→Editor の口（ギャラリー）→録画で見た目を確かめる」の順で、各タスクの終わりに compile とそのタスクのテストを緑にしてコミットする。共有ファイル（層 enum・tss・`MainGameUiRegistration`・`Tokens.uss`/`Theme.uss`・台帳・prefab）はこのレーンだけが書き、後続レーンには区画（tss の族別区画・画面登録区画）を渡す。

**Tech Stack:** Unity 6000.3.8f1 UI Toolkit（USS・TSS・PanelSettings）、UI Test Framework（`UITestFixture`）、NUnit、UniRx、VContainer、Node.js（`tools/uitk/*.mjs`）、pnpm（Mantine の `styles.css` を読むため webui の依存を入れる）、uloop CLI、プレイテスト DSL（`unity-playmode-recorded-playtest`）、gh CLI、bd（Beads）

## Global Constraints

- AGENTS.md: 1 ファイル 200 行以下・1 ディレクトリ 10 ファイル以下、partial 禁止、`Func<>` 禁止、try-catch 原則禁止（このplanのコードは使わない）、イベントは UniRx（`Action` のイベントを新設しない）、日英 2 行コメント（各 1 行）、`[SerializeField]` は `_` 無しの小文字キャメル、単純 getter/setter 禁止（`{ get; private set; }` は可）、デフォルト引数禁止、初期化は `Initialize`、`.meta` を手で作らない（ディレクトリの移動は `git mv` で `.meta` ごと動かし、新しいディレクトリの `.meta` は Unity に作らせてコミットする）、prefab・ScriptableObject・シーンは `uloop execute-dynamic-code` 経由でだけ変える・消す
- 名前に技術名（Uitk）を入れない。UITK 側を指す語は `GameUi`。ギャラリーの窓の題とメニューだけは人が探す表示名なので `UITK` を含めてよい（設計書 §3.3 の呼び名）
- 層の向き（設計書 §1.1）: `Client.Game` ← `Client.Ui.State` ← `Client.Ui`。Components は Foundation と `Client.Ui.State.Text` と `Mooresmaster.Localization.Generated` だけを使う
- 色・寸法は C# に書かない。USS の色リテラルは `Tokens.uss`・`SkitTokens.uss`・`SlotTokens.uss`・`MantineTokens.uss`・`DerivedTokens.uss` だけ（`UiStyleConventionRules.ColorLiteralExemptUssFileNames`）
- 生成物（`Tokens.uss`・`SkitTokens.uss`・`SlotTokens.uss`・`MantineTokens.uss`・`TokenConversionExclusions.txt`・`docs/uitk/translucent-tokens.md`）を手で直さない。スクリプトを直して流し直す
- フォント資産（`Assets/UI Toolkit/GameUi/Fonts/*.asset`）はテストや PlayMode で字形が足されて汚れる。各コミットの前に `git status --short "moorestech_client/Assets/UI Toolkit/GameUi/Fonts"` を見て、変わっていれば `git checkout -- "moorestech_client/Assets/UI Toolkit/GameUi/Fonts"` で戻す（theme plan `docs/superpowers/plans/2026-11-05-uitk-stage1-theme.md` Task 3 Step 8 と同じ扱い）
- `.moorestech-external-revisions.json`・`_CompileRequester.cs` は Unity が書き換える。このレーンでは変えないので `git checkout --` で戻してからコミットする
- fail-closed で拒否・無視する経路は理由をログへ出す。黙って続行する行には `silent-ok: <理由> / <誰がどこで気づくか>` を書く
- Unity は自分の worktree の Editor だけを使う。起動・停止の前に `moores-wt status` で所有を確かめる。run-tests とプレイテストを並走させない
- テストのコマンドは worktree の直下で実行する。`<UI>` は `moorestech_client/Assets/Scripts/Client.Ui`、`<T>` は `moorestech_client/Assets/Scripts/Client.Tests` の略記（Files 節は全部 repo 相対の完全なパスで書く）
- バックグラウンドのポーリングで待たない。全部前景で実行する。タスクごとにコミットする

```csharp
// moorestech_client/Assets/Scripts/Client.Tests/Ui/Conventions/UiThemeImportBundleRules.cs
using System.Collections.Generic;
using System.Linq;
using System.Text.RegularExpressions;

namespace Client.Tests.Ui.Conventions
{
    /// <summary>
    /// GameUiTheme.tss の束ね規約を検査し、違反を文で返す（L2・設計書 §1.4 C1・実行計画 E-1）
    /// Checks the GameUiTheme.tss bundling conventions and returns violations as sentences (L2, design C1, execution plan E-1)
    /// </summary>
    public static class UiThemeImportBundleRules
    {
        public const string UnityDefaultThemeUrl = "unity-theme://default";
        private const string ProjectUrlPrefix = "project://database/";
        private const string ClientUiAssetPrefix = "Assets/Scripts/Client.Ui/";

        // 族別区画の固定順。区画名は Client.Ui からの相対ディレクトリ
        // Fixed order of family sections; a section name is a directory relative to Client.Ui
        public static readonly string[] SectionOrder =
        {
            "Foundation/Theme", "Foundation/Stage",
            "Components/Panels", "Components/Slots", "Components/Controls", "Components/Gauges",
            "Components/Text", "Components/Decor", "Components/Recipe", "Components/NodeGraph",
            "Screens",
        };

        private static readonly string[] RootClassCheckedPrefixes = { ClientUiAssetPrefix + "Components/", ClientUiAssetPrefix + "Screens/" };
        private static readonly Regex ImportLine = new(@"^\s*@import\s+url\(""([^""]+)""\)\s*;\s*$");
        private static readonly Regex SectionLine = new(@"^\s*/\*\s*==\s*section:\s*([\w/]+)\s*==\s*\*/\s*$");
        private static readonly Regex Comment = new(@"/\*.*?\*/", RegexOptions.Singleline);
        private static readonly Regex FirstClassSelector = new(@"^\s*\.([\w-]+)", RegexOptions.Multiline);

        public static List<string> CheckBundle(string tssText, IReadOnlyCollection<string> clientUiUssAssetPaths)
        {
            var violations = new List<string>();
            var importCounts = new Dictionary<string, int>();
            string currentSection = null;
            var lastSectionIndex = -1;
            var importIndex = 0;
            var lines = tssText.Split('\n');
            for (var i = 0; i < lines.Length; i++)
            {
                var line = lines[i].TrimEnd('\r');
                var section = SectionLine.Match(line);
                if (section.Success)
                {
                    CheckSection(section.Groups[1].Value, i + 1);
                    continue;
                }
                var import = ImportLine.Match(line);
                if (import.Success) CheckImport(import.Groups[1].Value, i + 1);
            }

            // Client.Ui の USS は全部ちょうど 1 回束ねる
            // Every Client.Ui USS is bundled exactly once
            foreach (var path in clientUiUssAssetPaths)
            {
                importCounts.TryGetValue(path, out var count);
                if (count != 1) violations.Add($"{path} is imported {count} times (expected 1)");
            }
            return violations;

            #region Internal

            void CheckSection(string name, int lineNumber)
            {
                var index = System.Array.IndexOf(SectionOrder, name);
                if (index < 0) violations.Add($"line {lineNumber}: unknown section '{name}'");
                else if (index <= lastSectionIndex) violations.Add($"line {lineNumber}: section '{name}' is out of order");
                lastSectionIndex = System.Math.Max(lastSectionIndex, index);
                currentSection = name;
            }

            void CheckImport(string url, int lineNumber)
            {
                importIndex++;
                // 先頭は Unity の既定テーマ。区画の外に置く
                // The first import is Unity's default theme, outside any section
                if (importIndex == 1)
                {
                    if (url != UnityDefaultThemeUrl) violations.Add($"line {lineNumber}: first import must be {UnityDefaultThemeUrl}");
                    return;
                }
                if (!url.StartsWith(ProjectUrlPrefix))
                {
                    violations.Add($"line {lineNumber}: '{url}' is not a project://database/ url");
                    return;
                }
                var assetPath = url.Substring(ProjectUrlPrefix.Length);
                importCounts[assetPath] = importCounts.TryGetValue(assetPath, out var count) ? count + 1 : 1;
                if (!clientUiUssAssetPaths.Contains(assetPath)) violations.Add($"line {lineNumber}: '{assetPath}' is not an existing Client.Ui USS");
                if (currentSection == null || !assetPath.StartsWith($"{ClientUiAssetPrefix}{currentSection}/")) violations.Add($"line {lineNumber}: '{assetPath}' is outside its section '{currentSection}'");
            }

            #endregion
        }

        public static List<string> CheckUniqueRootClasses(IReadOnlyDictionary<string, string> ussTextByAssetPath)
        {
            // 部品と画面の USS は最初の規則のクラスがルート。ルートは全 USS で一意
            // The first rule's class is the root of a component or screen USS; roots are unique across all USS
            var violations = new List<string>();
            var ownerByRoot = new Dictionary<string, string>();
            foreach (var (path, text) in ussTextByAssetPath.OrderBy(pair => pair.Key, System.StringComparer.Ordinal))
            {
                if (!RootClassCheckedPrefixes.Any(path.StartsWith)) continue;
                var match = FirstClassSelector.Match(Comment.Replace(text, ""));
                if (!match.Success)
                {
                    violations.Add($"{path} has no root class selector");
                    continue;
                }
                var root = match.Groups[1].Value;
                if (ownerByRoot.TryGetValue(root, out var owner)) violations.Add($"root class .{root} is shared by {owner} and {path}");
                else ownerByRoot.Add(root, path);
            }
            return violations;
        }
    }
}
```

```csharp
using Client.Localization;
using Client.Ui.State.Text;
using Mooresmaster.Localization.Generated;
using UniRx;
using UnityEngine;
using UnityEngine.UIElements;

namespace Client.Ui.Foundation.Text
{
    /// <summary>
    /// UiText（キーと引数）を 1 つ持ち、パネルにいる間は言語変更で解決し直すラベル（plan.md §3.9・設計書 C9）
    /// Label holding one UiText (key and params) that re-resolves on language change while on a panel (plan.md §3.9, design C9)
    /// </summary>
    public class LocalizedLabel : Label
    {
        private UiText _text;
        private IDisposable _languageSubscription;

        public LocalizedLabel()
        {
            RegisterCallback<AttachToPanelEvent>(_ => OnAttached());
            RegisterCallback<DetachFromPanelEvent>(_ => OnDetached());
        }

        public void SetKey(LocalizationKey key)
        {
            SetText(new UiText(key));
        }

        public void SetText(UiText text)
        {
            _text = text;
            if (panel != null) Resolve();
        }

        private void OnAttached()
        {
            // 文が無いまま載ったら生の文言を出さず、開発者に知らせる
            // Report a label attached without a text instead of showing raw text
            if (_text == null) Debug.LogError($"[LocalizedLabel] attached without a text: {name}");
            _languageSubscription?.Dispose();
            _languageSubscription = Localize.OnLanguageChanged.Subscribe(_ => Resolve());
            Resolve();
        }

        private void OnDetached()
        {
            _languageSubscription?.Dispose();
            _languageSubscription = null;
        }

        private void Resolve()
        {
            // silent-ok: 文が無いときは OnAttached が LogError 済み / 開発者が Console で気づく
            if (_text == null) return;
            text = _text.Resolve();
        }
    }
```

```csharp
// moorestech_client/Assets/Scripts/Client.Ui.State/Text/UiText.cs
using System;
using System.Collections.Generic;
using Client.Localization;
using Mooresmaster.Localization.Generated;

namespace Client.Ui.State.Text
{
    /// <summary>
    /// 表示の直前に現在の言語へ解く文。辞書キー・コンテンツ辞書キー・解決済みの文の 3 種を運ぶ（設計書 A-40）
    /// A sentence resolved right before display; carries a dictionary key, a content key or already-resolved text (design A-40)
    /// </summary>
    public sealed class UiText
    {
        public UiTextSource Source { get; }

        // Source が Dictionary のときだけ意味を持つ
        // Meaningful only when Source is Dictionary
        public LocalizationKey Key { get; }
        public IReadOnlyList<LocalizationTextParam> Params { get; }

        // Source が Content のときだけ意味を持つ
        // Meaningful only when Source is Content
        public ContentLocalizationKey ContentKey { get; }

        // Source が Verbatim のときだけ意味を持つ
        // Meaningful only when Source is Verbatim
        public string VerbatimText { get; }

        public UiText(LocalizationKey key, IReadOnlyList<LocalizationTextParam> textParams)
            : this(UiTextSource.Dictionary, key, textParams, default, null)
        {
        }

        public UiText(LocalizationKey key) : this(key, Array.Empty<LocalizationTextParam>())
        {
        }

        private UiText(UiTextSource source, LocalizationKey key, IReadOnlyList<LocalizationTextParam> textParams, ContentLocalizationKey contentKey, string verbatimText)
        {
            Source = source;
            Key = key;
            Params = textParams;
            ContentKey = contentKey;
            VerbatimText = verbatimText;
        }

        // アイテム名・研究名・チャレンジのカテゴリ名など、マスタの GUID から導くキー
        // Keys derived from master GUIDs, such as item, research and challenge-category names
        public static UiText FromContent(ContentLocalizationKey key)
        {
            return new UiText(UiTextSource.Content, default, Array.Empty<LocalizationTextParam>(), key, null);
        }

        // サーバーのモーダル要求の題・本文・ボタン文言など、送り手が解決済みの文。訳さない
        // Text the sender already resolved (server modal titles, bodies, button labels); never translated
        public static UiText FromVerbatim(string text)
        {
            if (text == null) throw new ArgumentNullException(nameof(text), "[UiText] verbatim text must not be null");
            return new UiText(UiTextSource.Verbatim, default, Array.Empty<LocalizationTextParam>(), default, text);
        }

        public string Resolve()
        {
            // 種ごとの口で解く。言語変更での解き直しは LocalizedLabel と LocalizedTextBinding が呼ぶ
            // Resolve through the matching path; LocalizedLabel and LocalizedTextBinding call this again on language change
            switch (Source)
            {
                case UiTextSource.Dictionary:
                    return Params.Count == 0 ? Localize.Get(Key) : Localize.GetFormatted(Key, Params);
                case UiTextSource.Content:
                    return Localize.GetContent(ContentKey);
                case UiTextSource.Verbatim:
                    return VerbatimText;
                default:
                    throw new InvalidOperationException($"[UiText] unknown source {Source}");
            }
        }
    }

    public enum UiTextSource
    {
        Dictionary,
        Content,
        Verbatim,
    }
}
```

```csharp
using Client.Localization;
using Client.Ui.State.Commands;
using UnityEngine;

namespace Client.Ui.State.Toast
{
    /// <summary>
    /// 型付きコマンドの結果をトーストへ振り分ける唯一の口。受理は何もせず、拒否はログへ残し、良性でなければ翻訳文を error で出す
    /// The single place that routes typed command results to toasts: accepted does nothing, rejected is logged and, unless benign, shown as a translated error
    /// </summary>
    public sealed class UiCommandResultToaster
    {
        private readonly GameUiToastFeed _toasts;

        public UiCommandResultToaster(GameUiToastFeed toasts)
        {
            _toasts = toasts;
        }

        public void Report(string commandName, UiCommandResult result)
        {
            // 受理の案内（送信完了など）は画面ごとの文なので、ここでは出さない
            // Acceptance notices (such as "sent") are per-screen sentences, so none is shown here
            if (result is not UiCommandRejected rejected) return;

            // Always log the command name and failure code for developers; benign rejections stop at the log
            Debug.LogWarning($"[UiCommandResultToaster] {commandName} failed: {rejected.ToWireCode()}");
            if (UiCommandRejectReasonTraits.IsBenign(rejected.Reason)) return;
            _toasts.Show(Localize.Get(UiCommandRejectReasonTraits.ToLocalizationKey(rejected.Reason)), GameUiToastVariant.Error);
        }
    }
```

```csharp
// moorestech_client/Assets/Scripts/Client.Tests/Ui/Conventions/UiLayerDependencyRules.cs
using System.Collections.Generic;
using System.Linq;
using System.Text.RegularExpressions;

namespace Client.Tests.Ui.Conventions
{
    /// <summary>
    /// Client.Ui の中の層（Foundation・Components・Content・Screens）の参照の向きを using と完全修飾名で検査する（L2・設計書 §1.1・A-1）
    /// Checks the reference direction between layers inside Client.Ui (Foundation, Components, Content, Screens) by usings and qualified names (L2, design §1.1, A-1)
    /// </summary>
    public static class UiLayerDependencyRules
    {
        private sealed class LayerRule
        {
            public LayerRule(string directoryPrefix, string[] forbiddenNamespaces, string[] allowedNamespaces)
            {
                DirectoryPrefix = directoryPrefix;
                ForbiddenNamespaces = forbiddenNamespaces;
                AllowedNamespaces = allowedNamespaces;
            }

            public string DirectoryPrefix { get; }
            public string[] ForbiddenNamespaces { get; }
            public string[] AllowedNamespaces { get; }
        }

        // 層ごとの禁止 namespace と、禁止の中で許す例外（State の Text・Routing）
        // Forbidden namespaces per layer, and allowed exceptions inside them (State's Text and Routing)
        private static readonly LayerRule[] Rules =
        {
            new("Components/", new[] { "Client.Game", "Client.Ui.Screens", "Client.Ui.Content", "Client.Ui.State", "Core.Master", "Client.Network" }, new[] { "Client.Ui.State.Text" }),
            new("Foundation/", new[] { "Client.Ui.Components", "Client.Ui.Content", "Client.Ui.Screens", "Client.Ui.State" }, new[] { "Client.Ui.State.Text", "Client.Ui.State.Routing" }),
            new("Content/", new[] { "Client.Ui.Screens" }, new string[0]),
        };

        private static readonly Regex LineComment = new(@"//[^\n]*");
        private static readonly Regex BlockComment = new(@"/\*.*?\*/", RegexOptions.Singleline);
        private static readonly Regex StringLiteral = new(@"""(?:\\.|[^""\\])*""");
        private static readonly Regex QualifiedName = new(@"\b([A-Z]\w*(?:\.[A-Z]\w*)+)");

        public static List<string> FindViolations(string clientUiRelativePath, string sourceText)
        {
            var rule = Rules.FirstOrDefault(candidate => clientUiRelativePath.StartsWith(candidate.DirectoryPrefix));
            var violations = new List<string>();
            if (rule == null) return violations;

            // コメントと文字列を除いた本文の、ドット区切りの名前を全部見る
            // Look at every dotted name in the body after removing comments and strings
            var code = StringLiteral.Replace(BlockComment.Replace(LineComment.Replace(sourceText, ""), ""), "\"\"");
            foreach (Match match in QualifiedName.Matches(code))
            {
                var name = match.Groups[1].Value;
                var forbidden = rule.ForbiddenNamespaces.FirstOrDefault(ns => IsUnder(name, ns));
                if (forbidden == null || rule.AllowedNamespaces.Any(ns => IsUnder(name, ns))) continue;
                violations.Add($"{clientUiRelativePath}: {rule.DirectoryPrefix.TrimEnd('/')} must not reference {name}");
            }
            return violations.Distinct().ToList();

            #region Internal

            bool IsUnder(string name, string ns)
            {
                return name == ns || name.StartsWith(ns + ".");
            }

            #endregion
        }
    }
}
```

```js
// tools/uitk/webTokens/mantineTokens.mjs
// Mantine の styles.css から基底（:root,:host）と暗色の上書きブロックを読み、Web が使う --mantine-* の名前と生の値を返す
// Reads the base (:root,:host) and dark-override blocks from Mantine's styles.css and returns the --mantine-* names the Web uses with their raw values
import { stripComments } from "./parseCssTokens.mjs";

const scales = ["xs", "sm", "md", "lg", "xl"];
const paletteNames = ["dark", "gray", "blue", "red", "green"];
const accentNames = ["blue", "red", "green"];
const semanticNames = ["text", "body", "dimmed", "placeholder", "error", "default", "default-hover", "default-color", "default-border", "disabled", "disabled-color"];
const baseSelector = /^:root\s*,\s*:host$/;
const darkSelector = /^:root\[data-mantine-color-scheme='dark'\]\s*,\s*:host\(\[data-mantine-color-scheme='dark'\]\)$/;

// 出力する名前の一覧（出力順）。Web の CSS・features と UITK の部品が参照するものに限る
// Names to emit, in output order; limited to what the Web CSS/features and the UITK components reference
export function mantineTokenNames() {
  const names = ["--mantine-color-white", "--mantine-color-black"];
  for (const palette of paletteNames) for (let shade = 0; shade <= 9; shade++) names.push(`--mantine-color-${palette}-${shade}`);
  for (const semantic of semanticNames) names.push(`--mantine-color-${semantic}`);
  names.push("--mantine-primary-color-filled", "--mantine-primary-color-filled-hover");
  for (const accent of accentNames) names.push(`--mantine-color-${accent}-filled`, `--mantine-color-${accent}-filled-hover`, `--mantine-color-${accent}-text`, `--mantine-color-${accent}-light-color`);
  for (const kind of ["spacing", "radius", "font-size", "line-height"]) for (const scale of scales) names.push(`--mantine-${kind}-${scale}`);
  names.push("--mantine-radius-default", "--mantine-line-height");
  return names;
}

// 基底の宣言を読み、暗色の上書きを後から当てる（Web は MantineProvider defaultColorScheme="dark"）
// Read base declarations, then apply the dark overrides on top (the Web uses MantineProvider defaultColorScheme="dark")
export function readMantineRawTokens(cssText) {
  const raw = new Map();
  const darkBlocks = [];
  for (const match of stripComments(cssText).matchAll(/([^{}]+)\{([^{}]*)\}/g)) {
    const selector = match[1].trim().replace(/\s+/g, " ");
    if (baseSelector.test(selector)) addDeclarations(raw, match[2]);
    else if (darkSelector.test(selector)) darkBlocks.push(match[2]);
  }
  if (raw.size === 0 || darkBlocks.length === 0) throw new Error("Mantine styles.css has no :root,:host block or no dark override block");
  for (const block of darkBlocks) addDeclarations(raw, block);
  return raw;
}

// var(--x) だけの値を参照先の生の値まで辿る。辿れなければ止める
// Follow a bare var(--x) value to the referenced raw value; stop when it cannot be followed
export function resolveVarChain(raw, name) {
  let value = raw.get(name);
  const seen = new Set([name]);
  for (let reference = /^var\((--[\w-]+)\)$/.exec(value ?? ""); reference !== null; reference = /^var\((--[\w-]+)\)$/.exec(value)) {
    if (seen.has(reference[1]) || !raw.has(reference[1])) throw new Error(`${name}: cannot follow ${reference[1]}`);
    seen.add(reference[1]);
    value = raw.get(reference[1]);
  }
  if (value === undefined) throw new Error(`${name} is not declared in Mantine styles.css`);
  return value;
}

function addDeclarations(raw, body) {
  for (const declaration of body.split(";")) {
    const match = declaration.match(/^\s*(--[\w-]+)\s*:\s*([\s\S]+?)\s*$/);
    if (match) raw.set(match[1], match[2].replace(/\s+/g, " "));
  }
}
```

```js
  const comment = result.comment === undefined ? `web: ${result.value} α補正` : `${result.comment}; web: ${result.value} α補正`;
  return { ...result, value: ussValue, comment };
}
```

```csharp
// moorestech_client/Assets/Scripts/Client.Tests/Ui/Theme/Calc/CssCalcEvaluator.cs
using System;
using System.Collections.Generic;
using System.Globalization;
using System.Text.RegularExpressions;

namespace Client.Tests.Ui.Theme.Calc
{
    /// <summary>
    /// USS に宣言された値で calc の式を数へ評価する（px と単位なしは同じ数、rem は 16px。L2 の検算専用）
    /// Evaluates a calc expression using values declared in USS (px and unitless are the same number, rem is 16px; for the L2 recheck only)
    /// </summary>
    public sealed class CssCalcEvaluator
    {
        private const float RemPx = 16f;
        private static readonly Regex TokenPattern = new(@"\s*(var\(--[\w-]+\)|\d*\.?\d+(?:px|rem)?|[-+*/()])\s*");
        private static readonly Regex NumberLiteral = new(@"^(-?\d*\.?\d+)(px|rem)?$");
        private readonly IReadOnlyDictionary<string, string> _declaredValues;
        private List<string> _tokens;
        private int _position;

        public CssCalcEvaluator(IReadOnlyDictionary<string, string> declaredValues)
        {
            _declaredValues = declaredValues;
        }

        public float Evaluate(string expression)
        {
            _tokens = Tokenize(expression);
            _position = 0;
            var value = ParseSum();
            if (_position != _tokens.Count) throw new FormatException($"unexpected '{_tokens[_position]}' in '{expression}'");
            return value;
        }

        private float ParseSum()
        {
            var value = ParseProduct();
            while (Peek() == "+" || Peek() == "-")
            {
                var op = _tokens[_position++];
                var right = ParseProduct();
                value = op == "+" ? value + right : value - right;
            }
            return value;
        }

        private float ParseProduct()
        {
            var value = ParseFactor();
            while (Peek() == "*" || Peek() == "/")
            {
                var op = _tokens[_position++];
                var right = ParseFactor();
                value = op == "*" ? value * right : value / right;
            }
            return value;
        }

        private float ParseFactor()
        {
            var token = _tokens[_position++];
            if (token == "-") return -ParseFactor();
            if (token == "(")
            {
                var inner = ParseSum();
                if (Peek() != ")") throw new FormatException("missing ')'");
                _position++;
                return inner;
            }
            if (token.StartsWith("var("))
            {
                // 参照先は宣言値（px か単位なし）だけを受ける
                // A reference accepts only a declared px or unitless value
                var name = token.Substring(4, token.Length - 5);
                if (!_declaredValues.TryGetValue(name, out var declared)) throw new KeyNotFoundException($"{name} is not declared in the token USS");
                return ParseLiteral(declared.Trim());
            }
            return ParseLiteral(token);
        }

        private string Peek()
        {
            return _position < _tokens.Count ? _tokens[_position] : null;
        }

        private static float ParseLiteral(string text)
        {
            var match = NumberLiteral.Match(text);
            if (!match.Success) throw new FormatException($"'{text}' is not a px, rem or unitless number");
            var number = float.Parse(match.Groups[1].Value, CultureInfo.InvariantCulture);
            return match.Groups[2].Value == "rem" ? number * RemPx : number;
        }

        private static List<string> Tokenize(string expression)
        {
            var tokens = new List<string>();
            var position = 0;
            while (position < expression.Length)
            {
                var match = TokenPattern.Match(expression, position);
                if (!match.Success || match.Index != position) throw new FormatException($"cannot read '{expression.Substring(position)}'");
                tokens.Add(match.Groups[1].Value);
                position += match.Length;
            }
            return tokens;
        }
    }
}
```

```csharp
// moorestech_client/Assets/Scripts/Client.Ui/Foundation/Stage/UiStageFrame.cs
using System;
using UnityEngine.UIElements;

namespace Client.Ui.Foundation.Stage
{
    /// <summary>
    /// 1 つの層の中に「実画面いっぱい」と「中央の 1280×720 の舞台」の 2 つの子を作る。寸法と配置は UiStageFrame.uss が持つ
    /// Builds the two children of one layer, the full-screen viewport and the centered 1280x720 stage; sizes and placement live in UiStageFrame.uss
    /// </summary>
    public sealed class UiStageFrame
    {
        private const string ViewportClassName = "ui-stage-frame__viewport";
        private const string StageClassName = "ui-stage-frame__stage";

        private readonly VisualElement _viewport;
        private readonly VisualElement _stage;

        private UiStageFrame(VisualElement viewport, VisualElement stage)
        {
            _viewport = viewport;
            _stage = stage;
        }

        public static UiStageFrame Build(VisualElement layerContainer)
        {
            // 実画面の子を先、舞台を後に足す（同じ層の中では舞台が前面）
            // Add the viewport child first and the stage after it (the stage is in front within a layer)
            var viewport = CreateChild("viewport", ViewportClassName);
            var stage = CreateChild("stage", StageClassName);
            layerContainer.Add(viewport);
            layerContainer.Add(stage);
            return new UiStageFrame(viewport, stage);

            #region Internal

            VisualElement CreateChild(string suffix, string className)
            {
                // 族の子もクリックを受けず、空の場所はワールドへ抜ける
                // Family children take no clicks either, so empty spots fall through to the world
                var child = new VisualElement { name = $"{layerContainer.name}-{suffix}", pickingMode = PickingMode.Ignore };
                child.AddToClassList(className);
                return child;
            }

            #endregion
        }

        public VisualElement Get(UiFamily family)
        {
            return family switch
            {
                UiFamily.Stage => _stage,
                UiFamily.Viewport => _viewport,
                _ => throw new ArgumentOutOfRangeException(nameof(family), family, null),
            };
        }
    }
}
```

```csharp
// moorestech_client/Assets/Scripts/Client.Ui/Foundation/Layers/UiLayerStack.cs
using System;
using System.Collections.Generic;
using Client.Ui.Foundation.Stage;
using UnityEngine.UIElements;

namespace Client.Ui.Foundation.Layers
{
    /// <summary>
    /// ルート直下に層コンテナを enum 順で並べ、各層に舞台と実画面の 2 族の子を置いて、層と族で引けるようにする
    /// Lays out one container per layer under the root in enum order, gives each the stage and viewport family children, and looks them up by layer and family
    /// </summary>
    public sealed class UiLayerStack
    {
        private const string LayerUssClassName = "game-ui-layer";

        private readonly Dictionary<UiLayer, UiStageFrame> _frames;

        private UiLayerStack(Dictionary<UiLayer, UiStageFrame> frames)
        {
            _frames = frames;
        }

        public static UiLayerStack Build(VisualElement root)
        {
            // ルートも層もクリックを受けず、空の場所はワールドへ抜ける
            // Neither the root nor the layers take clicks, so empty spots fall through to the world
            root.pickingMode = PickingMode.Ignore;
            var frames = new Dictionary<UiLayer, UiStageFrame>();

            // 後に Add した子ほど前面に描かれるので enum 順に足す
            // Later children draw in front, so add them in enum order
            foreach (UiLayer layer in Enum.GetValues(typeof(UiLayer)))
            {
                var container = CreateLayerContainer(layer);
                root.Add(container);
                frames.Add(layer, UiStageFrame.Build(container));
            }

            return new UiLayerStack(frames);

            #region Internal

            VisualElement CreateLayerContainer(UiLayer layer)
            {
                var container = new VisualElement { name = $"layer-{layer}", pickingMode = PickingMode.Ignore };
                // 全面に広げて重ねる配置は UiStageFrame.uss の .game-ui-layer が持つ
                // The full-root overlapping placement lives in .game-ui-layer of UiStageFrame.uss
                container.AddToClassList(LayerUssClassName);
                return container;
            }

            #endregion
        }

        public VisualElement GetLayer(UiLayer layer, UiFamily family)
        {
            return _frames[layer].Get(family);
        }
    }
}
```

```csharp
    /// Verifies the IDs in the "look exceptions" ledger and the look-exception markers in code match exactly (L2, design §3.4)
    /// </summary>
    public class LookExceptionLedgerTest
    {
        private const string LedgerPath = "docs/uitk/TODO.md";
        private const string SectionHeading = "## 見た目の例外";
        private const string ClientUiDirectory = "moorestech_client/Assets/Scripts/Client.Ui";
        private static readonly Regex LedgerId = new(@"^\|\s*(LX-\d+)\s*\|", RegexOptions.Multiline);
        private static readonly Regex Marker = new(@"look-exception:\s*(LX-\d+)");

        [Test]
        public void LedgerIdsAndCodeMarkersMatch()
        {
            var ledgerIds = LedgerId.Matches(ReadSection()).Select(match => match.Groups[1].Value).ToList();
            Assert.IsNotEmpty(ledgerIds, $"{SectionHeading} has no LX rows");
            Assert.AreEqual(ledgerIds.Count, ledgerIds.Distinct().Count(), "duplicate LX ids in the ledger");

            // 1 つの例外が複数の行に印を持ってよい
            // One exception may mark several lines
            var markerIds = new[] { "*.uss", "*.cs" }
                .SelectMany(pattern => Directory.GetFiles(Path.Combine(RepositoryRoot(), ClientUiDirectory), pattern, SearchOption.AllDirectories))
                .SelectMany(path => Marker.Matches(File.ReadAllText(path)).Select(match => match.Groups[1].Value))
                .ToHashSet();
            CollectionAssert.AreEquivalent(ledgerIds.ToHashSet(), markerIds, "ledger ids and look-exception markers differ");
        }

        private static string ReadSection()
        {
            // 見出しから次の ## 見出しの前まで
            // From the heading up to the next ## heading
            var text = File.ReadAllText(Path.Combine(RepositoryRoot(), LedgerPath));
            var start = text.IndexOf(SectionHeading, System.StringComparison.Ordinal);
            Assert.GreaterOrEqual(start, 0, $"{LedgerPath} has no {SectionHeading}");
            var end = text.IndexOf("\n## ", start + SectionHeading.Length, System.StringComparison.Ordinal);
            return end < 0 ? text.Substring(start) : text.Substring(start, end - start);
        }

        private static string RepositoryRoot()
        {
```

```csharp
// moorestech_client/Assets/Scripts/Client.Ui/Foundation/Tooltip/HoverTooltipMark.cs
using System.Runtime.CompilerServices;
using Client.Ui.State.Text;
using UnityEngine.UIElements;

namespace Client.Ui.Foundation.Tooltip
{
    /// <summary>
    /// ホバーのツールチップを出す要素の印。部品が文を付け、宿主（C3-b の HoverTooltipHost）が指した要素から最も近い印を引く（Web の shared/ui/HoverTooltip・ADR 0019）
    /// Mark for elements that show a hover tooltip: components attach the text, and the host (HoverTooltipHost in C3-b) finds the nearest mark from the hovered element (Web shared/ui/HoverTooltip, ADR 0019)
    /// </summary>
    public static class HoverTooltipMark
    {
        public const string TargetClassName = "hover-tooltip-target";

        // 要素が消えれば印の文も一緒に回収される
        // A mark's text is collected together with its element
        private static readonly ConditionalWeakTable<VisualElement, UiText> TextByElement = new();

        public static void Mark(VisualElement element, UiText text)
        {
            TextByElement.AddOrUpdate(element, text);
            element.AddToClassList(TargetClassName);
        }

        public static void Unmark(VisualElement element)
        {
            TextByElement.Remove(element);
            element.RemoveFromClassList(TargetClassName);
        }

        public static bool TryFindMarked(VisualElement from, out VisualElement marked, out UiText text)
        {
            // 指した要素から親へ辿り、最初に見つけた印を返す
            // Walk from the hovered element up through its parents and return the first mark found
            for (var current = from; current != null; current = current.parent)
            {
                if (!TextByElement.TryGetValue(current, out text)) continue;
                marked = current;
                return true;
            }
            marked = null;
            text = null;
            return false;
        }
    }
}
```

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using UnityEditor;

namespace Client.Ui.Editor.Gallery
{
    // 見本を TypeCache で集める。部品レーンは IUiGalleryEntry を 1 つ足すだけでよい
    // Collects entries through TypeCache, so a component lane only adds one IUiGalleryEntry
    public static class UiGalleryEntryCatalog
    {
        public static IReadOnlyList<IUiGalleryEntry> CreateAll()
        {
            return TypeCache.GetTypesDerivedFrom<IUiGalleryEntry>()
                .Where(type => !type.IsAbstract && !type.IsInterface)
                .Select(type => (IUiGalleryEntry)Activator.CreateInstance(type))
                .OrderBy(entry => entry.Family)
                .ThenBy(entry => entry.ComponentName, StringComparer.Ordinal)
                .ToList();
        }
    }
}
```
