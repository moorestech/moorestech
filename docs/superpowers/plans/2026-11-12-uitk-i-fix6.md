# UITK I-fix6（X-audit の反映） Implementation Plan

> **For the controller session (実装を担うsubagentはこのブロックを無視してよい):** このplanの実行は moores-subagent-driven-development スキルが担う。実行モード（規模ゲート未満の単一subagent実装モード／閾値超のタスクごと派遣）は同スキルの規模ゲートに従って決める。ステップはチェックボックス（`- [ ]`）記法で書く。

**Goal:** feature/uitk 全体の横断レビュー（X-audit）が I-fix6 に割り振った未適用の Critical（AC）と設計判断（DC）を直し、UITK の UI を「Web と同じ見た目・適切な設計・コンポーネント化」へ近づける。

**Architecture:** X-audit の各項目の「修正」「案」を、指揮の決定（推奨の案 A を既定・A に「負債が残る」とあり根本案があれば根本案）で当てる。I-fix5 と重なる項目（共有 enum・部品・トークン）は I-fix5 が feature/uitk にマージされてから段 B で当て、それ以外を段 A で先に当てる。段ごとに moores-code-review → PR（base=feature/uitk）→ マージ。
