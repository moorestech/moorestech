# UITK S5-gate（段階 5 画面: 出展モードの言語ゲート〈DI より前の全画面ゲート〉）Implementation Plan

> **For the controller session (実装を担うsubagentはこのブロックを無視してよい):** このplanの実行は moores-subagent-driven-development スキルが担う。実行モード（規模ゲート未満の単一subagent実装モード／閾値超のタスクごと派遣）は同スキルの規模ゲートに従って決める。ステップはチェックボックス（`- [ ]`）記法で書く。

**Goal:** 全体スイッチ UITK（GameUi）で出展モード（`MOORESTECH_EVENT_MODE=1`）に起動すると、Web 版の `features/eventLanguageGate` と同じ見た目の全画面の言語ゲートが、ゲームの DI より前に `GameUiRoot` の最前面の層へ出て、言語のボタンを押すとその言語でゲームが始まるようにする（X-audit DC-37 の案 A）。辞書を通さない文言は C# の定数へ移し、L0/L1・並べ比べ（1280×720・2560×1080）・録画 `uitk/stage5/uitk-event-language-gate` まで済ませて `feature/uitk` へ取り込む。

**Architecture:** 画面レーン（単位エージェント・Mac の Editor 1 本）。State（`Client.Ui.State/EventMode/`）は既存の `EventLanguageGate` をそのまま使い、辞書を通さない見出しの定数 `EventLanguageGateText.Title` だけを足す（Web の結末の 1 行〈開始中・失敗〉は UITK の本番で見える状態が無いので写さない。D-6）。View（`Client.Ui/Screens/EventMode/`）は `UiLayer.FullScreenGate`・`UiFamily.Viewport` の層に不透明の黒い面を敷き、中身（見出し・`FormButton` の列）を `UiScreenPixelScope` に置いて舞台の倍率を打ち消し（[A-41]）、押下を受けてゲートの `SelectLanguage` を直接呼び、拒否が返ればログに残す（[A-8]）。Presenter は待機中に層へ載せ、受理で外すだけ。GameUi の系では composition root（`MainGameStarter.PrepareUiBeforeDi`）が、出展モードか否かによらず DI より前に土台 `GameUiPreDiFoundation`（`Client.Starter/` 直下。sRGB 合成 `GameUiSrgbCompositeInstaller`・ロケールのクラス `GameUiLocaleClassBinder`・倍率の見張り `GameUiStageScaleWatch`）を 1 本だけ立て、言語ゲートはその倍率を使い、DI へは作り済みのインスタンスを渡す（[A-183]・[A-75] の置き場を改める。Foundation は変えない。土台もゲーム寿命なので破棄しない）。DI 前の宿主 `EventLanguageGateBootHost` と境界 `IEventLanguageGateScreen` は `Client.Starter/EventMode/`。系の出し分けは composition root の `EventModeStartGate` 1 か所に置き、系ごとの待ちは描き手を必須で受ける（GameUi → 画面の境界で UITK のゲート、Web で hub あり → 既存の Web の Binder、Web で hub 無し → 既存の英語フォールバック）。GameUi の系でゲートを出す前提（層がパネルに付いている・言語の一覧が空でない）は、土台の Initialize と言語の一覧の生成が起動とビルドの段階で止めて保証するので、GameUi の系に英語開始の縮退は置かない（D-3）。

        // ログのコマンド名は Web の action 名と同じ（UiCommandResultToaster の書式に揃える）

        public EventLanguageGateView(EventLanguageGate gate, StageScaleSource stageScale, IReadOnlyList<LanguageInfo> languages)

            Add(scope);

            // Stack the fixed-English heading and the body, centred (Web Stack align center gap xl)

            column.AddItem(CreateTitle());
            var body = new EventLanguageGateBody(languages);

            column.AddItem(body);
            overlay.Add(column);

using System.Collections.Generic;
using Client.Ui.Foundation.Stage.ScaleReading;
using Client.Ui.State.EventMode;
using Mooresmaster.Localization.Generated;
using UniRx;
using UnityEngine.UIElements;

namespace Client.Ui.Screens.EventMode

    /// <summary>
    /// 言語ゲートの待機中だけ View を層へ載せ、受理で外す。押下と拒否のログは View が持つ
    /// Mounts the view on the layer only while the language gate waits and removes it on acceptance; presses and the rejection log belong to the view
    /// </summary>
    /// <remarks>
    /// DI に載せない: ゲームの DI は言語が選ばれた後に組まれるので、その前に要るこの画面は開始側（Starter の宿主）が作る。ゲート本体 EventLanguageGate と同じ扱い
    /// Not registered in DI: the game DI is built after the language is chosen, so this screen, needed before that, is built by the starter's host, like the EventLanguageGate itself
    /// </remarks>
    public sealed class EventLanguageGatePresenter
    {
        private readonly EventLanguageGate _gate;
        private readonly VisualElement _layer;
        private readonly EventLanguageGateView _view;
        private IDisposable _waitingSubscription;

        public EventLanguageGatePresenter(EventLanguageGate gate, VisualElement layer, StageScaleSource stageScale, IReadOnlyList<LanguageInfo> languages)
        {
            _gate = gate;
            _layer = layer;
            _view = new EventLanguageGateView(gate, stageScale, languages);
        }

        public void Initialize()
        {
            // silent-ok: 待機しないゲートは何も描かない（Web の非表示と同じ）/ 出展モードでない起動は EventModeStartGate が手前で抜けるので、ここへ来るのはテストだけ
            if (!_gate.IsWaitingSelection) return;

            _layer.Add(_view);
            // 受理の通知はその押下の中で同期に来るので、その場で外して二度目の押下を通さない
            // The acceptance notice arrives synchronously inside the press, so remove at once and block a second press
            _waitingSubscription = _gate.OnWaitingChanged.Subscribe(_ => Close());
        }

        private void Close()
        {
            _view.RemoveFromHierarchy();
            _waitingSubscription.Dispose();
        }
    }
}

    /// </summary>

    /// 出展モードか否かで DI の登録の形を分けないため、GameUi の系では常にここで立てる（A-183・A-75 の置き場を改めた。S5-gate D-2）。ゲーム寿命なので破棄の口を持たない（ゲームはメインメニューへ戻らない。AGENTS.md の既知の制約）

    /// </remarks>
    internal sealed class GameUiPreDiFoundation
    {
        private readonly GameUiRoot _gameUiRoot;
        private readonly GameUiSrgbCompositeInstaller _composite;
        private readonly GameUiLocaleClassBinder _localeClass;
        private readonly GameUiStageScaleWatch _stageScaleWatch;
        private readonly StageScaleSource _stageScale;
        private IVisualElementScheduledItem _compositeTickBeforeDi;

        public GameUiPreDiFoundation(GameUiRoot gameUiRoot)
        {
            _gameUiRoot = gameUiRoot;
            _composite = new GameUiSrgbCompositeInstaller(gameUiRoot);
            _localeClass = new GameUiLocaleClassBinder(gameUiRoot);
            _stageScaleWatch = new GameUiStageScaleWatch(gameUiRoot);
            _stageScale = new StageScaleSource(_stageScaleWatch.Scale);
        }

        public void Initialize()
        {
            // 合成はパネルを差し替えるので、root.panel を読む見張りより先に立てる（DI の入口だったときの並び :39・:46 と同じ順）
            // The composite swaps the panel, so it starts before the watch that reads root.panel (same order as the former DI entry points at :39 and :46)
            _composite.Initialize();
            _localeClass.Initialize();
            _stageScaleWatch.Initialize();

            // DI の ITickable が回り出すまでは、画面の大きさの追従をルートの予定で回す（言語ゲートの待ちの間に解像度が変わりうる）
            // Until DI's ITickable runs, follow the screen size on the root's schedule (the resolution may change while the language gate waits)
            _compositeTickBeforeDi = _gameUiRoot.GetRootElement().schedule.Execute(_composite.Tick).Every(0);
        }

        // 出展モードの言語ゲートの画面。最前面の層と、この土台の倍率の読み口を渡す
        // The exhibition language-gate screen, given the frontmost layer and this foundation's scale source
        public IEventLanguageGateScreen CreateEventLanguageGateScreen()
        {
            return new EventLanguageGateBootHost(_gameUiRoot.GetLayer(UiLayer.FullScreenGate, UiFamily.Viewport), _stageScale, LanguageCatalog.Languages);
        }

        // DI へ作り済みのまま渡す。DI 前の毎フレームはここで止め、以後は DI の ITickable が回す（同じ物を二度 Initialize しない）
        // Hand over to DI as built; the pre-DI per-frame tick stops here and DI's ITickable runs it from now on (never Initialize the same object twice)
        public void HandOverTo(ContainerBuilder builder)
        {
            _compositeTickBeforeDi.Pause();
            builder.RegisterInstance(_composite).As<ITickable>();
            builder.RegisterInstance(_stageScale);
        }
    }
}

using Client.Common;
using Client.Playtest.Core;

namespace Client.Playtest.Boot
{
    /// <summary>
    /// 出展モードで起動して言語ゲートを通る録画の起動口。ゲートで初期化が止まるので MainGame の読み込みで ready を書く
    /// Boot entry for recordings that start in exhibition mode and pass the language gate; the gate holds initialization, so ready is written on MainGame load
    /// </summary>
    /// <remarks>
    /// 出展モードの環境変数は Play の間だけ立て、Edit へ戻ったら前の値へ戻す。ワールドを消す自動開始は Play の最初のシーンがメインメニューのときだけ走り、この起動は GameInitialaizer から入るので走らない
    /// The exhibition env vars stand only during Play and return to their prior values on returning to Edit; the world-wiping auto start runs only when Play's first scene is the main menu, and this boot enters from GameInitialaizer
    /// </remarks>
    public static class PlaytestEventLanguageGateBoot
    {
        private const string ArmedKey = "PlaytestEventLanguageGateBoot_Armed";
        private const string AppliedKey = "PlaytestEventLanguageGateBoot_Applied";
        private const string SavedValuePrefix = "PlaytestEventLanguageGateBoot_Value_";
        private const string SavedPresencePrefix = "PlaytestEventLanguageGateBoot_Had_";
        // 録画の間に無操作終了が走らない長さ（既定の 180 秒は録画より短くなりうる）
        // Long enough that no idle quit fires during the recording (the 180 s default can be shorter than a recording)
        private const string RecordingIdleTimeoutSeconds = "3600";

        private static readonly string[] OverriddenKeys = { EventExhibitionSettings.EnableEnvKey, EventExhibitionSettings.EditorOptInEnvKey, EventExhibitionSettings.IdleTimeoutEnvKey };

        // 次の PlaytestBoot の起動 1 回だけを出展モードにする（run-scenario.sh より前に execute-dynamic-code で呼ぶ）
        // Puts only the next PlaytestBoot boot into exhibition mode (call via execute-dynamic-code before run-scenario.sh)
        public static string ArmForNextBoot()
        {
            if (EditorApplication.isPlayingOrWillChangePlaymode) return "ERROR: already playing";
            SessionState.SetBool(ArmedKey, true);
            return "exhibition-armed";
        }

        public static string Disarm()
        {
            SessionState.SetBool(ArmedKey, false);
            return "disarmed";
        }

        // PlaytestBoot のドメインリロード後に呼ぶ。武装していれば 1 回だけ環境変数を立て、MainGame の読み込みで ready を書く
        // Called after PlaytestBoot's domain reload; when armed, sets the env vars once and writes ready on MainGame load
        internal static bool ApplyIfArmed()
        {
            if (!SessionState.GetBool(ArmedKey, false)) return false;
            SessionState.SetBool(ArmedKey, false);

            SaveAndOverrideEnvironment();
            SceneManager.sceneLoaded += WriteReadyOnMainGameLoaded;
            Debug.Log("[PlaytestEventLanguageGateBoot] this boot runs in exhibition mode; ready is written when MainGame loads");
            return true;

            #region Internal

            void SaveAndOverrideEnvironment()
            {
                foreach (var key in OverriddenKeys)
                {
                    var previous = Environment.GetEnvironmentVariable(key);
                    SessionState.SetBool(SavedPresencePrefix + key, previous != null);
                    SessionState.SetString(SavedValuePrefix + key, previous ?? string.Empty);
                }
                Environment.SetEnvironmentVariable(EventExhibitionSettings.EnableEnvKey, EventExhibitionSettings.EnabledValue);
                Environment.SetEnvironmentVariable(EventExhibitionSettings.EditorOptInEnvKey, EventExhibitionSettings.EnabledValue);
                Environment.SetEnvironmentVariable(EventExhibitionSettings.IdleTimeoutEnvKey, RecordingIdleTimeoutSeconds);
                SessionState.SetBool(AppliedKey, true);
            }

            #endregion
        }

        private static void WriteReadyOnMainGameLoaded(Scene scene, LoadSceneMode mode)
        {
            // silent-ok: MainGame 以外のシーンの読み込みは待つ対象でない / MainGame が来なければ run-scenario.sh の ready 待ちが時間切れで NG を出す
            if (scene.name != SceneConstant.MainGameSceneName) return;
            SceneManager.sceneLoaded -= WriteReadyOnMainGameLoaded;
            PlaytestPaths.WriteReadyMarker();
        }

        [InitializeOnLoadMethod]
        private static void HookRestoreOnEditMode()
        {
            EditorApplication.playModeStateChanged -= RestoreOnEditMode;
            EditorApplication.playModeStateChanged += RestoreOnEditMode;
        }

        // Edit へ戻ったら立てる前の値へ戻す（残すと開発機の次の Play が出展モードで始まる）
        // On returning to Edit, restore the prior values (leaving them would start the developer's next Play in exhibition mode)
        private static void RestoreOnEditMode(PlayModeStateChange state)
        {
            if (state != PlayModeStateChange.EnteredEditMode) return;
            // silent-ok: この起動口を使わなかった Play では戻すものが無い / 使った Play は AppliedKey が真
            if (!SessionState.GetBool(AppliedKey, false)) return;
            foreach (var key in OverriddenKeys)
            {
                var hadValue = SessionState.GetBool(SavedPresencePrefix + key, false);
                Environment.SetEnvironmentVariable(key, hadValue ? SessionState.GetString(SavedValuePrefix + key, string.Empty) : null);
            }
            SessionState.SetBool(AppliedKey, false);
        }
    }
}

#!/bin/bash
# uitk-event-language-gate.cs の運転役: 全体スイッチを GameUi にし、次の起動 1 回だけを出展モードにしてから run-scenario.sh を前景で流す
# 出展モードの環境変数は Editor のプロセスに要るので、Unity の中の起動口（PlaytestEventLanguageGateBoot）が Play の間だけ立てる
# Driver for uitk-event-language-gate.cs: switch to GameUi, arm exhibition mode for the next boot only, then run run-scenario.sh in the foreground
# The exhibition env vars must live in the Editor process, so the in-Unity boot entry (PlaytestEventLanguageGateBoot) sets them only during Play
#
# usage: uitk-event-language-gate.sh <unity-project-path>
set -u
PROJECT="$1"
HERE="$(cd "$(dirname "$0")" && pwd)"
SKILL_DIR="$(cd "$HERE/../../.." && pwd)"
SCRATCH="$PROJECT/PlaytestResults/scratch/event-language-gate"
mkdir -p "$SCRATCH"

# 終わり方によらず武装を解き、シナリオが言語を戻せずに落ちていたら選ぶ前の言語へ戻す
# However this ends, disarm; if the scenario died before restoring the language, put the pre-choice language back
on_exit() {
  uloop execute-dynamic-code --project-path "$PROJECT" --code 'return Client.Playtest.Boot.PlaytestEventLanguageGateBoot.Disarm();' >/dev/null \
    || echo "ERROR: disarm failed; run Client.Playtest.Boot.PlaytestEventLanguageGateBoot.Disarm() via execute-dynamic-code"
  [ -f "$SCRATCH/language-before.txt" ] || return 0
  local code
  code=$(cat "$SCRATCH/language-before.txt")
  echo "WARN: the scenario left the language changed; restoring $code"
  # 戻せたかは EDC の戻り値の語で見る（終了コードは EDC が走ったかだけを表す）。戻せたときだけ控えを消す
  # Judge the restore by the word EDC returns (the exit code only says EDC ran); delete the note only on success

  if echo "$restored" | grep -q "language-restored"; then
    rm -f "$SCRATCH/language-before.txt"
  else
    echo "ERROR: language restore to $code failed; language-before.txt kept ($SCRATCH): $restored"
  fi
}
trap on_exit EXIT

# 武装できたかは EDC の戻り値の語で見る（終了コードは EDC が走ったかだけ。Play 中なら ArmForNextBoot は "ERROR: already playing" を返す）
# Judge arming by the word EDC returns (the exit code only says EDC ran; during Play, ArmForNextBoot returns "ERROR: already playing")

  || { echo "NG: could not switch to GameUi or arm exhibition mode (EDC failed)"; exit 1; }

  || { echo "NG: exhibition mode was not armed: $armed"; exit 1; }
