# UITK S5-gate（段階 5 画面: 出展モードの言語ゲート〈DI より前の全画面ゲート〉）Implementation Plan

> **For the controller session (実装を担うsubagentはこのブロックを無視してよい):** このplanの実行は moores-subagent-driven-development スキルが担う。実行モード（規模ゲート未満の単一subagent実装モード／閾値超のタスクごと派遣）は同スキルの規模ゲートに従って決める。ステップはチェックボックス（`- [ ]`）記法で書く。

**Goal:** 全体スイッチ UITK（GameUi）で出展モード（`MOORESTECH_EVENT_MODE=1`）に起動すると、Web 版の `features/eventLanguageGate` と同じ見た目の全画面の言語ゲートが、ゲームの DI より前に `GameUiRoot` の最前面の層へ出て、言語のボタンを押すとその言語でゲームが始まるようにする（X-audit DC-37 の案 A）。辞書を通さない文言は C# の定数へ移し、L0/L1・並べ比べ（1280×720・2560×1080）・録画 `uitk/stage5/uitk-event-language-gate` まで済ませて `feature/uitk` へ取り込む。

**Architecture:** 画面レーン（単位エージェント・Mac の Editor 1 本）。State（`Client.Ui.State/EventMode/`）は既存の `EventLanguageGate` をそのまま使い、辞書を通さない文言の定数 `EventLanguageGateText` と、選択の結果を「開始中／失敗／無し」に畳む純関数 `EventLanguageGateAnswers` を足す。View（`Client.Ui/Screens/EventMode/`）は `UiLayer.FullScreenGate`・`UiFamily.Viewport` の層に不透明の黒い面を敷き、中身（見出し・`FormButton` の列・結末の 1 行）を `UiScreenPixelScope` に置いて舞台の倍率を打ち消す（[A-41]）。ゲートは DI に載せない: DI より前の宿主 `EventLanguageGateBootHost` が、DI の入口と同じ sRGB 合成（`GameUiSrgbCompositeInstaller`）・倍率の見張り（`StageScaleWatch`）・ロケールのクラス（`GameUiLocaleClassBinder`）を借りて開き、選択の後に返す（返すために `UiSrgbPanelTarget.Dispose` が元の `PanelSettings` へ戻す 3 行を Foundation に足す）。系の出し分けは composition root の `EventModeStartGate` 1 か所に置く（GameUi → UITK のゲート、Web で hub あり → 既存の Web の Binder、Web で hub 無し → 既存の英語フォールバック）。

**Tech Stack:** Unity 6000.3.8f1 UI Toolkit（ランタイムパネル・USS・`panel.Pick`）、UniRx、UniTask、NUnit＋`com.unity.ui.test-framework`（`UITestFixture`・`PanelSimulator`）、uloop CLI、プレイテスト DSL（`run-scenario.sh`）、node（`tools/uitk/test-name-parity.mjs`）、gh CLI、bd（Beads）

```csharp
using System;
using Client.Ui.State.Commands;

namespace Client.Ui.State.EventMode
{
    /// <summary>
    /// 言語ゲートの押下 1 回の結末
    /// Outcome of one press on the language gate
    /// </summary>
    public enum EventLanguageGateAnswer
    {
        None,
        Starting,
        Failed,
    }

    /// <summary>
    /// 選択の結果を結末へ畳み、押下の可否と 1 行の文言をここ 1 か所で決める（Web useLanguageSelectionAnswer の写し）
    /// Folds a selection result into an outcome and decides pressability and the line in this one place (mirrors Web useLanguageSelectionAnswer)
    /// </summary>
    public static class EventLanguageGateAnswers
    {
        public static EventLanguageGateAnswer From(UiCommandResult result)
        {
            // 受理と選択済みは開始中。それ以外の拒否だけが「もう一度押して」になる
            // Accepted and already-selected mean starting; only other rejections ask to press again
            if (result is UiCommandAccepted) return EventLanguageGateAnswer.Starting;
            if (result is UiCommandRejected { Reason: UiCommandRejectReason.LanguageAlreadySelected }) return EventLanguageGateAnswer.Starting;
            return EventLanguageGateAnswer.Failed;
        }

        public static bool AcceptsPress(EventLanguageGateAnswer answer)
        {
            return answer != EventLanguageGateAnswer.Starting;
        }

        public static bool ShowsStatus(EventLanguageGateAnswer answer)
        {
            return answer != EventLanguageGateAnswer.None;
        }

        public static string StatusText(EventLanguageGateAnswer answer)
        {
            return answer switch
            {
                EventLanguageGateAnswer.Starting => EventLanguageGateText.Starting,
                EventLanguageGateAnswer.Failed => EventLanguageGateText.SelectFailed,
                _ => throw new ArgumentOutOfRangeException(nameof(answer), answer, "the None answer shows no line; check ShowsStatus first"),
            };
        }
    }
}
```

```csharp
using System;
using System.Collections.Generic;
using Client.Ui.Components.Controls;
using Client.Ui.Foundation.Layout;
using Client.Ui.Foundation.Text;
using Client.Ui.State.EventMode;
using Client.Ui.State.Text;
using Mooresmaster.Localization.Generated;
using UniRx;
using UnityEngine.UIElements;

namespace Client.Ui.Screens.EventMode.Parts
{
    /// <summary>
    /// 言語のボタンの列と結末の 1 行（Web EventLanguageGateBody の写し）
    /// The row of language buttons and the outcome line (mirrors Web EventLanguageGateBody)
    /// </summary>
    public sealed class EventLanguageGateBody : VisualElement
    {
        public const string OptionTestIdPrefix = "event-language-gate-option-";
        public const string StatusTestId = "event-language-gate-status";

        private readonly UiStack _stack;
        private readonly List<FormButton> _options = new();
        private readonly LocalizedLabel _status;
        private readonly Subject<string> _onLanguageChosen = new();

        public IObservable<string> OnLanguageChosen => _onLanguageChosen;

        public EventLanguageGateBody(IReadOnlyList<LanguageInfo> languages)
        {
            AddToClassList("event-language-gate__body");
            pickingMode = PickingMode.Ignore;

            // 本体は中央揃えの縦積み（Web Stack align center gap md）
            // The body is a centred column (Web Stack align center gap md)
            _stack = new UiStack(UiGap.Md) { pickingMode = PickingMode.Ignore };
            _stack.AddToClassList(UiLayoutClass.StackAlignCenter);
            Add(_stack);

            // 母国語表記のボタンを一覧の順に並べる（Web Group justify center gap lg・Button size xl）
            // Native-name buttons in list order (Web Group justify center gap lg, Button size xl)
            var group = new UiGroup(UiGap.Lg) { pickingMode = PickingMode.Ignore };
            group.AddToClassList(UiLayoutClass.GroupJustifyCenter);
            foreach (var language in languages) group.AddItem(CreateOption(language));
            _stack.AddItem(group);

            // 結末の 1 行は押下の後だけ出す。トーストはゲートの下に隠れるのでこの行だけが伝える
            // The outcome line shows only after a press; toasts hide beneath the gate, so this line alone reports it
            _status = new LocalizedLabel { name = StatusTestId, pickingMode = PickingMode.Ignore };
            _status.AddToClassList(UiTypographyClass.TextMd);
            _status.AddToClassList(UiTypographyClass.TextWhite);
            _stack.AddItem(_status);
            _stack.SetItemShown(_status, false);

            #region Internal

            FormButton CreateOption(LanguageInfo language)
            {
                var button = new FormButton(OptionTestIdPrefix + language.Code, UiText.FromVerbatim(language.DisplayName), FormButtonVariant.Filled);
                button.SetSize(FormButtonSize.ExtraLarge);
                var code = language.Code;
                button.OnClicked.Subscribe(_ => _onLanguageChosen.OnNext(code));
                _options.Add(button);
                return button;
            }

            #endregion
        }

        public void Render(EventLanguageGateAnswer answer)
        {
            // 押下の可否と 1 行は結末 1 つから決まる（旗を二重に持たない）
            // Pressability and the line both follow the single outcome (no second flag)
            var pressable = EventLanguageGateAnswers.AcceptsPress(answer);
            foreach (var option in _options) option.SetEnabled(pressable);
            var showsStatus = EventLanguageGateAnswers.ShowsStatus(answer);
            _stack.SetItemShown(_status, showsStatus);
            if (showsStatus) _status.SetText(UiText.FromVerbatim(EventLanguageGateAnswers.StatusText(answer)));
        }
    }
}
```

```csharp
using Client.Ui.Foundation.Stage.ScaleReading;
using Client.Ui.State.Commands;
using Client.Ui.State.EventMode;
using Mooresmaster.Localization.Generated;
using UniRx;
using UnityEngine;
using UnityEngine.UIElements;

namespace Client.Ui.Screens.EventMode
{
    /// <summary>
    /// 言語ゲートの待機を描き、押下を選択へ渡す。ゲート本体と同じく DI に載せず、DI より前に開始側が作る
    /// Draws the language-gate wait and hands presses to the selection; like the gate itself it stays out of DI and the starter builds it before DI
    /// </summary>
    public sealed class EventLanguageGatePresenter
    {
        private readonly EventLanguageGate _gate;
        private readonly EventLanguageGateView _view;
        private readonly CompositeDisposable _subscriptions = new();

        public EventLanguageGatePresenter(EventLanguageGate gate, StageScaleSource stageScale)
        {
            _gate = gate;
            _view = new EventLanguageGateView(stageScale, LanguageCatalog.Languages);
        }

        public void Initialize(VisualElement layer)
        {
            // silent-ok: 待機しないゲートは何も描かない（Web の非表示と同じ）/ 出展モードでない起動は EventModeStartGate が手前で抜けるので、ここへ来るのはテストだけ
            if (!_gate.IsWaitingSelection) return;

            layer.Add(_view);
            _view.OnLanguageChosen.Subscribe(Answer).AddTo(_subscriptions);
            // 受理の通知はその押下の中で同期に来るので、その場で外して二度目の押下を通さない
            // The acceptance notice arrives synchronously inside the press, so remove at once and block a second press
            _gate.OnWaitingChanged.Subscribe(_ => Close()).AddTo(_subscriptions);
        }

        private void Answer(string languageCode)
        {
            var result = _gate.SelectLanguage(languageCode);
            // 拒否は来場者には 1 行で、開発者にはログで知らせる（DI 前で UiCommandResultToaster が無い）
            // Rejections reach the visitor as one line and the developer as a log (no UiCommandResultToaster before DI)
            if (result is UiCommandRejected rejected) Debug.LogWarning($"[EventLanguageGate] select_language {languageCode} rejected: {rejected.Reason}");
            _view.Render(EventLanguageGateAnswers.From(result));
        }

        private void Close()
        {
            _view.RemoveFromHierarchy();
            _subscriptions.Dispose();
        }
    }
}
```

```csharp
        public static UniTask WaitForLanguageSelectionAsync(CancellationToken ct)
        {
            // UITK の画面は GameUiRoot の上に出す。Web の系では Open が呼ばれず、宿主は何も立てない
            // The UITK screen goes on GameUiRoot; in the Web system Open is never called and the host builds nothing
            var gameUiScreen = new EventLanguageGateBootHost(GameUiRoot.Instance);
            return WaitForLanguageSelectionWithHubAsync(Client.WebUiHost.Boot.WebUiHost.Hub, EventExhibitionSettings.FromEnvironment(), UiInputExclusivity.ActiveUiSystem, gameUiScreen, new EventIdleQuitWatcherArmer(), ct);
        }

        // hub・設定・系・画面・武装を引数で受ける本体。Kestrel と GameUiRoot を立てずに出し分けと順序を検証できるよう分ける（PlaytestStartGatesと同形）
        // The body takes hub, settings, UI system, screen and armer so dispatch and order are verifiable without Kestrel or GameUiRoot (same shape as PlaytestStartGates)
        internal static async UniTask WaitForLanguageSelectionWithHubAsync(WebSocketHub hub, EventExhibitionSettings settings, UiSystem uiSystem, IEventLanguageGateScreen gameUiScreen, IEventIdleWatchArmer armer, CancellationToken ct)
        {
            // topicの登録は出展モードか否かに関わらず無条件に行う。条件付き登録だとWeb側の購読が固着する
            // Registration happens unconditionally regardless of exhibition mode; conditional registration would wedge the web-side subscription
            EventLanguageGate gate = null;
            if (hub != null) gate = EventLanguageGateBinder.Bind(hub, settings.IsEnabled);

            if (!settings.IsEnabled) return;

            // UITK の系は Web ホストを立てないので、ゲームの DI より前に GameUiRoot へゲートを出す
            // The UITK system starts no Web host, so the gate goes onto GameUiRoot before the game DI
            if (uiSystem == UiSystem.GameUi)
            {
                await ShowGameUiGateThenArmAsync(settings.IdleTimeoutSeconds, gameUiScreen, armer, ct);
                return;
            }

            // 画面を出せないなら無人ブースを止めない方を採る。英語のまま開始し監視だけ始める
            // With no screen to show, keeping the unattended booth alive wins: start in English and only begin watching
            if (hub == null)
            {
                Debug.LogError("EventModeStartGate: WebUiHostが起動しておらず言語選択を出せないため英語のまま開始します");
                armer.ArmIdleWatch(settings.IdleTimeoutSeconds);
                return;
            }

            // 来場者が言語ボタンを押せるよう待機中は実カーソルを出す。選択後のロックはGameScreenStateの入場が担う
            // Show the real cursor while waiting so visitors can press a language button; GameScreenState re-locks it after the choice
            ShowCursorAfterSceneStartAsync(ct).Forget();

            await AwaitSelectionThenArmAsync(gate, settings.IdleTimeoutSeconds, armer, ct);
        }

        // UITK のゲートは開始側が作って画面へ渡す（DI に載せない）。武装の後に閉じ、合成とロケールを DI の入口へ返す
        // The starter builds the UITK gate and hands it to the screen (outside DI); close after arming to return the composite and locale to the DI entry points
        private static async UniTask ShowGameUiGateThenArmAsync(int idleTimeoutSeconds, IEventLanguageGateScreen screen, IEventIdleWatchArmer armer, CancellationToken ct)
        {
            var gate = new EventLanguageGate(true);
            screen.Open(gate);
            ShowCursorAfterSceneStartAsync(ct).Forget();

            await AwaitSelectionThenArmAsync(gate, idleTimeoutSeconds, armer, ct);
            screen.Close();
        }
```

```csharp
using System;
using Client.Common;
using Client.Playtest.Core;
using Client.Starter.EventMode;
using UnityEditor;
using UnityEngine;
using UnityEngine.SceneManagement;

namespace Client.Playtest.Boot
{
    /// <summary>
    /// 出展モードで起動して言語ゲートを通る録画の起動口。ゲートで初期化が止まるので MainGame の読み込みで ready を書く
    /// Boot entry for recordings that start in exhibition mode and pass the language gate; the gate holds initialization, so ready is written on MainGame load
    /// </summary>
    /// <remarks>
    /// 出展モードの環境変数は Play の間だけ立て、Edit へ戻ったら前の値へ戻す。ワールドを消す自動開始は Play の最初のシーンがメインメニューのときだけ走り、この起動は GameInitialaizer から入るので走らない
    /// The exhibition env vars stand only during Play and return to their prior values on returning to Edit; the world-wiping auto start runs only when Play's first scene is the main menu, and this boot enters from GameInitialaizer
    /// </remarks>
    public static class PlaytestEventLanguageGateBoot
    {
        private const string ArmedKey = "PlaytestEventLanguageGateBoot_Armed";
        private const string AppliedKey = "PlaytestEventLanguageGateBoot_Applied";
        private const string SavedValuePrefix = "PlaytestEventLanguageGateBoot_Value_";
        private const string SavedPresencePrefix = "PlaytestEventLanguageGateBoot_Had_";
        private const string EnabledValue = "1";
        // 録画の間に無操作終了が走らない長さ（既定の 180 秒は録画より短くなりうる）
        // Long enough that no idle quit fires during the recording (the 180 s default can be shorter than a recording)
        private const string RecordingIdleTimeoutSeconds = "3600";

        private static readonly string[] OverriddenKeys = { EventExhibitionSettings.EnableEnvKey, EventExhibitionSettings.EditorOptInEnvKey, EventExhibitionSettings.IdleTimeoutEnvKey };

        // 次の PlaytestBoot の起動 1 回だけを出展モードにする（run-scenario.sh より前に execute-dynamic-code で呼ぶ）
        // Puts only the next PlaytestBoot boot into exhibition mode (call via execute-dynamic-code before run-scenario.sh)
        public static string ArmForNextBoot()
        {
            if (EditorApplication.isPlayingOrWillChangePlaymode) return "ERROR: already playing";
            SessionState.SetBool(ArmedKey, true);
            return "armed";
        }

        public static string Disarm()
        {
            SessionState.SetBool(ArmedKey, false);
            return "disarmed";
        }

        // PlaytestBoot のドメインリロード後に呼ぶ。武装していれば 1 回だけ環境変数を立て、MainGame の読み込みで ready を書く
        // Called after PlaytestBoot's domain reload; when armed, sets the env vars once and writes ready on MainGame load
        internal static bool ApplyIfArmed()
        {
            if (!SessionState.GetBool(ArmedKey, false)) return false;
            SessionState.SetBool(ArmedKey, false);

            SaveAndOverrideEnvironment();
            SceneManager.sceneLoaded += WriteReadyOnMainGameLoaded;
            Debug.Log("[PlaytestEventLanguageGateBoot] this boot runs in exhibition mode; ready is written when MainGame loads");
            return true;

            #region Internal

            void SaveAndOverrideEnvironment()
            {
                foreach (var key in OverriddenKeys)
                {
                    var previous = Environment.GetEnvironmentVariable(key);
                    SessionState.SetBool(SavedPresencePrefix + key, previous != null);
                    SessionState.SetString(SavedValuePrefix + key, previous ?? string.Empty);
                }
                Environment.SetEnvironmentVariable(EventExhibitionSettings.EnableEnvKey, EnabledValue);
                Environment.SetEnvironmentVariable(EventExhibitionSettings.EditorOptInEnvKey, EnabledValue);
                Environment.SetEnvironmentVariable(EventExhibitionSettings.IdleTimeoutEnvKey, RecordingIdleTimeoutSeconds);
                SessionState.SetBool(AppliedKey, true);
            }

            #endregion
        }

        private static void WriteReadyOnMainGameLoaded(Scene scene, LoadSceneMode mode)
        {
            // silent-ok: MainGame 以外のシーンの読み込みは待つ対象でない / MainGame が来なければ run-scenario.sh の ready 待ちが時間切れで NG を出す
            if (scene.name != SceneConstant.MainGameSceneName) return;
            SceneManager.sceneLoaded -= WriteReadyOnMainGameLoaded;
            PlaytestPaths.WriteReadyMarker();
        }

        [InitializeOnLoadMethod]
        private static void HookRestoreOnEditMode()
        {
            EditorApplication.playModeStateChanged -= RestoreOnEditMode;
            EditorApplication.playModeStateChanged += RestoreOnEditMode;
        }

        // Edit へ戻ったら立てる前の値へ戻す（残すと開発機の次の Play が出展モードで始まる）
        // On returning to Edit, restore the prior values (leaving them would start the developer's next Play in exhibition mode)
        private static void RestoreOnEditMode(PlayModeStateChange state)
        {
            if (state != PlayModeStateChange.EnteredEditMode) return;
            // silent-ok: この起動口を使わなかった Play では戻すものが無い / 使った Play は AppliedKey が真
            if (!SessionState.GetBool(AppliedKey, false)) return;
            foreach (var key in OverriddenKeys)
            {
                var hadValue = SessionState.GetBool(SavedPresencePrefix + key, false);
                Environment.SetEnvironmentVariable(key, hadValue ? SessionState.GetString(SavedValuePrefix + key, string.Empty) : null);
            }
            SessionState.SetBool(AppliedKey, false);
        }
    }
}
```

```bash
# uitk-event-language-gate.cs の運転役: 全体スイッチを GameUi にし、次の起動 1 回だけを出展モードにしてから run-scenario.sh を前景で流す
# 出展モードの環境変数は Editor のプロセスに要るので、Unity の中の起動口（PlaytestEventLanguageGateBoot）が Play の間だけ立てる
# Driver for uitk-event-language-gate.cs: switch to GameUi, arm exhibition mode for the next boot only, then run run-scenario.sh in the foreground
# The exhibition env vars must live in the Editor process, so the in-Unity boot entry (PlaytestEventLanguageGateBoot) sets them only during Play
#
# usage: uitk-event-language-gate.sh <unity-project-path>
set -u
PROJECT="$1"
HERE="$(cd "$(dirname "$0")" && pwd)"
SKILL_DIR="$(cd "$HERE/../../.." && pwd)"
SCRATCH="$PROJECT/PlaytestResults/scratch/event-language-gate"
mkdir -p "$SCRATCH"

# 終わり方によらず武装を解き、シナリオが言語を戻せずに落ちていたら選ぶ前の言語へ戻す
# However this ends, disarm; if the scenario died before restoring the language, put the pre-choice language back
on_exit() {
  uloop execute-dynamic-code --project-path "$PROJECT" --code 'return Client.Playtest.Boot.PlaytestEventLanguageGateBoot.Disarm();' >/dev/null \
    || echo "ERROR: disarm failed; run Client.Playtest.Boot.PlaytestEventLanguageGateBoot.Disarm() via execute-dynamic-code"
  [ -f "$SCRATCH/language-before.txt" ] || return 0
  local code
  code=$(cat "$SCRATCH/language-before.txt")
  echo "WARN: the scenario left the language changed; restoring $code"
  uloop execute-dynamic-code --project-path "$PROJECT" --code "return Client.Localization.Localize.TrySetChosenLanguage(\"$code\");" \
    && rm -f "$SCRATCH/language-before.txt" \
    || echo "ERROR: language restore failed; language-before.txt kept ($SCRATCH)"
}
trap on_exit EXIT

uloop execute-dynamic-code --project-path "$PROJECT" --code 'Client.Starter.Initialization.Boot.UiSystemEditorSwitch.Set(Client.Input.UiSystem.GameUi); return Client.Playtest.Boot.PlaytestEventLanguageGateBoot.ArmForNextBoot();' \
  || { echo "NG: could not switch to GameUi or arm exhibition mode"; exit 1; }
bash "$SKILL_DIR/scripts/run-scenario.sh" "$PROJECT" "$HERE/uitk-event-language-gate.cs"
```
