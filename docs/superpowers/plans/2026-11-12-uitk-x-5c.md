# UITK X-5c（撤去 5c: Web ホストと Web 資産の撤去・突き合わせの最終記録・Web ホスト側の規則の重複の解消）Implementation Plan

> **For the controller session (実装を担うsubagentはこのブロックを無視してよい):** このplanの実行は moores-subagent-driven-development スキルが担う。実行モード（規模ゲート未満の単一subagent実装モード／閾値超のタスクごと派遣）は同スキルの規模ゲートに従って決める。ステップはチェックボックス（`- [ ]`）記法で書く。

**Goal:** X-5a（起動配線と共存機構）・X-5b（CEF と配布工程）が `feature/uitk` に入った後、`Client.WebUiHost`（asmdef ごと）・`Client.Playtest/WebUi` の残り・Web ホストを参照するテスト・`moorestech_web/`・Web の実物を読む道具と CI の段を消し、Web と照合していたテストは照合の部分だけを消して UITK 側の検証を残し、テスト名の突き合わせで全束の差分 0（削除の親で記録し、以後は `--web-rev <親>`）と、Web ホスト側の規則の重複一覧（18 行: S4-train 計画末尾の 8 項目・X-audit DC-23〈c54-si・c57-si・c58〉の 6 行・c46・c56 の 4 行）の Web ホスト側が消えたことを証拠付きで残して `feature/uitk` へ取り込む。

**Architecture:** 撤去の単位レーン（Editor 要。Mac の Editor 1 本）。新しい機能は作らない。順序は「起点の記録 → UITK 側を残す書き換えと移動（Web がまだある状態で緑）→ Web ホストを参照するテストの削除 → `Client.WebUiHost` と `Client.Playtest/WebUi` と asmdef の行の削除 → 突き合わせの最終記録 → CI・道具の段の削除 → `moorestech_web/` の削除（1 コミット）→ 撤去後の記録」。どの区切りでも compile が通り、テストのフィルタが緑になる順に積む。見た目が変わらないことは W6-6（部品ギャラリーの全 entry と `prerun-smoke-shots` を起点と撤去後で撮って PSNR が `inf`）で確かめ、挙動はラダー 6 本と全録画（GameUi）で起点と同じ合否を見る。

**Tech Stack:** Unity 6（`moorestech_client`）・NUnit（`Client.Tests`）・プレイテスト DSL（`run-scenario.sh`）・Node（`tools/uitk/test-name-parity.mjs`）・Python（G1 `.github/scripts/check-uitk-web-follow.py`・`check-test-external-dependencies.py`）・GitHub Actions（`run_test.yml`・`build.yml`）・bd・ffmpeg（PSNR）。
