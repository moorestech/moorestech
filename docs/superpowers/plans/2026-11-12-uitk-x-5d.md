# UITK X-5d（撤去 5d: NuGet の整理。依存グラフを確かめてから client 74→19・server 27→14）Implementation Plan

> **For the controller session (実装を担うsubagentはこのブロックを無視してよい):** このplanの実行は moores-subagent-driven-development スキルが担う。実行モード（規模ゲート未満の単一subagent実装モード／閾値超のタスクごと派遣）は同スキルの規模ゲートに従って決める。ステップはチェックボックス（`- [ ]`）記法で書く。

**Goal:** X-5c（Web ホストと Web 資産の撤去）が `feature/uitk` に入った後、NuGetForUnity の `packages.config` の推移閉包を計算し直して「どこからも要らなくなったパッケージ」を確かめ、client の 55 件（`Microsoft.AspNetCore.*` 24・`Microsoft.Extensions.*` 23〈DI は client では NuGet でない〉・その他 8〈`Microsoft.Net.Http.Headers`・Security 2・`DiagnosticSource`・`Channels`・MCP 2・`ServerSentEvents`〉）と server の 13 件（MCP 系）を、`packages.config` の行と `Assets/Packages/<id>.<ver>/`（.meta 込み）ごと消し、`Client.Tests/Tests.asmdef` の AspNetCore 4 DLL の名指しを同じコミットで外す。消す前後で compile（client と server の両プロジェクト）・テスト・ラダー 6 本・見た目の不変（W6-6）が同じであることを証拠で残し、`feature/uitk` へ取り込む。

**Architecture:** 撤去レーン（`単位`。Mac の Editor 1 本）。本番コードは 1 行も書かない。消す集合は人が選ばず、scratchpad に置く道具 `x5d_nuget_prune.py`（このファイルの Task 1 に全文。コミットしない）が「`manuallyInstalled` の根から Web の根 `Microsoft.AspNetCore` と MCP の根 `ModelContextProtocol` を除いた根の推移閉包」で導き、計画の期待（55／13）と一致し、消す DLL の名前を残る DLL・asmdef・rsp・link.xml・.cs のどれも参照していないときだけ `git rm` する。消すのは Editor を閉じた状態で行い、起動し直して NuGetForUnity が再解決しても消したものが戻らないことを見る。server の単体プロジェクトは winunity が扱えないので、Mac の client の Editor を閉じてから batchmode の Unity で compile する（Editor は常に 1 本）。

**Tech Stack:** Unity 6（6000.3.8f1）・NuGetForUnity（`com.github-glitchenzo.nugetforunity`・`packages.config`・`NuGet.config` の `repositoryPath=./Packages`）・Python 3（nuspec の XML と DLL のメタデータの文字列表の走査）・uloop・winunity（Windows の Client.Tests とサーバーテスト）・プレイテスト DSL（`run-scenario.sh`）・ffmpeg（PSNR）・bd・gh。

設計の出所: 実行計画 `docs/uitk-migration/execution/execution-plan.md` §1.5 の X-5d 行（完了条件の原文:「5d（依存グラフを確かめてから）」）・§2.2（W6 の Editor 枠）・§4.3・§5・§6.2、統合計画 `docs/uitk-migration/plan.md` §2.6 の撤去の区分「5d NuGet」（原文:「AspNetCore 系（裁定 3 で HttpListener の場合）と、使われなくなった `Microsoft.Extensions.*`。依存グラフを確かめてから消す。`packages.config` は 74 件で、47 件が `Microsoft.AspNetCore.*` か `Microsoft.Extensions.*`（実測）。`ModelContextProtocol 0.2.0-preview.3` は client と server の scripts に `using` が無い（実測）。未使用なら同じ PR で外す（推測）」）と裁定 3（遠隔実行は `HttpListener`。`Client.RemoteExec/Listen/RemoteExecHttpListener.cs` で実装済み）、裁定 `.decisions/2026-11-06-UITK一気切替の日にCEFとWebを同時に撤去する.md`。実物の調査は起草時（HEAD `9c83052273`）の全件で、本文の数はすべてこの計画の起草者が再計算して一致を確かめた（Task 1 の道具を HEAD で流した結果: client「全 74 / 残す 19 / 消す 55」・server「全 27 / 残す 14 / 消す 13」・残る DLL からの参照 0）。

def hidden(path):

def read_deps(project, pkgs):
    deps = {}
    for pid, (ver, _) in pkgs.items():

def closure(roots, deps):
    seen, stack = set(), list(roots)
    while stack:
        x = stack.pop()
        if x not in seen:
            seen.add(x)
            stack += [d for d in deps.get(x, ()) if d in deps]
    return seen

def scan_dlls(project, skip_dirs, names):
    hits, needles = [], [(n, b"\0" + n.encode() + b"\0") for n in names]
    for base in [f"{project}/{d}" for d in ("Assets", "Packages", "LocalPackages", "Library/PackageCache")]:
        for f in glob.glob(f"{base}/**/*.dll", recursive=True):
            if hidden(f) or any(f.startswith(s + "/") for s in skip_dirs):
                continue
            data, own = open(f, "rb").read(), os.path.basename(f)[:-4]
            hits += [f"{f} -> {n}" for n, b in needles if n != own and b in data]
    return hits


def code_hits(f, text):
    out = []
    for i, line in enumerate(text.splitlines(), 1):
        s = line.strip()
        if s.startswith(("//", "*", "/*")) or not CS_PATTERN.search(line):
            continue
        out.append(f"{f}:{i}: {s}")
    return out


def scan_text(project, names):

    keep = closure(roots, deps)
    remove = set(pkgs) - keep
    ok = True
    print(f"{args.side}: 全 {len(pkgs)} / 根 {sorted(roots)} / 残す {len(keep)} / 消す {len(remove)}")
    if remove != EXPECTED[args.side] or len(keep) != EXPECTED_KEEP_COUNT[args.side]:
        ok = False
        print(f"NG: 期待との差 余分={sorted(remove - EXPECTED[args.side])} 不足={sorted(EXPECTED[args.side] - remove)}")
    names = dll_names(project, pkgs, remove)
    for h in scan_dlls(project, [f"{project}/Assets/Packages/{p}.{pkgs[p][0]}" for p in remove], names):
        ok = False
        print(f"NG dll: 残る DLL が消す DLL を参照 {h}")
    asmdef, code = scan_text(project, names)
    for h in asmdef:
        # asmdef の名指しは同じコミットで外す。--apply の前に外し終えていなければ止める
        ok = ok and not args.apply
        print(f"{'NG' if args.apply else 'PENDING'} asmdef: {h}")
    for h in code:
        allowed = all(a in h for a in TEXT_ALLOW)
        ok = ok and allowed
        print(f"{'ALLOW' if allowed else 'NG'} cs: {h}")
    if not ok:
        sys.exit("NG: 消さない（上の NG を読む）")
    print("OK: 閉包・期待・参照の検査が一致")
    if not args.apply:
        return
    lines = open(path, encoding="utf-8-sig").read().splitlines(keepends=True)
    kept = [l for l in lines if not any(f'<package id="{p}" ' in l for p in remove)]
    with open(path, "w", encoding="utf-8-sig", newline="") as w:
        w.writelines(kept)
    targets = [t for p in sorted(remove) for t in (f"{project}/Assets/Packages/{p}.{pkgs[p][0]}", f"{project}/Assets/Packages/{p}.{pkgs[p][0]}.meta")]
    subprocess.run(["git", "rm", "-r", "-q", "--"] + targets, check=True)
    print(f"{args.side}: packages.config {len(lines)} -> {len(kept)} 行 / git rm {len(targets)} 個（ディレクトリ {len(remove)}・.meta {len(remove)}）")


if __name__ == "__main__":
    main()
