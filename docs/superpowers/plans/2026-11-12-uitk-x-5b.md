# UITK X-5b（撤去 5b: CEF と配布工程の撤去）Implementation Plan

> **For the controller session (実装を担うsubagentはこのブロックを無視してよい):** このplanの実行は moores-subagent-driven-development スキルが担う。実行モード（規模ゲート未満の単一subagent実装モード／閾値超のタスクごと派遣）は同スキルの規模ゲートに従って決める。ステップはチェックボックス（`- [ ]`）記法で書く。

**Goal:** X-5a（起動配線と共存機構の撤去）が `feature/uitk` に入った後、`jp.juha.cefunity` パッケージ・`MainGameUI.prefab` の CEF 面・CEF を参照する C#（Navigator・DSL の CEF 転送と座標変換・テストの CEF 前提）・配布工程の CEF（`CefRuntimeBundler`・`CefPackageLfsValidator`・`setup-cef.*`・CI の事前取得）を消し、共用部品（LFS ポインタ判定・Editor ロード時の環境変数浄化）を中立な名前と場所へ移し、`release-artifact.sh` の CEF helper 検査を「CEF のファイルが 0」の検査へ反転して、`feature/uitk` へ取り込む。

**Architecture:** 単位レーン（Mac の Editor 1 本）。新しい機能は作らず、消す・名前を変える・移すだけ。順序は「配布工程（文字列でしかパッケージを見ない側）→ 共用部品の改名と移動 → prefab の CEF 面と Navigator と CEF 前提のテスト → パッケージ本体（manifest・lock・asmdef・CI）→ 配布物の検査の反転」。各タスクで compile とフィルタ付きのテストを通し、レーンの起点と撤去後でラダー 6 本・vein-terrain 4 本・部品ギャラリーの全 entry の撮影（W6-6 (a)）・`prerun-smoke-shots.cs`（W6-6 (b)）を比べる。prefab は `uloop execute-dynamic-code`（EDC）で外す。配布ビルド・検証機・Steam は切替 PR（X-switch-pr）が回す。

**Tech Stack:** Unity 6（UPM・PrefabUtility・AssetDatabase）、C#（Editor の Build 工程・NUnit の EditModeInPlayingTest）、bash（`scripts/playtest/lib/release-artifact.sh` と契約テスト）、GitHub Actions（`.github/workflows/build.yml`）、プレイテスト DSL（`run-scenario.sh`）、ffmpeg（PSNR 比較）、bd。

設計の出所: 実行計画 `docs/uitk-migration/execution/execution-plan.md` §1.5 の X-5b 行（完了条件の原文:「5b（prefab は uloop で外す）」）・§2.6・§4.3・§5・§6.2、統合計画 `docs/uitk-migration/plan.md` §2.6 の 5b の行（原文:「`jp.juha.cefunity`（manifest 45 行目）。`CefUnity` を参照する 3 ファイル（`Client.WebUiHost/Cef/WebUiCefNavigator.cs`、`Client.Playtest/WebUi/CefScreenMapper.cs`、`Client.Playtest/WebUi/CefInputForwarder.cs`）。MainGameUI.prefab の CEF 一式（Canvas〈Overlay・sortingOrder 0。実測〉・RawImage・`CefUnityBrowserSample`・`WebUiCefNavigator`）を `uloop execute-dynamic-code` で外す。`CefRuntimeBundler` と `BuildPipeline` からの呼び出し、`CefPackageLfsValidator`、`scripts/setup-cef.*`、CI の CefUnity 事前取得。`scripts/playtest/lib/release-artifact.sh` の CEF helper 検査とその契約テスト（`scripts/playtest/tests/test-release-playtest-mac.sh`）、`scripts/playtest/README.md` の CEF raw input の確認。共用部品は消さずに整理する（`CefLfsPointer` は中立な名前へ改名。ffmpeg と Harmony の同梱検査が使う。`EnvironmentScrubOnEditorLoad` は `Client.ExternalProcess` 側へ移す）」）と「5b を 5c より先にする」の根拠・§5.1-1・§5.2、裁定 `.decisions/2026-11-06-*` の 7 本（特に「UITK一気切替の日にCEFとWebを同時に撤去する」「UITK長命ブランチの中は全体スイッチ1つで切り替え追従はブランチ側で記帳する」〈ビルドと検証機は切替 PR の中でだけ〉）。実物の全件調査は起草時（HEAD `9c83052273`）に取り、パス・行はこの計画の表に写した。

```csharp
using System;
using System.IO;
using System.Text;

namespace Client.Editor.Build
{
    /// <summary>
    /// Git LFS未解決のポインタファイルかを判定する（実体と殻の唯一の判定点）
    /// Decides whether a file is an unresolved Git LFS pointer; the single place that tells husk from payload
    /// </summary>
    public static class LfsPointerFile
    {
        // ポインタファイルは数百バイトなので、これを超える実体は読まずに除外する
        // A pointer file is a few hundred bytes, so anything larger is excluded without reading
        public const int MaximumPointerFileSize = 1024;

        private const string LfsPointerHeader = "version https://git-lfs";

        public static bool IsPointerFile(string filePath)
        {
            if (!File.Exists(filePath)) return false;
            if (MaximumPointerFileSize < new FileInfo(filePath).Length) return false;

            // 小さいファイルの先頭だけ読んでヘッダを照合する
            // Read only the prefix of small files and match the header
            using var stream = File.OpenRead(filePath);
            var prefixLength = (int)Math.Min(stream.Length, LfsPointerHeader.Length);
            var prefix = new byte[prefixLength];
            var bytesRead = stream.Read(prefix, 0, prefix.Length);

            return Encoding.ASCII.GetString(prefix, 0, bytesRead) == LfsPointerHeader;
        }
    }
}
```
