# UITK 段階 2 画面「常駐 HUD と画面の幕・ヴィネット」（S2-hud） Implementation Plan

> **For the controller session (実装を担うsubagentはこのブロックを無視してよい):** このplanの実行は moores-subagent-driven-development スキルが担う。実行モード（規模ゲート未満の単一subagent実装モード／閾値超のタスクごと派遣）は同スキルの規模ゲートに従って決める。ステップはチェックボックス（`- [ ]`）記法で書く。

**Goal:** Web 版の常駐 HUD 5 つ（`Crosshair`・`KeyHintHud`・`ProgressBar`・`TrainRidingHud`・`CurrentChallengeHud`）と、画面の幕（`screen-backdrop`）・常時のヴィネットを、Web と同じ見た目・同じ出し分けの UITK 画面として `Client.Ui/Screens/` に作り、L1・unityプレイ録画テスト・参照キャプチャとの並べ比べ（720p・2560×1080）まで済ませて `feature/uitk` へ取り込む。

**Architecture:** 画面ごとに Presenter（`IInitializable`・`IDisposable`。起動時に 1 回だけ View を層へ載せ、源を購読して View へ押す）・View（`VisualElement`。`Render(ViewModel)`／`SetShown(bool)` だけを持ち、源を知らない）・ViewModel（`Client.Ui.State`。出し分けの規則を `Create` に持つ）に分ける（前例 `ToastLayerPresenter`）。出し分けの規則は Web の `W/app/App.tsx` と各 HUD の早期 return の写し（blocking スキット中は退く・ヒント／目標が空なら描かない・列車 HUD は traits の `TrainHud` 列かつ乗車中・幕は traits の `Backdrop` 列）。見た目は C2 の部品（`GamePanelSurface`(hud)・`HudSectionHeading`・`GaugeBar`・`KeyCap`・`PaperSurface`・`UiStack`）と画面ごとの USS（Web の局所上書き変数と同名のつまみ）で決め、USS に無い描き方（楕円のヴィネット・クロスヘアの影）は段階 1 の前例（`GamePanelFace` の頂点カラー格子と `GamePanelFaceOpacityRamp`）で描く。

**Tech Stack:** Unity UI Toolkit（ランタイム）、USS カスタムプロパティ、`generateVisualContent`（頂点カラー）、UniRx、VContainer、NUnit + `UnityEngine.UIElements.TestFramework`（`UiTestHost`・`ScreenTestHost`）、uloop、プレイテスト DSL（`run-scenario.sh`）

- **パスの略記**: `S/` = `moorestech_client/Assets/Scripts/`、`W/` = `moorestech_web/webui/src/`、`E/` = `moorestech_web/webui/e2e/tests/`、`SC/` = `.agents/skills/unity-playmode-recorded-playtest/scenarios/`。Files 節と各コマンドはリポジトリ相対の完全なパスで書く
- **正本**: `docs/uitk-migration/execution/component-architecture.md`（設計書。§2.7 Screens/Shell・§3.2・§3.3・§4.1〜§4.4・A-44・A-47・A-48）、`docs/uitk-migration/execution/execution-plan.md`（レーン S2-hud の行・§4.3・§5・§6.2）、裁定 `.decisions/2026-11-06-UITK*.md`、`.agents/skills/ref-uitk-design/`。食い違ったら 裁定 → 統合計画 → 設計書 → 実行計画 → この計画 の順で上が勝つ。この計画が設計書・実行計画と違う所（A-55〜A-59）は改訂案を指揮へ渡してあり（判断記録 D-1）、このレーンは設計書と実行計画を書かない

// S/Client.Ui.State/SkitPresence/BlockingSkitPresence.cs
using Client.Skit.UI;
using UniRx;

namespace Client.Ui.State.SkitPresence
{
    /// <summary>
    /// blocking スキット（会話の演出が画面を持つ間）かを配る。常駐 HUD はこれが真の間だけ退く（Web の useBlockingSkitActive）
    /// Publishes whether a blocking skit owns the screen; resident HUDs withdraw only while it is true (Web useBlockingSkitActive)
    /// </summary>
    /// <remarks>
    /// 背景スキット（mode "background"）は数えない。使う画面は S2-hud のキーヒント・進行中チャレンジ、S2-tutorial のキー操作ヒント・ワールドピン、S3-hotbar-modal のホットバー（設計書 A-56）
    /// Background skits (mode "background") do not count; users are S2-hud key hints and current challenge, S2-tutorial key control hints and world pins, and the S3-hotbar-modal hotbar (design A-56)
    /// </remarks>
    public sealed class BlockingSkitPresence
    {
        private readonly ReactiveProperty<bool> _isBlocking;

        public IReadOnlyReactiveProperty<bool> IsBlocking => _isBlocking;

        public BlockingSkitPresence(SkitPresentationStateStore store)
        {
            // 今の値で始め、以後は store の変化だけで更新する。ゲーム寿命なので購読は解かない
            // Start from the current value and follow store changes; it lives for the whole game, so the subscription is never released
            _isBlocking = new ReactiveProperty<bool>(IsBlockingMode(store.GetCurrent()));
            store.ObserveChanged().Subscribe(data => _isBlocking.Value = IsBlockingMode(data));
        }

        private static bool IsBlockingMode(SkitPresentationData data)
        {
            // モード名は持ち主の定数を読む（生成と同じ値）
            // Read the owner's constant for the mode name (the same value the producer writes)
            return data.PresentationState.Mode == SkitPresentationData.BlockingMode;
        }
    }
}

```csharp
// S/Client.Ui/Screens/Shell/ScreenVignetteShape.cs
using UnityEngine;

namespace Client.Ui.Screens.Shell
{
    /// <summary>
    /// CSS の radial-gradient(ellipse W H at X Y, clear S, edge 100%) の縁色の重み（0〜1）を要素内の点ごとに返す
    /// Returns the edge-color weight (0 to 1) of CSS radial-gradient(ellipse W H at X Y, clear S, edge 100%) at each point of the element
    /// </summary>
    /// <remarks>
    /// 楕円の半径は要素の幅・高さ × 比、中心は幅・高さ × 位置の比。停止点より内は 0、楕円上と外は 1、その間は線形（色は乗算済みで補間されるので透明の色成分は効かない）
    /// The ellipse radii are the element width and height times the ratios and the center is width and height times the position ratios; zero inside the stop, one on and beyond the ellipse, linear between (colors interpolate premultiplied, so the clear stop's RGB has no effect)
    /// </remarks>
    internal readonly struct ScreenVignetteShape
    {
        private readonly float _widthRatio;
        private readonly float _heightRatio;
        private readonly float _centerX;
        private readonly float _centerY;
        private readonly float _clearStop;

        public ScreenVignetteShape(float widthRatio, float heightRatio, float centerX, float centerY, float clearStop)
        {
            _widthRatio = widthRatio;
            _heightRatio = heightRatio;
            _centerX = centerX;
            _centerY = centerY;
            _clearStop = clearStop;
        }

        public float EdgeWeightAt(float x, float y, float width, float height)
        {
            // 楕円で正規化した中心からの距離 t（楕円上で 1）
            // Distance from the center normalized by the ellipse (one on the ellipse)
            var dx = (x - width * _centerX) / (width * _widthRatio);
            var dy = (y - height * _centerY) / (height * _heightRatio);
            var t = Mathf.Sqrt(dx * dx + dy * dy);
            return Mathf.Clamp01((t - _clearStop) / (1f - _clearStop));
        }
    }
}

// S/Client.Ui/Screens/Shell/ScreenVignette.cs
using Client.Ui.Components.Panels;
using Client.Ui.Foundation.Theme;
using UnityEngine;
using UnityEngine.UIElements;

namespace Client.Ui.Screens.Shell
{
    /// <summary>
    /// 実画面の四辺を沈める常時のヴィネット。楕円のグラデを頂点カラーの格子で描く（Web の .viewport の radial-gradient）
    /// Persistent vignette that darkens every viewport edge, drawn as a vertex-colored grid of the elliptical gradient (Web .viewport radial-gradient)
    /// </summary>
    /// <remarks>
    /// 形と色は Shell.uss が --screen-shell-vignette-* で受け直したトークンから読む。頂点の α は面と同じく GamePanelFaceOpacityRamp で Linear 合成用に補正する（縁のトークンは S7 の式で補正済み）
    /// Shape and color come from tokens Shell.uss re-declares as --screen-shell-vignette-*; vertex alpha is corrected for Linear blending with GamePanelFaceOpacityRamp like the panel face (the edge token is S7-corrected)
    /// </remarks>
    internal sealed class ScreenVignette : VisualElement
    {
        // 格子の分割。2560×1080 でもセルは 80px 角で、双線形の補間と式の差は 1 段未満
        // Grid divisions; cells stay 80px square even at 2560x1080, keeping bilinear interpolation within one shade of the formula
        private const int Columns = 32;
        private const int Rows = 18;
        private const int Stride = Columns + 1;

        private ScreenVignetteShape _shape;
        private Color _edgeColor;
        private bool _hasTokens;

        public ScreenVignette()
        {
            name = "screen-vignette";
            AddToClassList("screen-shell__vignette");
            pickingMode = PickingMode.Ignore;
            generateVisualContent += DrawVignette;
            RegisterCallback<CustomStyleResolvedEvent>(_ => OnCustomStyleResolved());
        }

        private void OnCustomStyleResolved()
        {
            // 読めない値は UssCustomStyleReader が LogError で知らせ、そのときは描かない
            // UssCustomStyleReader reports unreadable values with LogError, and then nothing is drawn
            var hasWidth = UssCustomStyleReader.TryReadPercent(customStyle, "--screen-shell-vignette-width", out var widthRatio);
            var hasHeight = UssCustomStyleReader.TryReadPercent(customStyle, "--screen-shell-vignette-height", out var heightRatio);
            var hasCenterX = UssCustomStyleReader.TryReadPercent(customStyle, "--screen-shell-vignette-center-x", out var centerX);
            var hasCenterY = UssCustomStyleReader.TryReadPercent(customStyle, "--screen-shell-vignette-center-y", out var centerY);
            var hasClearStop = UssCustomStyleReader.TryReadPercent(customStyle, "--screen-shell-vignette-clear-stop", out var clearStop);
            var hasEdge = UssCustomStyleReader.TryReadColor(customStyle, "--screen-shell-vignette-edge", out _edgeColor);
            _shape = new ScreenVignetteShape(widthRatio, heightRatio, centerX, centerY, clearStop);
            _hasTokens = hasWidth && hasHeight && hasCenterX && hasCenterY && hasClearStop && hasEdge;
            MarkDirtyRepaint();
        }

        private void DrawVignette(MeshGenerationContext context)
        {
            // silent-ok: トークンが読めない間は描かない / 読めなかった名前は UssCustomStyleReader（TryReadPercent・TryReadColor）が LogError で出す
            if (!_hasTokens) return;
            var width = contentRect.width;
            var height = contentRect.height;
            // silent-ok: 寸法 0 はレイアウト前の一瞬だけ / 寸法が決まると UITK が描き直す
            if (width <= 0f || height <= 0f) return;

            var mesh = context.Allocate(Stride * (Rows + 1), Columns * Rows * 6);
            WriteVertices();
            WriteIndices();

            #region Internal

            // 縁の重みは Web の式、α は Linear 合成用の補正
            // Edge weight from the Web formula, alpha corrected for Linear blending
            void WriteVertices()
            {
                for (var row = 0; row <= Rows; row++)
                for (var column = 0; column <= Columns; column++)
                {
                    var x = width * column / Columns;
                    var y = height * row / Rows;
                    var tint = _edgeColor;
                    tint.a = GamePanelFaceOpacityRamp.OpacityAt(_edgeColor.a, _shape.EdgeWeightAt(x, y, width, height));
                    mesh.SetNextVertex(new Vertex { position = new Vector3(x, y, Vertex.nearZ), tint = tint });
                }
            }

            // 画面座標（y 下向き）で時計回りに張る（GamePanelFace と同じ向き）
            // Wind clockwise in screen space (y down), the same as GamePanelFace
            void WriteIndices()
            {
                for (var row = 0; row < Rows; row++)
                for (var column = 0; column < Columns; column++)
                {
                    var topLeft = (ushort)(row * Stride + column);
                    var topRight = (ushort)(topLeft + 1);
                    var bottomLeft = (ushort)(topLeft + Stride);
                    var bottomRight = (ushort)(bottomLeft + 1);
                    mesh.SetNextIndex(topLeft);
                    mesh.SetNextIndex(topRight);
                    mesh.SetNextIndex(bottomRight);
                    mesh.SetNextIndex(topLeft);
                    mesh.SetNextIndex(bottomRight);
                    mesh.SetNextIndex(bottomLeft);
                }
            }

            #endregion
        }
    }
}

    /// Mounts the dim and vignette once at startup in the back-most layer and toggles the dim on the screen router's decision
    /// </summary>

        private readonly CompositeDisposable _subscriptions = new();

            _routingState.Current.Subscribe(snapshot => _view.SetBackdropShown(ShowsBackdropOn(snapshot))).AddTo(_subscriptions);

    /// <summary>
    /// クロスヘアの円の外側に box-shadow 0 0 blur color 相当のぼかした影を輪の頂点カラーで描く
    /// Draws the blurred shadow of box-shadow 0 0 blur color outside the crosshair circle as a vertex-colored ring
    /// </summary>
    /// <remarks>
    /// 影は円と同じ大きさのガウスぼかし。円の縁から外向きの距離 d での濃さは半平面の被覆率 Φ(-d/σ)（σ=blur/2）で近似する。円の内側は白い点が覆うので描かない。α は GamePanelFaceOpacityRamp で Linear 合成用に補正する
    /// The shadow is a Gaussian blur of a circle the same size; the shade at outward distance d from the edge approximates the half-plane coverage Phi(-d/sigma) with sigma = blur/2; the white dot covers the inside, so nothing is drawn there; alpha is corrected for Linear blending with GamePanelFaceOpacityRamp
    /// </remarks>
    internal sealed class CrosshairShadowRing : VisualElement
    {
        // σ 単位の距離と Φ(-d) の表（標準正規分布の上側確率）
        // Distance in sigma and the Phi(-d) table (upper tail of the standard normal)
        private static readonly float[] DistancesInSigma = { 0f, 0.5f, 1f, 1.5f, 2f, 2.5f, 3f };
        private static readonly float[] Coverages = { 0.5f, 0.3085f, 0.1587f, 0.0668f, 0.0228f, 0.0062f, 0f };
        private const int Segments = 32;

        private float _blurRadius;
        private Color _shadowColor;
        private bool _hasTokens;

        public CrosshairShadowRing()
        {
            AddToClassList("crosshair-hud__shadow");
            pickingMode = PickingMode.Ignore;
            generateVisualContent += DrawRing;
            RegisterCallback<CustomStyleResolvedEvent>(_ => OnCustomStyleResolved());
        }

        // σ を単位にした縁からの距離の被覆率。表の間は線形、3σ より外は 0
        // Coverage at a distance from the edge in sigma units; linear between rows and zero beyond 3 sigma
        internal static float CoverageAt(float distance, float sigma)
        {
            var d = distance / sigma;
            for (var i = 1; i < DistancesInSigma.Length; i++)
            {
                if (d > DistancesInSigma[i]) continue;
                var t = (d - DistancesInSigma[i - 1]) / (DistancesInSigma[i] - DistancesInSigma[i - 1]);
                return Mathf.Lerp(Coverages[i - 1], Coverages[i], t);
            }
            return 0f;
        }

        private void OnCustomStyleResolved()
        {
            var hasBlur = UssCustomStyleReader.TryReadPixels(customStyle, "--crosshair-hud-shadow-blur", out _blurRadius);
            var hasColor = UssCustomStyleReader.TryReadColor(customStyle, "--crosshair-hud-shadow-color", out _shadowColor);
            // silent-ok: blur 0px は Web でも影なし / トークンを変えた人が並べ比べで気づく
            _hasTokens = hasBlur && hasColor && _blurRadius > 0f;
            MarkDirtyRepaint();
        }

        private void DrawRing(MeshGenerationContext context)
        {
            // silent-ok: トークンが読めない間は描かない / 読めなかった名前は UssCustomStyleReader が LogError で出す
            if (!_hasTokens) return;
            var center = contentRect.center;
            var radius = Mathf.Min(contentRect.width, contentRect.height) / 2f;
            // silent-ok: 寸法 0 はレイアウト前の一瞬だけ / 寸法が決まると UITK が描き直す
            if (radius <= 0f) return;

            var sigma = _blurRadius / 2f;
            var rings = DistancesInSigma.Length;
            var mesh = context.Allocate(Segments * rings, Segments * (rings - 1) * 6);
            WriteVertices();
            WriteIndices();

            #region Internal

            // 縁から外へ表の距離ごとに 1 周ずつ、被覆率の α で置く
            // One loop per table distance outward from the edge, with the coverage as alpha
            void WriteVertices()
            {
                for (var ring = 0; ring < rings; ring++)
                {
                    var distance = DistancesInSigma[ring] * sigma;
                    var tint = _shadowColor;
                    tint.a = GamePanelFaceOpacityRamp.OpacityAt(_shadowColor.a, CoverageAt(distance, sigma));
                    for (var segment = 0; segment < Segments; segment++)
                    {
                        var angle = segment * Mathf.PI * 2f / Segments;
                        var position = center + new Vector2(Mathf.Cos(angle), Mathf.Sin(angle)) * (radius + distance);
                        mesh.SetNextVertex(new Vertex { position = new Vector3(position.x, position.y, Vertex.nearZ), tint = tint });
                    }
                }
            }

            // GamePanelFace と同じく画面座標（y 下向き）で時計回りに張る。角度 0 で外周は右・次の角度は下
            // Wind clockwise in screen space (y down) like GamePanelFace; at angle 0 outer is right and next is down
            void WriteIndices()
            {
                for (var ring = 0; ring < rings - 1; ring++)
                for (var segment = 0; segment < Segments; segment++)
                {
                    var next = (segment + 1) % Segments;
                    var inner = (ushort)(ring * Segments + segment);
                    var innerNext = (ushort)(ring * Segments + next);
                    var outer = (ushort)((ring + 1) * Segments + segment);
                    var outerNext = (ushort)((ring + 1) * Segments + next);
                    mesh.SetNextIndex(inner);
                    mesh.SetNextIndex(outerNext);
                    mesh.SetNextIndex(innerNext);
                    mesh.SetNextIndex(inner);
                    mesh.SetNextIndex(outer);
                    mesh.SetNextIndex(outerNext);
                }
            }

            #endregion
        }
    }
}
```

（張る向きは `GamePanelFace` の `WriteIndices`〈topLeft→topRight→bottomRight・topLeft→bottomRight→bottomLeft。topRight は +x、bottomLeft は +y〉と同じ。角度 0 では外周の向きが +x・次の角度の向きが +y なので、topRight に outer、bottomLeft に innerNext が当たり、inner→outer→outerNext・inner→outerNext→innerNext が同じ時計回りになる。inner→innerNext→outerNext の順は反時計回りで、GamePanelFace と逆になる。Step 5 の録画で影が見えなければ、向きを変えて撮り直さず、録画と判断記録に書いて止める）

            _uiStateControl.OnStateChanged.Subscribe(_ => Rebuild());

            _blockingSkitPresence.IsBlocking.Skip(1).Subscribe(_ => Rebuild());

// S/Client.Ui/Screens/KeyHints/KeyHintHudView.cs
using Client.Ui.Foundation.Text;
using Client.Ui.Foundation.Theme;
using Client.Ui.Foundation.Layout;
using Client.Ui.Screens.KeyHints.Parts;
using Client.Ui.State.KeyHints;
using UnityEngine.UIElements;

namespace Client.Ui.Screens.KeyHints
{
    /// <summary>
    /// 左下に積むキーヒント（Web の KeyHintHud）。受け取ったヒントを行に作り直すだけで、源を知らない
    /// Bottom-left key hints (Web KeyHintHud); it only rebuilds rows from the hints it receives and knows no sources
    /// </summary>
    public sealed class KeyHintHudView : VisualElement
    {
        private readonly UiStack _rows;
        private float _bottomGap;
        private float _bandHeight;
        private float _rowMinHeight;
        private bool _deleteMode;

        public KeyHintHudView()
        {
            name = "key-hints";
            AddToClassList("key-hint-hud");
            AddToClassList(UiTypographyClass.KeyHintText);
            pickingMode = PickingMode.Ignore;
            _rows = new UiStack(UiGap.Xs);
            _rows.pickingMode = PickingMode.Ignore;
            Add(_rows);
            style.display = DisplayStyle.None;
            RegisterCallback<CustomStyleResolvedEvent>(_ => OnCustomStyleResolved());
        }

        public void Render(KeyHintHudViewModel model)
        {
            style.display = model.Shown ? DisplayStyle.Flex : DisplayStyle.None;
            _deleteMode = model.DeleteMode;
            ApplyBottom();

            // 行は毎回作り直す（高々十数行で、内容の正は state 側）
            // Rebuild the rows every time (at most a dozen, and the state owns the content)
            _rows.ClearItems();
            foreach (var hint in model.Hints)
            {
                var row = new KeyHintRow(hint);
                row.style.minHeight = _rowMinHeight;
                _rows.AddItem(row);
            }
            this.Query<VisualElement>().ForEach(element => element.pickingMode = PickingMode.Ignore);
        }

        private void OnCustomStyleResolved()
        {
            // 削除モードの底は Web の calc(帯 + 隙間)。USS に calc が無いので足し算は C#（設計書 A-47）
            // Delete-mode bottom is the Web calc(band + gap); USS has no calc, so C# adds them (design A-47)
            UssCustomStyleReader.TryReadPixels(customStyle, "--key-hint-bottom-gap", out _bottomGap);
            UssCustomStyleReader.TryReadPixels(customStyle, "--key-hint-hud-band-height", out _bandHeight);

            // 行の高さは Web の line-height（字の大きさ × 1.2）。UITK の Label は行高を持たないので最小の高さで写す
            // Row height is the Web line-height (font size x 1.2); UITK Labels have no line-height, so a min-height carries it
            var hasFontSize = UssCustomStyleReader.TryReadPixels(customStyle, "--key-hint-hud-font-size", out var fontSize);
            var hasLineHeight = UssCustomStyleReader.TryReadNumber(customStyle, "--key-hint-hud-line-height", out var lineHeight);
            _rowMinHeight = hasFontSize && hasLineHeight ? fontSize * lineHeight : 0f;
            foreach (var row in _rows.Children()) row.style.minHeight = _rowMinHeight;
            ApplyBottom();
        }

        private void ApplyBottom()
        {
            style.bottom = _deleteMode ? _bandHeight + _bottomGap : _bottomGap;
        }
    }
}

    /// Flattens every category's current challenges in received order and rebuilds on completions and blocking-skit changes (Web challenge.current topic)
    /// </summary>
    public sealed class CurrentChallengeHudModel : IInitializable
    {
        private readonly ChallengeProgressState _progressState;
        private readonly BlockingSkitPresence _blockingSkitPresence;
        private readonly ReactiveProperty<CurrentChallengeHudViewModel> _current;

        public CurrentChallengeHudModel(ChallengeProgressState progressState, BlockingSkitPresence blockingSkitPresence)

            _blockingSkitPresence = blockingSkitPresence;
            _current = new ReactiveProperty<CurrentChallengeHudViewModel>(Build());

        public void Initialize()
        {
            // 完了の知らせは Categories を置き換えた後に来る。ゲーム寿命なので購読は解かない
            // The completion notice arrives after Categories is replaced; it lives for the whole game, so subscriptions stay

            this.Query<VisualElement>().ForEach(element => element.pickingMode = PickingMode.Ignore);
