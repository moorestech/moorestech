# UITK I-fix4（integrator 修正）Implementation Plan

> **For the controller session:** この計画は起草したセッション（I-fix4）がそのまま実行する（指揮の指定。Execution Handoff はしない・§5 の独立評価は不要）。ステップはチェックボックス（`- [ ]`）記法。

**Goal:** 先行レーン（C4-a・C4-c・C4-d・S4-alpha・S4-inventory・I-blend・I-fix3・PLAN-W3c・PLAN-W4a）が integrator へ積んだ共有の道具・トークン・基盤・文書の直しを、S4-research 着手前に必要な RecipeActionButton の変種から順にまとめて片付ける。

**Architecture:** 部品・Foundation・道具の小さな直しの束。見た目に効くもの（研究ボタン・フォント atlas・renderScale の拡大）は並べ比べか画素の実測で確かめ、入力（DSL の Shift）は録画で確かめる。文書は設計書（`docs/uitk-migration/execution/component-architecture.md`）・実行計画（`execution-plan.md`）・カタログ・各レーン計画を新しい形へ直す。

**Tech Stack:** Unity UI Toolkit（USS・C#）・URP renderer feature・TextCore フォント資産・Input System・プレイテスト DSL（Client.Playtest）
