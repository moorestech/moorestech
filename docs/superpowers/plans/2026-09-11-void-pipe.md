# ボイドパイプ（VoidPipe）Implementation Plan

> **For the controller session (実装を担うsubagentはこのブロックを無視してよい):** このplanの実行は subagent-driven-development スキルが担う。実行モード（規模ゲート未満の単一subagent実装モード／閾値超のタスクごと派遣）は同スキルの規模ゲートに従って決める。ステップはチェックボックス（`- [ ]`）記法で書く。

**Goal:** 受け入れ面に届いた流体を種別を問わず全量消滅させる終端ブロック「ボイドパイプ」（blockType `VoidPipe`）を追加し、v8マスタで「蒸気機関」研究から使えるようにする。

**Architecture:** 新blockType `VoidPipe` のサーバー実装は `IFluidInventory` を実装する薄いコンポーネント1つ（`AddLiquid` が常に残量0を返す）と、それを組み立てるテンプレート1つ。パイプ網からは既存の `FluidNetworkDatastore` が「パイプ以外の `IFluidInventory`」を境界ポート（`FluidBoundaryPort`）として扱う経路にそのまま乗るため、シミュレーション（`FluidSimulationStepper`）・datastore・クライアントは変更しない。可変状態を持たないのでBlockState・セーブ・プロトコルは新設しない。

**Tech Stack:** Unity C#（`moorestech_server` / SourceGenerator による Mooresmaster モデル生成）、NUnit CombinedTest、`uloop` CLI（compile / run-tests）、マスタJSON（`../moorestech_master` v8 mod）。

## Requirements

- R1. スキーマ: `VanillaSchema/blocks.yml` の blockType enum に `VoidPipe` を追加し、blockParam の switch に `VoidPipe` ケース（`fluidInventoryConnectors` のみ。capacity・blockedRetryTicks を持たない）を追加する。受入: SourceGenerator が `Mooresmaster.Model.BlocksModule.VoidPipeBlockParam` を生成し `uloop compile` が通る。

- R3. サーバー: `VanillaVoidPipeTemplate : IBlockTemplate` を新設し `VanillaIBlockTemplates` に `BlockTypeConst.VoidPipe` で登録する。コンポーネントは `VoidPipeComponent` と `BlockConnectorComponent<IFluidInventory, DefaultConnectJudge>` の2つのみ（セーブコンポーネント無し）。受入: `TryAddBlock(VoidPipe)` で生成したブロックから両コンポーネントが `GetComponent` で取れ、`IBlockSaveState` は取れない。
- R4. パイプ→ボイド: パイプ列の終端にボイドを置くと、上流パイプの内容量が0まで減り続ける（詰まらない）。受入: CombinedTest で 2本のパイプに流体を入れてボイドへ接続し、十分なtick後に両パイプの残量が 0（許容 0.01）。

```csharp
using System.Collections.Generic;
using Game.Block.Interface.Component;
using Game.Fluid;

namespace Game.Block.Blocks.Fluid
{
    /// <summary>
    ///     ボイドパイプ本体。受け入れ面に届いた流体を種別を問わず全量消滅させる終端。
    ///     パイプ網からは機械と同じ境界ポート（FluidBoundaryPort）として扱われ、残量0を返すことで「全量受け入れ」を表現する。
    ///     内容量・可変状態を持たないためセーブもBlockState通知も無い（ADR 0058）。
    ///
    ///     The void pipe body: a terminal sink that destroys every fluid reaching its inflow face regardless of kind.
    ///     The pipe network treats it as a boundary port like a machine; returning a zero remainder expresses "accept everything".
    ///     It holds no amount or mutable state, so there is no save state and no BlockState notification (ADR 0058).
    /// </summary>
    public class VoidPipeComponent : IFluidInventory
    {
        public FluidStack AddLiquid(FluidStack fluidStack, ConnectedInfo connectedInfo)
        {
            // 全量を消滅させ、残量0を同じ流体IDで返す
            // Destroy the full amount and return a zero remainder with the same fluid id
            return new FluidStack(0, fluidStack.FluidId);
        }

        public List<FluidStack> GetFluidInventory()
        {
            return new List<FluidStack>();
        }

        public bool IsDestroy { get; private set; }

        public void Destroy()
        {
            IsDestroy = true;
        }
    }
}
```

using System.Collections.Generic;
using Game.Block.Blocks;
using Game.Block.Blocks.Fluid;
using Game.Block.Component;
using Game.Block.Interface;
using Game.Block.Interface.Component;
using Game.Block.Interface.Component.ConnectJudge;
using Mooresmaster.Model.BlocksModule;

namespace Game.Block.Factory.BlockTemplate
{
    /// <summary>
    ///     ボイドパイプのテンプレート。可変状態が無いので New と Load は同じ組み立てになる（ADR 0058）
    ///     Template for the void pipe; with no mutable state, New and Load assemble the same block (ADR 0058)
    /// </summary>
    public class VanillaVoidPipeTemplate : IBlockTemplate
    {
        public IBlock New(BlockMasterElement blockMasterElement, BlockInstanceId blockInstanceId, BlockPositionInfo blockPositionInfo, BlockCreateParam[] createParams)
        {
            return GetBlock(blockMasterElement, blockInstanceId, blockPositionInfo);
        }

        public IBlock Load(Dictionary<string, string> componentStates, BlockMasterElement blockMasterElement, BlockInstanceId blockInstanceId, BlockPositionInfo blockPositionInfo)
        {
            return GetBlock(blockMasterElement, blockInstanceId, blockPositionInfo);
        }

        private static BlockSystem GetBlock(BlockMasterElement blockMasterElement, BlockInstanceId blockInstanceId, BlockPositionInfo blockPositionInfo)
        {
            var voidPipeParam = (blockMasterElement.BlockParam as VoidPipeBlockParam)!;

            // 受け入れ面のコネクタとボイド本体だけを組み立てる（セーブ無し）
            // Assemble only the inflow connector and the void body (no save component)
            var connectorComponent = IFluidInventory.CreateFluidInventoryConnector(voidPipeParam.FluidInventoryConnectors, blockPositionInfo);
            var voidPipeComponent = new VoidPipeComponent();
            var components = new List<IBlockComponent>
            {
                voidPipeComponent,
                connectorComponent,
            };

            return new BlockSystem(blockInstanceId, blockMasterElement.BlockGuid, components, blockPositionInfo);
        }
    }
}
