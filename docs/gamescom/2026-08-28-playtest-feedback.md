# gamescom 展示プレイテスト FBメモ（2026-08-28）

会場で観察したフィードバックの原文メモをジャンル別に分類したもの。解釈・要約は加えず原文ママで記録する。
優先度付けや対応方針は別途 bd / ADR で扱う。

## 観察・所感
- ある程度自動化された部分からスタートする
- 本当にPCになれてない人もいる
- 黄色でハイライトされても人はクリックしないことがある、
- ゲームの目的をわかってないことが多い（英語がわからない？
- ゲーム基礎力が明らかにない人が一般デーから増えて辛い
- 一般参加しのフリして遠巻きに見てるのがちょうどいい
- 何をどれくらい作ったらやりたいことができるか、人は全然把握しない
- 早く自動化できるように来てほしい 自動化やりに来たんだから
- 資源が色んな所にあるのはきらい、まとまっててほしい

## バグ・不具合
- 本番環境でVeinエリア内なのに採掘機を設置できないことがある
- クラフトや建設UIからESCへの挙動がおかしい
- 機械にカーソルを合わせながらBを押すと何故かなにもないUIが映る
- Bを押すとなにもない黒い画面が表示され、一旦Bをして消し、再度開くと正常表示される
- ジャンプするとクラフトがキャンセルされ付
- Tab stone tool選択 tab で本来消えるべきインベントリ画面が消えない
- 研究UIを何も見えない端までドラッグできる
- Pcが暑いとき、極端にCEFのFPSが下がることがあるなぁ
- クラッシャーがwindmill一個で動かないのもおかしい

## 設置・ビルドメニュー
- 機械がVeinに埋まるやつはどうにかしていきたい
- 一個上の設置をデフォルトにしたい
- デフォルトでブロックが埋まらないようにする
- アイテムが足りないとき、ビルドメニューで、アイテムが足りないってだすようにするどのアイテムが足りない
- ブロックはカテゴリをやめて、長い1スクロールプラス、サイドバーはそのショートカットという位置づけにする
- ビルドモードを終わらせる方法を案内しておく
- 左クリックを押したらビルドモードをキャンセルしたい、全体的に、左クリックを押したらUIを解除できるようにする
- クラフトとビルドはわけないほうがいいかも
- クラフトレシピと同じところにブロックの設置画面がほしい→ まぁたしかに動線が一致するのはよさそう 果たしてどうしていくべきか、、、
- 接続の仕組みを理解させたい

## 機械・スロット
- レシピ選択しないと機械を動かせないようにする
- 機会に特定のアイテムしか入らないようにスフ 入れようとすると違うって出す
- スロットに入るアイテムを固定して、それ以外はいらないようにするのと、薄くオーバーレイを出してそのああテム

## チュートリアル・導線
- 設置のチュートリアルがあるのにアイテムがないことが多いから、そこをスムーズな導線にしていきたい
- アイテムが足りないとき、他のアイテムを集めるように言う
- 木を採掘できるという概念がないからチュートリアルする
- ストーンファーネスの設置チュートリアルがない（Tabせんたくしてほしい
- 右クリックしてカメラ回転のチュートリアルがないから追加
- 目標が変わったことを明確に示すにはどうしたらいいだろうか
- Hud矢印がわからない。
- それがアンロックされたかどうかのくわからなんもんだい
- ハイライトをクリックするように明確に示す UIハイライトも赤にして動かす？
- Tabを押す をもっと引からせるのと、原色赤にする
- 赤いキーボードを押す指示チュートリアルも赤いプラス揺らす
- ホットバーをアイテムスロットだと思う問題
- リセット方法を書いておく
- 言語選択を最初に出しておく

## インタラクト・採掘
- インタラクトできるのもは全部ハイライトする インタラクトの方法を示す（どのキーをおす的な
- カメラ中心にいなくても近かったらハイライトする、同じくらいの距離にいるときは視点の先にいるやつを優先にする
- ブロックのインタラクトが難しい
- 採掘してるものを全部光らせる
- 鉱脈の上に乗ったら採掘できると思う

## クラフトUI
- クラフトUIの進捗は保持してほしい
- クラフト可能個数が表示されているのは、クラフトしてるのに数が減っていて違和感がある

- アイテムを産まないmapobecjを消す
- 機械レシピは変えていきたい
- 青銅シートする
- こうせきのこな、砕いた石はなくしてもいいかもなあ
