# 次回展示の運用準備チェックリスト

gamescomの会場フィードバックを次回展示へ引き継ぐための準備表。出展ごとにコピーし、実物の確認が済んだ項目にチェックを付ける。

## トレーラー再生専用端末

- [ ] 試遊用PCとは別に、トレーラー再生専用の端末（タブレット等）を用意する。
- [ ] 展示するトレーラーを端末に保存し、会場の通信環境に依存せず再生できるようにする。
- [ ] 充電器・電源ケーブル・設置スタンドを用意し、会場の電源と設置場所を確認する。
- [ ] 出発前に使用する端末で映像を最後まで再生し、ループ再生・音量・画面の向きを確認する。
- [ ] 給電中に自動ロックやスリープで再生が止まらない設定を確認し、想定する展示時間で連続再生を試す。
- [ ] 開場前に設置した状態で再生を確認する。来場者から画面が見え、試遊操作を妨げない位置へ置く。

## 独英両面チラシ

- [ ] 配布用チラシを、片面ドイツ語・もう片面英語の構成で用意する。
- [ ] 両面の内容・案内先・QRコードを確認し、どちらの面だけを読んでも案内が伝わるようにする。
- [ ] 出発前に1枚試し刷りし、同じ紙の表裏が独語／英語になっていること、上下の向き・余白・文字の読みやすさを確認する。
- [ ] 両面印刷の設定を確認する（A4縦なら長辺とじを基準に、試し刷りで表裏の向きを確かめる）。
- [ ] 予定部数が独英両面で印刷されていることを確認し、搬入分・補充分を分けて準備する。
- [ ] 開場前に配布場所を決め、両面に別の言語があることをスタッフ間で共有する。

## 試遊端末・プレイガイドとの準備合わせ

- [ ] 既存のA4プレイガイドの独語版 `docs/gamescom/a4-play-guide-de.html` と英語版 `docs/gamescom/a4-play-guide-en.html` を確認する。配布用チラシの原稿とは区別し、必要なプレイガイドも準備する。
- [ ] 試遊用Macで `scripts/event/start-gamescom-loop.command` と展示用の `moorestech.app` を用意し、出発前にイベントモードで起動・終了後の再起動を確認する。

ゲーム起動スクリプトは試遊ゲーム用で、トレーラー再生は専用端末のプレイヤーで設定する。今回の変更は準備表の作成のみで、機材購入・印刷発注・外部公開は行わない。
