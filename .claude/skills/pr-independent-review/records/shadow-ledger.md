# シャドー台帳 — pr-independent-review

独立レビューのverdictと人間の実マージ判断を突き合わせ、見逃し率を実測するための帳簿。
「あなたの実判断」「一致」「reconcile」列は後から記入する（記入者はreconcileモードのセッション・人間は確認のみ）。
追記型・行の書き換え禁止（記入列を除く）。

`head` 列はレビューしたHEADのshort SHA（先頭7桁）。同じPRを別headで再レビューした行を区別するため空欄にしない。
`縮退` 列は「なし（5系統フル実行）／縮退内容（codex不在等）／スタブ」のいずれか。
verdictを額面どおり見逃し率へ数えてよいかの判別に使うため空欄にしない。
`reconcile` 列はreconcileモードだけが記入する（実施日／`対象外（スタブ）`）。空欄＝人間コメントとの突き合わせ未実施であり、
Step 0.5の負債ゲートはこの列を見る。
台帳はverdict比較の粒度までとし、欠陥単位の内訳はreconcileモードが人間コメントの存在するPR全件について
`records/pr-<番号>.md`（または `-rN`）へ caught / missed / false-positive で追記する

見逃し率は missed / human-confirmed で集計）。
