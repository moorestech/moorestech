# moorestech設計レンズ・ダイジェスト

実装前・タスクレビュー時のチェックリスト。詳細と前例は `.claude/skills/moores-code-review/lenses/*.md`。
（実PRレビュー指摘 PR978/987/988/996/997/1000/1108 由来）

1. **前例一致** — この形の問題をリポジトリが既にどう解いているか検索したか。前例は機構でなく**役割**で選ぶ。無言の乖離は禁止（乖離するなら理由を明記）。役割同型の前例がある新設クラスは、**前例の実装interface一覧を突合**し横断系（スキット非表示・初期化待機・セーブ等）への加入漏れを確認する。
2. **依存方向** — 汎用基盤（基底コンポーネント・共通サービス・Master・Template）に上位ドメインの語彙・`Func<bool>`述語・デフォルト値を漏らしていないか。判断は具体側、基盤は `SetHoge` でのプッシュ受けのみ。
3. **ポーリング排除** — `Update()` 内で毎tickの同値判定・状態導出をしていないか。UniRxの変化通知Subscribeか、変化を起こす操作直後のプッシュへ。`Update()` は物理進行専用。
4. **サーバー状態3点セット** — 新規サーバー可変状態に「イベントパケット＋初期データ（Handshake/va:get*）＋クライアント購読」が揃っているか。他プロトコル応答から間接導出するApplierは禁止。
5. **DataStore分離** — 読み取り `I*Lookup`（static公開可）と変更 `I*Mutation`（DI注入のみ）に分離したか。staticに変更系を露出しない。
6. **データ防御禁止** — スキーマ `optional: true`・`?? Default`・ローダーでのプリフィルで欠損を吸収していないか。正解は必須化＋`default`定義＋全JSON一括更新（波及を恐れない）。
7. **型で排除** — 「どれか1つが埋まっていたら有効」struct、N択1必須役割のnullable表現をしていないか。判別子＋ペイロード型 / 束ねinterface＋ctor必須へ。既存共通サービスと重複するロジックは委譲へ。
8. **Func禁止** — `Func<>` を新規に書いていないか（機械チェックで弾かれる）。`Action`/delegateへの置換は非本質で不可。interface導入・依存関係の整理・呼び出し方向の変更（判断を具体側へ、基盤へは値プッシュ）で解決する。
9. **配置規約** — `PacketResponse/` 直下はIPacketResponse実装のみ。DTOは別階層。1ディレクトリ10ファイル・1ファイル200行以内。ディレクトリは依存の下流→上流が見える構成。
10. **抽象の受益者** — 新設したinterface・ラッパー型・`IDisposable`実装・publicメンバーについて、**今それを必要としている具体的な受益者を名指しできるか**。実装が1つだけ・参照元が自ファイルだけ・`Dispose`に解放対象が無いなら削除する。「将来増えるかも」は受益者ではない。ゲーム寿命オブジェクトは解放対象を持っていても`IDisposable`を付けない（本ゲームはメインメニューに戻らずプロセス終了で破棄される設計。[[2026-08-02-ゲーム終了破棄前提なのでIDisposableを付けない]]）。
11. **公開範囲の最小化** — 新設publicの参照元が自ファイル/同アセンブリ/デバッグだけなら`private`/`internal`へ落とす。デバッグ専用APIをプロダクション型の公開面に残さない。
12. **同型の全数掃引** — 欠陥を1件見つけたら、その形をpatch全体で数え上げてから直す（1件だけ直して同型を残さない）。PR1095の見逃し17件中7件超がこれ。
13. **時間はティック** — サーバのゲームロジックの経過時間は`GameUpdater`のティック加算のみ。`Time.deltaTime`/`DateTime`/`Stopwatch`は使わない。
14. **非同期の寿命** — 受け取れる`CancellationToken`は呼び出し鎖の端まで貫通させる。`await`明けに破棄済みオブジェクトへ触らない。
15. **デフォルト解決は所有者内で** — 「未指定ならデフォルト」の解決を呼び出し側に漏らしていないか。`public const Default*` 公開＋呼び出し側 `?? X.Default` は責務漏れ。デフォルトはprivateで所有者に置き、APIをnullable化して内部で一箇所解決（PR1108/1109）。
