## 構成（機械学習的に再チェック可能な形）

| パス | 役割 |
|---|---|
| `tasks/task-XX.md` | 盲検入力（凍結）。逐次文脈込みで自己完結。このまま再予測に使う |
| `gold.json` | 実回答ラベル（凍結） |
| `runs/<日付-ラベル>/` | 実行1回分の pred-XX.json＋gold.json＋score.txt。再チェックのたびディレクトリを増やす |
| `transcripts/*.jsonl` | 匿名化済みセッションログ全量（b8102540=本体870行・d47d5de3=圧縮継続533行）。考古学用の一次資料 |
| `HEAD.txt` | セッションが見ていたリポジトリ状態（コミット範囲・worktree） |

## 再チェック手順（回帰評価）

1. 改善後の知識ベースで、`tasks/` の各taskを盲検予測（shadowモードprotocol手順3の型・opus・実回答遮断）
2. `runs/<新ラベル>/` に pred-XX.json と gold.json を置き、`score.py <runダイアリ>` で採点
3. 旧runのscore.txtと比較（exact・ベースライン比・逸脱問的中・確信校正）。改善指標は「ベースライン超え」「逸脱問1問以上的中」
