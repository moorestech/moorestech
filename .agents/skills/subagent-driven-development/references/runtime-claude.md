# Claude Code での派遣・待機・生存確認

SKILL.md の「派遣する」「待つ」「生存を確認する」を Claude Code で実行するときの具体手順。
実行環境に依存しない規則(規模ゲート・台帳・レビュー・モデルのティア)は SKILL.md が正。

## 派遣

- Agent ツールで派遣し、`model` を必ず明示する(`opus` / `sonnet` / `haiku`)。未指定はセッションの
  モデルを暗黙に継承し、SKILL.md「モデル選定」を無言で無効化する。
- **フォアグラウンドで派遣する**(`run_in_background` を付けない)。Agent ツールは subagent が
  返るまで戻らないので、呼び出しそのものが待ちになる。バックグラウンド派遣は孤児化して止まる
  事故があった。

## 待ち

- フォアグラウンド派遣なら待ちの操作は不要。返ってきた結果にそのまま対応する。
- 例外的にバックグラウンドのものがある場合も、完了は通知で届く。待つならターンを終える。
  `ls` / `test -f` / 状態確認の連打で待たない。

## 生存確認・継続

- 生存確認は `ListAgents`。compaction 後や途中終了の疑いがあるときは、再派遣の前に必ず行う
  (生きている subagent を死んだと決めつけて再派遣し、同じ worktree を二重編集した実事故がある)。
- 生きている subagent へ追加指示を送るときは `SendMessage`(新しく Agent を呼ぶと文脈が
  失われた別個体になる)。
