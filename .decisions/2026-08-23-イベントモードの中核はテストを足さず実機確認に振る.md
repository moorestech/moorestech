# イベントモードの中核はテストを足さず実機確認に振る

決定（2026-08-23 ユーザー裁定 / moores-code-review run 2026-08-23-1930 D5）:
イベントモード中核（環境変数判定・シーンガード・ワールド削除・言語リセット・自動開始・無操作判定）に
テスト seam を導入しない。gamescom までの時間は実機での通し確認に振る。

棄却案（レビュー側の推奨だったが不採用）:
- `IEventModeBootSteps` を導入して `EventModeAutoStart.Run(steps, isEventMode, activeSceneName)` を純粋な調停メソッドへ
  分解し、ガード2つ・呼び出し順・非発火を mutation で殺せるようにする
- 純粋ロジック（無操作タイマー・環境変数プロパティ・ワールド削除）だけ値クラスへ抜く最小案

残るリスク（承知のうえ）: 「メインメニュー以外では何もしない」ガードが反転すると、**通常起動でプレイヤーの既定ワールドを
丸ごと削除する（不可逆・R8違反）**。このガードに触る変更は必ず人手で通常起動を確認すること。
