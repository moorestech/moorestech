# 序盤圧縮は研究1〜3の削除と要求アイテム数の変更だけで行う

日付: 2026-08-27

## 決定
- **スコープ**: `craftRecipes.json` / `machineRecipes.json` のアイテム構成（どの機械でどのレシピを作るか）は一切変更しない。触るのは研究ノードの削除と付け替え、チャレンジの削除、要求アイテム数、初期解放フラグのみ
- **原始研究1〜3を削除**する。石の斧を装備済みで開始し風力掘削機を初期解放すると、この3ノードの払い出しが空になるため。付け替えは `石` / `砕いた石材` / `石の斧` の `initialUnlocked: true` 化と、風力掘削機ブロックの `initialUnlocked: true` 化だけ
- **削減ルール**: 一律係数ではなく「その時点で機械化できていないアイテムだけを大きく削り、機械で作れるようになったアイテムは据え置く」。自動化の動機を残したまま手作業だけを消すため
- **要求アイテム数**（アイテム種別は不変、数値のみ）
  - 原始研究4: 板20/棒20/砕石10 → 板8/棒6/砕石4
  - 原始研究5: 板10/レンガ45 → 板5/レンガ45
  - 原始研究6: 青銅インゴット30/レンガ50/棒20 → 青銅インゴット10/レンガ50/棒6
  - 原始研究7: 青銅40/レンガ94/砕石84/棒20/板32 → 棒6/板10 のみ変更、他は据え置き
  - 原始研究8: 板100/青銅シート35/砕石30 → 板15/青銅シート10/砕石30
  - 風力掘削機の設置費: 板10/砕石5 → 板4/砕石2
- **石の斧を装備済みで開始**、**風力掘削機を初期解放**

## 棄却案
- 板・棒・砕石を自動生産する機械（原始的な加工機・粉砕機）を最序盤へ前倒しし、木材だけで閉じた第0ティアを新設する — 「今後数十時間分のバランス調整やり直しになる」ため却下（ユーザー裁定 2026-08-27）
- 手クラフトの出力を5個単位にして待ち時間を消す — 「自動加圧が全く働かなくなる」ため却下（ユーザー裁定 2026-08-26）
- 研究1〜6のコストを一律係数で割る — 機械化済みアイテムまで下がり自動化の動機が消えるため、機械化前アイテム限定の削減へ差し替え
- 展示用ブランチ限定・masterへマージしない / 今日中の期限 — どちらも撤回済み（ユーザー裁定 2026-08-26「緊急対応はやめてちゃんとやる。期日は設けない」）

## 理由
研究1〜8のコストだけで手クラフトが約305回（板207・棒25・砕石25・青銅鉱石の粉30・青銅シート18）。板と棒は原始的な加工機（研究8）まで、砕いた石材は原始的な粉砕機（研究6）まで、手クラフト以外の入手手段が存在しない。とくに研究8は「板を作る機械を解放する直前に板を100枚手作りさせる」構造になっていた。
風力掘削機は `requiredPower: 0` で石・原木・青銅の鉱石・粘土の4種すべてを掘れるため、初期解放だけで序盤の採掘が全自動になる。
`attackSpeed` は振り間隔（秒）で小さいほど速く、石の斧1.0秒は石器2.0〜3.0秒の上位互換。`equipmentSlotCount` は1なので、石の斧を装備済みにすると石器へ持ち替える行為は純粋な劣化になる。

- 原始研究6と7の統合は行わない
