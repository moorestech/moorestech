# 停車駅の端はプロトコルで指定できUIが入線方向を固定する

決定: 駅ブロックの先端側・後端側どちらの Exit ノードも時刻表の停車駅として認識する。`va:trainScheduleEdit` の停車駅は駅座標と端（Front/Back）を持ち、サーバーは両方を受け付ける。Web UI は入線方向を固定し、新しく追加する停車駅は Back側で送る（既存の停車駅は届いた端をそのまま送り返す）。セーブ形式は変えない。

棄却案: 近い方の端にサーバーが着ける／端をサーバーで固定しプロトコルからは指定できない（いずれも選択肢として提示し、ユーザーは選ばず自由記述で上記を指示）。

理由: ユーザー発言（2026-09-25）「駅blockは先端と後端が両方駅nodeとして認識対象になるべきである(AIプランだと片側だけしか認識しないことになっている)」「原理上どちらも指定できるが、基本的にUIでは固定方向（つまり駅の入線方向は固定）としたい」「プロトコルではどちらも指定できる。UIレイヤーで固定する」。
