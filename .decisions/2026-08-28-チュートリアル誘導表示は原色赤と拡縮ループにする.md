# チュートリアル誘導表示は原色赤と拡縮ループにする

決定: keyControlヒントHUD・UIハイライト枠・ワールドピンの画面外矢印を `#ff0000` にし、拡縮ループを付ける。
ヒントと矢印は 1.0↔1.08 / 1200ms、ハイライト枠は 1.0↔1.03 / 1200ms。ハイライトは枠線とグロー（24%）の両方を赤化し、ラベル面は現状維持。矢印は fill のみ赤化し縁取りは維持。
赤化の範囲はチュートリアルHUD限定を維持する（インベントリ画面左下・研究画面左下のキーヒントは白のまま）。

棄却案:
- キーヒント全部（共有 keyHintText）を純赤にする → 2026-08-22裁定を覆すため不採用。パネル内ヒントは可読性の問題がない
- #ff2d2d の濃いめ赤に寄せる → ユーザーが原色を明示指定
- 枠の振幅を1.08で全要素統一 / 1.05・1600ms → 「軽く」の指定に対し1.03を採択
- D&Dドラッグガイド矢印も赤化する → 対象外
- 矢印を純赤化のみ（アニメ無し）/ 縁取りを白へ反転する → 不採用

理由: ユーザー裁定 2026-08-28 原文「Tabを押してください、みたいな画面上に出すチュートリアルは原色赤にして、拡縮のループアニメーションをさせたい。また、UIハイライトとも原色赤にして、こちらも軽く拡縮ループアニメーションしたい」「Hud矢印も」。誘導表示がワールド背景に埋もれて見落とされるため。
