# カード枠線のCSSはテンプレへ追加してAIの手足しをやめる

決定: digest-template.html の `<style>` 末尾へカード枠線・左色帯・summary-line・detailsのCSS（17行）を追加する。既存ルールは1文字も変えない。

棄却案: Global Constraints の文面どおりテンプレを一切触らず、レンダラがカード毎にインラインstyleを吐くか、枠線無しの見た目を受け入れる。

理由: この18行は旧SKILL.mdの「カード間の視覚分離」規約に従って著者AIが毎回手で足していたもので、planはその規約を「コンバータの責務へ移った」と削除したが移し先の実体が無かった（planの穴）。テンプレへ置くのは「AIが毎回CSSを書く」側を消すというADR 0015の目的そのもの。追加後の`<style>`は現行digest.htmlとバイト一致。
