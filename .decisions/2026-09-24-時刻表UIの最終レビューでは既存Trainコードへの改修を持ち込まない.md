# 時刻表UIの最終レビューでは既存Trainコードへの改修を持ち込まない

決定: feature/train-timetable-ui（ADR 0067 / bd moorestech-lc9ty）の moores-code-review 最終レビューで出た設計判断 D1〜D8（通知保留フラグの一本化・テスト専用 public の撤去・駅名の長さ/文字種制限・ReplaceTimetable の置き場・駅ノード解決の失敗理由分離・時刻表タブの駅名鮮度購読・snapshot の現在地表現・停車リストの行 key）はすべて採用しない。自動修正のうち C# 側（既存 TrainUnit / TrainUpdateService / TrainSnapshots / TrainDiagram 等への変更を含み、同期データの形を通じて連鎖していた）は取り消し、同期データの形に依存しない webui 側の修正だけを残す。
