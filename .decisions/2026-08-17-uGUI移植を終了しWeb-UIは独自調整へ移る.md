# uGUI移植を終了しWeb UIは独自調整へ移る

決定: uGUI正本への見た目パリティ追従を終了する。今後 Web UI は正本合わせではなくWeb独自の調整で進める。Web UI関連のコード・ドキュメントからuGUI由来の語彙（「正本」「uGUI」「原画像」等の参照）は削除してよい。当面の具体的帰結として、`--menu-upper-safe-area` を 128→168px へ広げる際に `e2e/parity_targets.py` の bbox・色ピック目標を引き直す必要はなく、パリティ目標の破綻は差し戻し理由にならない。

棄却案: 安全帯を広げつつ parity_targets.py の bbox 3件と色ピック値を新位置で再測定して維持する（正本一致を保てるが、以後もWeb独自の調整ごとに再測定が必要）／メニューを動かさずHUDの面の重なりを許容する（パリティは無傷だが、面が2枚重なる見た目を抱える）／面の縦を詰めて同時表示を2件に制限する（機能を削る）。

理由: uGUI描画は Phase1 で恒久停止済みで、参照すべき実物がもう無い（ユーザー「uGUIはもう見ない。もうuGUI移植は終わった」）。パリティ目標を維持し続けることは、実体のない基準へWeb独自の改善を縛り続けることになる。
