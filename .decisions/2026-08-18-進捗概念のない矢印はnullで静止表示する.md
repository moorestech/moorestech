# 進捗概念のない矢印は value=null で静止表示する

決定: `ProgressArrowGlyph` の props を `value: number | null` にし、`null` のとき `role="progressbar"` と `aria-value*`・塗り用clipPathを出さず、枠と輪郭だけ描く。機械レシピエントリは `value={null}` を渡す。

棄却案:
- 静止矢印を `ArrowGlyph` として切り出し `ProgressArrowGlyph` が内包する2部品構成 — 責務分離は明快だがSVGパスの共有管理が増える
- 現状維持（`value={0}`）— 実装コスト0だが機械エントリがprogressbarロールを名乗り続け、クラフト側に0専用表現を足すと進捗概念のない側へ自動波及する

理由: 支援技術に「0%で停止中のprogressbar」が最大4本読み上げられる。共有部品にドメイン語彙を持ち込まずに「進捗が無い」を型で表現でき、a11y・CSS・テストの下流まで区別が届く。
