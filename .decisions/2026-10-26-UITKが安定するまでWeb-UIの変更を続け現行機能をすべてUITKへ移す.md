# UITK が安定するまで Web UI の変更を続け、現行機能をすべて UITK へ移す

決定: UI Toolkit が安定稼働するまで、Web UI への変更（不具合修正・新機能）は従来どおり続ける。移行の範囲は現行 Web UI の全機能。移行計画 v3 の G1 は凍結ゲートから追従ゲートに変える（束ごとに暗転の起点コミットを台帳に書き、切替 PR で起点以降の Web 差分が全部「写した」か「捨てた（理由）」になっているかを機械で確かめる。切替済みの束の Web パスへの変更は落とす）。追従ゲートの形は agent 案。
棄却案: 計画 v3 裁定 4 の推奨（G1 で `web/features` の新規ファイルを止め、Web は致命的な不具合だけ直す）／全面凍結（不具合も直さない）。
理由: UITK が安定するまで出荷中の UI は Web で、そこで改善を止めるとテスターに届くものが止まる。帰結として移す対象が移行中も動き、暗転中の束に入った Web の変更は二重作業になる。
出所: ユーザー 2026-10-26「とりあえずUI T Kが安定稼働するまでは、ひとまずウェブUIのほうも引き続き変更行っていくつもりではある 現状の機能全部UKに置き換えて欲しい」
