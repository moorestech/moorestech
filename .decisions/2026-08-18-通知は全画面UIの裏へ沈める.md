# 通知は全画面UIの裏へ沈める（stage背面レイヤー）

- **決定**: ゲーム内通知(`NotificationHost`)を Portal から `.viewport` 直下（`.backdrop` と `.stage` の間）へ移し、全画面UI・常駐HUDの裏に回す。実ピクセル固定の見た目は維持。適用範囲は全画面UI全般。
- **棄却案**:
  - `--z-toast` を下げるだけ → `.viewport` が `position:fixed` でスタッキングコンテキストを作るため実現不能。
  - `.viewportOverlay`（常駐HUD族）へ移設 → 通知の文字サイズが `--ui-scale` 追従になり見た目が変わるため却下。
  - `ToastHost` も一緒に下げる → 障害・契約違反の表出は何を開いていても見えるべき系統なので前面のまま。
- **理由**: 通知は控えめな報告であり、プレイヤーが画面を開いて操作している最中は前面を占有すべきでない。
