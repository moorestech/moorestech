# pr-createの2段委譲は現状維持する

日付: 2026-09-13
出所: ユーザー裁定 指示ファイル剪定監査（PRレビュー系）の裁定3点のうち2。質問「pr-create の sonnet→opus 2段委譲を撤去し本体が直接実行する形にするか」→ 選択「やらない。現状維持」

## 決定
- pr-create は「薄いオーケストレータ（SKILL.md）＋ sonnet subagent が agent.md を実行、コンフリクト解消は opus subagent」の構造を維持する
- 例外2（ベースブランチ上で起動された場合）の手順だけは例外1と同型（`git branch <新> HEAD` ＋ `--head` 指定push）へ揃える。これは委譲構造の変更ではなく、`checkout -b` と `branch -f` による HEAD 移動を避ける正確性修正

## 棄却案
- 監査案（1ファイル化して本体が直接実行）: 呼び出し側4スキルが `/pr-create` 無引数＝全自動という契約に依存しており、構造変更の利得がコスト削減だけで挙動リスクに見合わない
