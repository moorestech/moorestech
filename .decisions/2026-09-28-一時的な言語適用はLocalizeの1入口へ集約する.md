# 一時的な言語適用はLocalizeの1入口へ集約する

決定: 「選べる言語か」の判定と、保存しない一時適用を Localize の1入口（Client.Localization の interface で出どころを受け取る `TryApplyUnchosenLanguage(source)`）に集約する。検証なしの internal setter と public `HasChosenLanguage` は置かない。Steam 読み取りの interface（ISteamGameLanguageReader）はこの source に吸収して削る。言語一覧を返す旧 API（`Localize.GetLanguageCodes` と辞書Factory側）は削除し、テストは `LanguageCatalog.Languages` 基準にする。

棄却案:
- Localize 内部の判定だけ共有し、HasChosenLanguage を public のまま残す（呼び出し側の先行判定が二重に残る）
- 現状維持（判定4箇所・検証なし setter）
- 言語一覧 API を残して中身だけ差し替える／旧実装へ戻す

理由: ユーザー裁定 2026-09-28 最終レビュー D1「両方削除しテストを新一覧へ」・D3「interface経由で1入口に集約」・D4「おまかせ」（D3 に吸収されるため agent 判断で削除）。
