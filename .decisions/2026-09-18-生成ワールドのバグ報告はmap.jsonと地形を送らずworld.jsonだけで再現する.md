# 生成ワールドのバグ報告は map.json と地形を送らず world.json だけで再現する

2026-09-18 ユーザー裁定（原文「それと、map.jsonとかhegihtとか送るひつようある？」→ 質問「バグ報告バンドルから map.json と地形を外す条件はどれにしますか？」→ 選択「生成ワールドなら常に外す」）。

決定: バグ報告バンドルの `world/` は、`world.json` の `mapMode` が `generated` なら `world.json` だけを入れ、`map.json` と `terrain/*.r16` は入れない。開発側は `world.json`（seed・generatorVersion・マスタ指紋・配置台帳ダイジェスト）と同じビルドから地形を引き当てる。手作りワールド（`mapMode` が `generated` 以外）は従来どおり全部入れる。

理由: 生成ワールドは seed 196 固定で全テスターが同じ地形を持ち、配布ビルドには同梱スナップショットもある。約100MBの箱のうち約88MBがこの重複分だった。`map.json` はプレイ中に書き換えられず、プレイ中の変化はスナップショットの `tick_*.json` 側にある。

棄却案:
- 同梱スナップショットと一致するときだけ外す — 判定にスナップショットのメタ読みが要り、Editor（開発者モード）ではスナップショットが無いので常に入ってしまう。
- 常に外す — 手作りワールドの報告は再現に元データの手配が要る。
