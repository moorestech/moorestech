決定: `abstract class SpawnDistanceBand`（`outerRadiusMeters` と `OuterRadiiOf` を保持）を置き、`OreBand` と `ObjectScatterBand` が継承する。逐語同一だった `OuterRadiiOf` の2複製を1本化する。

棄却案: 案B `ISpawnDistanceBand`（メソッド形）＋ `SpawnDistanceRing<TBand>` のジェネリック化（配列取り違えが型で不可能になるが、Config の POCO に interface が載りテスト用ダミー型が要る）／案E 現状維持（添字ベースのまま `OuterRadiiOf` 重複と配列取り違えリスクを残す）。

理由: planは「`Func<>`禁止・素通しプロパティ禁止のため添字ベースにした」と説明していたが、基底クラス案も interface案もどちらの禁止にも触れない。したがって添字ベースを選ぶ理由は成立していない。基底クラスは interface もジェネリクスも増やさずに重複を消せ、バンド検証の集約先にもなる。
