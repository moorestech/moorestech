# 無操作計測はプロセス起動直後から始める

決定（2026-08-23 ユーザー裁定 / moores-code-review run 2026-08-23-1930 D6）:
イベントモードの無操作タイムアウト計測は現状どおりプロセス起動直後から積算する。ロード完了時のリセットは入れない。

棄却案（レビュー側の推奨だったが不採用）:
- `GameInitializedEvent.OnGameInitialized` を購読して計測をリセットする（前例 `StandaloneTerrainQaBootstrap`）—
  「プレイ可能になってから180秒」を保証できるが、今回は入れない
- 起動用の別タイムアウトを足して本物のwatchdogにする — 環境変数が3本になり現地の運用ミス面が増える

残るリスク（承知のうえ）: ワールド生成のロードがタイムアウト閾値に近づく環境では、無人のまま quit → 再起動 →
また生成中に quit の起動ループから抜けられない。既定180秒なら現行のロード時間で問題ないが、
**現地でタイムアウトを短く（例60秒）する運用は踏み抜くため避けること**。
