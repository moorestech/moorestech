# ダイ表の Tier5 は良品合計を Tier4 と同じ 0.98 にし、Lv5 を足して良品が下がらないようにする

決定: v8 の Tier5 表の failedRate を 0.025→0.020 にし、差の 0.005 を Lv5（0.925→0.930）へ移す。ADR 0104 の表を揃え、Lv4×8 に Lv5×1 を足しても良品が下がらない回帰テストを足す。
棄却案: 案B（加えて起動時検証に「Tier t の良品は Tier t−1 以上」を足す）。
理由: 品質Lv4×8 に Lv5 を1個足すと最高Tierの切り替えで良品率が 94.87%→94.50% に下がる（クラスA）。Tier5 の良品合計(0.975)が Tier4(0.98)より小さいため。
明示引用: 最終レビューの設計判断「Lv4を8個入れた切断機にLv5を1個足すと…良品率が下がります。どうする？」→ 選択「Tier5の表を直す（推奨）」
