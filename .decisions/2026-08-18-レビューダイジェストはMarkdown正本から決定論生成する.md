# レビューダイジェストはMarkdown正本から決定論生成する

決定: `pr-independent-review` のAIは `digest.md` 1枚だけを書き、決定論コンバータが `digest.html` と `findings.json` の両方を生成する。ページ骨格（セクション分け・並び順・インデックス・0件行）もコンバータが導出する。

棄却:
- `findings.json` を正本にする — 長文の散文をJSON文字列に埋めることになり、可読性と編集性が落ちる
- `digest.md` と `findings.json` の2本立て — 現状の二重入力（id採番ズレ・recommended食い違い）を温存する
- セクションをAIがMarkdown見出しで並べる — 並び順と0件セクション存置の遵守がAI任せのまま残る

理由: HTML手書きを支える約60行の注意書きが毎回AI任せで、PR #1155 では `data-finding-id` の付与先が規約から外れて裁定ボタンが全部章末に落ちた。生成後検査も件数と重複しか見ておらず素通りした。
