# ブロック画面はマスタに画面IDを書き、クライアントのC#登録で引く

- 決定: マスタの各ブロックには画面のIDだけを書く（Prefab指定・コンポーネント指定のような本質的にID指定の形）。IDの先はクライアントに C# で登録した画面。
- 実装要件: 欄の構成も画面IDで選ぶ。出所は承認済み実装計画 R6（本文だけをIDで選び欄を blockType で引く案もあった）。
- 棄却案: ②画面と欄の設定値をマスタに直接書く ③画面を部品の並びでマスタに書く ④IDの先をUIアセット（UXML）のパスにする
- 理由: ユーザー裁定 2026-11-27 原文「Prefab指定やコンポーネント指定みたいに本質的にid指定になっていてほしい」→ 復唱確認のうえ選択「C#で登録した画面（推奨）」
