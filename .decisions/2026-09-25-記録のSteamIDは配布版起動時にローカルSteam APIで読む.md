# 記録のSteamIDは配布版起動時にローカルSteam APIで読む

日付: 2026-09-25
出所: ユーザー裁定 質問「報告・進行記録・異常終了箱に書くSteamIDは、どこから取りますか？」→ 選択「A：ローカルのSteam API（SteamUser.GetSteamID()）で起動時に読む」
追加裁定: 質問「同意ポップアップに1文足したあと、既に『了解』を押したテスターにもう一度見せますか？」→ 選択「B：再表示しない」

## 決定
起動時照合の撤去で受け口の検証済みIDが得られなくなるため、配布版の起動時に SteamUser.GetSteamID() を PlaytestSessionIdentityProvider へ差し込む。追跡の正は R2 の置き場所（トークン由来）。同意の表示規則は変えず、既読者に再表示しない。
[[2026-09-20]] の ADR 0065 裁定「受け口の検証済みID」を覆す。

## 棄却案
- 記録内の steamId 欄をやめ R2 の置き場所に一本化する
- 初回アップロードの認証成功時に検証済みIDを差し込む
- 同意の版を上げ既読の人にも1回再表示する

リンク: ADR 0070, ADR 0065
