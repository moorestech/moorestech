# マージ済みPR後追い独立レビューの裁定17件（第3弾の入力）

決定: 8/21〜8/30にマージ済みのPR19本への後追い独立レビューで「推奨案をそのまま採れない・ユーザー判断が要る」と仕分けた17件を、13件は推奨案A・4件は本質側の案で裁定した（下表）。2026-09-04 ユーザー裁定。裁定サイトは https://review.moores.tech/pr/900001 （元PRのdigestから該当カードだけを切り出した合成エントリ）。
棄却案: 推奨案をそのまま全件採る案（4件で「変更行数を減らすその場しのぎ」に寄っていたため）。#1255 F02 案A現状維持・#1255 F05 案A別鍵退避・#1258 F05 案A制約の記録維持・#1271 F07 案B存置。
理由: 「推奨案は本質的な改善か、変更行数を減らすその場しのぎか」の観点で仕分け、逃げ道の復活や制約の正当化になる案は採らない。
リンク: 第1弾 #1307、第2弾 #1309〜#1313（適用済み115件）。#1302 F01 は bd moorestech-99c8。Beads: moorestech-kjam.1.2

## 推奨と異なる裁定（4件）

| 元PR | ID | 裁定 | 理由 |
|---|---|---|---|
| #1255 | F02 | **B**: abstract base + `TemplateTerrainTransferMeta` / `GeneratedTerrainTransferMeta` の2型へ分割 | 案A「現状維持」に推奨マークが付いていたのは並びの誤り。判別子3本の分散と無検査derefは型で消す |
| #1255 | F05 | **B**: サーバー作成時に台帳を再生成し digest 一致を確定 | 案A「別鍵で自前焼きへ退避」は digest 不一致を迂回する逃げ道の復活。fail-closed は維持する |
| #1258 | F05 | **B**: `PlacementHaloChannelMap` の鍵をエントリ同定へ変え、veinGuid 一意性制約自体を不要にする | 案A「制約を裁定として記録し維持」は制約を正当化するだけ |
| #1271 | F07 | **A**: `ReleaseLocalBuildCli` を削除（batchmode 入口は不要）＋ ADR 0036 の「batchmode入口は残る」記述を訂正 | ADR 0036 と plan の矛盾は plan 側（コミットしない）が正 |
