# ベルト張替え（ADR 0055 / plan 2026-09-10）の事前計画レビュー裁定4件

2026-09-10 ユーザー裁定。SDDの事前計画レビューで Blocker 6 / Important 12 / Minor 11 が出たうち、
設計判断を要する4件を裁定した。所見全文は `.superpowers/sdd/pre-plan-review.md`（git管理外）。

## 決定

### B2 張替えのアトミック性 → 事前検証で失敗経路を消す
撤去前に「同セル・同向き・1x1x1・ファミリー同ロール」なら `TryAddBlock` が成功することを検証し、
検証を通ったセルだけ撤去へ進む。巻き戻し経路そのものを作らない。

- 棄却1: 失敗時に旧ブロックを再設置して `CommitRemoval` を打ち消すロールバック経路
  → 巻き戻し経路とそのテストが恒久的な保守対象になり、めったに通らない経路が腐る
- 棄却2: `WorldBlockDatastore` に「同セル差し替え」APIを新設してアトミック性をデータストア層の責務にする
  → 最も堅牢だが波及が大きく、張替えのためだけにデータストアの公開面を広げる

### B4 混在ランのコスト見積り → BlockIdごとに集計する
`ConstructionCostPreviewMarker` の代表セル方式をやめ、ランを BlockId ごとにグループ化して
それぞれ affordableCount を求める。分岐器をファミリーへ吸収したことで
「ファミリー内はコストと設置数/1セットが一致する」既存前提が偽になったため。

- 棄却1: 分岐器セルを代表セル選定と affordableCount の対象から外す
  → 変更は小さいが分岐器のコスト先読みが欠け、支払えない分岐器を送って失敗経路へ落とす
- 棄却2: `splitterBlockGuid` をやめ分岐器を別の対応付けでロール解決する
  → ADR 0055 の設計自体の差し戻しになる

### I12 高さオフセット → 張替え時はオフセットを無視する
R7「張替え中は高さオフセットを使わない」を文言どおり実装する。起点解決時に `HeightOffset` を 0 扱いし、
Q/E を押していても既設ベルトの上にホバーしていれば張替えが発動する。

- 棄却: 「オフセットが1以上の間は張替えモードに入らない」を仕様として ADR/plan に明記する
  → 実装は変わらないが、プレイヤーから見て Q を一度押しただけで理由不明に効かなくなる

### 規約違反3件 → 3件とも規約を優先し計画を直す
- B1 Task 8 の `System.Func<int>` → ローカル関数へ置換（AGENTS.md Func禁止・機械チェック対象）
- I9 テスト専用の public 化（`TicksOfItemEnterToExit` / `BuildUndoPlaceInfos`）→ internal へ落とすかテスト側の経路を変更
- I11 296行の `VanillaBeltConveyorComponent.cs` へ +45行 → 搬送品復元を別ファイルへ分割（200行規約）

- 棄却: B1のみ規約優先とし I9/I11 は既存債務の拡大として受け入れ bd へ積む
  → 規約違反を新規に持ち込む点は同じで、レビューで差し戻される
