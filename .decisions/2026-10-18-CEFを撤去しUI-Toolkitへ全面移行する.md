# CEF を撤去し UI Toolkit へ全面移行する

2026-10-18 ユーザー裁定。

## 決定
cef-unity（別プロセス Chromium + GPU テクスチャ共有）による Web UI を撤去し、UI を素の C#/UXML/USS（UI Toolkit）へ全面移行する。OneJS は経由しない。アニメーションは UI Toolkit 向けのフレームワークを導入または自作する。移行順・出荷形・完了条件は grill と plan で別途決める。

## 棄却案
- cef-unity の既知 7 機構を修理して Web UI を維持する: 修理しても別プロセス・GPU 共有・外部バイナリという構造は残り、数万環境でのサポート面積が減らない。
- OneJS（UI Toolkit 描画 + TS/React）へ移行する: 書き手が AI である現在、TS 層と C# の橋渡しは余計な層で、1 言語・1 プロセスの素の構成のほうが単純。
- 開発ループの速さ（Editor 無しの vitest/Playwright 1,020 ケース）を理由に Web を残す: 検証時間は待てば払えるコストで、環境差で壊れる UI は払えないコスト。

## 理由
配布先が数万環境のゲームで、UI が別プロセスの Chromium に乗る構造は環境差（GPU ドライバ・ウイルス対策・Steam オーバーレイ・パス）で壊れ、再現も採取も難しい。開発機だけで Init 失敗・Steam とのキャッシュ衝突・ゾンビ server・FD 継承・LFS 配布の問題が既に出ている。UI Toolkit はレンダラと同じプロセス・同じ検証面で「Unity が動く環境では UI も動く」保証になる。2026-02 の「UI Toolkit は全面採用できるほど洗練されていない」は当時の AI 性能を前提にした判断で、書き直しと部品自作のコストは現在は桁が違う。
