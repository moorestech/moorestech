# 成膜装置を削除し、トランジスタ設置済みウェハは EUV 装置で作る

決定: v8 から成膜装置を削除する。シリコンウェハ＋IPA→トランジスタ設置済みウェハのレシピは、EUV露光式半導体製造装置のレシピにする。クリーンルームの専用機は ウェハ切断機・EUV露光・ダイシング・パッケージング の4種になる。既存セーブに置かれた成膜装置は、ロード時のマスタ欠落の刈り込みで消える。
棄却案: 成膜装置を残し、品質モジュールを挿せなくする（直前の裁定。これを置き換える）。
理由: レベルはダイシングで決まり、成膜には失敗判定も無く、専用機として置く理由が無い。成膜装置は構想段階（10/22 のマスタ。機械は EUV 1台で、シリコンウェハ→EUV→トランジスタ設置済みウェハの並び）には無く、10/23 に agent が提案した機械だった。
