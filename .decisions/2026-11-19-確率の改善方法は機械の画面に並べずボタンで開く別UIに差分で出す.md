# 確率の改善方法は機械の画面に並べずボタンで開く別UIに差分で出す

- 決定: 「何を上げるとどれくらいの確率になるか」は機械の画面に常時並べない。ボタン（文言は「失敗率の改善方法」のようなもの）で開く別のUIに、今との差分（Lv1 +◯% / Lv2 +◯% / 失敗 −◯%）で出す。並べる改善は、部屋クラスを上げる・今刺さっている中で一番高い品質モジュールを増やす・1レベル上の品質モジュールを刺す。EUV露光式半導体製造装置も同じ形にする。
- 棄却案: 機械の画面の確率の欄の下に「上げると」の行を常時並べる（ユーザー棄却）。
- 理由: 同じところに表示するとごちゃつく。
- 明示引用: ユーザー原文「自分の装置の確率について書いてほしい 何がアップしたらどれくらいの確率になるのかUIに書いておいてほしい」／赤「上げるとどうなるかは別UIでボタンで見せるようにして（同じところで表示するとごチャル ボタンは（失敗率の改善方法）みたいにして で、差分を見せて 部屋クラスをBに Lv1 + 10% Lv2 +5% 失敗 -5% 品質モジュールLv1 追加 Lv1 + 10% Lv2 +5% 失敗 -5% 品質モジュールLv2 追加 みたいな 品質モジュールに関しては、今刺さってる中で一番高いモジュールを増やす表記と、1レベル上を刺すときの表記にする」／EUV の図への赤「これも同じく」
- 未決: 別UIの形（重なる小窓か画面内の切り替えか）。
