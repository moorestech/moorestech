# 面付き目標HUDの文字影は通知同族へ弱める

決定: 目標HUDに面を入れたあと、文字影は削除せず NotificationHost 同族の控えめな値（0.35px級）へ弱める。可読性の主担当は面へ移し、影は世界が透ける面上の補助に留める。

棄却案: 現行の強い影 `0 1px 2px rgb(0 0 0 / 85%)` を維持する（どんな地形でも読めるが、面の上では影が浮き、パネル本文・通知と影の強さが揃わない）／文字影を削除しインベントリパネル本文と同じ無影にする（最も清潔だが、明るい地形の上で可読性が面の不透明度だけに依存する）。

理由: 面は半透明で世界が透けるため無影は危険、一方で面がある以上は世界直置き用の強い影は過剰。面付きUIの影の強さを通知と一致させ、語彙を増やさない。
