# LEARN自動保存は続け、定期棚卸しで真に価値あるものだけskillへ昇格する

決定: 応答末尾の `LEARN:` を bd note へ自動保存する hook（beads-learn-capture）は続ける。たまに棚卸しし、skill（SKILL.md・references）へ追記・修正する価値のある学びだけを適用して、残りの session-log chore はすべて close する。
棄却案: LEARN を廃止して memory・skill・AGENTS.md へ一本化する（棚卸しで拾えば十分で、書く習慣自体は残したい）。
理由: 2026-09-29 時点で auto learn は554件あるのに読み出し経路が無く、9割が open の session-log chore に溜まって bd ready の6割を占めていた。中身の約6割は再利用可能な罠だが、効くのは skill に入ったときだけ。
