# ビルドメニューのジャンプ固定は操作イベントで解除する

- 日付: 2026-08-30
- 対象: `moorestech_web/webui/src/features/buildMenu/logic/buildMenuScrollSpy.ts` / `hooks/useBuildMenuCategoryScroll.ts`（ADR 0045 の実装）

## 決定

距離ベースの `isJumpAbandoned` を撤去し、視口へ `wheel` / `touchstart` / `pointerdown` / `keydown` を `{ passive: true }` で張る。発火時にジャンプ固定を即解除して scroll-spy へ戻す。

## 棄却した案

- `isJumpAbandoned` の比較を `>=` から `>`（厳密不等号）へ変えるだけの縮退案。

## 理由

距離の単調性はユーザー操作の代理指標にすぎない。目標と同じ方向へホイールを回して止めると距離は縮み続けるため固定が解除されず、視口に別カテゴリが見えているのにハイライトがジャンプ先を指したままになる。厳密不等号は横スクロール時の同値誤判定しか潰せず本題が残る。操作イベントを直接見る形が症状を消す。Codex の audit / bughunt も独立に同案を第一推奨とした。
