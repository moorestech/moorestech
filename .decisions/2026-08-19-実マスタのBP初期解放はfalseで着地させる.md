# 実マスタのBP初期解放はfalseで着地させる

決定: moorestech_master の `server_v8/mods/moorestechAlphaMod_8/master/buildMenu.json` へ追加する `blueprintInitialUnlocked` は `false`（初期未解放）。解放手段となる研究ノードの `clearedActions` への `unlockBlueprint` 配置が未着手でBPが一時的に到達不能になることは受け入れる。

棄却案: 暫定で `true` を入れて研究ノード配置と同時に `false` へ落とす（既存挙動から後退せず、テストプレイでBPの検証も続けられるが、ADR 0015の「開始直後は使わせない」が実マスタに入らない期間が伸び、`true` の暫定が恒久化する）。

理由: ユーザー裁定 2026-08-19。ADR 0015の意図をそのまま実マスタへ反映する。
