# digestコンバータは標準ライブラリのみの限定サブセットで書く

決定: Markdown→HTML変換は標準ライブラリのみで実装し、digestが実際に使う記法（見出し・段落・箇条書き・コードフェンス・diffフェンス・強調・インラインcode・リンク）だけを扱う。未知記法はエラーで落とす。

棄却:
- pipで markdown-it-py 等を導入 — レビューは使い捨てworktreeで無人headless実行されるため、パッケージ不在で黙って死ぬ。標準変換は現行CSSが想定しないタグも出す
- node側で変換 — 既存 `scripts/` が全てpythonで言語が混ざり、webuiの node_modules にレビュー基盤が依存する

理由: このマシンの python3 には markdown / markdown-it-py / pyyaml がいずれも未導入。記法を絞ることは「見た目が勝手に変わる道を塞ぐ」ことでもある。
