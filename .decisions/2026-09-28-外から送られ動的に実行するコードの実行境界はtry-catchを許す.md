# 外から送られ動的に実行するコードの実行境界は try-catch を許す

日付: 2026-09-28
出所: ユーザー裁定 質問「送ったC#コードの例外を応答に閉じ込める try-catch が許可された外部境界に当たりません。どうしますか？」→ 選択「AGENTS.mdに第5類型を追加」

## 決定
AGENTS.md の try-catch 許可境界に「外部から送られ動的にコンパイル・実行したコードの実行境界」を加える。根拠コメントとログ・欠損表明の義務は他の境界と同じ。

## 棄却案
- 規約は変えず、当該ファイルだけ根拠コメントで個別に例外扱いする

リンク: ADR 0072, ADR 0060
