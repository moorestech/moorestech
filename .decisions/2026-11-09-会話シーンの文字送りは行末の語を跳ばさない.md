# 会話シーンの文字送りは行末の語を跳ばさない

決定: UITK の会話シーン（スキット）のタイプライタは、全文で折り返しを決め、まだ出していない字を透明にして配置を止めたまま字を出す。打ち出し途中に行末の語が次の行へ跳ばない。
棄却案: Web と同じく出した分だけを切り出して描き、打ち出し途中に行末の語を跳ばせる。
理由: 全文が出た後の見た目は同じで、途中の跳びは Web の実装（切り出し描画）の副作用にすぎない。
出所: ユーザー 2026-11-09「ok」（指揮の問い「跳ばない（推奨）か Web に合わせて跳ばせるか」への回答）
