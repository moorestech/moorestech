# Tier9 統合で未実装 3 ブロックの解放取り消しをやめ、コスト 0 で完了済みの Tier9 研究をリセットする

決定: S1 の UnimplementedBlockUnlockRevoker（宇宙エレベーター拠点・ロケット発射台・核融合炉の保存済み解放を戻す処理）は統合で外す。代わりに、旧マスタでコスト 0 のまま完了できた Tier9 研究（フィルター分岐器・機械オーバークロック・金属超精密加工・核融合炉・反物質爆弾・軌道エレベーターの建設）の完了を、旧セーブから外す。そのノードが解放していたものも取り消す。手段（セーブ移行の部品で外すか、ノードの GUID を新しく振り直して MissingMasterPruner に落とさせるか）は実装時に決める。
棄却案: 取り消し処理を残す（ロード時に完了済み研究の ClearedActions が再実行されるので効かない。研究が unlockBlock を持ち直せば無意味になり、「未実装」という誤ったコメントも残る）。完了状態をそのまま残す（コストを入れた後も完了のままで、Tier9 を素通りできる）。
理由: WorldSaveDataRestorer は保存済みの解放を戻したあと、LoadResearchData で完了済み研究の解放をやり直す（S1 ブランチ WorldSaveDataRestorer.cs:103→:124、ResearchDataStore.cs:139-157）。旧セーブの効果を消すには、研究の完了そのものを外すしかない。
