# UITK 段階1 の画面（ポーズ・設定・バグ報告・トースト）は Web 版と同じ見た目にする

決定: ポーズ・設定・バグ報告・トーストの UITK 版は、Web 版（参照キャプチャ `moorestech_logs/uitk/reference-captures/web-a9d5123537/1-*.png`）と同じ見た目にする。具体的には、枠を GamePanel の様式（題の横線・下端の三角・半透明）から Web の枠（不透明に近い暗色・角丸 12px・大きい太字の題・節見出し）に戻し、トーストも Mantine Notification の見た目（暗色の角丸の小窓・丸い色帯）に合わせる。同じにするために影響の小さくない非本質的な対応が要る箇所だけは、無理にそろえず推奨案のままでよい。ポーズのボタンに操作音は付けない。
棄却案: 移すときに ref-webui-design の語彙で 4 画面を様式化する（[[2026-10-26-素の見た目の4画面はUITKへ移すときに様式化する]]。このうちトースト・ポーズのボタンについての部分を覆す）／GamePanel の様式のままにする（screens レーンの D-17・D-27）
理由: ユーザーは移行で見た目を変えたくない。
出所: ユーザー 2026-11-06 08:53「1 不要 2 どういう事？私はWeb版と同じ見た目にしたい。なるならそれで、ならないなら同じにして。のこりもその理屈で考えて。ただ、無理に同じにする必要はない、影響が小さく非本質的な対応が入るのであれば、推奨でも良い」（screens レーンの要裁定 7 件への回答）
