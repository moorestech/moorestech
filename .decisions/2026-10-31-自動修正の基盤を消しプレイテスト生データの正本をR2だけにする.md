# 自動修正の基盤を消し、プレイテスト生データの正本を R2 だけにする

決定: バグ報告の自動修正の基盤（bug-report-auto-fix スキル・inbox poller・prepare-run・enqueue-autofix・無人ゲートの bugfix 分岐・logs repo の harness/bug-report/）を丸ごと消す。プレイテストの生データの正本は R2（moorestech-playtest）だけにし、Mac mini には全件をコピーせず見るときに 1 件ずつ取る。logs repo には報告を読むための小物（manifest.json・READY・ingest.json・screenshot.png・logs/・repo の小さな diff/txt/json 等）だけを入れる。R2 の生データは報告が片付いて（修正のマージか却下）から 7 日で、こちらから消す。ダッシュボードの動画表示・1 件の生データを取る手段・日次ダイジェストは残し、ダイジェストの自動修正ランの draft PR 一覧は消す。「片付いた」の判定の仕組みは未決（PR #1566 で案を 1 つ挙げてユーザー判断に回す）。
棄却案: 手元の生データ置き場（MOORESTECH_PLAYTEST_RAW）に取り込みから 60 日の期限つきで全件を置く（PR #1566 の初版）。
理由: ユーザー裁定 2026-10-31。自動修正は一度も動いていない（runs/ は空、報告 421 件に AUTOFIX_* の目印なし、手での投入の実績もなし）。R2 には全件が残っており、手元の複製は容量と git 履歴を太らせるだけ。
