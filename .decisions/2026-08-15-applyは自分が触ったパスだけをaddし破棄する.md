# applyは自分が触ったパスだけをaddし破棄する

決定: pr-adjudicated-apply の commit は「Step 4 で編集したパス＋Step 3 で持ち越すと決めたパス」のみをパス指定で `git add` する（`git add -A` / `git commit -a` 禁止）。失敗時の後片付けも `git reset --hard` をやめ、同じパス集合を `git checkout --` で個別破棄する

棄却案: commit直前にdirty判定をもう一度回してから全体add／気にせず全体add／失敗時はreset --hardのまま

理由: apply実行中もUnityがdirtyを作り続ける（Step 5 の uloop compile で `_CompileRequester.cs`、ピンファイルは5〜30秒毎）。触ったパスだけを対象にすれば、実行中に何が汚れてもcommitに混入せず、持ち越した他人の変更も失われない
