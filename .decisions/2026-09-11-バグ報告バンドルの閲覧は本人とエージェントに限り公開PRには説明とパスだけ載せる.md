# バグ報告バンドルの閲覧は本人とエージェントに限り公開PRには説明とパスだけ載せる

決定: バンドル（動画・スナップショット・ログ）はprivateのmoorestech_logs側に置き、本人とエージェントだけが閲覧する。公開repoのdraft PRには再現手順の説明とmoorestech_logs内のパスだけを書き、動画やスナップショットは添付しない。修正後のプレイ録画も同じ扱い。

棄却案:
- 修正後の録画だけは公開PRに添付 → エージェントの録画にバンドル由来のワールドが写るため棄却
- 報告ごとに公開可否を選ぶ → 報告UIとエージェント側の分岐が増えるため棄却

理由: ユーザー裁定 2026-09-11（Codex残問Q11）。
