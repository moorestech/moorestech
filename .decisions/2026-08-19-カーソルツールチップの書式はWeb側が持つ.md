# カーソルツールチップの書式はWeb側が持つ（wireのfontSizeを撤去）

- **決定**: topic `ui.tooltip` と `TooltipPresentation` から `fontSize` を撤去し、書式はWeb UIのCSSトークン（フォント18px・padding 6/10px・max-width 320px）が唯一の正。uGUI側のfontSizeオーバーロード・`DefaultFontSize`・廃止済みターゲットのSerializeFieldも削除する。
- **棄却案**:
  - Unity側 `DefaultFontSize` を 36→18 → uGUI単位をCSS pxとして運ぶ構造が残り再発する。
  - Web側で受信値を0.5倍 → 値源の二重化でフォールバック補正になる。
- **理由**: 36pxの正体はuGUI TMPのフォントサイズで、CSS pxとして解釈されていた。可変経路は既にゼロ（uGUI廃止済み）なので、単位の異なる値をwireで運ぶ意味がない。
