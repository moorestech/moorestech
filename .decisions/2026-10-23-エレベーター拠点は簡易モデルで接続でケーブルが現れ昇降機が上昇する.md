# エレベーター拠点は簡易モデルで接続でケーブルが現れ昇降機が上昇する

決定: 宇宙エレベーター拠点は、土台＋空へ伸びるケーブル＋昇降機を Unity の基本図形で組んだ仮モデルで作る。接続するとケーブルが現れ、衛星を運ぶ間は昇降機がケーブルを昇っていく（進捗が見える）。本モデルは後で差し替える。核融合炉・重水素抽出装置・反物質製造装置・金属3Dプリンタは既存モデル（FusionReactor / Deuterium_extraction_equipment / Antimatter_manufacturing_equipment / 3D Printer）を使う（agent前提: 既存アセットと旧 mod_3/mod_4 の定義に一致）。
棄却案: (B) 土台＋ケーブルの仮モデルだけで昇降の進みは UI の数字・バーのみ、(C) クリーンルーム系と同じ仮の箱（TmpBlock）で UI だけ。
理由: 打ち上げの手応えを S2 の発射台（ロケット本体の上昇）と揃える。
明示引用: 質問「宇宙エレベーター拠点の見た目はどうしますか？」→ 選択「簡易モデル＋昇降機の上昇 (Recommended)」
