# 研究説明文は上流 PR #30 の文言を正とし、plan の M3 表を破棄する

日付: 2026-08-22 / 文脈: ADR 0029 実装 Task M3 着手時に発見した上流既変更

## 決定

- マスタrepo `origin/master`(7eb8de7) の PR #30「研究ノード47件のプレースホルダ説明文を1行の説明へ置換」で
  `research.json` の47ノード全てが既に日本語1行説明になっている。この文言を正とする。
- plan の Task M3（別文言の表で全件上書き）は**実行しない**。
- Task M4 では `localization.csv` の `research.<guid>.description` 47行（全て `New Research Description` のまま未追従）を、
  上流 `research.json` の日本語＋その英訳で埋める。

## 棄却した案

- plan Task M3 の表で `research.json` を全件上書きする案（上流PR #30 の文言を全廃棄することになる）。
- 47ノードを1件ずつ突き合わせて良い方を採る案（作業量に見合わない）。

## 理由

- R7 の受け入れ基準「research.json と localization.csv のどこにも "New Research Description" が残らない」は
  上流文言＋csv追従で満たされる。マージ済みPRとの無意味な文言衝突を避ける。
