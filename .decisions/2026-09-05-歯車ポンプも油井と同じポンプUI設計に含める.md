# 歯車ポンプも油井と同じポンプUI設計に含める

日付: 2026-09-05
決定: 歯車ポンプ（GearPump）も油井と同じポンプ共通セクション（内部タンク・生成速度・鉱脈警告）を持ち、動力行だけ電気なら電力充足率＋稼働状態ラベル、歯車なら既存 GearSection に差し替える。マスタの blockUIAddressablesPath は両方埋め、設置の流体鉱脈上限定も両方に適用する。歯車採掘機と電気採掘機の関係と同型。
出所: ユーザー裁定 2026-09-05 選択「含める（電力行を歯車行に差し替え）」
棄却案:
- 油井だけUI化し歯車ポンプはUIなしのまま（設置は鉱脈上限定になるのに開けない非対称が残る）
