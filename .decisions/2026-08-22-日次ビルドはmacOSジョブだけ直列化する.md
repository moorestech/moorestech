# 日次ビルドはmacOSジョブだけ直列化する

- 日付: 2026-08-22
- 決定: `build.yml` の `server-build` / `client-build` に job 単位の `concurrency` を置き、`macos-latest` のジョブだけ同一グループ (`unity-license-mac-<run_id>`) に入れて直列化する。Windows は並列のまま。
- 棄却案: (a) 4並列のまま維持し、マージ後に `workflow_dispatch` で1回実測して証跡をADRへ追記する。(b) mac ジョブと `cache-warm` に共有 concurrency group を張る（GitHub は実行中1本＋待機1本しか保持せず3本目以降を捨てるため matrix に不向き）。
- 理由: 削除した `max-parallel: 1` は時間短縮のための行ではなく、`55b9aa971`（macOSのライセンス競合）と `90a2d5f8e`（並列時のテスト落ち）という実際に落ちた事象への対処だった。実測なしで4並列に踏み切ると、コード起因でない失敗Issueが立ち無人修復が一晩空費する。
- 代償: 日次の壁時計時間は約57分から約71分へ（Win並列51分とMac直列71分のmax）。
- 関連: ADR 0028 / moores-code-review 2026-08-22-1742 の C-9
