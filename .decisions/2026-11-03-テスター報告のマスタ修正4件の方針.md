# テスター報告のマスタ修正4件の方針（採掘機・油井・石窯の電線・ふいご付き精錬炉）

決定:
- 鉄の採掘機・電気採掘機の mineSettings に青銅の鉱石と粘土を足す。採掘時間は各機種の既存の段階に合わせる。原始的な採掘機の鉄鉱石の重複登録は消す
- 油井の outflowConnects の offset を [1,1,9] から [1,1,8] に直す（向き [0,0,1] はそのまま）
- 石窯・ボイラーに電線がつながらないよう maxWireConnectionCount を 0 にする（最小案）。燃料機械用の blockType を分ける根本案は採らない
- ふいご付き精錬炉の青銅インゴットのレシピは「2個/3秒」にし、入力も出力に比例させる。同じ炉の他のレシピに石窯との逆転があっても、この件では直さず報告に留める
棄却案: 石窯・ボイラーの blockType を燃料機械用に分ける根本案（この PR では扱わない）
理由: いずれもテスター報告の不具合・逆転を、マスタの数値修正で最小に直すため
出所: ユーザー裁定 2026-11-03。対応方針 HTML（https://sakastudiomac-mini.tail3a5aa5.ts.net:8443/2026-11-03-moorestech-quick-fixes-2026-11-03/）の各件の「方針」を全件「この方針で OK」と承認。精錬炉の値は「2個/3秒で裁定済み（入力は出力に比例させる）」
