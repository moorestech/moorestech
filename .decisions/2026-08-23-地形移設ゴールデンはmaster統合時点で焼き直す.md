# 地形移設ゴールデンは master 統合時点で焼き直す

- 日付: 2026-08-23（PR #1232 の master コンフリクト解消時のユーザー裁定）
- 決定: `terrain_visual_golden.json` を master マージ後の出力で焼き直し、以後は「移設の無変化証明」ではなく「現在の見た目を固定する回帰ガード」として扱う
- 棄却案: (a) 落ちたまま残して PR 作者の判断へ回す (b) 焼き直す前にゴールデン fixture の岩座標をマージ前後で数値比較し、差分が配置移動のみだと実測してから決める
- 理由: master の PR #1224 が散布アルゴリズムを density → bands（`placementMode`/`placementParam` 共用体）へ変えたため岩の位置が動き、旧ハッシュはもうどの実装でも再現できない。移設前実装（client 側 `TerrainTileVisualProvider` 等）は本 PR で削除済みで、比較対象が存在しない。焼き直し後の差分は heights 4件が完全一致・alphamap/detail 8件のみ変化で、原因が配置移動でありテクスチャ規則の退行でないことは実測で確定した（棄却案(b)の確認内容は結果的に満たされている）
