# UITK 段階 0 の PR は 1 本に統合する

決定: UITK 移行の段階 0 は、各レーンのブランチを統合ブランチ `feature/uitk-stage0` へマージコミットで取り込み、master へ向けた PR を 1 本だけ立てる。先に出ていた PR（#1555・#1556・#1557・#1558）は統合 PR へ寄せて閉じる。以後のレーン（状態の移設・DSL・撤去と差し込みの統一）は PR を作らず、ブランチを push して統合ブランチへ取り込む。独立レビューは統合 PR に 1 回だけ行う。
棄却案: レーンごとに PR を出し、そろった順にマージする（移行計画の段階 0 の想定。マージと独立レビューがレーンの数だけ要る）。
理由: ユーザー裁定。帰結: 統合 PR は大きくなり、どれか 1 レーンの遅れが段階 0 全体のマージを止める。
出所: ユーザー 2026-10-26「3 PRは1本に統合したい」（指揮セッションが示した段階 0 の残り作業の一覧への回答）
