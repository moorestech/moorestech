# UITK 移行は長命ブランチで作り、全部そろってから一気に切り替える

決定: UITK の画面は束ごとに切り替えない。作りかけの UITK のコードは専用の長命ブランチに隔離し、master は完成まで Web だけのままにする。全部そろったら一気に UITK へ切り替える。master と配布物で、画面ごとに UITK と Web が混ざる状態は作らない。デバッグでどちらかの表示に切り替えられる程度の混在はよい。切替の日まで Web の新しい画面・機能の追加は止めず、UITK 側が Web の変更を追いかけて同じものを作る。
棄却案: 束ごとに master で暗転のまま作り、所有表の 1 行で切り替えて毎週出す（[[2026-10-26-UITK移行は束ごとに暗転で作り所有表の切り替えで毎週出す]]。これを覆す）／作りかけの UITK を master に入れ、全体スイッチで切り替える／切替の日まで Web の新機能を凍結する
理由: 束ごとの切替では約 3〜4 か月、コードを読み書きするたびにどの画面が CEF でどれが UITK かを意識し続けることになり、テスターの画面にも両方が混ざる。
帰結: 段階 1 の「CEF が死んでも Esc でセーブ・報告できる」は、切替の日までテスターに届かない。
