決定: Task 16 のレビューで見つかった実害3件を、いずれも本 PR の範囲内で修正する。(1) 岩の裸地テクスチャの合計が1を超える塗り方に対しキャッシュ書き込み側が1で頭打ちするため、初回生成時とキャッシュ読み込み時で色配分が変わる非冪等。(2) 木・鉱脈の最小距離を守る近傍グリッドがタイル内で完結しており、タイル境界の帯だけ最小距離が破られる。(3) mapObject の rotation が転送されず、生成された岩が全て同じ向きで斜面に対して直立する。

棄却案: 3件とも bd へ送り、本 PR は5x5化と移植復元に絞る案。

理由: (1) は移植元由来の「合計>1」自体は裁定済みでも、**キャッシュ往復の非冪等はこの PR で新規に入った縫い目**であり、リロードで見た目が変わるのはユーザーに見える退行。(2) は Task 15 の実生成マップで境界を挟む木が 0.710m の距離にあることを実測済みで、設定値 2m を大きく下回っている。木の高さ摂動や surround テクスチャは halo 切り出しで隣タイルを拾う設計に揃えたのに、配置そのものだけ halo が無いという非対称でもある。(3) は移植元が rotation と scale を必ず対で適用しているのに片側だけ復元した状態で、サーバーは斜面法線から rotation を既に計算しているのに捨てている＝新たな移植漏れ。いずれも「移植漏れは全て実装復元する」の射程内。
