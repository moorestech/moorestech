# ベルト経路は探索箱を持たず、重み付き探索で上限なしに引き、C キーは廃止する

決定: 2クリック設置の探索から X64×Z64 の箱と高さ上限を無くす。触ったセルだけをその場で調べる（地形は列ごとに初回だけ測る）重み付き A*（f = g + 2h）にし、開けた場所では最短、障害物の周りは遠回りを許す。経路なしは探索量の上限（20,000 展開）だけで決め、理由行は「経路が見つかりません」の1つに畳む（地形／既存ブロックの区別と塗りつぶし判定は廃止）。同コスト候補を送る C キーと `BeltRouteStepPriority` は廃止する。
棄却案: (1) 探索箱をカーソル追従で動かし上限を建築射程 100 にする（最短は保てるが遠い経路なしで重く、地形計測の引っかかりが残る。提示して「ダメです」）。(2) 経路なしの理由を地形／ブロックの区別つきで上限付きに残す（提示、「1 ok」で畳む側を採択）。(3) C キーを軸の優先順として残す（提示、「Cキー一旦撤廃で」）。
理由: ユーザー裁定 2026-11-09 原文「これが終わったら「64x64」のサイズ制限と高さのサイズ制限も撤廃したいという要望があります」「ダメです。最短じゃなくていいので障害物よけてy方向も無限でできるように横方向も、なんかかんがえられない」「1 ok 2ok Cキー一旦撤廃で」。箱を大きくするだけでは面積に比例して遅くなる（64×64・高さ24の経路なしで約105 ms の実測）。
