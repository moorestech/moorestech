# スキル3重ミラーを廃止しgit管理は1箇所に絞る

決定: `.agents/.claude/.codex` のskills 3重ミラーのgit管理をやめ、実体1箇所のみをtrackする。ミラーはgitから蹴り（gitignore+ローカルsymlink）、CIのsync-skills.ymlは廃止。追記ログ（eval/log.md等）は1ラン1ファイル化し、実行記録はmoorestech_logs/bdへ移してよい。
棄却案: (a) 3ディレクトリをtrackしたままsymlink化してCI syncを止める案 (b) merge=unionで衝突を自動解消する案（tracked 3重ミラー維持）
理由: ミラーが全コンフリクトを3倍化し、auto-merge付きsync PRがmaster側の変動源にもなっていた。track自体をやめれば衝突クラスが消える。eval/log.mdは2週間で全ブランチ横断53コミットの高頻度衝突源。
