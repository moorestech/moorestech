# ドイツ語は全訳し Codex 監査で相互チェックする

日付: 2026-08-25

## 決定
595行すべてを英語列を原文として Claude が全訳し、codex-audit でドイツ語ネイティブ視点のレビューを1周かけてから確定する。スキット本文47行も訳す。人称は Sie（敬称）+ Prinzessin。割れた箇所は Claude が裁定し、判断がつかないものだけ列挙して提示する。UIレイアウト崩れの事前検証はしない。

## 棄却案
- 暫定品質としてそのまま出す（監査なし）
- UI文言のみ訳し、スキット本文は空欄で英語へ fallback
- 列と設定行だけ用意して訳文は入れない
- du（親称）を使う / UIは du・スキットは Sie
- 監査の指摘を全部取り込む / 割れた箇所を全件ユーザー裁定へ
- プレイ録画テストで主要画面を独語で通す / 文字数上限を機械チェックして長い訳は短縮する

## 理由
翻訳品質は外部監査で担保しつつ、好みの問題まで往復させない。レイアウト崩れは実害が出てから直す方が安い。
