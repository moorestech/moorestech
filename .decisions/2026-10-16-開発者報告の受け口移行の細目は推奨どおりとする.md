# 開発者報告の受け口移行の細目は推奨どおりとする

- 日付: 2026-10-16
- 過去引用: 原文「それで」。指示対象となる提示一覧の逐語原文は保全されていない。
- 現在の採用根拠: `.decisions/2026-10-16-開発者報告の実装planを共通制約として無人実行する.md`。planの明示採用を根拠とし、過去原文の復元とは扱わない。
- 決定:
  1. 報告の確保時に Editor が未pushコミットの git bundle（moorestech と moorestech_master）を作って箱へ入れ、受け口（R2）経由で送る 当時の提示原文は保全されておらず、引用「それで」単独の含意検査は不能。
  2. 受け口への移行と同じ流れで、列車同期の停滞診断の同梱・Unity不要のトリアージスクリプト・報告の所在一覧も作る 当時の提示原文は保全されておらず、引用「それで」単独の含意検査は不能。
  3. 開発者報告の送り先は本番の受け口（playtest.moores.tech）。staging は使わない 当時の提示原文は保全されておらず、引用「それで」単独の含意検査は不能。
  4. 開発者トークンで送るのはバグ報告と感想だけ。進行記録は送らない 当時の提示原文は保全されておらず、引用「それで」単独の含意検査は不能。
  5. 各開発機に溜まった未送信の箱は、トークン設定後の起動で新経路がそのまま送る 当時の提示原文は保全されておらず、引用「それで」単独の含意検査は不能。
  6. 配布版は開発者が遊んでも Steam 認証。開発者トークンは Editor と開発ビルドだけで使う 当時の提示原文は保全されておらず、引用「それで」単独の含意検査は不能。
  7. 所在一覧は受け口と Mac mini だけを見る。送れない機材はゲーム内に「ローカル保存のみ」を出して気づかせる 当時の提示原文は保全されておらず、引用「それで」単独の含意検査は不能。
- 棄却案: 未pushコミットを送らない（push前の作業中のバグが再現できない）
