# ドラッグ軸はセッションの所有者（CommonBlockPlaceDragState）に持たせる

決定: ベルト設置のドラッグ軸（X先行かZ先行か）を `CommonBlockPlaceDragState` へ移し、セッションの生成/破棄と同じ寿命に縛る。`ResetRunAxis` という呼び出し元の対呼び規約自体を消す。併せて「Build を2回呼び、起点セルへ戻したら軸が引き直される」テストを追加する。

棄却案: `BeltConveyorPlaceRunBuilder.Build` にドラッグ状態を渡し、軸の寿命をビルダー内に閉じる。呼び出し元からリセット責務は消えるが、ビルダーがドラッグ状態を知ることになる。

棄却案: 対呼び規約のまま Enable / Disable / TryCancelInProgressOperation / PlaceBlock の4地点すべてでリセットを対にする。変更は最小だが、今後の追加地点で再び漏れる構造が残る。

理由: ドラッグ寿命の状態が2オブジェクトに分裂し、リセットの対呼びが4地点中2地点で漏れていた。現在は経路組み立て冒頭の自己回復で実害が出ていないが、ドラッグ起点セルの解決方法が変わった瞬間に「前回のL字の曲がり方向が次回へ持ち越される」形で表面化する。既に `PlacementDragSession` が採っている「片方だけ残る状態を作れなくする」形との前例一致でもある。
