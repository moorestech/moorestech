# 開発者報告の受け口送信はMacとWindowsの両方で確かめ再生停止時は次回再生で再送する

- 日付: 2026-10-16
- 出所: ユーザー裁定 2026-10-16 質問「完成条件に Mac と Windows 両方の Editor から送信→取り込みまでの実機確認を含めるか」→ 選択「Mac・Windows両方」。質問「報告直後に Editor の再生を止めた場合、送信途中の箱をどう扱うか」→ 選択「次回再生時に再送」
- 決定: Mac と Windows の両方の Editor で、送信から Mac mini への取り込みまでを実機で確かめて完成とする。再生を止めて中断した送信は、outbox に残った箱を次の再生で再送する。バグ報告画面では送信待ちと送信完了を区別して見せる。
- 棄却案: Mac のみ検証（Windows 側の不具合に気づけない）／再生停止後も Editor 側で送り続ける（配布版と別の送信経路ができる）
