# Web UI全体で文字入力欄以外のSpace既定動作を封じる

決定: Tabと同じく、Web UI全体で文字入力欄以外ではSpaceのブラウザ既定動作（フォーカス中ボタンのクリック・スクロール）を封じる。Spaceはジャンプ専用になる。検索欄での空白入力は従来どおり。

棄却案:
- クラフトボタンだけSpaceを無視する

理由: ユーザー裁定 2026-10-01 質問「『Spaceでボタンが押されない』をどこまで広げますか？」→ 選択「Web UI全体で封じる」。
