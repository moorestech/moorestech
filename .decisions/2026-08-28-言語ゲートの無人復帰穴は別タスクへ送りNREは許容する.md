# 言語選択ゲートの無人復帰穴は別タスクへ送り、待機中のNREは許容する

出展モードの言語選択ゲート（[[2026-08-28-出展モードの言語選択はロード完了後の全画面ゲートにする]] / ADR 0040）の
コードレビューで出た Critical 2件について、2026-08-28 にユーザーが裁定した。

## 決定1: 無人ブースの自動復帰が消える穴は今回塞がず、別タスクへ送る

無操作監視の武装点を「言語ボタン押下」へ移した結果、押下前は監視オブジェクトが存在せず、
次の4経路で自動終了→再起動が働かなくなった（改修前はどの経路でも180秒で自動復帰していた）。
1. `InitializeScenePipeline.cs:145` 初期化失敗 → MainMenu へ戻る
2. `InitializeScenePipeline.cs:187` ゲート通過前の例外 → MainMenu へ戻る
3. `WebUiCefNavigator` のWS接続が約15秒で諦める（`Hub != null` なのでフォールバックに掛からない）
4. ロードのハング

棄却案:
- 起動時から監視を作り、言語選択画面が実際に出ている間だけ抑止する（`SetIdleQuitSuppressed`）— 4経路すべてを1機構で塞げる推奨案だったが、今回のスコープに入れない
- CEF接続待ちを有界で追加し、立たなければ英語フォールバックへ合流 — 経路3のみ
- 出展モードでは初期化失敗時にMainMenuへ戻さず終了する — 経路1・2のみ

理由: gamescom本番までのスコープを切り、本PRは言語ゲート本体に限定する。穴は bd へ積んで別PRで対応する。

## 決定2: 待機中の毎フレームNREとロード時間の無操作算入は許容する

ゲートの `await` を `StartGame` より前に置いているため、待機中は依存注入が未完で
`MiningController.Update()` 等が毎フレーム NullReferenceException を出す。
また選択後のロード時間が無操作時間へ算入される。

棄却案:
- `EventIdleTimer.Reset()` と `GameInitializedEvent` 購読を復活させ、初期化完了でタイマーを測り直す
- 上記に加え、待機中はMainGameシーンのオブジェクトを無効化してNREも止める

検討したが採らなかった案（レビューの推奨だが不採用）:
- `await` をチュートリアル発火直前へ移す — `SkitFireManager` は `RegisterEntryPoint` 登録で
  `PostInitialize()` が `StartGame` 内の `builder.Build()` で発火するため、その位置では
  オープニングスキットが英語で先に流れる。ADR 0040 の主要要件に反するので選択肢から除外した

理由: 既定タイムアウト180秒に対しロードは十分短く、実害はログ汚染に留まると判断した。
