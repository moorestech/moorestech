# 油井UIはタンク・電力・生成速度・鉱脈状態を表示する

日付: 2026-09-05
決定: 油井（ElectricPump）のWeb UIは、内部タンク（液種・量・容量）、ADR 0010準拠の電力充足率と稼働状態ラベル、原油の分間生成量、鉱脈に乗っていない場合の警告表示を出す（採掘機UI MinerSection と同格）。
出所: ユーザー裁定 2026-09-05 選択「タンク + 電力 + 生成速度 + 鉱脈状態」
棄却案:
- タンク + 電力のみ（鉱脈外の油井が「稼働中なのに増えない」ように見える）
- タンクのみ（並列セッションの暫定最小実装をそのまま本設計にする）
注: プレビュー内の数値・文言（3600/min、「鉱脈がありません」等）は裁定に含めない。
