# プレイテストDSLの分岐設置は終点の向きを検証して出口の取り違えを失敗にする

決定: `BranchPlaceViaUi(blockName, beltCell, useAlternateExit, exitDirection, toOrigin, endDirection)` の引数は変えず、最後の待ちに「toOrigin に置かれたブロックの向きが endDirection と一致する」を足し、一致しなければ exitDirection と useAlternateExit の取り違えだと分かる文言で失敗させる。
棄却案: (1) exitDirection 引数を削り、DSL が Ctrl+クリック前に本番の `BeltRouteBranchOrigin.Judge` を呼んで出口を導出する（引数が1本減り二重指定が消えるが、計画 D9 を覆し呼び出し4か所と docs を直す）。(2) 同じく引数を削り、DSL 側で隣の辺を集めて `BeltRouteBranchGeometry.Resolve` を直接呼ぶ（辺の収集コードが DSL に増える）。
理由: ユーザー裁定 2026-11-09 AskUserQuestion 選択「終点の向きを検証する（推奨・最小）」。moores-code-review の統合結果 C3/D1（10系統一致: 出口の向きを書き損じても DSL が成功扱いになる。docs/playtest-dsl.md の手本に実際に誤りがあった）。
