# キーヒント赤字はチュートリアルHUD限定とする（上流PR #1227 を正とする）

日付: 2026-08-22 / 文脈: ADR 0029 実装ブランチを origin/master へマージした際の重複衝突

## 決定

- キー操作ヒントの赤字化は **チュートリアル keyControl HUD のみ** に適用する。
  上流 PR #1227 (`02de2d046`) の実装 — `--tutorial-key-hint-color` を
  `features/tutorial/keyControlHint.module.css` で適用する形 — を正とする。
- 本ブランチ Task 3 (`659712569`) の `--key-hint-color` を `:where(.keyHintText)` 共有様式へ適用する実装は畳む。
- webui-design SKILL.md は上流の「§8.19 に文字色の例外を追記」を正とする
  （Task 3 が入れた「HUD専用の色例外は作らない」は撤回する）。
- ドラッグ矢印 56px / 3200ms は両者一致のため差異なし。

## 棄却した案

- plan R5 の指定どおり「チュートリアルHUD・インベントリ画面左下・研究画面左下の3箇所すべてを赤にする」案。
  本ブランチの実装はこちらだったが、ユーザー裁定で範囲を縮めた。

## 理由

- 同一目的の実装が上流に先着してマージ済みであり、重複を残す理由がない。
- 赤字が必要なのは「面無しでワールド上に浮く」チュートリアルHUDであり、
  パネル内に載るインベントリ左下・研究左下は白のままで可読性の問題がない。
