# PF別コンパイル検査も初回失敗は無条件で再実行する

- 日付: 2026-08-22
- 決定: `ci-auto-rerun.cjs` の `RERUN_ON_FIRST_FAILURE_WORKFLOWS` へ `'Platform Compile Check'` を加える。
- 棄却案: 加えない（コンパイル検査の失敗は大半が実コンパイルエラーで再実行が無駄、という判断）。
- 理由: `Platform Compile Check` はPRレーンで `Unity Build` を置換した後継であり、置換対象自身が同リストに在籍していた理由（Unityステップの失敗はログ本文なしでflakyと実バグを区別できない）がそのまま当てはまる。加えないと、失敗ステップ名 `Compile check - <target>` が CODE_KEYWORDS の 'compile' に一致するため恒久的に再実行対象外になり、人が手でRe-runするまで全PRが赤のまま残る。
- 代償: 実コンパイルエラーのときも初回1回だけ無駄に再実行する（ubuntuランナー数分×2ターゲット）。
- 関連: ADR 0028 / moores-code-review 2026-08-22-1742 の W-2
