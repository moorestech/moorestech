# 台帳のクラスタ無しは番兵でなく nullable で表す

- 日付: 2026-08-23（moores-code-review C12/D6 の裁定）
- 決定: `readonly struct PlacementCluster { int Id; Vector2 Center; }` を導入し、`LedgerPlacement.Cluster` / `TileLocalPlacement.LocalCluster` を `PlacementCluster?` にする
- 棄却案: (a) `ClusterCenter` だけ nullable にする（番兵が2綴りに増える） (b) 現状維持（`ClusterId=-1` ＋未使用 `ClusterCenter=(0,0)`）
- 理由: 上流の `PlacementEntry.Cluster` は既に `RockClusterInfo?` という正しい optional を持っており、新設2型がそれを番兵へ落としていた。判定が4箇所（生成1・スライス2・painter1）へ散っており、新しい painter が `ClusterId < 0` ガードを書き忘れると独立配置の岩が全部「ID -1 の巨大クラスタ」に束ねられ、未初期化の重心(0,0)に巨大な裸地円が焼かれる。しかも結果は `TerrainVisualCache` に書き戻され、R6 によりヒット有無がログにも戻り値にも出ないため観測できない。波及は4箇所＋テストで asm 内に閉じる
