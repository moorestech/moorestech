# 設置チャレンジのBキーヒントはGameScreenのみに出し、石窯にも同じものを付ける

風力掘削機・石窯の設置チャレンジは summary に「Bでビルドメニューを開き…」と書いてあるのに
tutorials に `keyControl` が無く、中央下のキーヒントHUDに [B] が一度も出ていなかった。
両チャレンジへ `keyControl { uiState: GameScreen, keyName: B, controlText: "ビルドメニューを開く" }` を追加する。

- **uiState は GameScreen のみ**。ビルドメニューを開いた瞬間にヒントが消え、入れ替わりで既存の
  uiDragGuide（ビルドメニュー→ホットバー）が出る流れになる。
- **文言は「ビルドメニューを開く」**（英: Open the build menu）。左下HUDの「B ビルドメニュー」および
  前例の動詞形（「研究画面を開く」「インベントリを開く」）と揃える。
- **石窯を設置するチャレンジにも同じBヒントを足す**。B初出は風力掘削機だが、石窯側も summary と
  tutorials の不一致を抱えているため両方潰す。

## 棄却案

- **GameScreen + 破壊モード(DeleteBar)** — Bは実際に DeleteObjectState からもビルドメニューへ遷移できるが、
  この時点のチュートリアル進行で破壊モードに入る動線が無く、エントリが2件に増えるだけ。棄却。
- **GameScreen + ビルドメニュー(BuildMenu)** — 開いた先でも [B]（=閉じる）を出し続ける案。
  ドラッグガイドと同時に中央下へ出るため「閉じろ」と誤読されうる。棄却。
- **「ビルドメニューから風力掘削機を選ぶ」／「ビルドメニューを開いて風力掘削機を出す」** — 直後に
  ドラッグガイドが出るため冗長。棄却。
- **今回は風力掘削機だけに足す** — 石窯側の summary/tutorials 不一致が残るため棄却。
