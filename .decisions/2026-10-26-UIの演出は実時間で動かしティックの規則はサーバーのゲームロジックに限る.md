# UI の演出は実時間で動かし、ティックの規則はサーバーのゲームロジックに限る

決定: AGENTS.md の「経過時間は GameUpdater のティック加算だけで測る」は、サーバーのゲームロジックの規則と読む。UI の演出（UiMotion のフェード・脈動など）は、UITK のパネルのスケジューラの実時間で動かす。
棄却案: UI の演出も GameUpdater のティックで動かす（ポーズ中にポーズ画面の演出まで止まる）
理由: ポーズ中もポーズ画面の演出は動くべきため。
