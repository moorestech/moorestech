# uGUIホットバー行の除去は最小スコープで行う

決定: InventoryItems.prefab の `Hotbar` GameObject 削除と `PlayerInventoryMainSlotsView.hotBarSlotViews` の除去だけを行う。

棄却案:
- 中スコープ（`CommonSlotView.hotBarSelect` / `SetHotBarSelected` / `CommonSlotViewOption.HotBarSelected` も削除）… ResearchTreeElement が充足表示に流用しており、その置き換えが要るため今回は見送り
- 大スコープ（uGUIインベントリ系ごと廃止 = ugui-retirement-plan の Phase2 相当）… Web UI ブリッジからの参照解きが前提で、今回の症状修正には過大

理由: 症状（アイテムがブロック設置ホットバーと重なって表示される）の原因は `Hotbar` が `mainInventoryObject` の兄弟でWebモードのゲート経路を持たないことだけであり、最小差分で解消できる。
