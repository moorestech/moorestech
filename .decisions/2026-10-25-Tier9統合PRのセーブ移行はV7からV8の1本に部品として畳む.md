# Tier9 統合 PR のセーブ移行は V7→V8 の 1 本に部品として畳む

決定: S1（継承レベル・清浄室機械の液体スロット）・S2（初回打ち上げ履歴）・S3（ケーブルプール）のセーブ変換を、master の V6→V7 の後ろに 1 本の SaveMigrationStepV7ToV8 として置き、中身は機能ごとの部品クラスに分ける。CurrentVersion は 8。S1 の V8→V9 と S2/S3 の V6→V7・V7→V8 は統合で畳んで消す。
棄却案: S1 の 2 本の後ろに S2 を V9→V10、S3 を V10→V11 として連ねる 3 本立て（CurrentVersion=11）。機能ごとに変換を追いやすいが、版 8〜11 はどれも未出荷で、統合 PR 1 本で版を 4 つ上げることになる。
理由: AGENTS.md の「セーブ形式を変える PR は版を 1 つ上げ、ステップを 1 本足す」に統合 PR がそのまま合う。テスターのセーブは master の版 7 しか存在しない。機能ごとの追跡は部品クラスとそのテストで保てる。
