# 液体UIは開いたままRefresh更新をunityプレイ録画テストで検証する

## 決定
Task 3.5としてプレイテストDSLの1シナリオで、タンクをクリックで開く→液体PFを開く→ドッキングした液体貨車をFで開いたまま積込による量更新→閉画面を録画して検証する。result.jsonと録画パスを報告する。

## 棄却案
スクショと単体テストだけで完了する。

## ユーザー指定の根拠
「追加指示: planに Task 3.5「unityプレイ録画テスト」を足して実施してください（unity-playmode-recorded-playtest スキル、プレイテストDSLで1シナリオ）。シナリオ: 液体タンクに水を入れてクリックで開く→液体PFに水を入れて開く→液体貨車をドッキングさせ、Fで貨車画面を開いたまま積み込みを進めて量が変わることを確認→画面を閉じる。result.json と録画パスを報告に書く。」

## 理由
