# german.json は english 複写で locale と name だけ独語にする

日付: 2026-08-25

## 決定
ドイツ語追加で必須になる `Skit/i18n/german.json` は `english.json` を複写し、`locale` を `de`・`name` を `Deutsch` にするだけとする。translations は英語のまま。

## 棄却案
- スキットエディタ文言152件もドイツ語へ全訳する
- この機会に english.json の穴埋め（日本語残存2件・欠落71件・キー食い違い1件 / moorestech-9ls3）も一緒にやる

## 理由
`SkitLocalizationDynamicLoadContractTest` が LanguageCatalog と Addressable エントリの完全一致を要求するため german.json 自体は必須。ただし中身はスキットエディタ専用でプレイヤー非露出であり、独語化しなくても実害がない。
