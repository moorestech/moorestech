# 脈動下のe2e計測は尺でなく位相を止める

決定日: 2026-08-28（PR #1288 のレビュー裁定）

## 決定

脈動する要素（ハイライト枠・画面外矢印）の矩形をe2eで実測する箇所は、
`e2e/support/pulseFreeze.ts` の `freezeAttentionPulse(page)` で
**誘導表示の脈動だけを `currentTime = 0` で pause** してから測る。

適用先4口: `tutorialHighlightClip.spec.ts`（計測ヘルパ内）・`portalLayerScaling.spec.ts`（ラベル付着検査）・
`e2e/capture-world-pin-arrow.ts`・`e2e/captures/portal-scaling.ts`（視覚QAのスクショ採取）。

## 棄却した案

- **スイート先頭で `* { animation: none !important }`**: webui-design §6「アニメーションを足す場合、
  テスト時に尺をゼロへ落とす抜け道は作らない（実挙動と乖離するため）」と正面から衝突する。
- **許容値を 1.5px → 3.0px へ緩和**: 脈動のピーク（片側2.2px）は飲めるが、
  この検査が本来見張っている clip-path の 1〜2px のずれも同時に見逃すようになり、検出力が落ちる。

## 理由

尺を殺すと実挙動と乖離する（§6の明文）。位相だけ静止側（scale=1）へ固定すれば、
アニメーションは本番と同じ諸元で定義されたまま、計測だけが決定論になる。
