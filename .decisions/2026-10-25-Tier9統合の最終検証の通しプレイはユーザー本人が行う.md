# Tier9 統合の最終検証で、通しプレイはユーザー本人が行う

決定: Tier9 統合 PR をマージする前の最終検証は、次の 4 段で行う。(1) 自動ゲート G1〜G6 と CI、(2) 出荷マスタでの録画 7 段、(3) 目的だけを渡した別の評価役 2 体による判定、(4) MacBook Pro の Unity Editor で PR ブランチを開き、手元の world_1 をそのまま開いて、ユーザー本人が Tier8 終盤から最終研究まで裏口なしで遊ぶ（配布ビルドは焼かない）。(1)〜(3) を全部通してから (4) に渡す。
棄却案: playtest ブランチでテスターに配って通しプレイしてもらう。
理由: 実時間での手触り・配置・搬送の詰まり・待ち時間は、自動の検査や段に分けた録画では捕まらない。
