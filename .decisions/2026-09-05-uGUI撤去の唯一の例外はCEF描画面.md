# uGUI撤去の唯一の例外はCEF描画面

- 日付: 2026-09-05
- 決定: 外部パッケージ cef-unity の RawImage とそれを載せる MainGameUI.prefab の Canvas（CanvasScaler含む）だけは残す。これに伴い `com.unity.ugui`（TMP同梱）は manifest に残る。「完全撤去」の定義は「本repoのコード・prefab・シーンから UnityEngine.UI / TMPro / EventSystems への参照をゼロにし、Canvas は CEF 用1枚のみ」に修正。
- 棄却案（提示したもの）:
  - cef-unity 上流に uGUI 非依存の描画経路を追加して PR → 例外扱いで不要
  - moorestech 側で CEF 表示コンポーネントを自前実装 → 同上
  - cef-unity をフォークしてベンダリング → 同上
- 理由: ユーザー裁定 2026-09-05 原文「それだけは例外」→ 復唱確認「合っている」
