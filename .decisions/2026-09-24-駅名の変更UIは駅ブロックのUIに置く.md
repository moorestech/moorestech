# 駅名の変更UIは駅ブロックのUIに置く

- **日付**: 2026-09-24
- **文脈**: 駅名は `TrainStationComponent.StationName` として保存されるが設定手段が無く全駅 "test"。時刻表UIで駅を区別するため改名手段を新設する。

## 決定

蒸気機関車駅ブロックをFで開いた既存画面に名前欄を足す。時刻表タブ側は駅名を表示するだけ。貨物・液体プラットフォームには出さない。

出所: ユーザー裁定 2026-09-24 選択「駅ブロックの UI に名前欄 (Recommended)」

## 棄却案

- **時刻表タブからも改名できる**: 列車の画面からブロックのプロトコルを叩く導線が増える。
