# 石器の装備誘導は木を伐採チャレンジのtutorialsに付ける

決定: 「石器を装備する」を独立チャレンジにせず、既存「木を伐採して原木を入手する」の tutorials に Tab提示（keyControl）＋インベントリのアイテム→装備スロットの uiDragGuide を付ける。新しい taskCompletionType（equipItem）は追加しない。

棄却案:
- 独立チャレンジ「石器を装備する」＋新完了種別 equipItem{itemGuid}（サーバーの装備スロット更新イベント購読。装備した瞬間に達成が出るが、チャレンジと完了種別が1件ずつ増える）

理由: ユーザー裁定 2026-08-20「木を伐採の tutorials に付ける（チャレンジ追加なし）」。
