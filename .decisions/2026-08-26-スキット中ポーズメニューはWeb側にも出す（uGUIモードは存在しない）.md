# スキット中ポーズメニューはWeb側にも出す（uGUIモードは存在しない）

- 日付: 2026-08-26
- 決定: スキット中のポーズメニューは列車HUD(trainPause)同型でWeb UIに表示する。C#側はSkitPlayingSubStateのwebガードを撤去し、SkitStateがSubStateを公開、UiStateTopicがStory中もsubStateを配信、UiStateActionsはStory中のGameScreen要求を入れ子のみ閉じる。Web側はuiScreenRoutingにskitPauseを足しPauseMenuPanelを描画する。スキット再生はメニュー中も背後で継続（2026-08-26裁定維持）
- 背景: 2026-08-26の裁定「uGUIモードのみ」は `WebUiScreenGate.IsWebUiMode` が恒久trueである事実（uGUI廃止Phase1・docs/webui/ugui-retirement-plan.md）を見落とした質問設計だった。uGUIモードは存在しないため、その裁定どおりの実装は永久に発火しない
- 棄却案:
  - C#側だけ直してWeb対応は別タスクへ — 画面が出ないので依頼「スキット画面でもメニュー画面出すようにしたい」を満たさない
  - 中断してADRを書き直してから再開 — 設計は列車HUD同型で確定しており書き直しは本ファイルとADR追記で足りる
- 出所: ユーザー裁定 2026-08-26 質問「どう進めますか？」→ 選択「Web側にも出す（列車HUD同型）」
