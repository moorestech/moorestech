# UITK 一気切替の日に CEF と Web を同時に撤去する。長命ブランチは改名し PR #1589 は閉じる

決定: 切替の日に、全画面の UITK への切替と、CEF・Web ホスト・moorestech_web の撤去を続けて入れる。切替後に Web へ戻すデバッグ切替は残さない。長命ブランチは feature/uitk-stage1 から改名する（名前 feature/uitk は agent 前提）。PR #1589 は閉じ、切替の日に新しい PR を作る。

帰結: 切替の後に不具合が出たら、切替前のビルドへ戻すしかない。
