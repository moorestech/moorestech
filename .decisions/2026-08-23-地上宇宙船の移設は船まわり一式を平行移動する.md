# 地上宇宙船の移設は船まわり一式を平行移動する

## 決定
オープニングスキットの地上の宇宙船（`controlSkitBackground` の `100_start_2_SpaceShip_Interior`）が木と重なるため、
絶対座標 `(496.040009, 14.8022909, 475.811005)` → `(494.329987, 15.4799995, 484.440002)` へ移す（イベント仮対応）。

- 平行移動量 Δ = `(-1.710013, +0.6777087, +8.629002)`。JSONはスポーン基準の相対座標（ADR 0029）なので相対値へ同量を加算する
- 移動対象は「船まわり一式」= 内装セット(74)・キャラ配置(83/84/46/47)・船を映すカメラ全て(114,97,99,100,101,102,117,118 と 122以降すべて)
- 据え置き = 遠方に置いた惑星セット(55)・退避中のchr_003(68)・惑星カット用の下方ショットカメラ(95,98)。これらは船ではなく惑星セットに紐づく
- 船出後に実地形へ接地するキャラ(46/47)のYもΔを一律適用する（移動先の地形が約0.68m高い前提。浮き/めり込みは実走で微調整）

## 棄却した案
- **惑星カットのカメラ(95,98)も含めて全部移動**: 惑星セットを据え置くため、動かすと惑星の構図がずれる
- **内装セット(74)だけ移動**: カメラ・キャラが据え置きになり船が画角内でずれる

## 理由
イベントが近く、[[2026-08-22-スキット座標はスポーン基準の相対座標へ相対化する]] の相対化は済んでいるので、
相対値の平行移動だけで木との干渉を回避できる。移動先座標はユーザーがEditorで実測した値。
