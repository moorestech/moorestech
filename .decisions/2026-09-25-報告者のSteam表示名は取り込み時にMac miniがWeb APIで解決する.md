# 報告者のSteam表示名は取り込み時にMac miniがWeb APIで解決する

日付: 2026-09-25
出所: ユーザー裁定 原文「FBやバグ報告時、steamユーザー名などをとれるようにして追跡出るようにしておきたい」→ 質問「『誰の報告か』を、どこでSteamユーザー名に結びつけますか？」→ 選択「A：取り込み時にMac miniがSteam Web APIで名前を引く」
追加裁定: 対象は進行記録も含める（選択「A：進行記録にも付ける」）／保存は取り込み時点の名前とプロフィールリンクまでで現在名は引き直さない（選択「A：保存された名前とプロフィールリンクで足りる」）／別の連絡先は集めない（選択「A：集めない」）

## 決定
GetPlayerSummariesでSteamIDから表示名とプロフィールURLを引き、報告・進行記録のメタに取り込み時点の名前として保存する。日次ダイジェストは 名前（SteamID・プロフィールリンク）で出す。ゲーム本体とWorkerは名前を扱わない。

## 棄却案
- ゲームが送信時に自分の表示名を書く（本人申告）
- Workerが発行・アップロード時にWeb APIを引きR2メタに書く
- 進行記録はSteamIDのみ
- ダイジェスト生成ごとに現在名を引き直す
- 報告画面に任意の連絡先欄を足す

リンク: ADR 0070
