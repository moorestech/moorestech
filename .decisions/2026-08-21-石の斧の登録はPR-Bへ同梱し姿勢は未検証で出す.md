# 石の斧のAddressable登録はPR-Bへ同梱し、手持ち姿勢は未検証で出す

決定（ユーザー裁定 2026-08-21）:
- PR-C（石の斧の手持ちモデル登録）を独立PRにせず、PR-B のブランチ `feature/tutorial-anchor-inventory-equipment`（PR #1207）へ同梱する。
- 手持ちの見た目確認（plan Task C1 Step 3 のPlayMode確認）はこの環境で通らないため実施せず、姿勢は未検証のままPRに出す。PR本文とコミットメッセージに未検証である旨を明記する。

棄却案:
- Editorのみで見た目を詰めてから出す（Scene Viewのスクリーンショットが更新されず視認できなかった。実測boundsでの寸法合わせまでが限界）
- PR-Cを別セッションへ回す（PlayModeが通る環境待ちになり、登録作業自体が止まる）
- 姿勢が未検証のままマスタへ handGrabModel を設定する（マスタ追記は3本マージ後の別PRなので、実害が出る前に詰め直す猶予がある）

実装上の変更（planからの逸脱・agent判断）:
- ラッパーの元アセットを Sketchfab `StoneAxe.prefab` から **`StoneAxe.fbx` 直ネスト**へ変更した。前者はメッシュ参照が全てNULLで描画されないため（FBX側は3メッシュとも正常）。これは StoneTool.prefab と同じ形。
- 初期姿勢は plan の `scale 0.0025`（StoneToolからの流用）ではなく、Editor上の実メッシュboundsから算出した `scale=0.05702 / pos=(-0.2510, 0.1170, -0.0823) / rot=identity`。石器と長辺0.5744・中心が一致する。

ADR 0022 Decision 6 の「本体3PR（a/b/c）」は、b と c を1本にまとめる形へ更新される。
