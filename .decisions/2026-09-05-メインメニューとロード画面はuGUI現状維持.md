# メインメニューとロード画面はuGUI現状維持

- 日付: 2026-09-05
- 決定: MainMenuシーンとGameInitialaizerのローディング表示は今回のuGUI撤去の対象外とし、現状のuGUIのまま残す。CEF/Webホストの起動はゲーム内（InitializeScenePipeline以降）に限定し、ブート最初への前倒しはしない。UI Toolkit化は後日別途検討。
- 棄却案（提示したもの）:
  - Web UIへ移行（Webホスト起動をブート最初へ前倒し）
  - UI Toolkitで作り直す（今回は見送り、後から考える）
  - メインメニュー自体を廃止して起動直行
- 理由: ユーザー裁定 2026-09-05 原文「CEFの起動はゲーム内だけに限定したい。そもそも将来的にこのゲームは起動毎にpkillが必要になるゲームにする予定なので、ロード画面はさておきメインメニューまでCEF化するとややこしくなる。ロード画面も先にCEFの起動が立ち上がらないと画面を出せないので、ロード、メインメニューはCEF化の対象外とする。とりあえずuGUIの現状維持でOK,UI TK化はあとから考える」
- 帰結: 「本repo参照ゼロ」の定義は Client.MainMenu / Client.Starter のローディング表示 / Client.Localization の TextMeshProLocalize を除く。
