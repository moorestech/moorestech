# レベルの混ざったチップはプレイヤーが仕分け、止まった理由を機械UIに出す

決定: レベル継承の製品を作る機械（モジュール・GPU・パッケージング）の継承元スロットは、これまでどおり1レベルずつ受ける。Lv の混ざった IC チップ・ダイがベルトで届いて先頭で止まるのは、プレイヤーがフィルター分岐器でレベルごとに仕分ける前提とする。止まったときは機械の UI に「レベルの違う品が届いて止まっている」と出す（サーバーの状態と同期を足す）。
棄却案: (B) 仕分け前提を計画と録画テストに書くだけで、止まった理由は画面に出さない。(C) 機械にレベル別の入れ口を持たせ、混ざったベルトでも止まらず、数が揃ったレベルから作る。
理由: ベルトは先頭の1個しか渡さず、継承元スロットは混ぜない・格下げしない（裁定「製作上限を超えるチップは製品に入れず解放まで取っておく」）。仕分けは既存の分岐器で足りるが、理由が見えないと止まった原因が分からない。
明示引用: 質問「…Lv1 と Lv2 が混ざったベルトをつなぐと…ラインが止まったままになります。…どう扱いますか？」→ 選択「仕分け前提＋理由を表示」（シミュレーター予測→ユーザー承認 2026-10-24）
